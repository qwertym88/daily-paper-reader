## 摘要
我们提出了递归编码器和解码器（RED），用于构建一个单一的深度神经网络（DNN）模型，该模型可以分离包含未知数量说话人以及数量可变且几何排列未知的麦克风的多说话人混合语音，这是一项尚未被研究的任务。RED的解码器递归地检测是否还有活跃的说话人，并一次分离一个说话人。它被设计为以端到端的方式进行训练，以提高分离性能。RED的编码器递归地编码输入混合物的每个麦克风通道，依次整合空间线索。将两者结合，DNN可以训练来分离不仅具有未知说话人数量的混合语音，而且具有可变数量的麦克风，在多个公共数据集上实现了最先进的性能。

## Abstract
We propose $\textit{recursive encoder and decoder}$ (RED) for building a single deep neural network (DNN) model that can separate multi-speaker mixtures containing unknown numbers of speakers and variable numbers of microphones arranged in an unknown geometry, a task that has not been studied yet. The decoder of RED recursively detects whether there are active speakers left and separates one speaker at a time. It is designed to be trained in an end-to-end fashion to improve separation performance. The encoder of RED recursively encodes each microphone channel of the input mixture, sequentially incorporating spatial cues. Combining both, the DNN can be trained to separate mixtures not only with unknown numbers of speakers but also with variable numbers of microphones, achieving state-of-the-art performance on multiple public datasets.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：实际场景中，说话人数量往往未知，且录音设备可能是单个麦克风或数量、几何排布各异的麦克风阵列。现有语音分离系统通常假设固定的说话人数和麦克风配置，无法灵活应对真实世界的多变条件。
- **研究现状的缺口**：
  - **TAC**、**VarArray** 等方法支持可变麦克风数量，但假设说话人数量已知且固定。
  - **SepTDA**、**SR-CorrNet** 等方法支持未知说话人数，但假设麦克风数量和几何在训练与测试间固定。
  - **FlexIO** 支持可变麦克风数量和已知说话人数，但需要外部提供说话人数和声源类型先验。
  - **尚无统一方案**能在一个 DNN 中同时解决"未知说话人数"和"可变麦克风数量/未知几何"两个挑战。
- **研究意义**：本文首次尝试在单一 DNN 中联合解决上述两个问题，旨在构建一个通用、灵活的语音分离模型，可适应广泛的说话人数量、麦克风数量和阵列几何，具有重要的实际应用价值。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 整体架构

REDnet 由三个核心模块组成（如图 1 所示）：

- **递归编码器（Recursive Encoder, RE）**：处理可变数量的麦克风输入。
- **骨干网络（Backbone）**：基于修改的 TF-GridNet，建模频谱、时间和空间模式。
- **递归解码器（Recursive Decoder, RD）**：处理未知数量的说话人。

### 2.2 递归编码器（RE）

- **基本流程**：每个麦克风信号先经独立的 Conv2D 模块嵌入为特征表示 $\mathbf{X}_p$。随后从参考麦克风开始，逐麦克风递归处理：
  - 将当前麦克风特征 $\mathbf{X}_p$ 与之前累积的表示 $\mathbf{I}_{p-1}$ 拼接；
  - 经 shrink 层（逐点卷积）降维后送入 REBlock；
  - 经 enlarge 层恢复维度，并与 $\mathbf{I}_{p-1}$ 做残差连接，得到 $\mathbf{I}_p$。
- **设计优势**：
  - 避免了 TAC 式全局平均造成的信息压缩；
  - 避免了显式两两通道建模的二次方计算复杂度；
  - 只需当前麦克风与累积表示交互，计算复杂度与麦克风数量呈线性关系，并保留通道特有时间。

### 2.3 递归解码器（RD）

- **基本流程**：基于骨干网络输出 $\mathbf{Z}$（记为 $\mathbf{O}_1$），在每个迭代 c：
  1. **说话人检测**：通过 MLP 检测器判断是否还有活跃说话人，若无则终止；
  2. **说话人分离**：若检测到说话人，经 RDBlock 得到说话人 c 的特征 $\mathbf{U}_c$，再经 Deconv2D 估计该说话人的频谱；
  3. **门控更新**：利用 $\mathbf{U}_c$ 经过 enlarge 层得到 $\mathbf{G}_c$，通过门控机制 $\mathbf{O}_{c+1} = \mathbf{O}_c \odot (1 - \text{sigmoid}(\mathbf{G}_c))$ 更新残差表示。
- **说话人交互模块**：由于说话人是串行分离的，缺乏直接交互，论文引入 triple-path speaker interaction block（交叉说话人注意力 + 频率建模 + 时间建模），在所有说话人估计完成后对其特征进行联合建模与精化。
- **训练与推理**：
  - 训练时使用 oracle 说话人数量展开 C 次迭代；
  - 推理时通过说话人检测器的概率阈值（τ = 0.5）来自动估计说话人数量。

### 2.4 网络基本组成

- **REBlock / RDBlock / Backbone**：基于 TF-GridNet 块修改而来，含 intra-frame full-band 模块、sub-band temporal 模块和 cross-frame self-attention 模块。
- **两项修改**：
  - 将 PReLU 替换为 SiLU 激活；
  - 在模块前插入 TF-LocoFormer 的 Conv-SwiGLU，以更好地建模局部模式。

### 2.5 损失函数

总损失为四项加权和：
$\mathcal{L} = w^{RD}\mathcal{L}^{RD} + w^{RM}\mathcal{L}^{RM} + w^{TP}\mathcal{L}^{TP} + w^{BCE}\mathcal{L}^{BCE}$

- $\mathcal{L}^{RD}$：惩罚每次迭代单独分离的估计信号（SI-SNR 损失）；
- $\mathcal{L}^{RM}$：惩罚残差表示中仍包含已分离说话人信息的损失；
- $\mathcal{L}^{TP}$：惩罚说话人交互模块输出信号的 SI-SNR 损失；
- $\mathcal{L}^{BCE}$：说话人检测器的二元交叉熵，标签序列为 $[1, \ldots, 1, 0]$（C 个 1 后接 0）。
- 通过 permutation invariant training（PIT）解决标签置换问题。

## 6. 论文的主要结论与发现

- **RDnet 结论**：
  - 门控机制、SiLU、Conv-SwiGLU、三重损失设计均能逐步提升分离性能；
  - 在 WSJ0-{2,3,4,5}mix 上获得 SOTA 效果，5-mix 下比此前最优（SR-CorrNet-B）高约 0.9 dB；
  - 说话人计数准确率很高（5-mix 下 99.2%），估计说话人数导致性能下降极小；
  - 计算成本低于 SR-CorrNet-B，同时性能更高。
- **REnet 结论**：
  - 在相近计算成本下，RE 编码器始终优于 TAC，且对未见过的阵列几何有更好的泛化能力。
- **REDnet 结论**：
  - 在语音增强（C=1）和语音分离（C>1）任务上均优于需要 oracle 说话人数的 USES、TUSS、FlexIO 等强基线；
  - 在 CHiME-4 真实录音上，即使仅用仿真数据训练，REDnet 的 DNSMOS 也优于 FlexIO，展示了良好的领域泛化能力；
  - 使用估计说话人数时，性能几乎无损。

## 7. 优点

- **新颖性**：首次在单一 DNN 中联合解决"未知说话人数"和"可变麦克风数量/未知几何"两大挑战，填补了该研究空白。
- **设计巧妙**：
  - RE 通过递归融合各麦克风信息，实现线性复杂度并保留通道特有信息；
  - RD 将说话人计数与分离紧耦合，无需单独的后处理步骤；
  - 门控机制与 $\mathcal{L}^{RM}$ 残差损失的设计（确保残差只含未分离说话人信息）在逻辑上严密且有效。
- **端到端训练**：将说话人检测和分离联合优化，避免了级联误差。
- **实验系统性强**：从模块分解验证到整体评估，逻辑清晰，覆盖多数据集、多指标。
- **通用性好**：能同时处理语音分离和语音增强任务，且适应单/多麦克风、已知/未知阵列几何。
