## 摘要
Kolmogorov-Arnold网络（KAN）通过用可学习的单变量函数替换标量权重来增强非线性函数逼近。然而，为每条连接分配独立的函数会导致大量的参数冗余，限制了其可扩展性和效率。为了减少这种冗余，我们提出了HYDRA（HYperbolic Dynamic Representation Architecture），即双曲动态表示架构，这是KAN的一种参数高效的双曲扩展，它将基于样条的函数学习与庞加莱球中的表示相结合。HYDRA将向量值输入映射到有界的双曲潜在空间中，在切空间中进行KAN风格的更新，并采用低秩原型块在隐藏维度之间共享函数变换。由此产生的双曲表示为解释提供了一种结构化的径向坐标，同时半径控制通过防止边界饱和来提高训练稳定性。在八个基准数据集上的大量实验表明，HYDRA在提高参数效率和表示可解释性的同时，始终能达到有竞争力或更优的预测性能。

## Abstract
Kolmogorov-Arnold Networks (KANs) enhance nonlinear function approximation by replacing scalar weights with learnable univariate functions. However, assigning an independent function to every connection results in substantial parameter redundancy, limiting their scalability and efficiency. To reduce this redundancy, we introduce \textbf{HY}perbolic \textbf{D}ynamic \textbf{R}epresentation \textbf{A}rchitecture (HYDRA), a parameter-efficient hyperbolic extension of KAN that combines spline-based functional learning with representations in the Poincaré ball. HYDRA maps vector-valued inputs into a bounded hyperbolic latent space, performs KAN-style updates in tangent space, and employs a low-rank prototype block to share functional transformations across hidden dimensions. The resulting hyperbolic representations provide a structured radial coordinate for interpretation, while radius control improves training stability by preventing boundary saturation. Extensive experiments across eight benchmark datasets demonstrate that HYDRA consistently achieves competitive or superior predictive performance while improving parameter efficiency and representation interpretability.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- Kolmogorov-Arnold Networks（KAN）通过将传统神经网络中的标量权重替换为可学习的单变量函数（通常用样条参数化），显著提升了非线性函数逼近能力，并具备更强的可解释性。
- 然而，标准KAN为每一条连接分配一个独立的函数，导致隐藏层到隐藏层的参数复杂度呈二次增长：若隐藏宽度为 d、样条基数量为 K，则单个密集KAN块的代价约为 O(d²K)。这种参数冗余严重限制了KAN在大规模任务中的可扩展性和训练效率。
- 现有KAN变体（如ChebyKAN、Wav-KAN、FastKAN等）主要聚焦于替换样条基或优化函数参数化，但很少关注隐藏表示本身的几何结构。与此同时，双曲表示学习（如Poincaré ball嵌入）虽然在层级结构建模中表现优异，却较少与显式函数学习相结合。
- 本文提出HYDRA，旨在将双曲几何作为紧凑、可控的表示空间，与KAN的切空间样条更新相结合，在保持低参数成本的同时，兼顾性能与可解释性。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想

HYDRA的核心是将“表示尺度”与“局部函数建模”解耦：

- 隐藏状态表示在**有界的庞加莱球（Poincaré ball）**中，用径向坐标编码潜在尺度变化；
- KAN风格的样条函数学习在**切空间（tangent space）**中执行，保留一维样条的低参数特性；
- 通过**低秩原型块（low-rank prototype block）**压缩切空间更新，使隐藏维度之间共享函数变换，显著降低参数复杂度；
- 引入**半径控制机制**，防止表示漂移到庞加莱球边界附近造成梯度放大和训练不稳定。

### 关键技术细节

- **双曲嵌入与映射**：输入先经过线性嵌入，再通过原点处指数映射进入庞加莱球；每个HYDRA块在切空间做更新后，再经指数映射投影回流形，并用硬投影限制半径。

- **切空间KAN更新**：给定当前双曲状态 hₗ，先取对数映射得到 zₗ = log₀ᶜ(hₗ)，然后进行残差更新：
  zₗ₊₁ = zₗ + αₗ Δₗ(zₗ)。
  密集KAN的更新为 Δᵢ(z) = Σⱼ ϕᵢⱼ(zⱼ)，每个坐标对对应一个样条函数。

- **低秩原型函数学习**：
  - 先降维：pₗ = W↓ zₗ，其中 W↓ ∈ ℝ^{r×d}，r ≪ d；
  - 在原型空间应用样条块：sₗ = Φₗ(pₗ)；
  - 再升维：Δₗ(zₗ) = W↑ sₗ，其中 W↑ ∈ ℝ^{d×r}。
  - 参数复杂度从约 d²(K+1) 降至 2dr + r²(K+1)，压缩比主要由 r/d 决定。

- **半径控制机制**：
  - 硬投影 Π_{rₗ} 保证每层表示在预设半径内；
  - 软惩罚 L_rad 在表示接近边界前就改变训练方向，避免模型通过外推“偷懒”地降低损失。

- **整体目标函数**：L = L_sup + λ_rad L_rad + λ_sp L_sp，其中 L_sp 为样条系数的稀疏与平滑正则，L_sup 为监督损失（回归用MSE，分类用BCE）。

### 公式流程示意

每层HYDRA块的计算顺序为：
zₗ = log₀ᶜ(hₗ) → pₗ = W↓ zₗ → sₗ = Φₗ(pₗ) → z̃ₗ₊₁ = zₗ + αₗ W↑ sₗ → hₗ₊₁ = Π_{rₗ₊₁}(exp₀ᶜ(z̃ₗ₊₁))。
