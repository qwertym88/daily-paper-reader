## 摘要
可见光-红外人员重识别（VI-ReID）受到跨模态差异和判别能力有限的困扰，导致识别性能欠佳。现有方法在语义挖掘、跨模态融合和特征约束方面存在局限性。为应对这些挑战，我们提出了MDCRNet，一种多尺度分解卷积精化网络，以增强跨模态特征学习和判别度量学习。具体而言，我们引入了一个包含四个层次分解卷积注意力（HDCA）模块的层次学习模块（HLM），每个模块配备轻量级通道注意力和多尺度空间感知块，以捕获多尺度空间依赖关系。此外，我们开发了一种联合判别度量损失（JDML），其中包含一种新颖的粒度判别损失（GDL），可同时优化跨模态的身份内紧凑性和身份间可分离性。在SYSU-MM01和RegDB数据集上的大量实验表明，MDCRNet在两个基准上都达到了最先进的性能。代码可在https://github.com/Kevin-zms/MDCRNet获取。

## Abstract
Visible-infrared person re-identification (VI-ReID) suffers from cross-modal discrepancies and limited discriminative capabilities, leading to suboptimal recognition performance. Current approaches exhibit limitations in semantic mining, cross-modal fusion and feature constraints. To tackle these challenges, we propose MDCRNet, a Multi-scale Decomposed Convolution Refinement Network that enhances cross-modal feature learning and discriminative metric learning. Specifically, we introduce a Hierarchical Learning Module (HLM) containing four Hierarchical Decomposed Convolution Attention (HDCA) modules, each equipped with lightweight channel attention and multi-scale spatial perception blocks to capture multi-scale spatial dependencies. Moreover, we develop a Joint Discriminative Metric Loss (JDML) incorporating a novel Granularity Discriminative Loss (GDL) that simultaneously optimizes intra-identity compactness and inter-identity separability across modalities. Extensive experiments on SYSU-MM01 and RegDB datasets demonstrate that MDCRNet achieves state-of-the-art performance on both benchmarks. Code is available at https://github.com/Kevin-zms/MDCRNet.

  - **特征约束不统一**：现有损失函数分别处理模态间对齐或身份间判别，缺乏对同身份跨模态、异身份跨模态及模态内关系的统一约束。

**论文目标**

- 提出多尺度分解卷积精化网络（MDCRNet），通过层级特征学习与判别度量优化，有效缓解跨模态差异，提升 VI-ReID 的跨模态识别精度。

## 2. 方法论

**整体框架**

- 采用**四流架构**：同时对原始可见光图像、红外图像及其通道增强变体（channel-augmented variants）进行处理，生成互补特征表示。
- 基于 ResNet-50 骨干网络提取特征，在第 4 阶段引入层次学习模块（HLM）进行深层语义学习。

**核心模块**

- **层次学习模块（HLM）**
  - 包含四个层次分解卷积注意力（HDCA）模块。
  - 每个 HDCA 由两部分组成：
    - **轻量通道注意力（CA）**：对四流拼接特征进行全局平均池化（GAP），经两个 1×1 卷积和 Sigmoid 激活生成通道门控，实现高效的跨模态特征融合。
    - **多尺度空间感知块（MSPB）**：内含三个渐进距离感知注意力（PDPA）组件，核大小分别为 3、5、7，用于捕捉短程、中程和长程空间依赖关系。
  - PDPA 设计亮点：采用级联的深度可分离卷积（DWConv）与渐进膨胀率，使有效感受野呈**二次增长**（ERF = 2i² + 6i + 3），相比 ASPP 的线性增长，能在保持参数效率的同时更广泛地扩展空间上下文。

**损失函数——联合判别度量损失（JDML）**

- 由身份损失（L_ID）、四元中心三元组损失（L_QCT）和新提出的**粒度判别损失（GDL）**构成。
- GDL 包含三个协同约束：
  - **中心损失（L_center）**：拉近同一身份的可见光与红外特征到统一身份中心，实现跨模态对齐。
  - **余弦相似度损失（L_cosine）**：双向余弦相似度约束，最大化同身份跨模态相似度、最小化异身份跨模态相似度，提升身份间可分性。
  - **自适应特征聚合损失（L_adaptive）**：对每个身份组内的 K=4 个样本计算自适应权重，聚合得到身份级表示，再约束跨模态聚合特征的紧凑性。
- 总损失：L_JDM = (L_ID + L_QCT) + L_GD，其中三个 GDL 组件权重均为 0.1。

- 消融实验表明：
  - PDPA 多尺度核将 all-search Rank-1 从 74.86% 提升至 77.16%。
