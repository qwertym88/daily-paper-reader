## 摘要
概率屏蔽是一种用于安全强化学习（RL）的技术。通常，一个静态观察器——称为屏蔽——将学习代理的动作限制在那些保持安全可行的动作上。传统上，屏蔽是根据底层马尔可夫决策过程（MDP）的转移概率计算的。因此，当MDP模型不是先验给出时，该技术不适用，而不幸的是，这恰恰是典型RL应用中的情况。在本文中，我们研究了在MDP的转移图已知但转移概率未知的情况下计算屏蔽的问题。我们的方法将概率屏蔽与在线模型学习相结合：当RL代理探索环境时，我们估计转移概率。根据此估计，我们计算屏蔽。虽然屏蔽最初可能是保守的，但随着模型估计变得更加精确，它会自适应调整。因此，屏蔽与RL代理同步改进。这种自适应概率屏蔽范式引发了许多挑战，例如何时重新计算屏蔽以及在学习过程中如何平衡探索与安全。我们在多个环境中对多种此范式的变体进行了实证评估。

## Abstract
Probabilistic shielding is a technique for safe reinforcement learning (RL). Typically, a static observer -- called the shield -- constrains the learning agent's actions to those for which acting safely remains feasible. Traditionally, the shield is computed from the transition probabilities of the underlying Markov decision process (MDP). Thus, this technique is not applicable when the MDP model is not given a priori, which, unfortunately, is the case in typical RL applications. In this paper, we study the problem of computing a shield in the setting where the transition graph of the MDP is known, but the transition probabilities are unknown. Our approach integrates probabilistic shielding with online model learning: as the RL agent explores the environment, we estimate the transition probabilities. From this estimate, we compute a shield. While the shield may be conservative initially, it adapts as the model estimate becomes more precise. Thus, the shield improves in tandem with the RL agent. This paradigm of adaptive probabilistic shielding raises a number of challenges, such as when to recompute the shield and how to balance between exploration and safety during learning. We empirically evaluate multiple variants of this paradigm across several environments.

### 1. 核心问题与整体含义（研究动机和背景）

- 概率屏蔽（Probabilistic Shielding）是安全强化学习中的常用技术，通过一个“屏蔽器”在运行时限制智能体的动作，保证以不低于给定概率满足安全规范。
- 传统概率屏蔽依赖底层 MDP 的完整模型（包括精确转移概率），但实际强化学习场景中 MDP 通常未知，这严重限制了该技术的应用。
- 本文针对一个更现实的问题：**MDP 的转移图（拓扑结构）已知，但转移概率未知**，且只能通过黑盒交互采样数据。
- 核心意图是：将概率屏蔽与在线模型学习相结合，随着数据积累不断更新模型估计，并据此自适应地重新计算屏蔽器，从而在训练过程中既保证安全性，又逐步降低保守性，最终学习到安全且高回报的策略。
- 该问题本质上涉及安全与探索的平衡：过于保守的屏蔽会阻碍探索，导致无法收集足够数据来优化模型，进而影响策略学习和屏蔽精化。

### 2. 方法论：核心思想、关键技术细节、算法流程

**核心思想**

- 将“策略学习、模型估计、屏蔽合成”三者整合进同一在线学习循环：智能体交互采集数据 → 估计 MDP/iMDP → 合成屏蔽 → 在屏蔽约束下继续探索 → 循环迭代。
- 屏蔽随模型估计精化而自适应：初始数据极少时估计宽泛、屏蔽保守；随数据增加，概率区间收窄，屏蔽逐渐放松。

**关键技术细节**

- 使用 **区间 MDP（iMDP）** 表示估计的转移概率不确定性，区间越宽代表不确定性越大。
- 基于 iMDP 的屏蔽合成方法（源自 [12]）：对每个状态-动作对计算安全概率下界/上界，定义主屏蔽 ∇θ（要求安全概率 ≥ 1−θ）和回退屏蔽 ∇κ（在主屏蔽为空时允许 κ-接近最安全动作的动作）。
- 使用概率模型检测器 PRISM 计算 iMDP 上的安全概率。

**三种模型估计器**

1. **MAP**：最大后验点估计，基于对称先验权重 w，输出点估计 MDP。
2. **PAC**：在点估计基础上用 Hoeffding 不等式构造置信区间，输出 iMDP，具有有限数据统计保证。
3. **LUI**：线性更新区间估计器，使用先验区间和强度，输出 iMDP，无统计保证但经验上收敛。

**屏蔽态度（Attitude）**

- **鲁棒（Robust）**：采用最坏情况概率（opt = min），保守但安全。
- **乐观（Optimistic）**：采用最好情况概率（opt = max），允许更多探索。

**算法流程（Algorithm 1）**

1. 初始化 Q 表（策略）和转移数据库 D。
2. 每隔 u 个 episode：
   - 用当前 D 和估计器 E 生成模型估计（MDP 或 iMDP）。
   - 基于安全规范、θ、κ、h 合成屏蔽 ∇。
3. 每个 episode 内：
   - 使用 ε-greedy 策略：以概率 ε 从全部动作（注意：非屏蔽允许集合）中随机选择；否则选择屏蔽允许下 Q 值最高的动作。
   - 执行动作，观察转移和奖励，更新 Q 表和数据库 D。
4. 返回最终策略、屏蔽和模型估计。

### 6. 主要结论与发现

- **自适应屏蔽显著提升训练安全性**，在多数环境中安全违规次数接近 Oracle 屏蔽。
- **模型估计随时间改善**，最显著的改善发生在第一次屏蔽更新后（约 1000 episodes）。
- **估计器选择影响显著**：
  - LUI 和 PAC 区间估计优于 MAP 点估计，MAP 常因过度保守而探索不足。
  - 鲁棒估计器并不总是带来更安全策略，可能因“信息茧房”效应（已探索路径被误判为安全，未探索路径被阻挡）。
  - 乐观屏蔽能探索更多区域，但可能牺牲安全，在 Gravity 环境中尤其高风险。
- **无屏蔽探索（从全动作集探索）通常有益**，尤其在 Antlion 和 Gravity 环境，可避免因屏蔽导致过早收敛到次优路线。
- **屏蔽更新延迟 u 无统一最优值**，不同环境偏好不同。
- **屏蔽展望 h 影响安全-回报权衡**：h 较短时智能体倾向于更危险但高回报的路线；h 较长则更安全。
- 整体上，自适应屏蔽在保证安全的同时，能以较小的奖励代价换取大幅安全性提升，且模型精度和屏蔽质量随训练数据增加而提升。
