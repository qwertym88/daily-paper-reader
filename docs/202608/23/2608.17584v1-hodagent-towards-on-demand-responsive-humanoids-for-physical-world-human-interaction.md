## 摘要
我们提出HODAgent，一种用于服务场景中人形机器人的System-2具身代理，可解决情境意图、响应式执行、任务修订和结果验证等问题。其半双工架构集成了环境交互器、规划器、执行器和分层记忆，以在服务过程中保持连贯的交互、规划和任务状态。这使得机器人在运动过程中能够处理新请求、保留进度、修订动作，并在执行结果中实现闭环验证。一个共享接口连接仿真环境和实体机器人（Unitree G1），隔离平台特定的控制。在包含164个案例的交互式仿真中，HODAgent在两种VLM主干下分别达到84.8%和91.5%的联合成功率，比基线高出9.8和18.9个百分点。在实体机器人上，通过率分别为92%（原子任务）、72%（复合任务）和63.3%（完整任务）。在多个具身基准上，它比基线提高0.7-9.0个百分点。结果表明，一个统一的System-2代理能够在仿真和现实中实现适应性人形机器人服务。

## Abstract
We propose HODAgent, a System-2 embodied agent for humanoid robots in service settings, addressing situated intent, responsive execution, task revision, and outcome verification. Its semi-duplex architecture integrates an Env-Interactor, Planner, Executor, and hierarchical Memory to maintain coherent interaction, planning, and task state during service episodes. This allows handling new requests during motion, retaining progress, revising actions, and grounding closure in execution outcomes. A shared interface connects simulation and physical robots (Unitree G1), isolating platform-specific control. In an interactive simulation with 164 cases, HODAgent achieves 84.8% and 91.5% Joint Success under two VLM backbones, outperforming baselines by 9.8 and 18.9 points. On physical robots, pass rates are 92% (atomic), 72% (composite), and 63.3% (complete tasks). On multiple embodied benchmarks, it improves over baselines by 0.7-9.0 points. Results show a unified System-2 agent enables adaptive humanoid service across simulation and reality.

## 2. 方法论：HODAgent 系统设计

### 2.1 核心思想

- 采用 **半双工（semi-duplex）** 交互架构：机器人可以“边执行边监听”，在物理运动过程中持续处理用户输入，不需要等当前动作序列结束。
- 将 System-2 运行时组织为四个解耦模块，协调交互、规划、执行和记忆，使服务过程成为一个连贯的“服务片段（service episode）”。

### 2.2 关键技术细节

- **Env-Interactor（环境交互器）**：负责持续接收流式输入（文本/语音/图像/机器人状态），利用多模态 Omni 模型理解用户意图，并做出路由决策（直接回答、启动规划、打断重规划或忽略）。它保持对环境和用户的持续感知，不因机器人运动而挂起。
- **Planner（规划器）**：执行“任务分解 → 短视规划 → 结果审查”流程。先将长目标分解为有序子任务，再针对当前子任务生成短动作序列（工具调用），并在执行后根据反馈决定继续、推进或重规划；在任务结束前进行证据化完成审查，避免将“命令接收”当作“物理完成”。
- **Executor（执行器）**：将规划好的工具轨迹转换为时间扩展行为，异步调用平台技能，监控执行进度，并向 Planner 和 Memory 返回状态。支持流式推理，在非终止轨迹接近完成时可提前生成下一个计划，减少决策延迟。
- **分层 Memory（记忆）**：
  - 任务级：整体目标和历史任务摘要；
  - 子任务级：任务分解、已完成/当前/剩余工作；
  - 动作级：最近观测、执行动作和结果。
  - 记忆作为模块间协调的共享上下文，使任何模块都能从中断/重规划中恢复一致状态。
- **共享观测与执行契约**：平台无关的高层动作语义（如“向前移动 0.5m”“挥左手”）通过适配器映射到仿真（Isaac Sim）或真机（Unitree G1 + GR00T/SONIC）接口；平台特定的控制、安全约束和动作能力过滤保持在代理边界之下，使同一高层逻辑可直接跨平台复用。

## 3. 实验设计

### 3.1 交互式仿真评估（核心实验）

- **仿真平台**：Isaac Sim。
- **场景构建**：基于 SAGE-3D 生成 22 个室内服务环境（汽车展厅等），构建 164 个评估案例，39 条物理可达路线，平均每条路线 2.23 个语义目标（2–3 个）。
- **交互覆盖**：5 种具身交互机制：多目标有序导航、后续服务请求、中断与恢复、路线复盘、服务完成确认；其中 15 个案例含执行期间中断策略。
- **用户模拟**：设计了四种用户人格（新手引导型、时间受限型、中性合作型、证据谨慎型），由“案例约束 + 状态条件化”的 User Agent 根据冻结工作流和可观测执行状态生成自然语言请求（包括执行中打断）。
- **评估协议**：记录对话、动作、轨迹、终端状态对齐形成 episode record；独立后验评估：

  - **Service Judge**（模型式）判断交互质量（相关、清晰、事实锚定、符合人格）；
  - **Joint Success** 要求同一 episode 中两个 verdict 同时通过。
- **对比方法**：ReAct（顺序 observe-reason-act 基线），在相同模型、相同案例、相同工具接口下对比。

### 3.2 真机实验（Unitree G1）

## 6. 主要结论与发现

- HODAgent 的半双工架构能有效协调“交互/规划/执行/记忆”，在服务过程中实现真正的按需响应，优于 ReAct 式顺序式 agent。
- 共享观测与执行契约使同一高层 agent 能在仿真和真实机器人上运行，真机初步验证了该路径的可行性。
- 任务分解、结构化进度记忆、多图像上下文和视觉状态抽象在多个通用具身基准上带来一致提升，表明其能力可迁移。
- 主要价值不在于选择单个机器人动作，而在于在动作展开过程中维持连贯的服务关系，适用于接待、导览、零售协助等场景。

## 7. 优点

1. **问题定义清晰**：形式化定义了“按需响应”这一具体需求，并分解为三个可评估的能力。
2. **架构解耦合理**：Env-Interactor / Planner / Executor / Memory 的模块划分避免了感知-规划-执行的刚性流水线，支持执行中交互。
3. **仿真-真机共享接口**：高层代理逻辑与平台底层解耦，便于跨平台复用，工程上很实用。
4. **评估框架严谨**：
   - 用户代理由工作流约束、状态条件化，可复现且多样化；
   - 任务验证与服务判断分离，Joint Success 指标能反映“物理完成+交互质量”的综合效果；
   - 强调用执行证据而非命令回执来判断任务完成。
5. **多层次测试**：同时进行仿真基准、真机渐进式测试和通用基准测试，覆盖从原子能力到完整服务片段的不同粒度。
6. **真机实验不依赖语义地图**：仅用本体感知逐步观察-行动-更新计划，对未知环境有一定泛化潜力。

## 8. 不足与局限

1. **交互协议为半双工而非全双工**：机器人运动过程中仍存在一段“推理间隙”，如案例中用户喊“stop”后，机器人仍额外前进 0.3m；论文未给出硬实时延迟保证。
2. **真机验证范围有限**：仅 Unitree G1 一个平台、每组 trial 数量少、能力集有限（无操作、无可信地图），统计意义和跨平台普适性不足。
3. **仿真与真机差距大**：仿真中允许的重要语义（如目标到达判据）与真机物理状态不同，未实现任务级 sim-to-real 迁移。
4. **模型与感知瓶颈**：G1 板载摄像头视野窄、音频采集质量低；模型在较长序列中容易丢失动作状态、重复或幻觉动作。
5. **通用基准上的提升不稳定**：某些子集（如 EB-ALFRED 长时程、EB-Habitat 复杂指令）出现性能下降，说明方法并非在所有任务上都优于基线。
6. **未报告资源消耗**：缺少推理时间、GPU 算力、token 成本等资源指标，难以评估实际部署的实时性。
7. **未训练新的低层策略或 VLA 模型**：系统依赖现有基础模型和预配置技能，个性化长期记忆和显式义务追踪尚未实现。
