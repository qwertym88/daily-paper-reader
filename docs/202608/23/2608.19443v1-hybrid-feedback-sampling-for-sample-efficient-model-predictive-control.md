## 摘要
得益于其可并行性和灵活性，基于采样的模型预测控制（MPC）已广泛用于控制真实世界的机器人系统。然而，对于高维且开环不稳定的动态系统，改进控制序列所需的样本数量随预测时域指数增长，导致样本效率低下和数值不稳定。本文研究了基于采样的MPC中打靶法的不稳定性，并表明最优采样建议分布可以通过采用优化反馈策略的采样来实现。我们将该算法称为反馈采样MPC（FS-MPC）。FS-MPC包含一种混合采样设计，基于系统稳定性和可用计算预算来平衡局部与全局搜索。我们的理论分析表明，我们的混合采样方法比标准MPPI收敛更快，比标准反馈采样具有更优的最优性。在经验上，在诸如人形机器人移动操作和灵巧操作等多种接触丰富的控制任务中，我们展示了FS-MPC成功处理了标准基于采样方法难以应对的动态不稳定任务，并且严格优于单独的反馈策略。最后，我们在真实世界的人形机器人运动和操作任务中验证了我们的方法。

## Abstract
Thanks to its parallelizability and flexibility, sampling-based Model Predictive Control (MPC) has become widely popular for controlling real-world robotic systems. However, for high-dimensional and open-loop unstable dynamical systems, the required number of samples to improve the control sequence will grow exponentially with the horizon, leading to poor sample efficiency and numerical instability. This paper investigates the instability of shooting methods in sampling-based MPC and shows that the optimal sampling proposal distribution can be realized by sampling with an optimized feedback policy. We refer to this algorithm as Feedback Sampling MPC (FS-MPC). FS-MPC involves a hybrid sampling design which balances local and global search based on the system stability and the available computation budget. Our theoretical analysis shows that our hybrid sampling approach achieves faster convergence than standard MPPI and better optimality than standard feedback sampling. Empirically, in diverse contact-rich control tasks like humanoid loco-manipulation and dexterous manipulation, we show that FS-MPC successfully tackles dynamically unstable tasks where standard sample-based approaches struggle, and strictly outperforms feedback policies alone. Finally, we validate our method on humanoid robot locomotion and manipulation tasks in the real world.

- **现有改进的不足**：已有方法（如协方差整形、时域缩短、离线学习采样分布）均未直接针对开环 rollout 的不稳定性源头，因而无法从根本上解决长时域下的样本发散问题。

论文的整体含义是：**将开环采样替换为反馈闭环采样，从而从根本上抑制采样轨迹的发散趋势，在不稳定系统中实现样本高效的 MPC**。

## 2. 方法论：核心思想、关键技术细节、公式与算法流程

### 2.1 核心思想

论文的核心洞察是：**线性时变（LTV）系统的最优采样建议分布，等价于对该系统的最优反馈策略进行带噪采样**。具体而言，与其从高维各向同性高斯分布中直接采样整条控制序列（导致轨迹发散），不如在 rollout 过程中递归地施加一个反馈控制律，并注入少量噪声——后者能天然保证采样轨迹保持在稳定区域附近。

### 2.2 关键技术细节

#### （1）最优协方差设计（定理 2）

论文考虑如下单样本期望代价优化问题：

min_{Σ≻0, det(Σ)=1} E_{V∼N(U_k,Σ)}[J(V)]

该问题有闭式解：Σ*_k = (ρ/m)·D⁻¹，其中 D = MᵀQM + R 是代价函数的 Hessian。在此最优协方差下：
- 期望代价 E[J] = Θ(H)（随时域线性增长而非指数）；
- 方差 Var[J] = Θ(H)；
- 采样到低代价轨迹的概率为常数 Θ(1)；
- 样本复杂度 N = Θ(log(1/δ))（与 H 无关）。

#### （2）反馈采样与最优协方差的等价性（定理 3）

论文证明：使用 iLQR 反馈增益 K_h 和噪声缩放矩阵 Z_h 进行递归采样：

u_{h+1} = −K_h·x_h + Z_h·w_h,  w_h∼N(0, σ²I)

所诱导的控制序列分布与直接从最优协方差 Σ*_k 采样的分布完全一致。这提供了最优协方差的一个状态空间最小实现，避免了显式构造高维稠密协方差矩阵的计算开销。

#### （3）混合反馈采样（核心创新）

为了在**非线性系统**中兼顾局部搜索效率与全局收敛性，论文提出混合建议分布：

q_α(U_k) = α·q(·; U_k, Σ*_k) + (1−α)·q(·; U_k, σ²I)

其中第一项为基于局部线性化的优化反馈采样（局部搜索），第二项为标准各向同性高斯采样（全局搜索）。混合系数 α 由样本预算 N 动态确定：

α = min(N*_local / N, 1)，N*_local = (mH/C_local)·log(1/δ)

即：样本量少时优先保证局部搜索（α→1），确保能找到局部最优；样本量充裕时，剩余样本用于全局探索。

#### （4）不可微系统的扩展

对于接触丰富等不可微系统，梯度方法不可用，论文支持使用预训练的 RL 策略（如 PPO）作为反馈，将第（9）式的参数 θ* 作为反馈策略参数，混合采样结构保持不变。

### 2.3 算法流程（Algorithm 2）

```
1. 输入：初始状态 x₀、初始控制序列 U₀、参数 λ、α₀
2. 确定混合比例 α，将 N 个样本分为 N_local 和 N_global 两组
3. 对每次优化迭代 k：
   a. 求解最优采样参数（iLQR 求 Σ*_k 或 RL 求 θ*_k）
   b. 从局部反馈建议分布采 N_local 个样本
   c. 从全局各向同性建议分布采 N_global 个样本
   d. rollout 所有样本（闭环/开环混合方式）
   e. 计算累积代价，按 softmax 加权更新控制序列 U_{k+1}
4. 返回最终控制序列 U_K
```

## 6. 主要结论与发现

1. **理论基础**：严格证明了标准 MPPI 在不稳定线性系统上具有指数级样本复杂度（定理 1），而最优协方差设计可将样本复杂度降至对数级（定理 2），且最优协方差可由反馈采样实现（定理 3）。
2. **方法有效性**：FS-MPC 通过混合反馈采样（局部 + 全局），在保持全局搜索能力的同时显著提升局部采样效率，在高维不稳定、接触丰富的任务中超越标准 MPPI 和纯反馈采样。
3. **通用性**：FS-MPC 是元算法框架，可实例化为 iLQR 反馈（可微系统）或 RL 策略反馈（不可微系统），拓展了采样型 MPC 的适用范围。
4. **实物验证**：在 Unitree H1 人形机器人上完成行走和操作任务，验证了方法的实用性，解决了此前采样型 MPC 难以处理的高维不稳定控制问题。
