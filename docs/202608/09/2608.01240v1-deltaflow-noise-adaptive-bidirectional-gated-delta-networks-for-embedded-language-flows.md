## 摘要
嵌入语言流（ELF）主要依赖完全非因果注意力进行迭代去噪，在每个采样步骤中反复产生二次序列混合成本。门控Delta网络（GDN）提供了一种高效的循环替代方案，但其标准因果公式无法直接捕获ELF所需的双向上下文。我们引入了DeltaFlow，一种用于连续语言去噪的噪声自适应双向GDN主干。我们研究了两种变体：DeltaFlow-A，它在各层之间交替扫描方向；以及DeltaFlow-P，它在每一层内并行执行前向和后向扫描。我们进一步引入了噪声自适应记忆控制和计划的时间状态一致性（TSC），以稳定相近噪声级别下的隐藏表示。在OpenWebText上，使用32步随机微分方程采样器，DeltaFlow-P将生成的困惑度从全注意力ELF基线的24.218降低到21.228，同时保持了可比的单字熵，训练token暴露量为36B，而基线为45B。在仅去噪器的基准测试中，DeltaFlow-P在序列长度为16k时实现了比全注意力基线2.72倍的吞吐量提升。这些结果表明，DeltaFlow是密集注意力的一种有前景的替代方案，可用于高效的连续语言去噪。

## Abstract
Embedded Language Flows (ELF) rely primarily on full non-causal attention for iterative denoising, repeatedly incurring quadratic sequence-mixing cost at each sampling step. Gated Delta Networks (GDNs) provide an efficient recurrent alternative, but their standard causal formulation cannot directly capture the bidirectional context required by ELF. We introduce DeltaFlow, a noise-adaptive bidirectional GDN backbone for continuous language denoising. We study two variants: DeltaFlow-A, which alternates scan directions across layers, and DeltaFlow-P, which performs parallel forward and backward scans within each layer. We further introduce noise-adaptive memory control and scheduled Temporal State Consistency (TSC) to stabilize hidden representations across nearby noise levels. On OpenWebText, using a 32-step stochastic differential equation sampler, DeltaFlow-P reduces generated perplexity from 24.218 for the full-attention ELF baseline to 21.228 while maintaining comparable unigram entropy, with 36B training-token exposure compared with 45B for the baseline. In a denoiser-only benchmark, DeltaFlow-P achieves a 2.72x throughput speedup over the full-attention baseline at a sequence length of 16k. These results show that DeltaFlow is a promising alternative to dense attention for efficient continuous language denoising.

## 1. 论文的核心问题与整体含义

- **背景**：嵌入式语言流（Embedded Language Flows, ELF）是一种基于扩散/流匹配的连续语言生成模型，其去噪过程依赖全非因果注意力（full non-causal attention）来迭代更新 token 的连续潜在表示。每一步去噪都需要对所有 token 对进行交互，导致 O(KL²) 的序列混合成本（K 是采样步数，L 是序列长度），在长序列或深采样时计算开销极为高昂。
- **核心问题**：Gated Delta Networks（GDN）作为一种高效的循环线性注意力替代方案，虽能降低序列混合成本，但其标准形式是因果的（causal），无法直接捕获 ELF 所需的前后双向上下文；此外，GDN 的记忆衰减和写入机制没有对扩散时间步进行建模，难以适应不同噪声水平下的去噪需求。
- **论文目标**：设计一种高效的双向 GDN 主干（DeltaFlow），在保留 ELF 语义接口（前缀/控制 token 顺序不变、端点预测、自条件、解码与采样流程不变）的前提下，实现线性或类线性的序列混合成本，同时保持甚至提升生成质量与多样性。

## 2. 论文提出的方法论

### 2.1 核心思想

DeltaFlow 将 ELF 中的大部分全注意力层替换为双向 GDN 块（bidirectional GDN blocks），仅保留少量周期性全注意力块进行精确校正。其核心设计包括三个组件：

- **前缀保留的双向 GDN 扫描**（Prefix-Preserving Bidirectionality）
- **噪声自适应记忆控制**（Noise-Adaptive Memory Control）
- **计划的时间状态一致性**（Scheduled Temporal State Consistency, TSC）

### 2.2 双向 GDN 构造

- **问题**：若直接反转整个输入序列，会将前缀/控制 token 放到语义错误的位置。
- **解决方案**：引入反转算子 R_B，仅反转有效目标 token 主体（body），保留前缀和 padding 位置不变：

```
R_B(X; Lv) = (p1:P, x_{Lv}:1, x_{Lv+1}:L)
```

该算子满足 R_B² = 恒等映射，即两次反转恢复原序。

- **两个方向视图**：
  - 前向视图 G→：原始顺序上的 GDN 扫描。
  - 反向视图 G←：先反转 body，做 GDN 扫描，再反转输出；由于两次反转保持原始顺序，因此输出与输入对齐。

### 2.3 两种变体

- **DeltaFlow-A（交替扫描）**：在每个 GDN 层中仅执行一个方向的扫描，层间交替方向。奇数层向前扫描，偶数层向后扫描。每层只有一次循环扫描，无层内合并。
- **DeltaFlow-P（并行扫描）**：在同一 GDN 层内并行执行前向和反向两个方向的扫描，并将两个方向的输出取平均后，经过一个共享的输出门和投影：

```
Y_bi = 1/2 × (G→(X) + G←(X))
```

### 2.4 噪声自适应记忆控制

- 对每个扫描方向的衰减率 a 和写入率 b，加入依赖于扩散时间 t 的可学习偏移：

```
ã(t) = a + u_a(e(t))
b̃(t) = b + u_b(e(t))
```

- 其中 e(t) 是扩散时间嵌入，u_a 和 u_b 是共享的线性投影，初始化为零（从而在训练初期退化为标准 GDN）。
- 通过上述偏移调制 GDN 的衰减系数 d 和写入门 β，使模型在不同噪声级别下自适应地决定记忆保留强度和写入强度。

### 2.5 时间状态一致性（TSC）

- 在某个固定的后端块（第 6 层，即第 5 个 GDN 层）后附加一致性损失。
- 对同一共享噪声 ϵ，构造两个相邻噪声级别下的输入：z_t（更噪）和 z_{t+}（更干净），其中 t⁺ = (1+t)/2。
- 将较干净分支的状态作为 stop-gradient 目标，对齐两个分支的归一化隐藏状态：

```
L_TSC = (1/|Ω|) Σ_{i∈Ω} || r̂_i(z_t, t) − sg(r̂_i(z_{t+}, t⁺)) ||²
```

- TSC 仅在去噪分支上启用，权重按训练进度 p 进行余弦衰减调度：前 50% 训练进度时固定为 0.05，之后衰减至零。

### 2.6 混合堆栈结构

- 12 层结构，排列为 [GDN, GDN, GDN, Attn] × 3，即 9 个双向 GDN 块 + 3 个全注意力块。
- 注意力块提供精确的双向校正，GDN 块提供高效的循环全局记忆。

## 6. 论文的主要结论与发现

1. **DeltaFlow-P 在生成质量上超越全注意力基线**：SDE32/CFG-3 下，Gen. PPL 从 ELF-full 的 24.218 降至 21.228（降低 12.3%），单字熵基本持平（5.084 vs 5.069），且训练 token 少 9B。
2. **DeltaFlow-A 提供更高的多样性**：在熵维度（5.149）显著高于 ELF-full，但 PPL 改善有限，适合偏向多样性的场景。
3. **双向聚合是熵恢复的关键**：单向 GDN 熵崩溃（<5.0），双向 GDN 维持健康熵水平。
4. **噪声自适应记忆控制改善质量-多样性平衡**：仅双向核心会降低多样性，加入噪声自适应的衰减/写入控制后，模型在高噪声抑制不可靠更新、低噪声选择性修正，平衡了 PPL 和熵。
5. **TSC 进一步优化了 PPL-熵前沿**：对齐相近噪声级别的中间表示，稳定训练。
6. **条件生成可迁移**：XSum 上 DeltaFlow-P 与 ELF-full 几乎持平（ROUGE-2: 12.22 vs 12.35；ROUGE-L: 27.79 vs 27.87），WMT14 上匹配 LION-S（24.16 vs 24.12 BLEU），但与 ELF-full（26.94）仍存差距。
7. **长序列推理效率显著提升**：16k 序列时 DeltaFlow-A 和 DeltaFlow-P 分别较 ELF-full 提速 3.04× 和 2.72×；1k 时提速 1.56× 和 1.16×。

## 7. 优点

- **方法创新性**：
  - 前缀保留的双向扫描算子是巧妙的设计，既保留 ELF 语义接口，又获得双向上下文。
  - 将扩散时间嵌入引入 GDN 的衰减/写入控制，是循环线性注意力与扩散模型结合的有价值的探索。
  - TSC 作为一种辅助训练目标，在无需外部编码器的情况下对齐跨噪声级别的表示，思路新颖。
- **实验严谨性**：
  - 匹配 token 暴露量的对照实验（ELF-full 36B）有效排除了训练数据量差异的混淆。
  - 报告了置信区间和多种多样性指标（Dist-1/2/3、Rep-3、T5 JSD）。
  - 同时评估两种采样器（SDE32/ODE32），增加了结论的鲁棒性。
  - 效率评测区分训练和推理，并给出多序列长度下的完整数据。
- **实用性**：保留 ELF 接口意味着可无缝替换现有 ELF 模型的骨干，应用于已有流程。

## 8. 不足与局限

- **条件生成仍有性能差距**：WMT14 翻译中 DeltaFlow-P（24.16 BLEU）比 ELF-full（26.94 BLEU）低 2.78 分，说明循环骨干在强条件依赖任务上仍不如全注意力，距离实际部署有距离。
- **DeltaFlow-P 的训练吞吐低于 ELF-full**：0.353 vs 0.416 steps/s，并行双扫描带来额外计算开销。其节省的总 GPU-h 主要来自更少的训练 token（36B vs 45B），而非单步效率。
- **内存开销**：DeltaFlow-P 在 16k 序列下占用约 21 GiB，显著高于 ELF-full（14.90 GiB）和 DeltaFlow-A（15.04 GiB）。
- **实验覆盖有限**：
  - 未评测更长序列（如 32k、64k）下的行为。
  - 未进行更大模型规模（如 ELF-L 或更大 hidden size）的验证。
  - 未评估 DeltaFlow 在纯长上下文生成（而非仅去噪器吞吐）上的端到端质量。
  - 消融实验的数值精度不足（仅曲线图），且条件任务上缺少消融。
- **效率声称的范围**：16k 加速比是去噪器单独评测的结果，论文明确指出这不能解释为端到端长上下文生成质量的证据。
- **其他潜在偏差**：训练 token 数不同（36B vs 45B），虽然提供了 token 匹配对照，但 DeltaFlow 模型的最终评估仍是在更少数据下取得的，若训练更充分其上限未知；对比的基线种类有限，未纳入更多近年高效线性模型。
