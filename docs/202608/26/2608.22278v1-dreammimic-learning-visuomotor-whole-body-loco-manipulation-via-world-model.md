## 摘要
基于视觉的人形机器人全身移动操控具有挑战性，原因在于部分可观测性、接触丰富的动力学，以及从高维视觉输入中学习长时程行为的困难。我们提出了DreamMimic，一个通过世界模型辅助蒸馏将特权教师策略提炼为基于视觉的人形控制器的框架。我们没有使用Dreamer风格的RSSM进行规划，而是将其重新用于学习预测性潜在动态，既作为表示空间，又作为动作条件下的多步监督信号，同时向学生策略暴露紧凑的预测特征以减少长期漂移。除了本体感觉和视觉观察的标准重建目标外，我们还添加了用于特权状态、接触、物体状态和奖励估计的辅助预测头。这些预测头提供了与智能体-物体交互和任务进展相关的额外监督，鼓励潜在表示保留对接触丰富的移动操控有用的信号。我们进一步引入了性能条件引导（PCG），一种奖励驱动的自适应蒸馏调度，计算教师和学生双方的表现分数，以动态平衡引导与探索。PCG防止了在具有挑战性的视觉设置中过早的教师退火和过度的教师干扰。在OMOMO和BEHAVE上的实验表明，与强视觉基线相比，在基于跟踪的移动操控性能上有所提升，且在部署时不向学生暴露在线特权交互状态。定性模拟进一步考察了形态和模拟器变化。这些结果表明，世界模型可以为在接触丰富的人形行为中稳定视觉策略蒸馏提供一种有用的机制。

## Abstract
Vision-based whole-body loco-manipulation on humanoid robots is challenging due to partial observability, contact-rich dynamics, and the difficulty of learning long-horizon behaviors from high-dimensional visual inputs. We present \href{https://github.com/DreamMimic/DreamMimic}{DreamMimic}, a framework that distills privileged teacher policies into vision-based humanoid controllers via world-model-assisted distillation. Instead of using a Dreamer-style RSSM for planning, we repurpose it to learn predictive latent dynamics that serve as both a representation space and an action-conditioned multi-step supervision signal, while exposing compact predictive features to the student policy to reduce long-term drift. Beyond standard reconstruction objectives for proprioceptive and visual observations, we add auxiliary prediction heads for privileged state, contact, object state, and reward estimation. These heads provide additional supervision related to agent--object interaction and task progress, encouraging the latent representation to retain signals that are useful for contact-rich loco-manipulation. We further introduce Performance-Conditioned Guidance (PCG), a reward-driven adaptive distillation schedule that computes performance scores for both teacher and student to dynamically balance guidance and exploration. PCG prevents both premature teacher annealing and excessive teacher interference in challenging visual settings. Experiments on OMOMO and BEHAVE show improved tracking-based loco-manipulation performance over strong vision-based baselines, without exposing online privileged interaction states to the student at deployment. Qualitative simulations further examine morphology and simulator changes. These results suggest that world models can provide a useful mechanism for stabilizing visual policy distillation in contact-rich humanoid behaviors.

## 1. 核心问题与整体含义（研究动机与背景）

- **任务背景**：人形机器人需要在工厂自动化与日常服务中执行**视觉驱动的全身移动操控（whole-body loco-manipulation）**，即协调全身运动与物体交互，并根据视觉反馈完成任务。
- **核心难题**：
  - **部分可观测性（partial observability）**：部署时机器人无法获取仿真器中的特权状态（如真实物体位姿、接触标签、交互图等）。
  - **接触丰富的动力学（contact-rich dynamics）**：人与物体的接触不连续、时序性强，接触时序与物-体耦合关系对任务至关重要。
  - **高维动作与大自由度**：如SMPL-X 153自由度、Unitree G1 42自由度，学习空间极大。
  - **长时程行为**：从高维视觉输入直接学习长时程行为易产生累积误差与策略漂移。
- **现有方法局限**：
  - 许多方法只关注无物体交互的纯运动；或依赖特权信息/预计算状态估计器，无法直接部署；或端到端视觉RL在接触丰富任务中极不稳定。
  - 缺少能够捕捉**时序结构化、可预测表示**的机制，难以对抗长时程复合误差。
- **核心思想**：**世界模型**能够学习预测性潜在动态，在部分可观测条件下为视觉策略蒸馏提供稳定的表示空间与多步监督信号，从而稳定接触丰富的人形机器人全身操控策略学习。

## 2. 方法论：核心思想、技术细节与公式

### （1）整体框架：三阶段蒸馏

- **第一阶段——特权教师训练**：多个专业教师（specialist）在完整仿真状态上训练，再整合为统一的通用特权教师（generalist），负责提供监督。
- **第二阶段——世界模型学习**：在学生的视觉-本体感受经验上训练一个Dreamer风格的RSSM（循环状态空间模型），学习动作条件下的潜在动态。
- **第三阶段——学生蒸馏**：视觉学生策略同时接受单步动作模仿、多步潜在一致性损失和PPO正则化，逐步掌握鲁棒的视觉运动操控。

### （2）学生策略条件

学生策略输入为：

```
c_t = [p_t, g_t, φ_wm_t]
```

- p_t：非特权本体感受观测（移除仿真器对象状态、交互图、接触标签）。
- g_t：紧凑目标条件（目标物体位姿 + 短时机器人轨迹线索，含根与关键部位目标）。
- φ_wm_t：世界模型特征：

```
φ_wm_t = [h_t, r̂_t, x̂_priv_t, ĉ_contact_t, x̂_obj_t]
```

其中 h_t 是RSSM确定性循环状态，r̂_t 是奖励预测，其余为特权状态、接触、物体状态的辅助预测。**部署时学生不接触任何在线特权状态**。

### （3）世界模型：RSSM

- **编码器**：Eξ 将当前观测（深度图+分割图+本体感受）与上一动作编码为嵌入 e_t。
- **RSSM动态**：
  - 确定性转移：ht = fξ(h_{t-1}, s_{t-1}, a_{t-1})
  - 后验随机状态：s_t ∼ qξ(s_t | h_t, e_t)
  - 先验（开环预测）：h_prior_t 与 s_prior_t
- **解码与辅助预测**：
  - 重建头（RecH）：重建视觉与本体感受观测（MSE损失）。
  - 奖励预测头、特权状态预测头（13D物体状态 + 交互图 + 接触标签）、接触预测头、物体状态预测头。
  - 注意：**重建输出不直接输入策略**，仅作为表示学习的监督；策略消费的是确定性潜状态 h_t 与辅助预测特征。
- 世界模型总损失：

```
L_wm = L_KL + L_rec + L_rew + L_priv + L_con + L_obj
```

其中 KL 损失使用 free-bits 机制防止后验坍缩。

### （4）多步潜在蒸馏（Multi-step Latent Distillation）

- **动机**：单步动作匹配无法约束未来状态演化。
- **做法**：从同一后验潜状态 z_t 出发，用冻结的世界模型做**H步先验展开**（H=3），分别以学生策略均值动作 μ(S) 和教师策略均值动作 μ(T) 为条件，比较两条轨迹的潜状态差异：

```
L_latent = Σ_{k=1}^{H} [ ||h(S)_{t+k} - h(T)_{t+k}||² + λ_stoch ||s(S)_{t+k} - s(T)_{t+k}||² ]
```

- **核心作用**：该损失不需要教师的视觉观测；它利用学习到的动态作为**动作条件下的局部一致性度量**，对齐学生与教师在多步未来的状态演化。

### （5）性能条件引导（PCG）

- **目标**：动态平衡教师引导与学生探索，避免过早退火或过度干预。
- **做法**：
  - 在每回合开始时采样环境角色 m∈{0,1}，m=1 表示该环境由教师执行动作。
  - ρ ∈ [0,1] 为教师驱动环境的比例。
  - 维护教师/学生驱动环境的EMA奖励 r̂_T 与 r̂_S，计算性能分数 π = r̂_S / (r̂_T + ε)。
  - 当 π 趋近目标性能比时，将 ρ 从 ρ_max 平滑退火至 ρ_min（EMA平滑）。
  - **模仿监督系数全程固定**（与基于迭代数的退火不同）。
- **参照缓冲课程**：失败的学生驱动回合用于更新困难时间窗口附近的参考状态，使后续回合可重访困难交互状态。

### （6）总训练目标

```
L_total = c·w_action·L_action + w_wm·L_latent + w_ppo·L_ppo
```

- **模仿主导**：动作匹配为主要学习信号；PPO在热身期后作为低权重正则化器，应用于学生驱动回合。
- 世界模型定期从回放序列更新，避免策略与表示目标联合漂移。

## 6. 主要结论与发现

- DreamMimic在OMOMO上达到**92.2%成功率**、184.18平均步数、5.4cm机器人跟踪误差、8.8cm物体跟踪误差，优于所有直接视觉编码器基线（如ResNet-18 DAgger+RL：66.7%成功率、163步、8.9cm/10.1cm）。
- 增加物体质量的压测下，DreamMimic仍保持**41.2%（×5）与63.6%（×2）的成功率**，显著优于基线，但差距略为缩小。
- **单阶段Dreamer RL在接触丰富的人形任务上几乎失败（成功率0%）**，而世界模型用于蒸馏时却能显著提升性能——说明世界模型作为**蒸馏监督信号**比作为**直接RL规划器**更适合此类问题。
- **多步潜在蒸馏是最大贡献**：移除后OMOMO成功率从92.2%降至70.6%（−21.6个百分点）。
- **辅助预测头**（奖励、接触、物体状态、特权状态）均有助于降低物体跟踪误差。
- **确定性循环状态h_t是策略特征中的核心**：仅用随机特征时成功率降至74.5%；移除循环状态降至88.2%；移除动作条件降至90.2%，说明动作条件化与循环记忆都有贡献。
- **PCG优于朴素退火**：在相同DAgger+RL框架下，PCG在BEHAVE上将平均执行步数从275.21提高到289.53，跟踪误差更低，且减少对人工调节退火调度的依赖。
- **深度+分割是最佳视觉组合**，优于仅深度、仅分割、RGB。

## 7. 优点

### 方法亮点

1. **创新地重新定位世界模型**：不用于规划，而作为蒸馏的预测性表示空间与多步监督信号来源，与教师-学生蒸馏范式天然契合。
2. **多步潜在一致性损失**：不依赖教师视觉观测，利用冻结世界模型对齐学生/教师的未来状态演化，直接针对长时程漂移问题。
3. **辅助预测头设计巧妙**：特权状态、接触、物体状态、奖励预测为交互相关信号提供监督，部署时仅消费预测特征，不泄露特权信息。
4. **PCG自适应调度**：基于师生奖励性能动态调整教师占比，避免过早退火和过度干扰，减少对手动调度的依赖。
5. **参考缓冲课程**：基于学生自身状态分布更新困难时间窗口，更贴合学生的实际失败模式。
6. **模块解耦**：世界模型与策略损失分离，避免联合优化中的协同漂移问题。

- 全面消融覆盖各个设计选择，归因清晰。

- **世界模型不参与规划**：潜力受限，未探索利用该世界模型的想象滚动来直接改进策略的路径。
- **消融中部分差距不大**（如RSSM无动作条件、无循环状态之间的差异），可能说明某些设计的改善有限。
