## 摘要
零成本代理使神经架构搜索（NAS）能够根据初始化时计算的统计量对候选网络进行排序，从而避免重复训练。然而，不同的代理捕捉不同的属性，并且通常在不同的搜索空间上产生不一致的排名。集成代理可以结合互补信号，但自动化发现必须同时优化离散的聚合结构及其连续系数，这使得结构质量难以与参数校准分离。我们提出Bi-EZP，一个将这两种决策解耦的双层框架。在上层，大型语言模型在四个互补的基础代理上生成可执行的聚合程序，并带有特定于程序的参数边界。在下层，协方差矩阵自适应进化策略（CMA-ES）在内部训练划分上优化每个固定程序的连续参数。然后，使用肯德尔秩相关系数在不相交的验证划分上评估校准后的程序，从而使进化选择偏向于泛化能力超出其校准数据的结构。在NATS-Bench和网络设计空间上的实验评估了跨异构搜索空间的排名性能，而DARTS实验则评估了下游架构搜索。结果表明，将程序发现与数值校准分离为自动化集成零成本代理构建提供了一种有效的方法。源代码可在以下网址获取：https://anonymous.4open.science/r/Bi-EZP-318D

## Abstract
Zero-cost proxies enable neural architecture search (NAS) to rank candidate networks from statistics computed at initialization, avoiding repeated training. However, different proxies capture different properties and often produce inconsistent rankings across search spaces. Ensemble proxies can combine complementary signals, but automated discovery must optimize both discrete aggregation structures and their continuous coefficients, making structural quality difficult to separate from parameter calibration. We propose Bi-EZP, a bilevel framework that decouples these decisions. At the upper level, a large language model generates executable aggregation programs over four complementary base proxies with program-specific parameter bounds. At the lower level, covariance matrix adaptation evolution strategy (CMA-ES) optimizes the continuous parameters of each fixed program on an inner training split. The calibrated programs are then evaluated using Kendall's rank correlation on a disjoint validation split, enabling evolutionary selection to favor structures that generalize beyond their calibration data. Experiments on NATS-Bench and Network Design Spaces evaluate ranking performance across heterogeneous search spaces, and DARTS experiments assess downstream architecture search. Results show that separating program discovery from numerical calibration provides an effective approach to automated ensemble zero-cost proxy construction. ## 1. 论文的核心问题与整体含义（研究动机和背景）

零成本代理（zero-cost proxies）使神经架构搜索（NAS）能够在网络初始化阶段，仅通过少量前向/反向传播提取的统计量来评估架构质量，从而避免逐候选网络的昂贵训练。然而，这类代理存在一个根本性的可靠性缺陷：不同代理从不同角度（如激活模式、特征相关性、参数显著性、梯度一致性）刻画未训练网络的属性，其排名在不同搜索空间上往往不一致甚至相互矛盾。因此，如何将多个互补的代理信号整合为一个更可靠的评估函数，是零成本NAS领域的关键挑战。

已有的集成与自动化代理发现方法分为两类：固定形式的集成（如AZ-NAS、ParZC）在结构上受限，表达能力有限；符号搜索方法（如EZNAS、ECP、EvoREP）虽然扩展了结构空间，但引入了结构依赖的连续参数，形成结构搜索与参数校准耦合的联合优化问题——一个结构良好的程序可能在次优系数下表现平庸，而一个受限结构经过充分调参也可能显得有竞争力。这使得比较不同聚合结构时难以分离"结构本身的价值"与"参数校准的效果"。

Bi-EZP的核心洞见是：**符号结构发现与连续参数拟合扮演着根本不同的角色，应分层优化**。上层用LLM生成可执行的聚合程序及其参数边界，下层用CMA-ES对每个固定程序独立校准参数后再进行结构比较。这一设计将"结构质量"与"参数校准"显式解耦，使结构选择建立在充分校准的基础上，而非任意的初始系数之上。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
将集成零成本代理发现形式化为双层优化问题：
- **上层（结构进化）**：LLM生成可执行聚合程序 G（Python代码）及其参数域 B，采用锦标赛选择、语义交叉和定向变异进行进化搜索；
- **下层（参数校准）**：对每个固定程序 (G, B)，CMA-ES在内部训练集 Dtrain 上优化连续参数 θ，目标为最大化Kendall秩相关系数。

### 关键公式与表示
- **基础代理池**：S = {s_nw, s_mc, s_ss, s_sz}，分别对应NASWOT（激活模式多样性）、MeCo（特征相关性最小特征值）、Sweet-SNIP（参数显著性）、SZiCo（梯度一致性），由ECP选定并固定。
- **候选程序表示**：C = ⟨H, G, B⟩，H为LLM生成的启发式说明，G为可执行Python代码，B = ∏^{d}_{k=1}[L_k, U_k]为d个连续参数的可行域。
- **代理函数**：Φ(S; G, θ): R^{4×n} × Θ(G) → R^n，将n个架构的4维代理向量矩阵映射为n个标量得分。
- **双层优化目标**：
  - 下层（参数校准）：θ*(G, B) ∈ argmax_{θ∈B} τ(Φ(S_train; G, θ), A_train)
  - 上层（结构选择）：(G*, B*) ∈ argmax_{(G,B)∈Q} τ(Φ(S_val; G, θ*(G, B)), A_val)
  - 两个层次使用相同的Kendall τ目标，但使用不同的数据划分（80/20内部分割）和不同的优化变量。

### 关键流程
1. **LLM初始化与变异/交叉**：提示词要求生成包含"Idea"与"Code"两部分的响应；代码必须定义非空字面量BOUNDS列表和唯一的同步函数 aggregate(s_naswot, s_meco, s_zico, s_ssnip, params)，参数为与架构维度对齐的一维数组。
2. **可执行代码校验门**：使用AST解析器检查Python语法、函数签名、参数类型和BOUNDS合法性；无效响应返回LLM进行有限次纠正，全部失败则插入固定加权和回退候选，保证种群可评估性。
3. **CMA-ES下校准**：均值初始化为参数域几何中心，步长按边界范围比例缩放；采样、裁剪到边界、计算Kendall τ（或对NaN/Inf施加大惩罚999.0）、更新协方差矩阵（rank-μ与rank-1更新）。
4. **上层进化选择**：锦标赛选择（规模3）→ LLM交叉（概率P_c）或定向变异 → 校验 → CMA-ES校准 → 验证集适应度 → (P+P)精英截断选择。
5. **冻结代理评估**：发现过程使用基准精度监督；冻结后，新架构只需计算四个基础代理统计量并应用 Φ(·; G*, θ*) 即可打分，无需训练。

## 6. 论文的主要结论与发现

1. **双层解耦有效**：将结构发现与参数校准分离（w/o Bilevel Structure消融从TSS C-10的0.809降至0.783）表明，专门的下层优化器比LLM直接输出系数更可靠。
2. **排名相关性显著提升**：在NATS-Bench上，Bi-EZP在TSS上达到0.809（C-10）/0.791（C-100)/0.775（IN-16），在SSS上达到0.792/0.733/0.826，全面超过ECP等基线；在NDS上，DARTS空间从ECP的0.568提升至0.621，Amoeba空间从0.406提升至0.511。
3. **跨数据集迁移损失小**：NATS-TSS上，匹配设置平均τ=0.792，跨数据集平均τ=0.775，仅下降0.017。
4. **跨搜索空间迁移存在但非不变**：NDS上匹配设置平均0.557 vs 跨空间平均0.515，下降更明显（约0.042），NASNet/Amoeba转移最弱（0.429–0.519范围）。
5. **下游搜索有效**：在DARTS空间，Bi-EZP引导的搜索在CIFAR-10上达到2.47%测试误差（优于ECP的2.52%），CIFAR-100为16.10%，ImageNet top-1误差24.7%与ECP持平但参数量更少（5.3M vs 6.7M）。
6. **超参数敏感度**：种群20和20代是最佳平衡点，超过后无一致收益甚至下降；CMA-ES在GA/DE/PSO中表现最好；不同LLM（GLM-4.7-Flash vs DeepSeek-V4-Flash）结果接近但GLM略优。
7. **进化动态**：最优验证Kτ在1-5代快速上升（0.799→0.812），经历平台期后在第17代达到0.826的峰值。

## 7. 优点

- **问题建模新颖且合理**：将代理发现明确形式化为双层优化，解决了现有方法中"结构比较受制于任意系数"的混淆问题，思路清晰、动机充分。
- **LLM角色定位精准**：LLM被限定为"结构生成器"而非数值优化器或NAS决策者——利用其开放性生成多样化的非线性变换与跨代理交互，同时通过可执行代码校验门（AST解析+签名检查+边界验证+纠正/回退机制）将开放性约束在可评估范围内，工程实现完整。
- **实验设计严谨**：区分同域评估、冻结迁移评估（跨数据集和跨搜索空间）和下游搜索评估三个层次，迁移矩阵设计能清晰地区分"匹配源"与"非匹配源"的贡献；发现/评估的数据划分明确（80/20内部划分 + 外部保留集），避免验证信息泄漏。
- **消融覆盖全面**：针对核心设计决策（双层结构、LLM提案、下层优化器、种群/代数超参、LLM骨干）均有对应实验，且超参数扫描范围（到50）超出了默认值，能观察非单调效应。
- **诚实的方法学边界**：论文多次用"under the reported protocol"限定结论，明确澄清发现阶段有监督而使用阶段无训练的区分，并指出实验未能隔离结构表示、算子选择或表达式大小的因果贡献，学术诚信度高。

- **公平性隐患**：与公开数据集的基线数值比较可能存在评估协议差异（例如部分基线具体采样子集不清）；与ECP的比较在同一协议下进行，但未报告多次重复。
- **可解释性与简洁性不足**：最终进化出的聚合函数（如"Frequency-Modulated Saturation Layer"）结构复杂、包含大量自定义变换，物理意义模糊，实用性存疑；论文未与GP/EZNAS等符号方法对比表达式大小或搜索效率。
