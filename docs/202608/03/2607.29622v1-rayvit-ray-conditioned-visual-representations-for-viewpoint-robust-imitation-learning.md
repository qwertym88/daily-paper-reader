## 摘要
视觉模仿学习使机器人能够直接从图像中获取视觉运动技能，但RGB观测缺乏显式几何线索，使学习到的策略对相机扰动非常脆弱。为解决这一问题，我们提出了**射线条件视觉Transformer编码器（RayViT）**，一种轻量级架构，将相机几何注入预训练的ViT骨干网络。RayViT将相机几何表示为Plücker射线图，将其分块为射线特征，并使用门控交叉注意力生成射线条件的类别令牌。这些射线特征作为密集位置嵌入添加，而射线类别令牌替换原始ViT类别令牌，以提供几何感知的摘要表示。我们将该方法与辅助余弦相似度损失相结合，持续提升几何感知令牌的性能和鲁棒性。在仿真和真实机器人任务上的实验表明，与基线相比，RayViT在多任务RoboCasa基准的相机扰动下鲁棒性提升约13个百分点，在真实多任务成功率中平均完成阶段数提升1.78。

## Abstract
Visual imitation learning enables robots to acquire visuomotor skills directly from images, yet RGB observations lack explicit geometric cues, making learned policies brittle to camera perturbations. To address this, we propose \textbf{Ray-conditioned Vision Transformer Encoder (RayViT)}, a lightweight architecture that injects camera geometry into pretrained ViT backbones. RayViT represents camera geometry as a Plücker ray map, patchifies it into ray features, and uses gated cross-attention to produce a ray-conditioned class token. These ray features are added as dense positional embeddings, while the ray class token replaces the original ViT class token to provide a geometry-aware summary representation. We combine this approach with an auxiliary cosine similarity loss to consistently improve the performance and robustness for geometry-aware tokens. Experiments on sim- and real-robot tasks demonstrate that RayViT improves robustness by approximately 13 percentage points under camera perturbations in multi-task RoboCasa benchmark and by 1.78 average completed stages in real-world multi-task success rate compared to baselines.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **核心问题**：视觉模仿学习策略通常依赖RGB图像作为观测，但RGB图像**缺乏显式几何线索**，导致策略对相机位姿变化（如平移、旋转等扰动）非常敏感。当测试时相机参数发生改变，策略性能会显著下降。
- **根本原因**：预训练视觉表示（如DINOv3）编码了场景外观，但**忽视相机与世界之间的几何关系**，因而策略倾向于学习“视点特定的外观-动作映射”，而非“视点不变的任务表示”。
- **现有方法的不足**：
  - 依赖多视角数据增强/多相机采集：有效但成本高，难以扩展到真实世界；
  - 显式3D表示（点云、点图等）：需要额外传感器或重建，且与纯图像预训练视觉基础模型不兼容；
  - 现有Plücker射线图方法（如CamPose）只做简单的特征拼接，迫使编码器从零学习射线对齐，未充分利用预训练ViT的能力。
- **本文解决思路**：在**不增加额外传感器、不依赖多视角增强**的前提下，将相机内外参编码为轻量级Plücker射线图，以非侵入方式注入预训练ViT骨干，使视觉表示同时具备**相机感知能力**和**跨视点一致性**。

## 2. 论文提出的方法论

### 2.1 总体框架

RayViT以预训练ViT（DINOv3 ViT-Small）为骨干，在完全微调的条件下注入相机几何。

### 2.2 核心思想

将相机几何作为**射线图（Ray Map）**，通过两种互补机制注入预训练ViT：
1. **射线条件类令牌**（ray-conditioned class token）：替换原始CLS令牌，提供几何感知的全局摘要；
2. **射线位置嵌入**（ray positional embedding）：为每个图像patch提供显式3D空间定位。

### 2.3 关键技术细节

#### Plücker射线图建模
- 对于像素点 $p=(u,v,1)^{\top}$，相机中心与世界系方向分别为：
  $$o_w = -R^{\top}t, \quad d_w(u,v) = \frac{R^{\top}K^{-1}p}{\|R^{\top}K^{-1}p\|_2}$$
- 每条射线的Plücker坐标为：
  $$r(u,v) = [d_w(u,v),\ m_w(u,v)] \in \mathbb{R}^6, \quad m_w(u,v) = o_w \times d_w(u,v)$$
- 所有像素的射线坐标堆叠形成与图像空间对齐的密集射线图，**仅需相机内外参，无需额外传感器**。

#### 注入机制一：射线条件类令牌（Ray-Conditioned Class Token）
- 使用**两个门控交叉注意力块**（gated cross-attention blocks），可学习查询令牌（query token）与patch对齐的射线特征交叉注意力，逐步将相机几何压缩为单一全局令牌；
- 采用类似Qwen的**逐元素sigmoid门控**，自适应控制几何调节强度，避免过度破坏预训练表示分布；
- 最终查询令牌作为射线条件类令牌，**取代**ViT原始CLS令牌进入后续Transformer层。

#### 注入机制二：Patch对齐射线位置嵌入（Patch-aligned Ray Features）
- 使用**平均池化**（kernel size = patch size）将射线图下采样至与patch令牌对齐的分辨率，平均池化非参数化、能更好地保留Plücker坐标的几何语义；
- 通过两层MLP（GELU激活）将6维射线特征投影到编码器隐层维度；
- 在输入第一个Transformer块前加到patch令牌上；
- **保留原始RoPE位置编码不变**，RoPE负责图像平面局部空间推理，射线信号提供绝对3D定位，二者互补。

#### 跨视点一致性目标（Cross-view Alignment Objective）
- 以**夹爪视角（in-hand view）令牌**为锚点，因其最接近操作目标、背景干扰最少；
- 在骨干网络中间层提取类令牌，计算余弦相似度损失：
  $$\mathcal{L}_{cos} = 1 - \frac{1}{N-1}\sum_{v \in V} \cos(c_v, c_g), \quad \mathcal{L} = \mathcal{L}_{IL} + \lambda \mathcal{L}_{cos}$$
- 作为辅助正则项，与主策略学习损失相加（默认 $\lambda=0.01$，应用于第10层）。

## 3. 实验设计

### 3.1 仿真实验（RoboCasa基准）

- **数据集**：RoboCasa，真实厨房环境，**16个多任务**（涵盖抽屉开关、灶台开关、水龙头操作、咖啡制作、微波炉操作等多种操控技能）；
- **设置**：单策略多任务训练，每个模型训练50 epoch、3个随机种子，评估第30、40、50 epoch的最佳结果；每个任务评估50个episode；
- **扰动设置**：构建变体环境，将两个静态相机在方位角、仰角范围内随机旋转，并随机调整与参考装置的距离；
- **相机配置**：三视角（左、右、夹爪），以夹爪视角为对齐锚点。

### 3.2 对比方法

| 方法 | 描述 |
|---|---|
| **Adapt3R** | 将预训练2D语义特征与3D几何信息结合，用3D点定位语义线索 |
| **PMP-xyz / PMP** | 显式3D点图表示，PMP-xyz仅用点图特征，PMP将3D与2D语义令牌拼接 |
| **CamPose** | 同样使用射线图，但通过后期拼接方式融合，依赖多视角数据增强 |
| **RGB（图像-only变体）** | 无任何射线条件注入的纯RGB基线 |

### 3.3 真实机器人实验

- **平台**：Franka Panda七自由度机械臂；外部视角用ZED Mini立体相机，夹爪视角用Intel RealSense D405，图像分辨率256×256；
- **任务**：4个长时程真实任务——抽屉操作（Drawer）、插入（Insertion）、抓放（Pick Place）、叠杯（Cup Stack）；
- **数据集规模**：Drawer/Pick Place/Cup Stack各50条带语言指令的演示，Insertion为100条语言条件轨迹；
- **评估指标**：将每个任务分解为多个阶段，按完成阶段数计分（每阶段1分），每个模型每任务20次rollout；
- **扰动设置**：默认环境使用左相机+默认右相机+夹爪相机；变体环境将右相机替换为**位姿显著不同的扰动相机**。

### 3.4 消融与扩展实验

- **射线条件注入的效果**：有无辅助余弦损失 × 有无射线注入；
- **余弦损失应用层位置**：第6/8/10/12层对比；
- **无预训练权重的效果**：从零训练（scr）；
- **跨骨干迁移性**：将骨干换为EUPE（Efficient Universal Perception Encoder）。

## 6. 论文的主要结论与发现

1. **将相机几何注入预训练ViT可显著提升视点鲁棒性**：无需多视角增强或额外传感器，即可在相机扰动下保持策略性能。RayViT相比RGB基线在RoboCasa扰动设置下平均成功率**提升13个百分点以上**（37.3% vs 24.0%），且性能下降仅2.5个百分点（RGB基线下降18.5个百分点）；
2. **射线条件类令牌和射线位置嵌入共同作用**：仅用射线类令牌（RayViT-cls）即可大幅提升鲁棒性；进一步加入patch级射线嵌入（RayViT）在两个设置中表现略有差异（仿真中RayViT-cls默认设置更好，真实中RayViT更强）；
3. **跨视点一致性目标依赖几何感知表示**：余弦相似度损失仅在令牌已携带几何信息时有效，对纯RGB基线无稳定增益；在**更深层**（第10-12层）应用效果最好；
4. **优势不依赖预训练权重**：从零训练时，几何感知表示仍优于纯图像表示；
5. **方法可迁移至不同预训练ViT骨干**：在EUPE骨干上同样有效，且RayViT（全注入）在EUPE上优于RayViT-cls；
6. **显式3D表示（如PMP-xyz）不足以解决视角鲁棒性**：仅依赖密集型几何，不显式建模相机诱导变换，仍会在相机扰动下显著退化。

## 7. 优点

1. **轻量高效**：新增参数仅约4M（0.15M投影 + 3.85M门控注意力），在保持预训练ViT结构不变的前提下完成几何注入；
2. **无需额外传感器**：仅需相机内外参计算射线图，成本低、实用性强；
3. **保持预训练分布一致性**：相比朴素拼接，门控机制和类令牌替换方式对预训练特征分布的干扰最小；
4. **显式利用3D几何但不依赖重建**：避免了传统3D表示中点的密度、噪声和尺度不一致问题；
5. **与RoPE互补的设计**：保留图像平面局部推理（RoPE）的同时补充绝对3D定位，融合自然；
6. **辅助损失有明确前提与适用范围**：发现了几何感知表示是跨视点一致性约束有效的必要条件，提供了有价值的分析性洞见；
7. **验证充分**：仿真+真实、消融完整、含从零训练和骨干迁移等多角度验证；
8. **具备工程实用性**：所需标定工具成熟，工作量低，容易部署到现有系统。

## 8. 不足与局限

1. **仅覆盖ViT架构**：未考虑卷积类视觉骨干（如CNN/ResNet），适用范围有限；
2. **依赖多视角设置**：跨视点一致性目标需要至少两个视角且需要一个任务相关的锚点视角（夹爪视角），在单视角或稀疏视角场景下不适用；
3. **相机外参标定需求**：虽然标定工具成熟，但相比纯RGB方法仍增加额外工程负担；在标定误差较大时，射线图质量下降，对鲁棒性的影响未被量化分析；
4. **真实实验对比范围有限**：未与Adapt3R、PMP等显式3D方法在真实平台对比，结论的泛化性有所折扣；
5. **扰动范围有限**：相机扰动局限于一定范围的旋转和平移，未测试极端视角变化、光照变化与相机扰动耦合的复杂场景；
6. **与基线性能差异分析不足**：在默认相机设置下，RayViT与RGB基线性能接近（甚至部分任务略低），削弱了“几何注入总是有益”这一结论；
7. **任务类型局限**：主要在桌面级操控任务上评估，未验证在移动机器人或更复杂动态场景中的效果；
8. **缺少对失败模式的分析**：未讨论在哪些类型任务或扰动下方法仍会失败，以及失败的具体原因。
