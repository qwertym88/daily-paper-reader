## 摘要
线性规划（LP）公式为连续空间中的无限时域、无模型非线性最优控制提供了一种概念上优雅的方法。然而，除了维度灾难之外，其实际使用还受到难以一致获得有界解的限制。在这项工作中，我们使用矩匹配技术来推导出基于可用数据集和LP成本向量的充分有界性条件。此外，我们讨论了非线性系统和多项式特征的实际设计方法。

## Abstract
Linear programming (LP) formulations offer a conceptually elegant approach to infinite-horizon, model-free nonlinear optimal control in continuous spaces. However, in addition to the curse of dimensionality, their practical use is limited by the difficulty of consistently obtaining bounded solutions. In this work, we use moment-matching techniques to derive sufficient boundedness conditions in terms of the available dataset and the cost vector of the LP. Moreover, we discuss practical design methods for nonlinear systems and polynomial features.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想

- 将数据驱动 LP 的有界性问题归结为**对偶可行性**问题。利用线性规划对偶理论，原 LP 有界当且仅当对偶 LP 可行，即有界性等价于成本向量（由测度 c 决定）落在数据矩阵 Φ 的列的**锥包**中。
- 与传统“先固定测度 c，再检查有界性”的思路相反，本文**由数据出发反向设计成本向量**，使其自动落入有界方向锥内，从而保证解有限。

### 关键技术细节（公式与流程）

1. **数据驱动 LP 构造**（公式 6）：
   - 将 Q 函数限制在有限维基函数空间：q(z) = αᵀϕ(z)；
   - 从系统中采样 N 个数据元组 (xi, ui, x⁺ᵢ, ℓᵢ)，构建数据矩阵 Φ = [ϕ(z₁)−γϕ(z⁺₁) ... ϕ(zₙ)−γϕ(z⁺ₙ)] 和成本向量 ℓ；
   - 得到 LP：max αᵀ∫ϕ(z)c(dz)，s.t. Φᵀα ≤ ℓ。

2. **有界性充要条件（定理 1）**：
   - 原始 LP (6) 有有限解 **当且仅当** 存在 λ ≥ 0 使得 ∫ϕ(z)c(dz) = Φλ。
   - 几何解释：成本向量必须落在数据矩阵 Φ 的列向量的锥包中。

3. **多项式特征的矩匹配条件**：
   - 对于多项式特征 ϕ(z) = vec(p(z)p(z)ᵀ)（命题 1），有界性条件转化为构造一个正半定的矩矩阵。
   - 对于二次特征（命题 2）：由于 truncated moment problem 存在充要条件，有界性等价于存在 λ ≥ 0 使得 mat(Φλ) ⪰ 0。
   - 对于高次多项式（命题 3，**一般实用方案**）：引入辅助数据矩阵 ΦA = [ϕ(y₁) ... ϕ(y_M)]（y 为辅助采样点），要求 mat(Φλ) = mat(ΦAμ)（λ, μ ≥ 0）。该等式等价于将成本向量匹配到辅助数据构造的矩矩阵，因此得名 **moment-matching**。该条件只需求解线性可行性问题，可操作性强。

4. **有界成本向量的求解流程**：
   - 在数据下求解命题 3 的线性可行性问题（同时归一化 ‖λ‖₁ = 1 避免零解）；
   - 得到满足条件的成本向量 Φλ（即 ΦAμ）；
   - 将该成本向量代入 LP (6) 求解，即可保证有界解。

5. **闭环策略提取（命题 4）**：
   - 对 quad-in-u 多项式函数 q(x,u) = [p(x); u]ᵀQ[p(x); u]，若 Quu ≻ 0，则贪婪策略具有闭式解 π(x) = −Q⁻¹_uu Qᵀ_xu p(x)。

## 8. 缺点与局限性

1. **框架依赖多项式特征假设**：所有有界性设计（命题1-3）均建立在特征为多项式函数的假设上。对于非多项式基（如RBF、神经网络特征），矩匹配条件的构造和验证方式不再适用，限制了方法的通用性。

2. **仅保证有界性，不保证最优性**：矩匹配方法只解决了LP解的存在性和有限性，并未提供关于解与真实最优Q函数或最优策略之间误差的定量上界。实验中的性能验证是经验性的，缺乏理论收敛性保证。

3. **辅助采样点设计缺乏指导**：辅助数据矩阵ΦA的采样点y如何选择、需要多少M才能确保可行性，论文仅给出实验范围，未提供理论下界或自适应选择策略。M过小可能导致条件过紧，过大则增加计算负担。

4. **与正则化方法的对比缺失**：尽管论文批评了正则化方法的畸变问题，但未在实验中直接与正则化LP（如L1/L2惩罚）进行有界性、解质量和算力对比，削弱了对方法优势的客观论证。

5. **未考虑噪声与模型偏差**：所有实验和理论均基于精确的转移样本和成本值。若系统存在随机噪声、数据采集误差或成本函数不确定性，矩匹配条件的可行性和解的鲁棒性未得到分析。

6. **闭环稳定性缺乏严格保证**：虽然仿真显示策略能稳定非线性系统，但论文未从理论上证明提取的策略具有稳定性或性能下界，仅停留在数值验证层面。
