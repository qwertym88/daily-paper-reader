## 摘要
许多关于有限时域随机最优控制（包括协方差转向）的研究将控制策略参数化为状态历史仿射形式。这种参数化使得凸重构成为可能，从而提供了一种易处理的求解方法。然而，对先前状态依赖的必要性尚未得到充分证明。\textit{这种依赖是必要的，还是仅仅凸重构的产物？}我们证明这是一种可以无损去除的产物。给定状态历史仿射公式的最优解，我们构造一个在当前状态上仿射的确定性马尔可夫策略。我们证明，即使对于具有广泛使用的状态和控制安全约束的协方差转向问题，所合成的马尔可夫策略几乎必然产生与历史依赖策略相同的控制动作，因此也具有相同的状态轨迹、成本和矩。因此，历史依赖公式的每个最优解都允许无损马尔可夫变换。从几何上讲，历史依赖公式为凸性提升了策略空间，其最优解可以投影回马尔可夫策略空间。我们将分析扩展到输出反馈和风险价值成本的一种凸上界替代函数。

## Abstract
Many studies on finite-horizon stochastic optimal control, including covariance steering, parameterize control policies as state-history-affine. This parameterization enables a convex reformulation, thereby yielding a tractable solution method. However, the necessity of dependence on previous states has not been well established. \textit{Is this dependence necessary, or merely an artifact of the convex reformulation?} We show that it is an artifact that can be removed losslessly. Given an optimal solution of the state-history-affine formulation, we construct a deterministic Markovian policy which is affine in the current state. We show that, even for the covariance steering problem with a broad class of commonly used state and control safety constraints, the synthesized Markovian policy almost surely produces the same control actions as the history-dependent policy and therefore the same state trajectories, cost, and moments. Thus, every optimum of the history-dependent formulation admits a lossless Markovian transformation. Geometrically, the history-dependent formulation lifts the policy space for convexity, and its optimal solution can be projected back to the Markovian policy space. We extend the analysis to output feedback and a convex upper-bounding surrogate for value-at-risk costs.

## 1. 论文的核心问题与整体含义

- **研究背景**：协方差转向（Covariance Steering）是随机最优控制中的一类重要问题，目标是在有限时域内将随机系统的状态分布引导至期望分布，并常用于自主车辆路径规划、航天器控制、动态投资组合优化等不确定性下的决策场景。
- **核心问题**：现有研究通常将控制策略参数化为**状态历史仿射**（state-history-affine）形式（即当前控制依赖于全部历史状态），以换取问题的凸性重构。然而，这种对历史状态的依赖究竟是问题的本质需要，还是仅仅为了凸重构而引入的人为产物（artifact），此前未被严格回答。
- **整体含义**：本文证明，在满足"协方差单调"（covariance-monotonic）约束的一大类机会约束协方差转向问题中，**历史依赖是可以无损去除的**。任何状态历史仿射最优策略都可以被一个确定性马尔可夫策略（仅依赖当前状态）替代，且两者几乎必然产生相同的控制动作、状态轨迹、代价和统计矩。这意味着现有凸重构方法得到的最优解，本质上是对马尔可夫策略空间的一种"凸提升"，最优解可以无损地投影回马尔可夫策略空间。

## 2. 方法论

- **核心思想**：给定一个最优的状态历史仿射策略 πC，利用条件正交投影（协方差框架下的最小二乘投影）构造一个当前状态仿射的马尔可夫策略 πM，并证明两者之差在最优性条件下必须为零（几乎必然）。
- **关键公式与技术细节**：
  - 状态历史仿射策略：`uk = vk + Σᵢ₌₀ᵏ Kk,i (xi − E[xi])`
  - 马尔可夫策略：`πMk(xk) = vk + Hk(xk − E[xk])`
  - **Algorithm 1**：给定 πC 后，计算状态/控制协方差 {Px,k, Pu,k, Pux,k}，再计算马尔可夫增益 `Hk := Pux,k P†x,k`（Moore-Penrose 伪逆），输出 πM。
  - **Lemma 1**：误差项 `ek = δuk − Hkδxk` 满足 `E[ekδxk⊤] = 0`，且 `Pe,k = Pu,k − Pux,k P†x,k P⊤ux,k`。
  - **Lemma 2**：构造"混合策略" π′(k)（前 k 步用 πC，之后用 πM），推导状态/控制协方差的递推关系：`Px,t = P′x,t + Tt,k Pe,k T⊤t,k`，`Pu,k = P′u,k + Pe,k` 等。
  - **Lemma 3**：证明 π′(k) 的代价不高于 πC，且由协方差单调性保证可行性。
  - **Theorem 1**（核心定理）：通过从 k = N−1 到 0 的**反向归纳**，若 Pe,k ≠ 0，则 π′(k) 是严格更优且可行的可行解，与 πC 的最优性矛盾，从而强制 Pe,k = 0，即 `πCk = πMk a.s.`。
  - **Theorem 2**（更强结论）：当初始状态协方差 P0 ≻ 0 且过程噪声 GkGk⊤ ≻ 0 时，状态历史协方差 PX ≻ 0，最优增益矩阵 K 本身就是分块对角的，即 K = KM，无需后处理。
  - **输出反馈扩展（Theorem 3）**：利用 Kalman 估计的估计误差与估计值相互独立这一性质，将结论推广到仅能获得带噪测量（当前估计仿射）的情形。
  - **VaR 代理扩展（Proposition 1）**：对控制系统欧氏范数的 VaR 上界代理目标，构造的马尔可夫策略保持最优性，且协方差"不大于"原策略（P^M ⪯ P^C），但两者协方差轨迹可以不同。

## 3. 实验设计

- **场景与 benchmark**：数值实验基于经典的双积分器（double-integrator）协方差转向问题，采用 **Youla 参数化**（(11) 式）作为凸重构方法，使用 YALMIP 建模、MOSEK 求解。
- **三个实验情形**：
  1. **非退化约束情形（nondegenerate constrained case）**：N=20，P0 = diag(0.1, 0.1, 0.01, 0.01)，Gk = 0.01I₄，带两个状态机会约束（违反概率 5×10⁻⁴）。此情形 PX ≻ 0，适用于 Theorem 2。
  2. **限制 L 情形（restricted-L case）**：与情形 1 相同的动力学和约束，但将 Youla 变量 L 限制为分块对角矩阵，用于演示"限制解空间可能破坏马尔可夫等价性"。
  3. **奇异输出反馈情形（singular output-feedback case）**：仅含三维观测 Ck = [0₃ₓ₁, I₃]，Dk = 10⁻³I₃，初始协方差在估计先验和估计误差之间按 0.75/0.25 分配，使堆叠估计协方差奇异，适用于 Theorem 3。
- **评价指标**：三个归一化残差指标——δoff（增益矩阵非对角块大小）、δcond（验证等式 Pe,k = Pu,k − Pux,k P†x,k P⊤ux,k 的成立程度）、δsupp（验证 (K−KM)PX^{1/2} = 0 的成立程度）。
- **对比方法**：本文没有对比其他控制算法，而是对比三种情形下的马尔可夫等价性，并额外做了**求解器容差研究**（MOSEK 收敛容差从 10⁻⁴ 扫描到 10⁻⁹），以区分结构残差与数值求解精度导致的残差。

## 6. 论文的主要结论与发现

- **历史依赖是凸重构的伪影**：对于形如 (1) 的机会约束协方差转向问题，若约束满足协方差单调性（覆盖仿射机会约束、欧几里得范数机会约束、协方差不等式和均值等式约束等大多数实际安全约束），则状态历史仿射公式的任何最优解都可以通过 Algorithm 1 无损地转换为确定性马尔可夫策略，两者几乎必然产生相同控制动作、状态轨迹、代价和矩。
- **非退化情形下最优策略天然是马尔可夫的**：当初始状态和过程噪声协方差均为正定时，最优增益 K 自动为分块对角阵，无需任何后处理。
- **存储复杂度显著下降**：在线增益存储从 N(N+1)/2 个矩阵（O(N²)）降为 N 个矩阵（O(N)），且无需保留历史状态；离线求解的凸公式不受影响（后处理在求解之后进行）。
- **对凸重构的新理解**：批量凸公式（历史仿射）和协方差传播公式（马尔可夫）的差异可理解为"为凸性而提升解空间"的程度不同；历史仿射公式的解空间维度（N(N+1)mn/2）大于协方差传播公式（N(n+m)(n+m+1)/2）。
- **扩展结论**：结果可推广到输出反馈（Kalman 滤波在环）场景和 VaR 成本凸上界代理；此时马尔可夫策略保持最优，但协方差轨迹可以与原策略不同（最大特征值约束下存在不唯一性）。
- **限制解空间的警告**：若在凸变量（如 Youla 变量 L）上施加额外结构限制（如分块对角），可能将马尔可夫控制器排除在可行集之外，此时 Algorithm 1 恢复的策略不再等价，数值实验也证实了这一点。

## 8. 不足与局限

- **未证明全局最优性**：Theorem 1 只说明"状态历史仿射公式的每个最优解都允许一个等价的马尔可夫实现"，并未证明仿射策略在约束问题中具有全局最优性——非仿射策略是否可能更优仍是一个开放问题。
- **约束假设有一定局限**：所有结果依赖于协方差单调约束（Definition 1）。虽然该假设覆盖面广，但并非所有实际约束都满足（例如违反概率 ε > 0.5 的仿射机会约束不满足单调性）。
- **实验覆盖有限**：数值验证仅使用双积分器系统、有限时域（N=20）和特定约束参数，缺乏更复杂系统、更大规模问题和高维情形的验证；也未与其他求解方法（如直接马尔可夫策略的 SCP 方法）进行性能对比。
- **限制解空间情形的负面结果**：实验表明，若用户为了计算效率而限制凸变量结构（如分块对角 L），恢复的马尔可夫策略可能与原策略不等价且可能违反约束，但论文未给出在这种情况下如何安全恢复马尔可夫策略的补救方案。
- **VaR 扩展的协方差不唯一性**：Proposition 1 只保证代价相等和协方差偏序，不保证协方差轨迹一致；在依赖精确协方差轨迹的应用中需要额外注意。
