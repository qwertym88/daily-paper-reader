## 摘要
用于地震断层分割的神经网络通常借鉴计算机视觉和医学影像领域，这些领域在相对更大的标注数据资源下进行训练。在地球物理应用中常见的标注数据预算紧张的情况下，优化其架构并非易事。手动设计数据最优架构耗时，而经典神经架构搜索（NAS）则局限于手工设计的搜索空间和庞大的计算预算。我们提出了一种代理式NAS系统，其中由三个大型语言模型（Claude、GPT-5.1和Gemini 2.5 Pro）组成的小组对每个候选架构进行辩论直至达成一致共识，编写完整的PyTorch实现，进行交叉审查，并将其提交到自动化的验证-训练-评分循环中，该循环设有450K参数的硬性预算、保留或回滚的血统机制以及失败机制的记录。该系统直接在源代码上运行，而非预定义的操作菜单，在单个消费级GPU上运行，并且仅训练了八个候选模型。它发现了我们的模型：一个425K参数的编码器-解码器，具有条带池化瓶颈、挤压-激励门控、非对称单卷积解码器和特征金字塔融合颈部。在与所有基线相同的协议下，在源自Thebe断层数据集的部分上进行训练，它取得了所有测试模型中最高F1（0.578）和IoU，同时模型最小，性能优于已发表容量的U-Net（31M参数，F1 0.484）、DeepLabV3-ResNet50（39.6M，0.516）和Attention U-Net（1.83M，0.502）。搜索成本为101次LLM调用（约115万输入/39万输出token）和大约一个GPU天，使得共识门控的LLM小组成为领域特定架构发现的一种实用、低成本途径。

## Abstract
Neural networks for seismic fault segmentation are often borrowed from computer vision and medical imaging domains where they train under relatively much larger labeled data resources. Optimizing their architecture under tight labeled data budgets as are common in geophysical applications is not a trivial problem. Manually designing data-optimal architectures is time-consuming while classical neural architecture search (NAS) is restricted to hand-crafted search spaces and large compute budgets. We present an agentic NAS system in which a panel of three large language models (Claude, GPT-5.1, and Gemini~2.5~Pro) debates each candidate architecture to unanimous consensus, authors the complete PyTorch implementation, cross-reviews it, and submits it to an automated validate-train-score loop with a hard 450K parameter budget, keep-or-revert lineage, and a memory of failed mechanisms. Operating on source code rather than a predefined operation menu, the search ran on a single consumer GPU and trained only eight candidates. It discovered \ours{}: a 425K-parameter encoder-decoder with a strip-pooling bottleneck, squeeze-and-excitation gating, an asymmetric one-conv decoder, and a feature-pyramid fusion neck. Trained under a protocol identical to all baselines on sections derived from the Thebe fault dataset, it attains the highest F1 (0.578) and IoU of all models tested while being the smallest, outperforming a published-capacity U-Net (31M parameters, F1 0.484), DeepLabV3-ResNet50 (39.6M, 0.516), an Attention U-Net(1.83M, 0.502). The search cost 101 LLM calls ($\sim$1.15M input / 0.39M output tokens) and roughly one GPU-day, making consensus-gated LLM panels a practical, low-cost route to domain-specific architecture discovery.

## 1. 核心问题与整体含义

地震断层分割是地震解释中的关键任务，直接影响圈闭几何、流体运移和钻井风险评估。当前主流方法直接借用计算机视觉和医学影像领域的分割网络（如 U-Net、DeepLab），但这些模型通常在数百至数千张标注图像上训练，而地球物理应用中标注数据极为稀缺（本文使用的 Thebe 数据集仅有约 5.6% 像素属于断层）。因此存在两个核心矛盾：

- **手动设计架构耗时且难以数据最优**：针对地震数据的特殊结构（细长斜向断层、极端类不平衡、大尺寸切片导致 batch size 只能为 1）手动调架构需要大量专家经验。
- **经典神经架构搜索（NAS）不适用**：强化学习/进化方法需要训练上千个候选模型，可微分方法（如 DARTS）受限于人工定义的搜索空间，且全部需要巨大计算资源。

本文提出一种**共识门控的多智能体 NAS 系统**：由三个大型语言模型（Claude、GPT-5.1、Gemini 2.5 Pro）对候选架构进行辩论直至达成一致共识，自动编写完整 PyTorch 代码并交叉审查，在严格的参数预算和保留/回滚机制下迭代搜索。最终仅训练 8 个候选就发现了一个 425K 参数的紧凑网络，在相同协议下同时实现了**最小模型和最高精度**，表明 LLM 驱动的架构搜索可以成为低资源领域架构发现的实用、低成本路线。

## 2. 方法论

### 核心思想

将传统 NAS 的“离散操作枚举+控制器采样”替换为“LLM 直接在源代码上推理与编辑”。系统维护单一架构谱系，每一轮由 LLM 小组对当前父模型提出一个有理由的架构突变，并经过辩论、代码审查、自动验证、训练评分后才决定保留或回滚。搜索空间不预定义，模型可以发明新机制（例如条带池化瓶颈）。

### 搜索循环（Orchestrator）

- **初始化**：run 0 训练一个 1.49M 参数的参考基线（超出预算，但作为参照）。
- **每轮突变**：要求小组给出单个架构突变（ADD / REMOVE / CHANGE），并提供设计理由、预期参数量、与失败机制的区别等。
- **预训练验证器**：AST 解析并实例化代码，在 batch size 1 下对三种形状（256×256、400×800、600×1504）执行前向/反向传播，检查空间维度保持，并强制参数 ≤ 450K。验证不通过则不消耗 GPU。
- **训练与评分**：在 5 个固定截面上训练，3 次独立试验 × 5 次随机重启 × 300 epochs，每个试验取最佳重启得分；保留/回滚依据 3 次试验的**平均 F1**（而非最佳值），避免幸运种子。
- **保留/回滚**：若平均 F1 超过当前父代，则保留并成为新父代；否则回滚，并将该机制加入硬性禁令列表，小组后续不得再引入。
- **停止规则**：最多 15 轮突变，或满足停滞条件（最近三轮均超过基线均值，但运行最佳平均 F1 提升 < 0.01）。实际搜索在第 9 轮后由停滞规则终止。

### 辩论小组（Debate Panel）

- **PROPOSE 阶段**：三个模型各自独立输出结构化设计规格（名称、delta 变化、拓扑、机制、预计参数、与禁令差异、风险）。
- **DEBATE 阶段**（最多 4 轮）：每个模型点名批评其他两个提案，可以采纳对手设计，并投两票：ENDORSE（支持哪个规格）和 APPROVE（是否同意建）。共识要求三模型全部 APPROVE 且支持同一规格。
- **僵局处理**：若死锁，将分歧汇总为共同问题，重新提案（最多 6 次重启动）；若仍无共识，则该轮以零 GPU 成本放弃。
- **代码审查**：被支持模型编写完整实现，另外两个模型对照训练契约（接口、空间约束、batch-1 风险、超时风险）审查，最多两轮修改。

### 训练协议与损失

所有候选与基线均使用相同固定方案：Adam（lr=1e-3）、batch size 1、损失为类加权交叉熵（断层权重 15）加辅助图像重建 MSE，即 `L = CE_w + MSE`。每个网络同时输出分割头和重建头。搜索阶段使用 5 个固定截面做代理；最终比较时改用全部 100 个训练截面训练 60 epochs。

### 发现的架构

最终获胜的 **StripPool-UNet+FPN**（425,177 参数）是一个 U-Net 形编码器-解码器，包含四个关键设计：

- **窄全秩编码器**：5 个阶段，通道数 16/32/48/64/80，每个阶段两个 3×3 卷积 + GroupNorm + SiLU + SE 门控（reduction=8）。作者明确拒绝了深度可分离卷积（run 1 证明其回归），认为窄全秩滤波器更划算。
- **条带池化瓶颈**（H/16 处）：沿整行/整列平均池化，经 (3,1) 和 (1,3) 卷积混合，广播相加后经 sigmoid 作为门控。这能捕捉贯穿整个截面的长程横向上下文，且参数代价极低，而完整 ASPP 会超出预算。
- **非对称单卷积解码器**：每级使用 1×1 降维、双线性上采样、跳跃连接和单个 3×3 卷积 + SE，仅为编码器深度一半。理由：表示学习在编码器完成，解码器只需重新定位。
- **FPN 融合颈部**：四个解码尺度经 1×1 卷积统一为 16 通道，上采样至全分辨率后求和，再经一个 3×3 卷积细化；两个输出头都从融合图读取，所有解码级都有直接梯度路径。
