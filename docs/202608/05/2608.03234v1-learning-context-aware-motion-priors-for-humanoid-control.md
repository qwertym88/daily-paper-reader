## 摘要
运动先验为学习自然的人形行为提供了强大的指导。然而，现有方法通常从整个参考数据集中学习一个通用的、任务无关的先验，并在策略训练过程中统一应用。因此，该先验无法区分哪些参考动作与当前任务情境相关，可能提供不相关甚至冲突的指导。我们提出了情境感知运动先验（CMP），一种无需手动技能标签、数据集划分或单独技能发现阶段即可将通用运动先验适应于当前任务情境的框架。具体而言，CMP利用高优势策略回滚学习情境-动作兼容性，同时基于演示的目标函数使学习到的相关性保持对参考分布的忠实。生成的相关性分数重新加权参考监督，以训练一个轻量级的情境条件适配器。为了评估CMP的有效性和通用性，我们使用对抗运动先验和得分匹配运动先验两种方法进行实例化。在五项人形控制任务中，CMP一致地提升了任务性能和样本效率，学习了有意义的情境-动作对齐，并对不平衡的参考分布保持稳健。这些结果表明，将运动先验适应于任务情境为人形策略学习提供了更相关的指导。

## Abstract
Motion priors provide powerful guidance for learning naturalistic humanoid behaviors. However, existing methods typically learn a general, task-agnostic prior from the entire reference dataset and apply it uniformly throughout policy training. As a result, the prior cannot distinguish which reference motions are relevant to the current task context, potentially providing irrelevant or conflicting guidance. We present Context-Aware Motion Priors (CMP), a framework that adapts a general motion prior to the current task context without manual skill labels, dataset partitioning, or a separate skill discovery stage. Specifically, CMP learns context-motion compatibility using high-advantage policy rollouts, while a demonstration-based objective keeps the learned relevance grounded in the reference distribution. The resulting relevance scores reweight reference supervision for training a lightweight context-conditioned adapter. To evaluate the effectiveness and generality of CMP, we instantiate it with both Adversarial Motion Priors and Score-Matching Motion Priors. Across five humanoid control tasks, CMP consistently improves task performance and sample efficiency, learns meaningful context-motion alignment, and remains robust to imbalanced reference distributions. These results show that adapting motion priors to task contexts provides more relevant guidance for humanoid policy learning.

## 2. 方法论

### 核心思想

CMP 将参考分布的重加权视为核心操作。它学习一个相关性函数 \(R_\phi(c, x)\)，衡量任务情境 \(c\) 与参考动作序列 \(x\) 的兼容性，并用 softmax 归一化的权重 \(w_\phi(c,x)\) 对参考数据重新加权，形成**情境条件化的有效参考分布** \(q_\phi(x|c) = w_\phi(c,x)p_E(x)\)。这一重加权分布用于训练一个轻量级的情境条件适配器（adapter），而基础运动先验保持原有训练方式不变。

### 关键技术细节

**（1）相关性函数的设计**

- 采用对比学习框架：情境编码器 \(f_{\phi_c}\) 和动作编码器 \(g_{\phi_x}\) 分别提取嵌入向量。
- 相关性分数定义为两个 ℓ2 归一化嵌入的余弦相似度：
  \[
  R_\phi(c,x) = \frac{f_{\phi_c}(c)^\top g_{\phi_x}(x)}{\|f_{\phi_c}(c)\|_2 \|g_{\phi_x}(x)\|_2}
  \]
- 使用温度参数 \(\tau\) 缩放后取指数：\(s_\phi(c,x) = \exp(R_\phi(c,x)/\tau)\)。

**（2）双分支对比学习目标**

- **在线任务相关性分支（Online Branch）**：从策略回滚中筛选高优势（GAE > 0）的样本作为正样本对（情境-动作），并用优势值对正样本加权。损失为：
  \[
  \mathcal{L}_{on}(\phi) = -\frac{1}{|\mathcal{I}_{on}|}\sum_{i \in \mathcal{I}_{on}} \rho_i \log \frac{s_\phi(c_i, x_i)}{\sum_{j} s_\phi(c_i, x_j)}
  \]
  其中 \(\rho_i = \sigma(\hat{A}_i/\beta_{adv})\)。
- **演示正分支（Demonstration-positive Branch）**：由于在线探索可能没有完全覆盖参考数据集中包含的行为，额外引入一个分支，将参考动作视为正样本、在线动作视为负样本，将情境嵌入锚定到参考分布的支持集上：
  \[
  \mathcal{L}_{demo}(\phi) = -\frac{1}{B}\sum_i \log \frac{\sum_{x_E \in \mathcal{B}_E} s_\phi(c_i, x_E)}{\sum_{x \in \mathcal{B}_E \cup \mathcal{X}_{on}} s_\phi(c_i, x)}
  \]
- 最终权重裁剪到 \([w_{min}, w_{max}]\) 范围保证训练稳定性。

**（3）与 AMP 的集成（CMP-AMP）**

- 基础 AMP 判别器输出 logit \(l_\theta(x)\) 保持冻结（stop-gradient），以残差形式叠加适配器输出：
  \[
  l_{\theta,\psi}(c,x) = sg[l_\theta(x)] + \lambda_{res}\Delta l_\psi(c,x)
  \]
- 参考侧损失为加权的二分类交叉熵（权重来自相关性模型），策略侧保持标准负项。
- 新损失函数 \(L_{+}^{AMP}(\psi)\) 和 \(L_{-}^{AMP}(\psi)\) 结合得到最终的适配器目标。

**（4）与 SMP 的集成（CMP-SMP）**

- 预训练扩散去噪器 \(\epsilon_\theta(\tilde{x}_t, t)\) 保持冻结，仅训练残差去噪适配器 \(\Delta\epsilon_\psi(c, \tilde{x}_t, t)\)。
- 参考侧损失为加权噪声预测误差，另加残差正则化项防止适配器过度覆盖基础先验。
- 训练时用 \(sg[\bar{w}_\phi]\) 阻止梯度回传到相关性模型和基础先验。

**（5）适配器训练的通用公式**

CMP 的适配器损失采用一般形式：
\[
\mathcal{L}_{adapt}(\psi|\theta,\phi) = \mathbb{E}_{c\sim d^\pi, x\sim p_E}\left[ sg[\bar{w}_\phi(c,x)] \cdot \ell_{adapt}^\psi(c,x;\theta) \right]
\]
即对参考侧的适配器损失按相关性权重加权。

## 6. 主要结论与发现

### 性能提升

CMP 在全部五个任务上一致超越基础先验（AMP 和 SMP）：

- **CMP-AMP 相对 AMP**：最终测试回报提升约 7.8%–59.7%（各任务不同），样本效率提升 1.4–2.5 倍（四个任务达到阈值速度提升，Steering 与 AMP 持平）。
- **CMP-SMP 相对 SMP**：最终回报小幅但一致的提升（约 1.8%–6.4%），样本效率多数任务也有改善。

### 情境-动作对齐

- 相关性权重随训练进程从"无差别偏好走路"演化为"情境区分"：目标近时偏好长距步行，远时偏好快速跑，侧向/背后目标偏好对应方向的跑步动作。
- 演示正分支将情境嵌入锚定在参考分布支持集内，显著改善动作检索质量：无该分支时 FF（远前方）情境在 PCA 投影中成为离群点，检索结果也与情境不符。

### 消融发现

- 仅增加适配器容量（Uniform Adapter）不足以解释性能提升；打乱权重对应关系会显著降低样本效率并增大方差；移除演示正分支也会拖慢学习。说明**保持情境-动作对应关系的意义**和对参考支持集的锚定都至关重要。

### 不平衡鲁棒性

- 步行动作重复 ×100 时，AMP 回报下降 11.5%，而 CMP-AMP 仅下降 2.8%，最终回报 454 vs 361。

## 7. 优点

### 方法层面

- **模块化设计**：CMP 与基础先验解耦，可无缝集成到不同先验（AMP、SMP）中，无需改变基础先验的训练方式。
- **免标注、免划分**：无需手工技能标签、数据集分区或独立技能发现，直接从策略经验中学习相关性。
- **重加权视角清晰**：将参考数据使用方式从"统一采样"推广为"情境条件化软加权"，理论上有明确的等价关系（加权训练 ≈ 从有效分布采样）。
- **双分支对比学习设计巧妙**：在线分支捕捉任务相关性，演示分支保证对参考分布的支持——两者互补，解决在线探索不充分的问题。
- **轻量级适配器**：只增加少量参数（256 维隐藏层），计算开销小；输出零初始化保证训练初期不破坏基础先验行为。

### 实验层面

- 方法在两种形态（标准人形、G1）、两种运动先验、五个任务上验证，通用性较好。
- 不平衡压力测试设计现实且结论鲜明。
- 除数值指标外，还提供定性可视化（时间对齐快照）、相关性权重热力图、PCA 投影和动作检索示例，解释性强。

## 8. 不足与局限

### 方法本身的局限

- **受限于参考数据集的支持范围**：CMP 无法恢复参考数据中不存在的任务相关行为——若某种情境所需动作在数据里完全没有，则无论权重如何调整都无法提供有效指导。
- **依赖策略优势信号**：相关性学习依赖 GAE 估计，Critic 误差会直接影响相关性质量；探索不足时高优势样本可能不具代表性。
- **对比学习以余弦相似度为度量**：对动作序列的语义区分能力有限，复杂情境（如多物体交互）下可能不足。

### 实验覆盖的局限

- **仅限结构化情境**：任务情境都是向量化的小维度量（目标位置、速度指令、球状态），未验证高维感知输入（像素、点云）。
- **仅限仿真环境**：未进行真实机器人部署验证；仿真到现实的迁移问题未讨论。
