## 摘要
Koopman算子理论利用状态和输入可观测量中的线性项与双线性项来表示非线性系统，极大地简化了控制器设计。然而，将输入约束纳入基于Koopman的控制器综合仍然具有挑战性，限制了其在跟踪等约束控制任务中的适用性。本文提出了一种约束Koopman控制参数化（cKoCoP）框架，用于综合状态反馈控制器，使其在满足给定输入约束的同时，保证所辨识的提升闭环系统具有Lyapunov意义下的稳定性。cKoCoP通过观测变量线性反馈提供非线性状态反馈，从而能够采用线性控制器设计方法。所提出的控制器通过凸优化获得：我们利用S-过程或基于Farkas引理的条件，纳入椭球或多面体输入约束。我们还引入了一种用于轨迹跟踪并考虑输入约束的控制Lyapunov函数（CLF）。该方法在两个典型非线性系统——双摆和独轮车——上进行了验证，展示了在遵守输入约束的同时实现数据驱动跟踪。实验验证了该方法对测量噪声的鲁棒性，以及相对于Koopman模型预测控制（KMPC）基线在运行时间上的改进。结果表明，cKoCoP在显著降低在线计算成本的同时实现了具有竞争力的跟踪性能，支持其在实时约束跟踪应用中的潜力。

## Abstract
Koopman operator theory represents nonlinear systems with linear and bilinear terms in the state and input observables, greatly simplifying control design. However, incorporating input constraints into Koopman-based controller synthesis remains challenging, limiting their applicability to constrained control tasks such as tracking. This paper develops a constrained Koopman Control Parametrization (cKoCoP) framework for synthesizing state-feedback controllers that satisfy prescribed input constraints with Lyapunov-certified stability of the identified lifted closed loop. The cKoCoP offers nonlinear state-feedback via linear-in-observables feedback, enabling linear controller design. The proposed controller is obtained through convex optimization: we incorporate ellipsoidal or polytopic input constraints with the S-procedure or Farkas-lemma-based conditions. We also introduce a Control Lyapunov Function (CLF) for trajectory tracking which incorporates input constraints. The approach is validated on two canonical nonlinear systems, a double pendulum and a unicycle, demonstrating data-driven tracking while respecting input constraints. Experiments validate the method's robustness to measurement noise, and runtime improvements over Koopman Model Predictive Control (KMPC) baselines. The results demonstrate that cKoCoP achieves competitive tracking performance with substantially reduced online computational cost, supporting its potential for real-time constrained tracking applications.

## 1. 核心问题与整体含义

- **背景**：Koopman 算子理论可将非线性系统提升到高维（可观测）空间，用线性/双线性模型近似，从而复用线性控制设计工具（如 LQR、MPC）。但实际机器人系统普遍存在执行器饱和，而将输入约束纳入 Koopman 控制器综合仍很困难。
- **核心问题**：现有 Koopman 控制多采用 MPC，需在每个控制步求解有限时域优化，在线计算负担重；且原始 Koopman 控制参数化（KoCoP）只针对原点镇定，不考虑执行器限制。如何**离线凸综合**一个满足输入约束、具有 Lyapunov 稳定性认证、并能跟踪非零/时变参考的 Koopman 状态反馈控制器，是本文要解决的问题。
- **整体含义**：论文提出 cKoCoP 框架，用“线性于可观测量的反馈”实现非线性状态反馈，把椭球/多面体输入约束通过 S-procedure 或 Farkas 引理转化为凸约束，并引入前馈项与 CLF 在线优化实现约束跟踪。其意义在于：以显著低于 KMPC 的在线计算成本，实现数据驱动的约束跟踪，为实时应用提供可行路径。

## 2. 方法论

### 2.1 双线性 Koopman 模型与控制器参数化

- 考虑控制仿射离散系统 \(x_{t+1}=F(x_t)+G(x_t)u_t\)，采用双线性 Koopman 表示：
  \[
  \psi_{x,t+1}=K_{xx}\psi_x+K_B u+K_{xu}(S\psi_x\otimes u)
  \]
  其中 \(K_{xx}\) 为漂移项，\(K_B\) 为线性输入项，\(K_{xu}\) 为状态-输入交叉项，\(S\) 为选择矩阵以控制 Kronecker 积维度。
- 设计**线性于可观测量的反馈** \(u=K_u\psi_u\)，并假设存在矩阵 \(H,C\) 使
  \[
  S\psi_x\otimes\psi_u=H\psi_x,\qquad \psi_u=C\psi_x
  \]
  从而得到提升空间闭环：
  \[
  \psi_x^+=\tilde K\psi_x,\quad \tilde K=K_{xx}+K_BK_uC+K_{xu}(I\otimes K_u)H
  \]
- 该结构使非线性状态反馈转化为对 \(K_u\) 的线性/双线性设计问题。

### 2.2 系统辨识

- 用随机控制器采集状态-输入数据，构造提升数据集。
- 先最小二乘辨识 \(C\)；再假设初始全选 \(S\)，拟合 \(H\)，按逐块残差阈值 \(\epsilon_{th}\) 关闭不显著的选择项并重新拟合 \(H\)；最后联合最小二乘辨识 \(K_{xx},K_B,K_{xu}\)。

### 2.3 稳定性综合与双凸性处理

- 选取二次 Lyapunov 函数 \(V(\psi_x)=\psi_x^\top P\psi_x\)，通过 Schur 补得到约束：
  \[
  \begin{bmatrix}P&P\tilde K\\ \tilde K^\top P&\lambda P\end{bmatrix}\succeq0,\quad \lambda\in[0,1)
  \]
- 该问题对 \((P,K_u,\lambda)\) 是双凸的。论文采用**交替凸搜索（ACS）**：
  - 固定 \(K_u\)，对 \(\lambda\) 做二分搜索并求解 SDP 更新 \(P\)；
  - 固定 \(P\)，求解 SDP 更新 \(K_u\)；
  - 交替迭代直至收敛。
- 初始可行 \(P\) 由随机矩阵经解码算子投影并加正则项构造。

### 2.4 输入约束的凸嵌入

- 目标条件为：\(\psi_u\in\mathcal P_\psi\Rightarrow K_u\psi_u\in\mathcal P_u\)。
- **椭球约束**：若 \(\psi_u^\top Q_\psi\psi_u\le q_\psi\Rightarrow u^\top Q_u u\le q_u\)，由 S-procedure 得存在 \(\tau\ge0\)：
  \[
  \tau Q_\psi-K_u^\top Q_uK_u\succeq0,\quad q_u-\tau q_\psi\ge0
  \]
  再用 Schur 补转为 LMI，与稳定性约束联合求解。
- **多面体约束**：若 \(\mathcal P_\psi=\{A\psi_u\le b\}\)、\(\mathcal P_u=\{Gu\le g\}\)，由 Farkas 引理得存在 \(Z\ge0\)：
  \[
  GK_u=ZA,\quad Zb\le g
  \]
  这是线性约束，计算更快。
- **状态空间约束的转换**：
  - 椭球状态集：对落入状态椭球的提升数据拟合**最小体积椭球**，作为提升空间约束的外近似。
  - 多面体状态集：可用逐特征 min/max 的 box 近似；或提出基于数据的**鲁棒线性规划**，用对偶变量 \(z_j,\lambda_j\) 得到更紧的约束：
    \[
    z_j^\top b+\lambda_j\le g_j,\quad X^\top A^\top z_j+\lambda_j\mathbf1\ge\psi^\top K_u^\top G_j^\top,\quad z_j\ge0
    \]

### 2.5 非零平衡点镇定与前馈

- 控制律扩展为
  \[
  u_t=K_u(\psi_{u,t}-\psi_{u,t}^{ref})+k_{ff}
  \]
- 对常值参考，利用平衡点方程推导误差动态，取 \(k_{ff}=u_{ref}\) 可消去残差项，得到
  \[
  e_{x,t+1}=\bar K(\psi^{ref},k_{ff})e_{x,t}
  \]
- 若 \(u_{ref}\) 未知，可由 Koopman 逆动态伪逆估计；若平衡点已知，还可把平衡点约束加入辨识，减少稳态误差。
- 若某参考点下闭环不稳定，可用新的 \(\bar K\) 重新设计 \(K_u\)。

### 2.6 基于 CLF 的时变轨迹跟踪

- 在线求解以 \(k_{ff}\) 为变量的优化：
  \[
  \min_{k_{ff}}\ \|k_{ff}\|_2^2+\gamma\delta
  \]
  约束一步 Lyapunov 下降 \(V(e_{x,t+1})-\lambda V(e_{x,t})\le\delta\)，\(\delta\ge0\) 为松弛变量，并施加输入约束。
- 对固定当前状态，误差下一步对 \(k_{ff}\) 是线性的：
  \[
  e_{x,t+1}=A_{ff}(\psi_{x,t})k_{ff}+b_{ff}(\psi_{x,t})
  \]
- 多面体约束下为二次规划（QP）；椭球约束下为二次约束二次规划（QCQP）。前者仅加线性约束，通常更快。
- 在线约束被写成对全部状态成立的硬约束 \(u\in\mathcal P_u\)，比原始的“条件包含”更强。

### 2.7 整体算法流程

- 离线：选观测字典 → 采数据 → 辨识 \(C,H,S\) → 辨识 \(K_{xx},K_B,K_{xu}\) → 求解带约束 SDP 得 \(K_u,P\)。
- 在线：常值参考用前馈 \(k_{ff}\)；时变参考每步解 CLF-QP/QCQP 得 \(k_{ff,t}\)，施加 \(u_t=K_u(\psi_{u,t}-\psi_{u,t}^{ref})+k_{ff,t}\)。

- **方法组合具有系统性**：双线性 Koopman 模型、线性于可观测量的反馈参数化、S-procedure/Farkas 引理约束嵌入、ACS 双凸求解、前馈镇定与 CLF 在线跟踪共同构成较完整的离线-在线流程。

- **计算优势明显**：常值参考下仅需一次前馈计算；时变参考下每步求解 QP/QCQP，通常显著快于滚动求解 KMPC，适合高频实时场景。

### 6.2 关键假设与潜在脆弱性

- **模型结构假设较强**：\(S\psi_x\otimes\psi_u=H\psi_x\) 与 \(\psi_u=C\psi_x\) 要求输入观测量与状态观测量之间存在线性关系，且交叉项可由固定 \(H\) 精确表示；对复杂执行器非线性或观测字典选择不当的情形，该假设可能带来较大建模误差。
- **闭环稳定性依赖提升模型精度**：Lyapunov 认证是在辨识得到的双线性 Koopman 模型上完成的，未显式考虑辨识误差、噪声与扰动；因此“稳定性认证”主要对名义模型成立，真实系统上的鲁棒性缺乏理论保证。
- **ACS 为局部方法**：双凸问题的交替求解不能保证全局最优，结果依赖初始化与迭代路径；论文未给出收敛到可行解的成功率、迭代次数分布或失败回退策略。
- **约束处理偏保守**：将“条件包含”强化为对提升空间约束集内所有状态成立的硬约束，并用最小体积椭球/box/鲁棒 LP 外近似状态集，可能牺牲可行域与跟踪性能；在线 CLF 约束在强参考或大初始误差下可能不可行，松弛变量 \(\delta\) 仅能缓解而不能保证硬输入约束与下降条件同时满足。
- **参考跟踪的适用范围受限**：前馈项基于平衡点方程与 Koopman 逆动态估计，常值参考较自然；对快速时变参考，一步 CLF 下降条件可能过于短视，且参考观测量需与训练分布一致。
- **可扩展性证据不足**：观测维度仅 13/6 量级，未报告 SDP 规模、求解时间随维度增长情况；高维字典下 SDP 与在线 QCQP 的成本可能成为新瓶颈。

### 6.3 与现有工作的关系

- 相对于 Koopman MPC，本文以离线综合换取在线轻量计算，但牺牲了 MPC 的预测能力与在线约束处理灵活性；在强非线性、参考突变或模型失配下，KMPC 可能仍具优势。
- 相对于原始 KoCoP，本文增加了输入约束、非零平衡点前馈与时变跟踪，但稳定性仍建立在二次 Lyapunov 函数与固定反馈结构上，尚未覆盖输出反馈、部分观测或鲁棒/随机 Koopman 情形。
- 与安全控制中的 CBF/CLF-QP 思路相比，本文的 CLF 仅用于前馈修正，闭环主反馈固定；这降低了在线负担，但也限制了对大扰动和约束紧变化的适应能力。

## 7. 结论、启示与后续方向

- **结论**：cKoCoP 提供了一条“数据驱动双线性 Koopman 模型 + 离线凸综合约束状态反馈 + 在线轻量前馈/CLF 修正”的约束跟踪路径。仿真结果表明，其在双摆与独轮车上能以明显低于 KMPC 的在线成本实现设定点镇定与轨迹跟踪，并具备一定的噪声/扰动容忍度；但其稳定性与约束保证主要针对名义提升模型，实验证据仍以仿真和有限任务为主。
- **实践启示**：若目标平台计算资源受限、参考轨迹较平滑且系统可由中等维观测字典较好描述，cKoCoP 是 KMPC 的有力替代；部署时应重点校核观测字典、约束外近似保守度、ACS 初始化与在线 QP 可行性回退机制。
- **后续方向**：引入辨识误差与扰动的鲁棒/分布鲁棒约束；发展输出反馈与部分观测 Koopman 控制；将 ACS 替换为全局或更可靠的雙凸求解策略；系统报告离线 SDP 与在线 QP 的规模-耗时曲线；在真实机器人上验证执行器饱和、延迟与摩擦下的性能；补充统计重复性、消融实验与更严格的 MPC 调参基准。
