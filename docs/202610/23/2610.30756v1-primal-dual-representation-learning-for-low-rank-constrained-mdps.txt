## Abstract 

Representation learning has substantially improved the efficiency of unconstrained continuous-state Markov Decision Processes (MDPs), but its extension to Con-strained MDPs (CMDPs) is difficult because the transition representation must be learned while constraint violation is controlled. In this paper, we study represen-tation learning for low-rank CMDPs with continuous state spaces, and propose REP-PD-TEG for the soft cumulative-violation setting. In the feature learning period, the algorithm interacts with the environment using a decaying-ϵ-greedy mixture execution policy, and uses the collected samples to learn transition features by maximum likelihood. Based on the learned features, it constructs uncertainty bonuses and plans with an optimistic Lagrangian objective to obtain the return policy. We prove regret and soft-violation guarantees for the return policies, and quantify the influence of the decaying-ϵ-greedy exploration. In particular, REP-PD-TEG achieves the optimal eO(√K) return policy bound, and gives a eO(K3/4)

overall sample bound when exploratory actions are charged. For the stricter hard cumulative violation, where feasibility must be verified episode by episode, we propose REP-PD-H-TEG. It plans under a bonus-corrected lower-confidence utility certificate with the learned representation, and performs a stabilized dual search to obtain the return policy, yielding regret and hard-violation bounds. Together, these results give the first theoretically guaranteed representation-learning method for low-rank continuous-state CMDPs with both soft cumulative guarantees and certified hard-violation control. 

## 1 Introduction 

Constrained Markov Decision Processes (CMDPs) provide a principled framework for constrained reinforcement learning with both reward objectives and safety requirements [4, 22]. This framework is especially relevant in safety-critical domains, and a growing line of provably constrained RL algorithms has been developed within this framework [8, 9, 16, 24, 27, 39]. These works primarily focus on the tabular setting, where guarantees scale with the cardinality of the state space and become unsuitable for continuous or high-dimensional environments. Linear CMDP methods [5, 13, 17, 18, 26, 42] partially address this issue by assuming that transitions are linearly represented by known low-dimensional features, yielding state-dimension-independent bounds. However, existing tabular/linear CMDP methods all rely on a priori knowledge of the latent feature representations. In the absence of such prior feature knowledge, their guarantees no longer apply, leaving CMDPs with unknown features insufficiently addressed. Representation learning has been effective for discovering low-dimensional transition features in unconstrained MDPs [2, 29, 31, 36, 37, 41, 44]. Extending this idea to CMDPs is more challenging because representation error now affects both reward optimization and constraint evaluation. The

This creates a coupling between representation coverage and constraint-aware policy optimization that is absent from unconstrained low-rank RL and is not handled by existing CMDP results with known features. In this paper, we develop primal-dual representation-learning algorithms for low-rank continuous-state CMDPs with unknown transition features. During feature learning, the algorithms interact with the environment via an ϵ-greedy mixture execution policy and use the collected samples to learn transition features by maximum-likelihood estimation (MLE). For soft violation criterion, where only the total constraint shortfall across episodes is charged, our algorithm, REP-PD-TEG, uses the learned features to construct uncertainty bonuses, and plan with the bonus-augmented Lagrangian objective that couples reward maximization, utility optimization, and exploration. The algorithm outputs the return policies with a primal-dual update, and admits both return-policy and execution-policy guarantees. For the stricter per-episode hard-violation metric, where each episode’s shortfall is charged separately, we develop REP-PD-H-TEG, which keeps the representation-learning procedure but plans under a tight lower-confidence utility certificate and conducts a stabilized dual search to obtain the return policy. Specifically, we make the following contributions: • We propose the first theoretically guaranteed representation-learning method for low-rank continuous-state CMDPs with unknown features. Starting from the occupancy of the current return policy, it uses ϵ-greedy auxiliary probes for action coverage, fits transition features by MLE, and constructs a merged-covariance uncertainty bonus. We quantify the effect of decaying-ϵ exploration for both return and execution policies. • For the aggregate soft-violation criterion, we propose REP-PD-TEG, which updates the return policy through an optimistic Lagrangian whose reward and dual-weighted utility terms are both bonus-augmented based on the learned features. We show that REP-PD-TEG achieves return policy regret and soft violation of order ˜O(K1/2+ p) sample complexity under the schedule ϵk = k−p, where ϵk is the exploration level in episode k. In particular, this recovers the optimal ˜O(√K) return policy rate when p = 0 , which corresponds to uniform auxiliary probing over actions during the whole procedure. We also prove an execution policy overall bound: executing the ϵk-greedy exploration adds O(K1−p) complexity, and the balanced choice p = 1 /4 yields a ˜O(K3/4) execution policy regret and soft violation up to problem-dependent factors. • For the stricter per-episode hard-violation criterion, we propose REP-PD-H-TEG, which uses the learned features to conduct a stabilized dual search and certifies feasibility through a bonus-corrected lower-confidence utility certificate. For return policies, we obtain regret of order ˜O(K3/4+ p) and hard violation of order ˜O(K1/2+ p); taking p = 0 again gives uniform probing and the clean ˜O(√K) hard-violation dependence. For execution policies, we show that the cost of ϵk-greedy exploration is also O(K1−p) and choosing p = 1 /8

gives a ˜O(K7/8) regret and hard violation up to problem-dependent factors. Appendix H provides the empirical study of REP-PD-TEG on a simulated job-scheduling task. Besides, we also implement an approximate neural network version of REP-PD-TEG on the Safety Gym task to validate the effectiveness of our representation learning procedure for a complex state-action space. 

Remark on the probing schedule. In tabular and linear CMDPs, the state or feature representation is known, so the analyzed policy is the execution policy. In low-rank CMDPs, the transition features must be learned online, and auxiliary ϵk-greedy probing is needed to obtain coverage over the state-action space for representation learning. This creates a distinction between the return-policy sequence and the execution policy. The latter is especially relevant in constrained RL because exploratory behavior can incur real training-time costs—for example, robot collisions or excessive contact forces—even when the final return policy is safe. 1.1 Related Work Provably Constrained RL CMDPs provide a rigorous framework for safe RL, balancing reward maximization with cumulative cost constraints [4, 19]. Several practical constrained RL methods have been developed on this foundation, including policy-gradient, Lagrangian, shielding, and model-based approaches [1, 6, 7, 11, 21, 35]. On the theoretical side, there has been a growing body of work on provably safe reinforcement learning. Many works [8, 9, 14, 16, 24, 25, 27, 39] consider the tabular setting. Among the best known regret and constraint-violation guarantees are of order 

˜O(√K) [16, 27]. However, their polynomial dependence on the cardinality of state space |S| makes them unsuitable for large or continuous state spaces. Recent advances in linear CMDPs [5, 13, 17, 18, 26, 30, 42, 43] achieve dimension-independent sample complexity by assuming known low-dimensional features ϕ⋆(s, a ). They enforce safety through confidence intervals, optimistic bonuses, primal-dual updates, pessimistic constraints, or safe baselines. However, their reliance on predefined latent features, assumed to be known a priori or handcrafted, limits applicability when transition structures are unknown and must be learned from data. Our setting instead has unknown latent features that must be learned online. To our knowledge, the only prior work on low-rank CMDPs is [20], which studies the sample complexity of identifying a near-optimal feasible policy after training. In contrast, our work analyzes the entire learning trajectory and provides regret and constraint-violation guarantees. 3Representation Learning for Unconstrained MDPs A growing body of research has focused on theoretically grounded representation learning in RL, aiming to derive low-dimensional features that efficiently capture environment dynamics. For example, works such as [15, 28, 46] investigated representation learning in block MDPs, leveraging hierarchical or modular state decompositions to improve sample efficiency. [38] studied representations under a Gaussian noise model, establishing guarantees for feature learning in noisy environments. Low-Rank MDPs have emerged as a pivotal framework for representation learning in structured environments. Within this regime, model-based approaches [2, 36, 41, 44, 45] learn latent transition features by leveraging model classes of transition probabilities, achieving sample-efficient exploration under realizability assumptions. In contrast, model-free methods like [29] eschew explicit transition models and show efficiency under minimal reachability conditions. The framework has recently expanded into reward-free exploration [10, 20] and multi-agent Markov games [31, 34, 47, 48]. However, these works do not address online safety constraints in CMDPs. Consequently, this work gives the first representation-learning framework for low-rank CMDPs that bridges feature discovery and provable online safety.

The soft constraint violation quantifies the cumulative difference between the desired constraint threshold and the achieved utility, allowing for both positive and negative deviations over time. In contrast, the hard constraint violation is a stricter metric that measures only the cumulative positive deviations. Stochastic-oracle feedback model. Following prior low-rank representation-learning work, we study an occupancy-based stochastic-oracle setting. ## 3 Soft Violation via Cumulative Primal-Dual Control 

We first study low-rank CMDPs under the soft cumulative-violation metric, where constraint deficits and surpluses are aggregated before taking the positive part. The learner must identify an unknown low-rank transition representation while updating policies through a primal-dual procedure: return-policy data may lack action coverage, whereas always-uniform actions are less policy-adaptive. REP-PD-TEG ( Rep resentation-learning Primal-Dual with Tertiary decaying-ϵ- Greedy probing) resolves this tension by keeping the probing kernel close to the previous return policy while retaining a uniform action floor; the tertiary transition supplies the coverage needed for optimism. Unless stated otherwise, regret and soft violation are evaluated on the return policies {πk}Kk=1 ; auxiliary tuples are used only for model estimation and bonus construction. We later quantify the cost of charging the execution policy.

Reward optimism promotes exploration, while utility optimism is valid for soft violation because episode-level deficits and surpluses are aggregated. Thus one episode consists of auxiliary tertiary sampling, representation learning, bonus construction, optimistic primal update, and projected dual update. Algorithm 1 uses exact MLE and exact optimistic-Lagrangian planning to isolate the statistical challenge of learning unknown representations. The proof exposes a conditional interface for other learners: a representation method may replace MLE if it establishes the same prediction event under all three probing designs, with any excess prediction error added to the representation-error term. Likewise, full-planning suboptimality enters through the cumulative planning term. A raw MLE objective gap need not imply the required prediction event, so the present theorems do not claim guarantees for arbitrary approximate oracles, misspecified models, or infinite classes. Spectral representation learning [37] is an example of a non-MLE alternative, but its three-design event would have to be verified separately here. 

3.2 Polynomial-Schedule Guarantees 

We state the guarantee for polynomial schedules ϵk = k−p, which make the exploration–deployment tradeoff explicit. ## 4 Hard Violation via Per-Episode Certification 

We now consider the hard cumulative-violation metric. Unlike soft violation, hard violation does not allow constraint surplus in one episode to offset constraint deficit in another. Therefore the optimistic utility estimate used by the soft primal-dual update is insufficient for certifying feasibility at the episode level: an optimistic estimate may exceed the threshold b even when the true utility remains below it. REP-PD-H-TEG (the Hard-violation version of REP-PD-TEG) therefore keeps the same representation-learning procedure but changes the policy decision: policy search remains optimistic, while a tight feasibility test on the lower-confidence utility of the policy is explicitly conducted. 

4.1 Lower-Certificate Planning in REP-PD-H-TEG

In REP-PD-TEG, the optimistic utility value can be used in the dual update because violation is aggregated across episodes. ## 5 Conclusion 

We develop representation-learning algorithms for low-rank continuous-state CMDPs with unknown transition features. REP-PD-TEG combines auxiliary probing, covariance bonuses, and optimistic primal-dual planning for soft-violation control; REP-PD-H-TEG adds a lower-confidence utility certificate and stabilized dual search for hard-violation control. Both provide return- and execution-policy guarantees. 

Limitations. The theorems assume finite realizability and exact MLE/planning; alternative learners require the same three-design prediction guarantee. The hard result additionally uses a positive optimistic-score gap. The occupancy oracle is implementable with resets and geometric roll-ins, but our bounds do not charge full roll-in trajectories. H.1 Job scheduling. 

To validate the convergence of REP-PD-TEG in CMDPs, we first evaluate it in a simulated job scheduling environment. This toy domain lets us visualize how the learned representation, optimistic bonus, and primal-dual update interact under unknown dynamics. Following [17, 18], we design a constrained MDP with state space S = {0, 1, . . . , 9}, where s

After each episode, the newly collected transitions are appended to the dataset, the representation learner is updated on the accumulated data for multiple gradient steps, and the primal-dual policy update is then executed with the induced exploration bonus. To demonstrate the effectiveness of our constraint-aware design, we compare against REP-UCB [41], an unconstrained low-rank MDP approach using similar representation learning but without dual-variable updates, and a linear method [17] where the transition feature is known. As shown in Figure 1, REP-PD-TEG has higher regret than REP-UCB on this toy instance but substantially lower cumulative constraint violation, illustrating the tradeoff induced by constraint-aware learning. Despite not knowing the transition feature, REP-PD-TEG is comparable in scale to the known-feature linear method of Ghosh et al. [17] on both metrics. Because this illustrative plot reports a single run without uncertainty bands, we do not infer statistical significance or an empirical asymptotic rate from it. 

H.2 Practical Neural Implementation Neural Safety Gym implementation. To probe scalability beyond the toy domain, we instantiate a practical neural variant, denoted REP-PD-NN for neural REP-PD-TEG. The theoretical algorithm uses a per-round full-batch MLE representation-learning step, which is difficult to scale directly to continuous-control domains. REP-PD-NN therefore replaces this step with a mini-batch SPEDER-style stochastic representation objective [37], while preserving the primal-dual safe RL structure. The learned state-action representation is used as the input to neural reward and cost critics, and the policy is trained with a Lagrangian-style constrained policy update. H.3 Computational Resources 

All experiments were run on a local institutional server equipped with eight NVIDIA RTX 4090 GPUs, each with 24GB of memory, and standard x86_64 CPUs. The tabular job-scheduling experiment is lightweight and can be reproduced on a CPU-only machine. Each Safety Gym training run uses one GPU; the eight-GPU server was used only to run independent seeds and methods in parallel, and is not required for reproducing any single run. The implementation uses Python with PyTorch, CUDA-enabled GPU execution, MuJoCo, and Safety Gym. Table 4 summarizes the approximate compute required to reproduce the reported experiments. For Safety Gym, each environment is evaluated with two methods, raw and REP-PD-NN , and three random seeds, resulting in six runs per environment and eighteen final training runs in total. Thus, the reported Safety Gym results require approximately 144–360 GPU-hours in total. When all eight GPUs are used in parallel, the final runs can be completed in roughly 18–45 wall-clock hours. During method development, we also ran preliminary hyperparameter sweeps and diagnostic experiments that are not required to reproduce the reported tables. These preliminary runs used additional GPU time of the same order as the final reported experiment set; failed or preliminary runs were excluded from the reported results. 44
