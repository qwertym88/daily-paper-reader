## 摘要
表示学习显著提升了无约束连续状态马尔可夫决策过程（MDP）的效率，但将其扩展到约束马尔可夫决策过程（CMDP）较为困难，因为需要在控制约束违反的同时学习转移表示。本文研究连续状态空间下低秩CMDP的表示学习，并针对软累积违反设定提出REP-PD-TEG。在特征学习阶段，该算法使用衰减的$\epsilon$-贪心混合执行策略与环境交互，并利用收集到的样本通过最大似然学习转移特征。基于学习到的特征，它构建不确定性奖励，并以乐观拉格朗日目标进行规划以获得回报策略。我们证明了回报策略的遗憾界和软违反保证，并量化了衰减$\epsilon$-贪心探索的影响。特别地，REP-PD-TEG达到了最优的$\widetilde O(\sqrt K)$回报策略界，并在探索动作被计入代价时给出$\widetilde O(K^{3/4})$的总体样本界。对于更严格的硬累积违反情形，即必须逐回合验证可行性，我们提出REP-PD-H-TEG。它利用学习到的表示，在带奖励修正的效用下置信界证书下进行规划，并执行稳定化对偶搜索以获得回报策略，从而给出遗憾界和硬违反界。这些结果共同给出了首个具有理论保证的表示学习方法，适用于同时具备软累积保证和经认证的硬违反控制的低秩连续状态CMDP。

## Abstract
Representation learning has substantially improved the efficiency of unconstrained continuous-state Markov Decision Processes (MDPs), but its extension to Constrained MDPs (CMDPs) is difficult because the transition representation must be learned while constraint violation is controlled. In this paper, we study representation learning for low-rank CMDPs with continuous state spaces, and propose REP-PD-TEG for the soft cumulative-violation setting. In the feature learning period, the algorithm interacts with the environment using a decaying-$ε$-greedy mixture execution policy, and uses the collected samples to learn transition features by maximum likelihood. Based on the learned features, it constructs uncertainty bonuses and plans with an optimistic Lagrangian objective to obtain the return policy. We prove regret and soft-violation guarantees for the return policies, and quantify the influence of the decaying-$ε$-greedy exploration. In particular, REP-PD-TEG achieves the optimal $\widetilde O(\sqrt K)$ return policy bound, and gives a $\widetilde O(K^{3/4})$ overall sample bound when exploratory actions are charged. For the stricter hard cumulative violation, where feasibility must be verified episode by episode, we propose REP-PD-H-TEG. It plans under a bonus-corrected lower-confidence utility certificate with the learned representation, and performs a stabilized dual search to obtain the return policy, yielding regret and hard-violation bounds. Together, these results give the first theoretically guaranteed representation-learning method for low-rank continuous-state CMDPs with both soft cumulative guarantees and certified hard-violation control.

## 1. 核心问题与研究动机

- **背景**：约束马尔可夫决策过程（CMDP）是在奖励最大化之外同时满足安全/效用约束的强化学习框架，适用于安全关键场景。已有可证明约束 RL 工作主要集中于表格型 CMDP 和线性 CMDP，二者均依赖**已知**的低维特征或转移表示。
- **核心问题**：在连续状态、转移函数具有未知低秩结构的 CMDP 中，智能体必须**在线学习转移特征表示**，同时控制累计约束违反。表示误差会同时影响奖励优化与约束评估，形成“表示覆盖—约束感知策略优化”的耦合难题。
- **现有空白**：
  - 表格/线性 CMDP 方法在特征未知时理论保证失效；
  - 无约束低秩 MDP 的表示学习不处理在线安全约束；
  - 已有低秩 CMDP 工作仅研究训练后识别近优可行策略的样本复杂度，未分析完整学习轨迹的遗憾与约束违反。
- **整体含义**：论文首次为低秩连续状态 CMDP 提出具有理论保证的表示学习框架，分别覆盖**软累计违反**与**逐回合可认证的硬累计违反**两种设定。

## 2. 方法论

### 2.1 问题设定

- 转移函数满足低秩分解：  
  \(P^*(s'\mid s,a)=\langle \phi^*(s,a),\mu^*(s')\rangle\)，其中 \(\phi^*,\mu^*\) 未知。
- 目标：最大化折扣奖励 \(V_r^\pi(s_1)\)，同时满足效用约束 \(V_g^\pi(s_1)\ge b\)。
- 采用基于占用测度的随机 oracle：可查询按当前策略占用分布采样的状态及辅助转移；理论分析中 K 为外层 oracle 轮数，不计算完整 roll-in 轨迹成本。
- 使用有限可实现模型类与最大似然估计（MLE）学习 \(\hat P=(\hat\mu,\hat\phi)\)。

### 2.2 REP-PD-TEG：软累计违反算法

核心思想是：用辅助探索保证表示学习所需覆盖，用乐观奖励与乐观对偶加权效用进行原始-对偶规划，并以衰减 \(\epsilon\)-贪心平衡探索与部署成本。

**算法流程（文字版）**：

1. 第 \(k\) 回合设置执行策略  
   \[
   q_k=q'_k=q''_k=(1-\epsilon_k)\pi_{k-1}+\epsilon_k U(A),
   \]
   即以当前回报策略为主、均匀动作作为探索下限。
2. 查询一个“三级”辅助元组：  
   \(s\sim d^{\pi_{k-1}}_{P^*}\)，依次采样 \(a\sim q_k\)、\(s'\sim P^*\)、\(a'\sim q'_k\)、\(s''\sim P^*\)、\(a''\sim q''_k\)、\(\bar s\sim P^*\)，分别存入 \(D_k,D'_k,D''_k\)。
3. 在 \(D_k+D'_k+D''_k\) 上做 MLE，得到 \(\hat P_k=(\hat\mu_k,\hat\phi_k)\)。
4. 构造合并协方差  
   \[
   \hat\Sigma_k^{\text{mix}}
   =\sum_{D_k}\hat\phi_k\hat\phi_k^\top
   +\sum_{D'_k}\hat\phi_k\hat\phi_k^\top
   +\lambda_k I,
   \]
   注意第三流 \(D''_k\) 用于 MLE 和覆盖证明，但不直接加入该协方差。
5. 构造不确定性奖励  
   \[
   \hat b_k(s,a)=\min\{\alpha_k\|\hat\phi_k(s,a)\|_{(\hat\Sigma_k^{\text{mix}})^{-1}},\bar b\}.
   \]
6. 乐观拉格朗日规划：
   \[
   \pi_k\in\arg\max_\pi
   \left(Q^{\pi}_{\hat P_k,r+\hat b_k}
   +Y_k Q^{\pi}_{\hat P_k,g+\hat b_k}\right).
   \]
7. 对偶更新：
   \[
   Y_{k+1}=\Pi_{[0,\xi]}
   \left(Y_k+\eta\left(b-V^{\pi_k}_{\hat P_k,g+\hat b_k}(s_1)\right)\right).
   \]

**理论调度**：取 \(\epsilon_k=k^{-p}\)。

- 回报策略遗憾与软违反约为  
  \[
  \widetilde O(K^{1/2+p}).
  \]
- 当 \(p=0\)，即全程均匀三级探测时，回报策略达到  
  \[
  \widetilde O(\sqrt K)
  \]
  的遗憾与软违反界。
- 若把探索动作计入执行策略成本，额外项约为 \(O(K^{1-p})\)；取 \(p=1/4\) 时，执行策略总体达到  
  \[
  \widetilde O(K^{3/4}).
  \]

### 2.3 REP-PD-H-TEG：硬累计违反算法

硬违反只计算每回合正缺口，不能由其他回合的约束盈余抵消，因此乐观效用估计不足以证明当前回合可行。

- **保留相同前端**：三级采样、MLE、合并协方差与奖励构造不变。
- **引入下置信效用证书**：  
  \[
  \ell_k=C_{\text{cert}}\sqrt{\frac{\Gamma_k\zeta_k}{1-\gamma}},
  \quad
  \Gamma_k=\frac{|A|}{\epsilon_k},
  \]
  \[
  U_k(\pi)=\left[V^{\pi}_{\hat P_k,g-\hat b_k}(s_1)-\ell_k\right]_+.
  \]
  在表示学习好事件上，\(U_k(\pi)\le V^\pi_{P^*,g}(s_1)\)，因此 \(U_k(\pi)\ge b\) 可认证真实可行性。
- **稳定化对偶搜索**：在回合内按网格搜索对偶水平 \(Y\)，对每个 \(Y\) 求解乐观拉格朗日规划，并形成状态级 softmax 候选；部署第一个满足 \(U_k(\pi_{k,Y})\ge b\) 的候选；若到上限 \(Y_{\max}=K^{1/4}\) 仍无候选，则部署上限候选。
- **理论结果**：
  - 回报策略遗憾约为 \(\widetilde O(K^{3/4+p})\)；
  - 硬违反约为 \(\widetilde O(K^{1/2+p})\)；
  - \(p=0\) 时硬违反达到 \(\widetilde O(\sqrt K)\)，遗憾为 \(\widetilde O(K^{3/4})\)；
  - \(p=1/8\) 时执行策略遗憾与硬违反均为 \(\widetilde O(K^{7/8})\)。

  - 框架原则上可扩展到多约束 CMDP，只需将对偶变量向量化并调整证书；
  - 低秩表示学习可与更一般的非线性表示或深度近似结合，但理论保证会依赖表示类可实现性与优化精度；
  - 硬违反证书思路可迁移到其他需要逐回合安全认证的约束 RL 场景，但网格搜索对偶水平在高维多约束下可能成为瓶颈。

## 9. 总体评价

论文的核心价值在于把“未知低秩转移表示学习”和“带累计约束的策略优化”从表格/线性设定推进到连续状态 CMDP，并给出软、硬两类累计违反的可证明界。其理论贡献较扎实：三级探测解决表示覆盖，原始-对偶规划处理约束，硬违反版本进一步用下置信证书保证逐回合可认证可行性。相对而言，实验主要是机制性验证而非充分经验评估：硬违反算法未被实验检验，神经近似与理论算法差距较大，基线数量与种子数有限，计算量报告还有不一致。总体可视为一篇以理论为主、实验为辅的低秩约束 RL 工作；其结论应主要依据理论保证来理解，实验部分更适合作为可行性示例而非强经验证据。
