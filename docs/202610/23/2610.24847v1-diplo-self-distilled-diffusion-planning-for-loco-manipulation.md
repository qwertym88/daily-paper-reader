## 摘要
人形机器人的移动操作尤其具有挑战性，因为它需要协调运动、平衡和物体交互，这使得从有限示范中学习或通过强化学习（RL）从零开始学习都很困难。我们提出 DiPLO（用于移动操作的自蒸馏扩散规划），该框架将自蒸馏扩散规划器与低层全身跟踪策略相结合。我们的规划器通过监督学习在由人到人形机器人重定向得到的运动数据上进行预训练，而跟踪器则通过强化学习训练以执行这些运动。DiPLO 围绕两个互补的后训练阶段展开。首先，我们引入自蒸馏扩散策略优化（SD:DPO），以消除规划器对强任务条件的依赖；我们发现强任务条件是有效预训练的关键要素，因为一旦省略它，下游微调无法恢复相当的性能。随后，我们使用扩散增强的近端策略优化（DA:PPO）——一种面向扩散模型的最大熵强化学习方法——对该蒸馏模型进行微调，以提高任务成功率，并使生成的规划与冻结跟踪器的执行能力对齐。这些阶段共同使得仅通过状态历史和目标条件即可生成运动，在拾取-搬运-放置任务中实现 99% 的任务成功率，而预训练模型仅为 45%。所得的规划器还能为未见过的物体目标生成运动，并在踢击和推/拉任务上进行了进一步评估。最后，我们将该流程部署到硬件上，在 Unitree G1 上使用我们的 DA:PPO 规划器-跟踪器，在无需任何真实世界微调的情况下实现了重复成功执行。

## Abstract
Humanoid loco-manipulation is particularly challenging because it requires coordinating locomotion, balance, and object interaction, making it difficult to learn from limited demonstrations or from scratch through Reinforcement Learning (RL). We introduce DiPLO (self-distilled Diffusion Planning for Loco-manipulation), a framework that combines a self-distilled diffusion planner with a low-level whole-body tracking policy. Our planner is pretrained via supervised learning on motions derived from human-to-humanoid retargeting, while the tracker is trained via RL to execute them. DiPLO centers around two complementary post-training stages. First, we introduce Self-Distillation Diffusion Policy Optimisation (SD:DPO) to remove the planner's dependence on strong task conditioning, which we identify as a crucial ingredient for effective pretraining, as downstream fine-tuning does not recover comparable performance when it is omitted.. We then fine-tune this distilled model with Diffusion-Augmented Proximal Policy Optimization (DA:PPO), a maximum-entropy RL method for diffusion models, to improve task success and align generated plans with the frozen tracker's execution capabilities. Together, these stages enable motion generation through state-history and goal conditioning alone, enabling 99% task success in pick-carry-place tasks, compared to just 45% for the pretrained model. The resulting planner also generates motions for unseen object goals, with further evaluations on kicking and pushing/pulling tasks. Finally, we deploy our pipeline on the hardware, using our DA:PPO planner-tracker on a Unitree G1, achieving repeated successful executions without any real-world fine-tuning.

## 一、核心问题与研究动机

- **核心问题**：人形机器人的移动操作（loco-manipulation）需要同时协调行走、平衡与物体交互，是一个高维、欠驱动、强耦合的控制问题。作者希望解决两大痛点：
  1. **数据稀缺**：高质量人形机器人-物体交互示范数据难以大规模采集，论文仅从 29 条重定向运动序列（约 2.7 分钟）出发；
  2. **从零强化学习困难**：直接从零用 RL 学习全身移动操作极不稳定，且难以泛化到新目标。
- **整体含义**：作者提出一种“规划器-跟踪器”分层架构——高层扩散规划器生成全身+物体运动块，低层 RL 跟踪器执行。核心洞察是：**强任务条件（IK 重定向参考轨迹）对有限数据下的预训练至关重要，但可以通过后训练去除**，从而在部署时仅凭状态历史和物体目标就能生成可执行运动。
- **研究目标**：用户只需给出目标物体位姿，机器人自主决定如何到达；并能在未见过的目标位置上泛化，最终零微调部署到真实 Unitree G1。

## 二、方法论

### 1. 整体架构
- **规划器**：基于 Diffusion Transformer（DiT）的条件扩散模型，输出 n=64 帧（1.28 s）的全身+物体运动块。
- **跟踪器**：单一通用 RL 策略（PPO 训练），以 50 Hz 输出残差关节目标，叠加到规划器参考上，由 200 Hz PD 控制器执行。
- **闭环**：规划器每步生成 n 帧，跟踪器执行前 m ≤ n 帧（默认 m=56），然后从实测状态重新规划，从而吸收跟踪误差。

### 2. 运动表示
- 状态 $s_t$ 包含机器人部分（平面位移、朝向变化、根高度、根朝向 $\in SO(3)$、29 个关节位置）与物体部分（位置、朝向 $\in SO(3)$）。
- 平面量表达在当前机器人朝向系下，去除全局位置/朝向依赖；旋转用连续 6D 表示输入网络，每帧 48 维特征。
- 目标 $g_t$ 为相对当前物体位姿的位移、6D 相对旋转与裁剪距离（10 维），随任务完成自然趋零。

### 3. 预训练（监督学习）
- **数据增强**：先用 SBTO（采样式轨迹优化）从扰动初始条件生成动力学可行的运动变体；再对矢状面镜像 + 物体 90° 旋转对称性扩增，最终形成 7184 条运动。
- **扩散过程**：
  - 欧氏特征：VP 扩散 + 余弦噪声调度，v-prediction，损失为分组加权 Smooth-L1；
  - 旋转特征：在 $SO(3)$ 上用 IG_SO(3) 前向核做 VP 扩散，网络预测切空间标准化角噪声，反推收缩中心并按 DDPM 系数组合。
- **条件掩码**：预训练时 50% 样本将 IK 参考替换为空 token ∅，使网络同时见到有无参考两种条件。
- **跟踪器训练**：在 mjlab 中用 PPO 训练，奖励包括根/身体/关节跟踪、物体位置/朝向/速度跟踪、接触匹配及正则项；采用非对称 actor-critic 与自适应参考状态初始化。

### 4. 后训练阶段一：SD:DPO（自蒸馏去除任务条件）
- **动机**：预训练依赖 IK 参考，部署时若无参考，闭环存活率从 96.5% 骤降至 57.7%。
- **做法**：
  - 学生 $G_\phi$ 只接收状态历史 + 目标（参考置 ∅），教师 $G_{\bar\phi}$ 额外接收 IK 参考；二者均由预训练模型初始化。
  - 每步以 1/2 概率执行学生或教师的提案，用冻结跟踪器在仿真中闭环 rollout，将学生提案及其上下文存入缓冲区。
  - 训练时对学生提案加噪到随机扩散步 k，教师与学生接收同一噪声块，学生匹配教师的 v-prediction 与旋转噪声预测（教师目标 stop-gradient，教师权重用学生 EMA 更新）。
  - 损失 = 蒸馏项 + 原始数据预训练损失 + 锚定损失（约束参考条件下的行为不漂移）。
- **理论联系**：附录 J 证明该回归目标等价于学生与教师反向核之间 KL 的加权形式（权重取 1）。

### 5. 后训练阶段二：DA:PPO（最大熵 RL 微调）
- 将扩散去噪过程建模为 Diffusion-Augmented MDP：增广状态 $\tilde s_k=(z,\tilde a_k,k)$，动作是下一级更干净的运动块，反向核密度可 tractable 计算。
- 环境奖励只在 k=1（执行阶段）给出，通过软 Bellman 递归传播到所有去噪决策；用反向/前向密度对数比 $\ell_\phi$ 替代动作对数似然，实现每步熵正则。
- 用 PPO 裁剪目标 + GAE + 重要性比 $\rho_i$ 优化，跟踪器全程冻结；温度 T=1e-4 控制熵强度。

## 六、主要结论与发现

1. **强任务条件对预训练至关重要**：完整 IK 参考下存活率 96.3%，无任何先验仅 45.3%；且从零无先验预训练后再微调也无法恢复（74.1% 存活、67.0% 成功率），远低于“强先验预训练 + 蒸馏”的路线。
2. **SD:DPO 能有效去除部署时对参考的依赖**：学生存活率从 57.7% 提升到 100%，任务成功率从 45.4% 提升到 55.1%；再叠加 DA:PPO 后达到 99.5% 存活、98.8% 成功率。
3. **DA:PPO 显著优于 DPPO 风格更新**：最大熵形式避免模式坍缩，存活率 100%、成功率 96.4%（DPPO 风格为 99.1% / 94.0%）。
4. **SO(3) 扩散优于欧氏处理**：存活率从 85.9% 提升到 96.5%，物体朝向误差从 19.6° 降至 14.0°。
5. **运动级扩散 + RL 跟踪器优于动作级扩散**：96.5% vs 87.5%（PDP 风格）vs 58.2%（state-action 引导先验）。
6. **微调规划器比微调跟踪器更有效**：规划器微调成功率 96.5%，跟踪器微调最多 89.3%。
7. **泛化能力**：在 0.5–5 m 极坐标网格、4 个朝向上达到约 100% 存活、88% 成功率，远超示范集最远 1.9 m 的范围；并迁移到踢、推/拉任务。
8. **真机零微调部署成功**：重复目标 10/10、不同目标 5/5 成功，MPKPE 约 6.5–6.8 cm。

## 七、优点

- **方法论亮点**：
  - 提出“强先验仅作为预训练脚手架”的清晰原则，并用 SD:DPO 给出可操作的实现路径，具有普适性启示。
  - SD:DPO 巧妙借鉴 LLM 的 SDPO 思想，把“带特权信息的教师”蒸馏到“仅状态+目标”的学生，且在闭环 rollout 状态上监督，覆盖规划/跟踪误差导致的分布外状态。
  - DA:PPO 将去噪步显式建模为 MDP 决策，用可 tractable 的反向核密度做最大熵正则，避免 DPPO 截断去噪带来的抖动。
  - 旋转在 $SO(3)$ 上做扩散，几何处理严谨，并有消融支撑其必要性。
- **实验设计亮点**：
  - 消融维度全面（数据、条件、几何、RL 目标、微调对象、预测视野）；
  - 所有对比共享同一冻结跟踪器与评估协议，公平性较好；
  - 从仿真到真机、从单一任务到多任务、从示范内到示范外目标的递进验证，说服力强；
  - 数据效率极高（仅 2.7 分钟示范 + 增强）。

## 八、不足与局限

- **应用限制**：
  - 真机部署依赖外部动捕系统提供机器人基座与物体位姿，尚未实现机载感知，限制了野外/非结构化环境应用。
  - 规划器推理约 12.5 Hz（10 步去噪 + 通信延迟），对高动态任务可能构成瓶颈。
  - 每个任务族（pick-place / kick / push-pull）需单独预训练+后训练，尚未验证单一多技能统一模型。
- **实验覆盖局限**：
  - 真实世界仅 15 次试验、单一机器人型号（Unitree G1）、单一物体（箱体），统计效力有限。
  - 物体种类、

- 物体种类、几何形状、质量与摩擦特性单一（以箱体为主），规划器的物体状态仅含位置与 $SO(3)$ 朝向，不含形状、尺寸、质量等物理属性，因此难以直接推广到多样物体或需要精细力控的任务（如开门、拧阀、柔性物体操作）。
- 任务族之间相互独立：pick-carry-place、kick、push/pull 各自单独预训练 + 后训练，未验证单一统一模型能否在多技能间共享表示、避免灾难性遗忘，也未讨论技能切换与任务识别问题。
- 评估协议为自建，缺乏与其他人形移动操作系统的**同任务直接对比**：基线主要是同框架内的变体（数据增强、先验强度、旋转几何、动作级扩散），而非与 MPC、分层 RL、遥操作示教等不同技术路线的横向比较，外部有效性有限。
- 指标存在一定的循环性风险：MPKPE 以“生成运动”为参考，而生成运动本身来自预训练分布，可能对参考质量敏感；成功率容差（15 cm / 30°）相对宽松，未报告更严格容差下的退化曲线。
- 未系统报告**超参数敏感性**：如执行帧数 $m$、预测视野 $n$、蒸馏损失权重、锚定损失系数、DA:PPO 温度 $T=10^{-4}$、去噪步数等对稳定性与成功率的影响，仅对 $n$ 做了有限消融。
- 缺少**失败模式分类分析**：论文报告了存活率与成功率，但未细化摔倒、掉物、物体滑移、规划-跟踪失配等失败类型的占比与触发条件，不利于诊断与改进。
- 鲁棒性验证不足：未讨论外力扰动、物体初始位姿偏移、动捕噪声/丢帧、地面摩擦变化等对闭环稳定性的影响；真机试验为受控环境下的短时程执行，长期连续运行的漂移与安全性未评估。
- 理论部分（附录 J）仅建立了 SD:DPO 回归目标与 KL 加权形式之间的等价关系，对 DA:PPO 的收敛性、熵正则强度与策略性能之间的理论联系未展开，属于经验性论证为主。
- 算力与工程细节披露不足（如前所述），且未明确说明代码、数据与模型权重是否开源，影响复现与后续基准化。

## 九、可复现性与开放性问题

- **可复现性中等偏上**：方法描述细致（网络结构、损失、扩散调度、奖励项、评估协议均有交代），关键设计可被重新实现；但算力配置、部分超参数、真实实验的动捕布置与安全措施披露不足。
- **开放问题**：
  1. 能否将“强先验作为预训练脚手架、后训练去除”的范式推广到视觉/触觉等机载感知输入，替代外部动捕？
  2. 如何在单一模型中统一多技能，并支持在线任务指定与长时程组合（如“走过去—拿起—搬运—放置—推开门”）？
  3. 规划器推理频率（约 12.5 Hz）与高动态任务（奔跑、跳跃、快速接抛）之间的匹配问题；
  4. 物体物理属性（质量、摩擦、可变形性）如何进入扩散规划器的条件表示；
  5. 蒸馏与 RL 微调的样本效率能否进一步提升，减少对大规模并行仿真的依赖。

## 十、总体评价

- **贡献定位**：论文的核心贡献不在于单一模块的新颖性（DiT 扩散、PPO 跟踪、SDPO 蒸馏、扩散策略 RL 均有先例），而在于**系统性地回答了一个方法论问题**——在数据极少的人形移动操作场景中，“强任务条件先预训练、再通过自蒸馏与最大熵 RL 去除”是一条可行且高效的路线，并用完整消融与真机验证支撑。
- **证据强度**：仿真侧消融充分、对照公平、统计报告规范；真机侧虽规模小，但实现了零微调部署，构成有说服力的“存在性证明”。
- **适用边界**：方法最适用于**有动捕或高质量状态估计、任务族相对固定、物体较规整**的场景（实验室、舞台表演、结构化工业搬运）；距离非结构化野外自主作业仍有明显差距。
- **写作与呈现**：结构清晰、动机—方法—实验链条完整，消融组织有条理；不足主要在于外部对比、失败分析与算力披露，属于该领域论文的常见短板而非致命缺陷。
