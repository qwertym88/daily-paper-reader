Abstract 

Distributed control requires choosing how far information travels and how long it is retained. For networked linear quadratic regulation (LQR), we use System Level Synthesis to bound these resources for a specified performance loss per node relative to centralized control. For locally coupled systems under uniform regularity assumptions, including stabilizability and detectability, we prove that the centralized optimal state and input responses to disturbance impulses satisfy exponential decay bounds in both time and spatial distance. On networks with polynomial neighborhood growth, sufficient communication ranges and memory horizons grow logarithmically with the inverse tolerance, independently of network size. Truncating these responses gives local finite-memory filters with stability and performance guarantees under a computable small-gain condition. Under an additional uniform local feedback condition, we also obtain controllers that confine nominal disturbance effects in space and eliminate them in finite time. Numerical experiments illustrate how performance and disturbance containment requirements guide architecture selection. 

Keywords: Control architecture design, distributed control, linear quadratic regulator, localized control, response decay, System Level Synthesis. 

# 1 Introduction 

Large networked systems arise in power grids, transportation networks, building climate systems, and spatially distributed industrial processes. Their controllers must coordinate physically coupled subsystems without requiring every local unit to communicate with, store, and process information from the entire network. Centralized LQR provides a natural performance benchmark, but its optimal feedback is generally global. A scalable design must therefore quantify how much local information and memory are sufficient to approach centralized performance, rather than only require that a controller be distributed [3, 35]. Distributed controller synthesis is difficult under arbitrary information constraints [7]. Tractable theories exploit spatial invariance or interconnections described by graphs [4–6], characterize convex information structures through quadratic or sparsity invariance [8–10], or impose locality and delay directly on disturbance responses through System Level Synthesis (SLS) [13–17]. Regularization and joint controller and control architecture design can also select among candidate links, devices,

A remaining question is how to choose which signals each local controller receives and how long it retains them, while guaranteeing a prescribed performance loss relative to centralized control. An overly restrictive choice can substantially degrade the best achievable performance [12]. Implementing a local controller requires specifying which signals it receives, when they become available, and how long they are retained [11, 15, 16]. The immediate communication radius specifies how far a signal can be transmitted for use within one control update. The maximum spatial footprint limits where that signal may be delivered and used over subsequent updates [15, 17]. The 

memory horizon specifies how long past signals are retained for filtering, measured in control updates. These three quantities impose different communication and storage requirements and can be selected separately. The exponential decay of sensitivity in optimization problems defined on graphs offers a possible route from global optimality to such local resource choices. In optimal control, spatially distributed LQR can inherit spatial decay from the plant data [26]. For finite graph local LQR, the centralized optimal gain decays with graph distance, and truncating that gain can give a distributed controller with near optimal performance [28]. More recent work studies spatially decaying network LQR and predictive SLS performance as communication is enlarged [29, 30]. Gain decay quantifies how a control action weights the current global state. Implementation resources, however, depend on how a localized disturbance propagates through state and input trajectories over both space and time. The cited results do not give a guarantee uniform over network size that converts a prescribed LQR performance loss into separate requirements on immediate communication radius, maximum spatial footprint, and memory horizon. This motivates the question studied here: what immediate communication radius, maximum spatial footprint, and memory horizon are sufficient to attain a prescribed performance loss per node relative to centralized LQR? We study the disturbance responses of the centralized optimum. SLS represents a state feedback controller by the maps from a disturbance impulse at one node to the resulting state and input trajectories across the network. Each impulse response coefficient represents how a disturbance at one node affects a state or input at a given node after a given number of steps. These indices let us quantify how much of the centralized optimal response lies outside a prescribed local space and time support. Although the centralized optimal state and input responses are generally dense, their spatial and temporal decay allows small coefficients to be discarded; Fig. 1 illustrates this geometry. When graph neighborhoods grow slowly enough, summing bounds on the discarded coefficients controls the total approximation error. This connects response decay to the choice of which signals a local controller receives and how long it retains them. Discarding coefficients generally violates the SLS equality linking the state and input responses to the plant dynamics. We therefore develop two controller constructions. Direct truncation implements the retained coefficients as local filters that use the specified signals and retain them for the chosen memory horizon. The achieved closed-loop responses may extend beyond the spatial and temporal support of these filters. Exact localized SLS reoptimizes the coefficients permitted by the chosen implementation mask subject to the SLS equality. When feasible, the nominal response to each disturbance impulse remains within a prescribed neighborhood and vanishes after a specified horizon. Both constructions use decay to guide resource selection; the choice also depends on whether the application requires disturbance containment.

Related work. Localized LQR optimizes performance subject to the SLS achievability equality and prescribed spatial and finite impulse response (FIR) constraints [17]. Separable SLS decomposes such fixed-mask problems into local computations [16]. These results provide synthesis tools once the permitted response support is specified; they do not determine its spatial and temporal scales from a prescribed performance loss. Exact FIR localizability combines finite time elimination of disturbance effects with spatial containment and can be restrictive. Virtually localizable and robust SLS instead allow a nonzero SLS residual and use a small gain condition to certify the resulting closed loop [15, 18]. Under approximate achievability, the response achieved by the controller is generally dense. The SLS approximation result further shows exponential convergence in the horizon when temporal decay of the centralized response is known, and outlines a spatial extension if spatial decay is assumed [15]. System level bases beyond FIR responses reduce the conservatism of a fixed horizon [20]. 3We establish the spatial and temporal response decay needed by the SLS residual mechanism and bound the achieved LQR loss of direct truncation uniformly in network size. Our exact result establishes when truncation residuals admit local repair within fixed margins while preserving the decay rate. The exact guarantee uses an additional uniform local deadbeat certificate; response decay and stabilizability alone do not guarantee exact localizability. Our decay analysis builds on exponential off-diagonal decay for inverses and functions of sparse matrices [21–23] and its extension to sensitivity in graph structured optimization [24]. Temporal decay has also been studied in long horizon optimal control [25]. The closest LQR works differ in the object and scaling they characterize. Motee and Jadbabaie develop a continuous time operator framework for infinite spatially distributed systems; the inverse closedness argument underlying the original result was subsequently qualified [26, 27]. Shin et al. give a nonasymptotic decay bound for the static optimal feedback gain on finite graph local systems and analyze a gain truncation with one spatial radius [28]. Zhang et al. broaden the plant class to spatially exponentially decaying models and characterize quasi-spatial decay of both the gain and a disturbance response controller, with rates that depend on network size; Zhang et al.’s result is spatial rather than a joint law over space and time for SLS system responses [29]. Predictive SLS integrates disturbance forecasts and bounds regret as a function of communication range and prediction error, rather than deriving the spatial footprint and memory of the centralized infinite horizon response [30]. We instead index both optimal SLS response maps by disturbance location, responding state or input location, and elapsed time, sum their discarded tails over space and time, and translate the result into separate bounds on immediate communication radius, maximum spatial footprint, and memory horizon. Decay of distant influence also supports local computation in graph decision problems, statistical physics, and multiagent reinforcement learning [31–33]; these results concern different decision variables from the SLS responses studied here.

# 7 Conclusion 

Spatiotemporal response decay provides a quantitative basis for control architecture selection. Under the stated assumptions, a prescribed LQR loss per node relative to centralized control can be attained with communication, storage, and filtering counts independent of network size. The two controller constructions distinguish limits on implementation resources from limits on disturbance propagation. Direct truncation uses local filters while allowing disturbance tails; exact localized SLS additionally confines the nominal disturbance response. The thermal mesh illustrates how this distinction changes the control architecture and implementation route selected for a prescribed performance target. Further work can address three limitations of the present analysis. One direction is to replace the uniform local deadbeat assumption with weaker, verifiable conditions for local residual repair that preserve the performance and resource bounds. Another is to quantify disturbance propagation outside the prescribed support under model uncertainty and incorporate this sensitivity into control architecture selection. A further direction is to incorporate communication service choices, delays, and installation costs into control architecture models and develop scalable algorithms for controller and control architecture co-design. Response decay could guide the selection of candidate control architectures within these richer models. 19 A Auxiliary Facts and Proofs
