## 摘要
分布式控制需要选择信息传播的距离和保留的时间。对于网络化线性二次调节（LQR），我们利用系统级综合，在相对于集中式控制的每节点指定性能损失下，对这些资源进行界定。对于满足一致正则性假设（包括可镇定性和可检测性）的局部耦合系统，我们证明集中式最优状态和输入对扰动冲激的响应在时间和空间距离上均满足指数衰减界。在邻域呈多项式增长的网络上，充分的通信范围和记忆时域随容差的倒数呈对数增长，且与网络规模无关。截断这些响应可在可计算的小增益条件下得到具有稳定性和性能保证的局部有限记忆滤波器。在附加的一致局部反馈条件下，我们还得到能将标称扰动影响限制在空间内并在有限时间内消除它们的控制器。数值实验说明了性能和扰动遏制要求如何指导架构选择。

## Abstract
Distributed control requires choosing how far information travels and how long it is retained. For networked linear quadratic regulation (LQR), we use System Level Synthesis to bound these resources for a specified performance loss per node relative to centralized control. For locally coupled systems under uniform regularity assumptions, including stabilizability and detectability, we prove that the centralized optimal state and input responses to disturbance impulses satisfy exponential decay bounds in both time and spatial distance. On networks with polynomial neighborhood growth, sufficient communication ranges and memory horizons grow logarithmically with the inverse tolerance, independently of network size. Truncating these responses gives local finite-memory filters with stability and performance guarantees under a computable small-gain condition. Under an additional uniform local feedback condition, we also obtain controllers that confine nominal disturbance effects in space and eliminate them in finite time. Numerical experiments illustrate how performance and disturbance containment requirements guide architecture selection.
