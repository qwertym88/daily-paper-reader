## 摘要
可变形物体的人-机器人协同运输需要预测运动过程中的物体变形，因为与障碍物的间隙取决于抓取点和未受驱动的内部区域。我们提出一种分层规划框架，将学习得到的布料模型与双臂移动机械臂的降阶全身模型相结合。物理残差条件循环变分自编码器（p-cRVAE）通过从抓取点观测预测完整布料构型，并学习对计算高效的线性化物理模型的残差修正，从而限制40步规划时域上的误差累积。将预测的布料动力学嵌入模型预测路径积分（MPPI）规划器，该规划器使用双臂移动机械臂的降阶表示，同时保留非完整基座约束和机械臂工作空间限制。随后，MPC层将采样运动细化为平滑、可执行的全身控制参考。降阶方案在跟踪性能上与完整17自由度模型相当，同时将计算时间减少约80%。在四种协同运输场景和两种搬运速度下，所提框架能够保持布料与障碍物之间的间隙，而角点跟随基线会导致碰撞；同时全身细化将最终布料变形从0.93 m降至0.28 m。

## Abstract
Human--robot co-transportation of deformable objects requires predicting object deformation during motion, since obstacle clearance depends on both the grasp points and the unactuated interior. We present a hierarchical planning framework that combines a learned cloth model with a reduced-order whole-body model of a dual-arm mobile manipulator. A physics-residual conditional recurrent variational autoencoder (p-cRVAE) predicts the full cloth configuration from grasp-point observations by learning a residual correction to a computationally efficient linearized physics model, limiting error accumulation over 40-step planning horizon. The predicted cloth dynamics are embedded in a model predictive path integral (MPPI) planner using a reduced-order representation of a dual-arm mobile manipulator that preserves the non-holonomic base constraint and arm workspace limits. An MPC layer subsequently refines the sampled motion into smooth, executable references for whole-body control. The reduced-order formulation achieves tracking performance comparable to the full 17-DoF model while reducing computation time by approximately 80%. Across four co-transportation scenarios and two carrying speeds, the proposed framework maintains cloth-obstacle clearance where a corner-following baseline results in collisions, while whole-body refinement reduces final cloth deformation from 0.93\,m to 0.28\,m.
