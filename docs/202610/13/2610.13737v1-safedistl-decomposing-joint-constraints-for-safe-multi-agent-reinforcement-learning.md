## 摘要
协作式多智能体任务通常对共享目标或集体安全施加约束。团队级违反成本函数可以度量该约束结果，但无法区分哪些智能体的动作对该违反影响最大。我们提出 SafeDiSTL，一个约束多智能体强化学习框架，即使面对联合约束测量也能进行信用分配。我们使用信号时序逻辑（STL）鲁棒性，通过运行最大值成本增量来度量回合级违反。平滑的完整回合鲁棒性和可微动力学提供动作敏感度，从而在同一决策时刻将每个成本增量分配给各智能体。在加权各智能体对每个成本增量的分摊份额时，这些敏感度考虑了延迟效应。我们在协作式载荷运输、联网导航和网络化交通控制任务中研究该框架。与约束基线相比，SafeDiSTL 在运输任务中达到 1.6-5.1 倍的安全成功率，将导航安全成功率提高 11.1%，并在交通任务中提供 50-68% 更高的吞吐量。结果表明，所学策略在处理共享约束方面有显著提升，同时保持无约束策略的性能。

## Abstract
Cooperative multi-agent tasks often impose constraints on a shared objective or collective safety. A team level violation cost function can measure this constraint outcome, but does not distinguish which agents' actions most strongly influence that violation. We present SafeDiSTL, a constrained multi-agent reinforcement learning framework that allows for credit assignment even with joint constraint measurements. We use Signal Temporal Logic (STL) robustness to measure episode-level violation through running-maximum cost increments. Smooth full-episode robustness and differentiable dynamics provide action sensitivities, which allocate each cost increment across agents at the same decision time. These sensitivities account for delayed effects when weighting agents' shares of each cost increment. We study the framework in cooperative payload transport, connected navigation, and networked traffic control tasks. SafeDiSTL achieves 1.6-5.1x the safe-success rate in transport, improves navigation safe-success by 11.1%, and delivers 50-68% more throughput in traffic when compared to constrained baselines. Results demonstrate a strong improvement of the learned policy in dealing with shared constraint while retaining the performance of unconstrained policies.

# SafeDiSTL 论文总结

## 1. 核心问题与研究动机

- **背景**：多智能体协作任务（空中集群、智能交通、自动化仓储）要求智能体在共享空间中完成集体目标（协同搬运、路径规划、编队控制），同时满足连通性、避碰等系统约束。单智能体约束强化学习通常用 CMDP + 拉格朗日/CPO 处理，多智能体侧已有 MACPO、MAPPO-Lagrangian、IsCPO 等扩展。
- **核心痛点**：现有工作大多假设每个智能体的成本函数是**解耦、良定义**的，但真实协作任务中约束往往是**共享/联合**的（例如多机器人抬同一块刚性载荷，载荷撞到障碍物很难归因到某个机器人）。
- **关键矛盾**：团队级违规成本只能告诉团队"违规了多少"，**不能告诉每个智能体"该如何改"**。若对所有智能体施加统一的惩罚，会产生相互冲突的修正信号，导致策略学习受阻甚至死锁（论文图 1 的搬运示例：均匀分摊责任使三台机器人互相僵持；按责任归因后，绿色智能体改为向上推，成功避障）。
- **研究意义**：需要一个有原则的机制，把共享约束成本**按智能体、按时间步**分解，同时考虑动作的延迟效应，从而在保留无约束任务性能的前提下提升安全性。

## 2. 方法论：SafeDiSTL

### 2.1 整体思想
- 用 **信号时序逻辑（STL）鲁棒性**刻画整条轨迹对共享约束的满足/违反程度；把回合级违规成本拆成"运行最大值增量"；再借助**平滑全回合鲁棒性 + 可微动力学**求动作敏感度，把每个成本增量分摊给各智能体。
- **守恒原则**：归因只改变成本在智能体间的分布，不改变其时间位置与团队均值；对偶（λ）更新仍使用**未归因的原始回合成本**。

### 2.2 关键技术细节
- **约束规范**：考虑"Always + 合取"型 STL 规范，如 `□[0,T-1] ∧_{j=1..K} μ_{gj}`，鲁棒性为 `ρ_φ(τ) = min_t min_j g_j(s_{t+1})`（g_j 通常为距离函数）。
- **回合违规成本**：`C_φ(τ) = [-ρ_φ(τ)]_+`（**无折扣**，保留峰值违规）。
- **运行最大值增量**：定义瞬时违规 `c_ins(s_{t+1}) = [-min_j g_j(s_{t+1})]_+`、运行最大 `c_max,t = max{c_max,t-1, c_ins}`，增量 `Δc_t = [c_ins - c_max,t-1]_+`；增量可**望远镜求和**得到回合成本 `Σ_t Δc_t = C_φ(τ)`，即只有超过此前峰值的新违规才产生成本。
- **动作敏感度（信用分配核心）**：对平滑鲁棒性 `ρ̃_φ` 关于各智能体动作求导，
  `z_{i,t} = || ∂[-ρ̃_φ(τ)] / ∂a_{i,t} ||_2`；由于梯度贯穿整条记录轨迹（其他动作固定），因此**天然包含延迟效应**。
- **归一化与分摊**：按决策时刻跨智能体归一化 `w_{i,t} = z_{i,t} / Σ_j z_{j,t}`（Σ_i w_i,t = 1）；分摊 `c̃_{i,t} = N·Δc_t·stopgrad(w_{i,t})`，保证 `(1/N)Σ_i c̃_{i,t} = Δc_t` 且 `(1/N)Σ_i Σ_t c̃_{i,t} = C_φ(τ)`。
- **平滑与鲁棒性近似**：用 log-sum-exp 近似最小算子 `ρ̃_φβ(τ) = -(1/β)log Σ_t Σ_j exp(-β g_j(s_{t+1}))`；代理量只提供导数，不替代精确成本与满足性判定。
- **策略优化（MAPPO 风格 + 拉格朗日）**：
  - 奖励评论家 `V_R`；成本侧采用**混合结构**：智能体级评论家 `V^i_C(o_{i,t}, c_max,t-1)` + 集中式评论家 `V^g_C(s_t, c_max,t-1)`，并加一致性正则 `ζ((1/N)Σ_i V^i_C - V^g_C)^2`。
  - GAE 得到 `A_{R,t}`、`A^i_{C,t}`、`A^g_{C,t}`；演员优势 `A_{i,t} = A_{R,t} - λ_k A^i_{C,t}`，代入 PPO 裁剪目标 `L_actor = E[min{q_i,t A_i,t, clip(q_i,t,1-ε,1+ε)A_i,t}]`。
  - **对偶更新**仍用精确回合成本均值 `Ĉ_k`：`λ_{k+1} = clip(λ_k + η_λ(Ĉ_k - d)/d, 0, λ_max)`。
- **算法流程（Algorithm 1）**：收集完整回合 → 计算 C_φ、Δc_t、全回合敏感度 z_{i,t} → 归一化并分摊 c̃_{i,t} → 计算三类优势 → 拟合三个评论家（含一致性正则）→ 更新演员 → 更新 λ。
- **实现细节**：带掩码的归一化（仅对活跃智能体求和，敏感度全为零时回退为均匀权重，非有限导数单独标记）；同时支持个体约束（个体障碍/边界成本各自有评论家、预算与对偶更新，不进入共享鲁棒性梯度）。

## 3. 实验设计

- **三个协作基准场景**（均为共享约束）：

  2. **连通导航**：4 个同质点质量智能体穿过两条交错障碍通道到达共同目的地；共享约束为**带缓冲的全回合通信连通性**（智能体位置欧氏最小生成树最长边 ≤ 3.325 m）；成功需末 20 步全部处于目标区域。

- **评价指标**：任务回报、目标成功率、约束满足率、安全成功率（两者联合）。

## 6. 主要结论与发现

- **运输**：SafeDiSTL 在 1/2/3 障碍下安全成功率分别为 **35.6%、16.2%、3.5%**，均高于所有基线；最近的 MAPPO-L 仅为 7.0%/4.5%/2.2%，MACPO 完全失败（0%）。相对约束基线安全成功率提升约 **1.6–5.1 倍**。
- **导航**：SafeDiSTL 目标成功率 **71.88%**、安全成功率 **43.88%**（MAPPO-L 安全成功率 32.81%，MAPPO 几乎总违反约束但回报最高）；约束满足率略低于 MAPPO-L（54.69% vs 56.64%）。
- **交通**：SafeDiSTL 保留 MAPPO **71.4% 的吞吐量**，同时把核心车辆时压到 MAPPO 的 **8.8%**、超限时间压到 **0.3%**；MACPO/MAPPO-L 虽同样降低违规，但吞吐仅剩 47.6% / 42.5%。
- **总体**：SafeDiSTL 在"约束满足–任务性能"权衡图中始终位于**右上象限**，即在保持 MAPPO 任务性能的同时显著提升约束满足；消融表明**责任归因**是性能提升的关键（均匀归因即使配合 max-incremental 成本与 Adam 对偶，安全成功率仍接近 0），说明"共享约束定义本身不够，必须做归因分解"。

## 7. 优点

- **问题切中要害**：明确指出共享/联合约束下"有成本但无归因"的盲点，并用死锁示例直观说明均匀惩罚的失效模式。
- **方法有原则且守恒**：运行最大值增量 + 望远镜求和保证成本在数值上完全守恒（`Σ_i Σ_t c̃_{i,t}/N = C_φ(τ)`）；归因只改分布、不改总量与时机，对偶仍用真实团队成本，避免"归因污染约束统计"。
- **显式建模延迟效应**：通过贯穿整条轨迹的鲁棒性梯度获得敏感度，而非仅看即时影响，契合"早期决策导致后续违规"的场景。
- **工程细节完备**：掩码归一化、均匀回退、非有限导数标记、混合评论家 + 一致性正则、与个体约束的兼容（个体约束不被共享归因抹除）等都给出了明确处理。
- **实验设计相对克制而清晰**：三个性质差异较大的任务（几何接触、图连通性、网络流量约束），统一的 6 种子 + 公共重置评估，并做了归因/成本形式/对偶优化器三因素消融。

## 8. 不足与局限

- **依赖可微动力学**：敏感度需对系统动力学反向传播，接触丰富、非光滑或不可微的动力学场景难以直接获取梯度；作者提出可用有限差分近似，但会增加仿真调用成本，未做实证。
- **仅使用影响幅值**：`z_{i,t}` 取 2-范数，丢弃了影响方向，可能丢失"同向/反向修正"的信息。
- **理论保证缺失**：作者明确指出"成本守恒不等于归因后的策略梯度是原共享成本梯度的无偏估计"；对偶更新有限步、乘子上限为工程选择，因此**不保证每回合严格可行**，也不继承 CPO 的信任域界。
- **实验覆盖有限**：仅在 3 个仿真基准、3–6 个同质智能体上验证；无真实机器人或高保真平台迁移实验；交通任务缺少明确的"成功"定义，改用代理指标。
- **公平性上的潜在混杂**：SafeDiSTL/MAPPO 共享 actor 参数，而 MAPPO-L/MACPO 使用每智能体独立 actor，架构差异可能影响对比；基线实现细节（顺序更新、乘子重置）与原始实现是否完全一致也需谨慎解读。
- **算力与可复现信息不完整**：未报告 GPU 型号/数量/训练时长，超参敏感性与随机种子之外的稳健性验证不足。
