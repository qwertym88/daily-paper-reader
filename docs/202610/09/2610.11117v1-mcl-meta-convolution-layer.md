## 摘要
动态卷积通过使卷积核适应输入内容来增强卷积神经网络（CNN），但它将有效卷积核表示为少量基卷积核的线性混合，这限制了表达能力，并且随着混合规模的增大而增加了优化难度。在这项工作中，我们从函数视角重新审视动态卷积，并提出元卷积层（MCL），它通过高阶多项式展开将卷积核直接建模为以输入为条件的函数 W(x)。受深度多项式网络启发，MCL 利用嵌套残差块实现了一个结构化多项式元网络，生成单个输入自适应卷积核，从而将表征能力与显式混合核数量解耦，并缓解训练不稳定性。MCL 可与标准卷积即插即用地结合，并能无缝集成到 CNN 和 Transformer 主干网络中。实验评估表明，加入 MCL 使 ResNet-18、ResNet-50 和 ResNet-101 在 ImageNet 数据集上的 Top-1 准确率分别提升 6.61%、3.42% 和 3.05%。此外，所提方法显著提升了 ResNet 和 Wide-ResNet 变体在 CIFAR-10 和 CIFAR-100 数据集上的准确率。另外，在使用 Swin 和 ViT 主干网络的细粒度视觉分类任务上，所提方法优于先前方法。这些结果表明，高阶多项式卷积核生成是线性混合式动态卷积的一种强大且可扩展的替代方案。

## Abstract
Dynamic convolution enhances convolutional neural networks (CNNs) by adapting kernels to input content, but it expresses the effective kernel as a linear mixture of a small number of basis kernels, which limits expressivity and complicates optimization as the mixture size grows. In this work, we revisit dynamic convolution from a functional perspective and propose the Meta Convolution Layer (MCL), which directly models the convolutional kernel as an input-conditioned function W(x) realized via a high-order polynomial expansion. Leveraging nested residual blocks inspired by deep polynomial networks, MCL implements a structured polynomial meta-network that generates a single input-adaptive kernel, thereby decoupling representational power from the explicit number of mixture kernels and alleviating training instability. MCL is a plug-in addition with standard convolutions and can be seamlessly integrated into both CNN and transformer backbones. Experimental evaluation shows that adding MCL improves the Top-1 accuracy of Resnet- 18, Resnet-50 and ResNet-101 by 6.61%, 3.42% and 3.05% on the ImageNet dataset. Moreover, the proposed method significantly boosts the accuracy of Resnet and Wide-Resnet variants on CIFAR-10 and CIFAR-100 datasets. Additionally, the proposed method outperforms previous methods on fine-grained visual classification tasks using Swin and ViT backbones. These results demonstrate that high-order polynomial kernel generation is a powerful and scalable alternative to linear mixture based dynamic convolution.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：标准卷积使用静态卷积核，无法适应输入内容的多样性。动态卷积通过使卷积核依赖输入来增强 CNN 表达能力，成为一条重要技术路线。
- **核心问题**：现有动态卷积方法（DY-Conv、CondConv、ODConv、KernelWarehouse 等）均将有效卷积核表示为**少量基核的线性混合**，混合权重由注意力模块预测。这种范式存在三大局限：
  - **表达力受限**：混合规模 n 通常被限制在 n < 10 以控制参数与计算量，增加 n 会导致参数和 FLOPs 线性增长。
  - **优化困难**：需要联合优化多个基核及其注意力权重，依赖 softmax 温度调度 τ 与专门初始化策略来稳定训练。
  - **梯度问题**：softmax 趋近 one-hot 时，未使用基核的梯度趋近于零，导致其停止学习。
- **研究动机**：作者从函数视角重新审视动态卷积，将卷积核视为**输入条件函数 W(x)**，而非线性混合，借鉴深度多项式网络（Π-Nets）的 NCP / NCP-Skip 分解，用高阶多项式展开直接生成单个自适应核，从而将表征能力与显式核数量解耦。
- **整体含义**：MCL 桥接了动态卷积与深度多项式网络两个领域，保留了动态卷积的即插即用特性，同时用结构化多项式展开替代线性混合，为输入自适应参数化提供了一种可扩展的替代方案。

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想
- 将卷积核 W(x) 直接建模为输入特征 x 的高阶多项式函数，通过嵌套残差块实现，最终生成**单个**输入自适应卷积核。
- 关键区别：不做 softmax 加权的核聚合，避免零梯度区域；引入归一化缩放因子 γ 保证初始化时的方差稳定。

### 2.2 多项式递归公式（NCP-Skip 风格）
- 定义隐状态序列 x₁, …, x_N：
  - **一阶**：x₁ = (A₁ᵀx) ⊙ (B₁ᵀb₁)
  - **递推**：xₙ = (Aₙᵀx) ⊙ (Sₙᵀxₙ₋₁ + Bₙᵀbₙ) + xₙ₋₁，n = 2, …, N
  - 其中 Aₙ 将输入投影到隐空间，Sₙ 捕捉跨阶递归依赖，Bₙ、bₙ 定义偏置变换，⊙ 为 Hadamard 积。
- **阶数含义**：每个残差块对应二次展开，堆叠 N 个块得到 **2ᴺ 阶**多项式展开，阶数随 N 线性增长，而非指数增长。

### 2.3 实现层面的递归
- 每个线性映射用 **Conv–BN–ReLU** 实现：
  - Ãₙᵀ(x) = σ(BN(Conv_{Aₙ}(x)))
  - S̃ₙᵀ(xₙ₋₁) = σ(BN(Conv_{Sₙ}(xₙ₋₁)))
  - B̃ₙᵀ(bₙ) = σ(BN(Conv_{Bₙ}(bₙ)))
- 若 σ 取恒等映射，则退化为纯多项式形式；保留 ReLU 则形成**分段多项式**，可缓解过拟合并稳定训练。

### 2.4 最终核生成与归一化
- 最终核：**W(x) = reshape(C·x_N + β)**，C、β 为可学习线性变换。
- 归一化缩放因子（类似 Xavier/He 初始化）：
  - **γ = √(2 / (c·k² + f))**，其中 c 为输入通道，k 为元核尺寸，f 为输出通道。
  - 该 γ 是固定架构常数，用于保证初始化时输入输出方差一致，避免梯度随网络维度缩放而失稳。
- 最终输出：**y = γW(x) ⊗ x + B**，后接 BN 与激活函数。

### 2.5 优化稳定性机制
- **残差连接**：每个元块将前一隐状态加回变换输出，为梯度提供无阻塞通路，使 2ᴺ 阶展开仍能稳定训练。
- **无 softmax**：避免 one-hot 导致的梯度消失问题，ReLU 以分段线性方式传递或阻断梯度。
- **γ 缩放**：消除 W(x) 方差对输入通道、核尺寸、输出通道的依赖。

### 2.6 实现细节
- 仅在**主干网络最后一个特征提取阶段之后**插入一个 MCL，保持主干不变。
- 采用**紧凑元块**（1×1 卷积替代 3×3）降低参数开销。
- 默认设置：n = 2（两个元块，即 4 阶展开），对称元核 k ∈ {1, 3, 5}，stride = 1，padding 分别为 0/1/2。
