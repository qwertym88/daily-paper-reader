## Abstract
Sampling transitions between metastable states is a central problem in dynamical systems theory and molecular dynamics in particular. A key challenge is the existence of high free-energy barriers that separate the states, making transitions extremely rare. Recent machine learning-based methods cast transition path sampling (TPS) as an optimal stochastic control (OSC) problem over a fixed time horizon, and parameterize the drift bias via a neural network trained by simulation-in-the-loop, requiring repeated biased rollouts. To address computational and performance guarantee issues of these models, we propose a new approach for the problem based on Koopman operators. Because Koopman operators are linear, their leading eigenfunctions reveal the metastable sets and provide an estimate of the committor function with no transition path information required. Furthermore, we formulate TPS as an OSC problem up to an exit time. Our time horizon is the first hitting time of the target set, and our running cost penalizes time spent in nonreactive regions by encoding the estimated committor function. We derive the optimal controller in closed form and approximate it in a reproducing kernel Hilbert space (RKHS). This reduces the problem of constructing the optimal controller to solving a single equality-constrained quadratic program, whose solution can be characterized by a linear Karush-Kuhn-Tucker (KKT) system. On the two-channel double well and alanine dipeptide, our controller increases the fraction of trajectories reaching the target from 0% to 99.8% within 1000 steps, and from 0% to 93% within 1ps, respectively.

## 2. 方法论

### 2.1 核心思想

- 将 TPS 视为路径空间上的 Gibbs 测度采样问题，参考测度取原始动力学路径测度，能量项通过 committor 函数惩罚在非反应区域停留的时间。
- 将时间范围设为**首次命中目标集的退出时间**（而非固定时域），从而避免人工选择时域。
- 利用 Koopman 算子的线性谱结构，从**固定数据集**中估计亚稳态集合与 committor 函数，进而构造控制器。

### 2.2 关键技术细节

- **Koopman 生成元**：对 Itô 扩散 dXₜ = b(Xₜ)dt + σ(Xₜ)dWₜ，其无穷小生成元 L 为二阶线性微分算子；主特征函数揭示亚稳态结构，常数函数 ψ₀≡1 对应 λ₀=0。
- **Committor 函数**：q(x) = P(τ_{A_j} < τ_{A_i} | x₀=x)，满足边界值问题 Lq = 0 于 D_q，q|∂A_i = 0，q|∂A_j = 1。
- **自由能最小化**：定义 H(χ) = ∫₀^{τ_D} f(Xₜ)dt + Φ(X_{τ_D})，由 Gibbs 变分原理，最小化自由能的路径测度唯一为 dP*/dP = e^{-H}/Z。
- **最优控制器闭式解**：
  - 定义 ρ(x) = E_x[exp(-∫₀^{τ_D}f(Xₜ)dt - Φ(X_{τ_D}))]，满足 Lρ - fρ = 0，ρ|∂D = e^{-Φ}。
  - 最优控制器 **u\*(x) = -∇v(x) = ∇log ρ(x) = ∇ρ(x)/ρ(x)**（定理 1）。
- **理论保证（定理 1）**：
  - (i) 最优性：v(x) = J(u\*, x) = min_u J(u, x)。
  - (ii) 变分不等式：对任意路径测度 P̃，J(u\*, x) ≤ D_KL(P̃‖P^x) + Ẽ[H(χ)]，等号成立当且仅当 P̃ = P̃\*,x。
  - 该结果在**所有路径测度**上成立，而不仅限于容许控制器生成的测度。
- **RKHS 近似**：将 ρ 的求解化为等式约束凸二次规划，其解由单个线性 KKT 系统刻画，无需仿真在环。
- **控制器构造三要素**（均通过 Koopman 生成元 L 刻画）：
  1. 亚稳态核心：对前 m-1 个特征函数做 k-means 聚类，以 ε_k 半径定义核心 A_k；
  2. Committor 函数：ˆq = ψ̃ + h，其中 ψ̃ 为谱项，h ∈ H_κ 为 RKHS 余项；
  3. ρ 的因式分解：ˆρ(x) = ρ₀(x)w(x)，其中 ρ₀(x) = ˆq(x) + (1-ˆq(x))r，r = 1/(1+βT₀)，T₀ = 1/|λ₁|。
- **重加权机制**：受控路径可按权重(χ) = ˆρ(x̃₀)e^{H(χ)} 重新加权，恢复原始动力学统计量（附录 F）。
- **算法四阶段**：
  - 阶段 I：构造 Koopman 主特征对，识别亚稳态核心；
  - 阶段 II：由 Koopman 特征函数计算 committor ˆq；
  - 阶段 III：构造最优控制器 ˆu = ∇log ˆρ；
  - 阶段 IV：从源集采样初始点，积分受控 SDE 直至命中目标集。
