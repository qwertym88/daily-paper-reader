# Learning to Explain Solutions of Optimal Control Problems* 

Jiyong Lee 1 and Ilias Mitrai 1,2

Abstract — In this paper, we propose an explainable artificial intelligence framework to explain the solution of optimal control problems predicted with graph neural networks (GNNs). The proposed approach first trains a GNN that predicts the solution of the optimal control problem for a given instance represented as a graph. Given the trained GNN, we use explainable AI algorithms to identify variables, constraints, variable–constraint connections, and parameters, i.e., nodes, edges, and features in the graph representation of the optimal control problem, that affect the prediction of the optimal solution the most. We apply the proposed approach to a case study regarding the optimal control of a continuous stirred tank reactor. First, the results show that the GNN model can accurately predict the optimal values of the manipulated variables. Application of explainable AI algorithms reveals equality and inequality constraints that are the most important for predicting the optimal solution. The inequality constraints correspond to ramping constraints, some of which are active at the optimal solution. 

I. I NTRODUCTION 

Constrained optimal control problems arise in many ap-plications across science and engineering, such as process control and supply chain management. A characteristic ex-ample is model predictive control, where the control action is computed by repeatedly solving an optimization problem. Usually, the mapping between the problem formulation, i.e., variables, constraints, and parameters, and the optimal solution is treated as a black box. In general, a solver can provide a solution and a guarantee of local or global optimality, subject to numerical tolerances, but it does not explain why the specific solution is optimal. This can limit trust and implementation of the solution, especially when the returned solution is counterintuitive. Traditionally, analysis of the optimal solution has relied on tools from optimization theory. For example, Lagrangian multipliers can quantify how perturbations in constraint coefficients affect the optimal objective value [1]. Similarly, the set of active constraints provides information about the inequalities that bound the optimal solution. Recent approaches either focus on “what-if” analysis using counter-factual explanations [2] in tandem with inverse optimization [3], [4] and large language models [5], aim to identify a subset of the variables and constraints that affect the solution [6], or compare the solution with previously obtained ones [7]. Despite these advances, application of such approaches to explaining the solution of optimal control problems,

For example, some approaches are applicable only to certain classes of optimization problems, e.g., linear programming problems, or require the repeated solution of the optimization problem under consideration for different parameter values, which can incur additional computational cost. In parallel, machine learning models have been used extensively to predict solutions to optimal control prob-lems. These approaches approximate the mapping between problem parameters, e.g., set-point, and the optimal solution using a vectorial feature representation of the problem. For example, the features can capture the set-point and initial conditions of an MPC problem, and the label can be the first control action to implement [8], [9], [10], [11], [12] or the entire trajectory [13]. Although these approaches can have good predictive accuracy, they are black-box. Explainable artificial intelligence tools [14], [15] can quantify feature importance. However, application to ML models that use a vectorial representation of the optimal control problem cannot provide insights about the role of the constraints since constraint-relevant information is not typically provided as an input to the ML model. In this paper, we propose a novel approach to explain the solution of an optimization problem by combining ex-plainable artificial intelligence and graph neural networks (GNN). The proposed approach is presented in Fig. 1 and has two components. First, a GNN model is trained to predict the solution of an optimal control problem using a graph representation of the problem as an input. This representation captures the structural coupling between the variables and constraints of the control problem and the functional coupling, i.e., the bounds and domain of the variables and constraint types. Given the trained GNN model, graph explanation algorithms seek a subgraph, i.e., a subset of nodes, edges, and features, which, if passed through the trained GNN, will lead to the same prediction as the original graph. We use the identified subgraph to explain the prediction of the optimal solution using GNNs. We use the proposed approach to explain the solution of optimal control problems arising in the operation of an isothermal continuous stirred tank reactor. For a given initial condition, set-point profile, and ramping rates, the GNN model predicts the inlet flow rate over the entire time horizon. Application of the proposed framework to an instance of the optimal control problem shows that the most important constraints for predicting the value of the manipulated vari-ables at the optimal solution are ramping constraints, some of which are also active at the optimal solution. The rest of the paper is organized as follows: In Section II we present the arXiv:2610.08493v1 [eess.SY] 6 Oct 2026 application of GNNs for predicting the solution of optimal control problems; in Section III we present the application of explainable AI algorithms for obtaining the most important variables, constraints, and parameters of the optimization problem, and in Section IV we present the application of the proposed framework to a case study. In this paper, we proposed a graph-based explainable AI framework to interpret solutions of optimal control problems predicted with GNNs. The optimal control problem is repre-sented as a variable-constraint bipartite graph, which is the input to a GNN model which predicts the values of the ma-nipulated variables at the optimal solution. The explanation algorithm identifies the most important variables, constraints, and parameters when predicting the optimal solution for each manipulated variable. Application to an isothermal CSTR case study shows that GNNs can accurately predict the optimal values of the manipulated variables. Moreover, the explanation obtained captures the “local” structure of the optimization problem and some of the identified “important” inequalities correspond to active constraints in the optimal solution. Although these results show the promise of the proposed integrated predict-then-explain approach, several limitations exist. First, the proposed approach explains the GNN’s pre-dictions, not necessarily the behavior of a numerical solver. Moreover, the explanation task is solved to local optimality, which can affect the quality of the explanation obtained. Although mixed-integer optimization solvers can be used to solve the explanation problem [26], their scalability can be limited for large graphs.
