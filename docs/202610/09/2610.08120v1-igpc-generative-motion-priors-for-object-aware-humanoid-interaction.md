## 摘要
在非结构化环境中运行的人形机器人必须将鲁棒全身控制与感知并物理交互周围物体的能力结合起来。虽然大规模人体运动数据为自然且多样的人形控制提供了强大的先验，但有效地将此类先验迁移到感知驱动的物体交互仍然具有挑战性。为解决这一瓶颈，我们提出一个框架，将最近提出的生成式预训练控制器（GPC）从一般人体运动扩展到全身人形-环境交互。首先，我们将 GPC 适配为以场景可供性线索和特权状态信息为条件的交互专家。这些专家利用预训练的人体运动先验，同时学习任务特定的接触行为，包括伸向物体、抓握环境支撑以稳定身体，以及推动可移动物体。其次，我们引入一个感知驱动的学生策略，它保留预训练的 GPC 策略，并利用机载传感观测从专家中蒸馏交互技能。为弥合特权专家观测与传感输入之间的差距，我们提出两个互补的训练目标，使预训练运动先验在蒸馏过程中能够有效适应。值得注意的是，我们在多个全身交互任务上的实验表明，大规模生成式人体运动先验为学习可在接触丰富的真实世界环境中部署的人形交互策略提供了有效基础。

## Abstract
Humanoid robots operating in unstructured environments must combine robust whole-body control with the ability to perceive and physically interact with surrounding objects. While large-scale human motion data provides powerful priors for natural and versatile humanoid control, effectively transferring such priors to perception-driven object interaction remains challenging. To address this bottleneck, we propose a framework that extends the recently proposed Generative Pretrained Controller (GPC) from general human motion to full-body humanoid-environment interaction. First, we adapt GPC into interaction experts conditioned on scene affordance cues and privileged state information. These experts leverage the pretrained human motion prior while learning task-specific contact behaviors, including reaching toward objects, grasping environmental supports for stabilization, and pushing movable objects. Second, we introduce a perception-driven student that retains the pretrained GPC policy and distills interaction skills from the experts using onboard sensory observations. To bridge the gap between privileged expert observations and sensory inputs, we propose two complementary training objectives that enable effective adaptation of the pretrained motion prior during distillation. Notably, our experiments across multiple whole-body interaction tasks demonstrate that large-scale generative human motion priors provide an effective foundation for learning deployable policies for humanoid interactions in contact-rich real-world environments.

- **背景**：人形机器人在非结构化环境中需要同时具备两项能力——稳健的全身运动控制，以及感知并物理交互周围物体（伸手、抓握支撑、推动物体等）。

- **核心瓶颈**：
  - 运动先验提供的是**协调全身运动的知识**，但**不告诉机器人在特定场景中“在哪里、如何”与物体交互**。从自由空间全身控制扩展到接触丰富的物理交互是主要难点。
  - 现有感知型人形控制工作（地形条件运动跟踪、参考条件物体交互、感知型 loco-manipulation）大多**保留参考运动输入**，且尚不清楚生成式运动先验能否被系统性地适配到物体感知交互，并在**必须依赖机载感知而非特权状态**时仍被保留。

## 2. 方法论

### 2.1 总体框架
iGPC 在 **GPC 运动基座（motor foundation）** 之上分两阶段构建：
1. **物体感知交互专家**（特权仿真信息 + 场景可供性条件）；
2. **感知驱动学生策略**（机载深度/LiDAR/本体感受），蒸馏专家技能。

关键设计原则：**保留 GPC 的运动词表、自回归先验参数 θ 与解码器 ψ，只训练任务适配器与条件投影**（DoRA/FiLM 类低秩适配）。

### 2.2 保留的运动基座
- 沿用 G1 专用运动基座：FSQ（有限标量量化）表示、自回归先验、条件低秩适配。
- 设 z_t = (z_{t,1},…,z_{t,M}) 为控制步 t 的运动 token 序列；先验 p_{θ,ϕ_k}(·|z_{t,<j}, o_t) 依据前序 token 与完整控制器输入 o_t 预测第 j 个 token，ϕ_k 为任务适配器参数。
- 解码器输出关节位置目标：u_t = D_ψ(s_t, z_t)，a_t = T(u_t) = q_off + q_scale ⊙ tanh(u_t)。
- 自回归在**单个控制步内**生成 M 个 token（不是跨控制步的历史）。跟踪编码器 E_trk 与 FSQ 仅用于训练期提供 token 目标，任务执行时不需要。

### 2.3 交互与可供性预训练
- 将 G1 重定向的 BONES-SEED 动作与**支撑场景**配对：依据动作元数据与手/根运动学在交互区间附近放置固定支撑；附近有支撑的行走片段作为非交互样本，无效几何作为负例。
- **支撑描述符 g_t**：对选定身体部位 i，几何特征 d_{t,i} = R_t^⊤(p^obj_{t,i} − p^body_{t,i})（世界坐标下支撑面最近采样点与身体部位之差，R_t 为骨盆朝向到世界系的映射）。取左/右手、腕、肘共 **6 个位移向量** + **6 个归一化身体接触力量级** + **1 个几何有效性标志**。
- **稳定性描述符 b_t**：躯干朝向、相对地面高度、线速度与角速度。
- 训练样本来自**冻结跟踪器的 rollout**：输入为当前仿真身体状态、支撑/稳定性描述符、参考推导的未来根平面目标；由跟踪编码器 + FSQ 提供对齐 token 目标。仅优化 DoRA/FiLM 适配器与条件投影，采用 teacher-forcing 交叉熵（M = 8 个 token，标签平滑 0.01）。
- **特权任务学习**：在 GPC 的 token 空间优化中专门化 ϕ_k，最大化任务回报 J_k(π_k)（式 1），无需执行时参考运动轨迹。

### 2.4 学生蒸馏与传感迁移（三步）
- **第一步：结构化观测重建**
  - 估计器 F_ϑ 从传感器历史 I_t 重建控制器输入 ô_t = (ŝ_t, ê_t)；供给的任务条件原样透传。
  - 深度与 LiDAR 编码器提取局部几何，循环本体感受编码器汇总运动、力矩、跟踪误差与上一动作；融合特征预测身体相对表面位移、接触特征与几何有效性。
  - **不逐量独立预测身体状态**，而是用已知运动学重建关节体状态；另用独立循环估计器从本体历史与地面特征预测躯干高度与朝向局部线速度 ξ̂_t = (ĥ_t, v̂_t)（地面特征结合 LiDAR 平面拟合与前向运动学足部几何）。
  - (ŝ_t, b̂_t) = K(q_t, q̇_t, Q_t, ω_t, ξ̂_t)，K 补偿控制器高度约定、关节诱导运动与连杆原点-质心速度偏移。
  - 蒸馏损失：L_distill = λ_o L_obs + λ_z L_tok + λ_a L_act（仅更新 ϑ）。
- **Token 监督**：同一仿真状态下由特权输入与估计输入分别得到 z^E_t、z^S_t；教师前缀与学生前缀的下一 token 分布对齐（温度 τ 的 KL），并加入专家序列交叉熵：
  - L_tok = w_E K_E + w_S K_S + w_CE L_CE，其中 K_r 为按前缀来源 r∈{E,S} 的逐 token KL 平均。学生前缀监督让估计器暴露于自身 token 选择错误（把 on-policy 蒸馏原则应用于一个控制步内）。
- **动作监督**：L_act 对解码器输出与物理关节目标施加 Huber 损失，含教师 token 项（隔离 ŝ_t 下的解码误差）与学生 token 项。Token 损失经冻结先验反传到估计输入，动作损失经冻结解码器反传到 ŝ_t——**冻结权重不等于梯度不流过其输入**。
- **第二步：先验输入校准**
  - Δη(ô_t) = ε_o ⊙ tanh(C_η(sg[ô_t]))，õ_t = ô_t + Δη(ô_t)；C_η 初始化为零输出，stop-gradient，ε_o 为逐分量边界，任务条件字段校正界为零。
  - **token 选择用 õ_t，解码器仍用 ŝ_t**——显式分离“决策输入校正”与“解码状态重建”。
  - 因 GPC 的参考引导核采样（reference-guided nucleus sampling）会受条件误差影响，校准对齐参考分布：L_cal = Σ_{r∈{E,S}} (μ_r K^r_ref + ν_r L^r_cov + ζ_r L^r_NLL)，含参考 KL、核集覆盖损失与专家 token 负对数似然；只更新 η。
- **第三步：任务适配器精炼**
  - 在学生控制 rollout 上用 GPC 的 token 空间 PPO 精炼 ϕ_k，并正则化到冻结特权参考：L_RL = L^S_PPO + β·E[Σ_j D_KL(p^{E,S}_ref ‖ p^S_{t,j})]。
  - 执行时分布 p̄^S_{t,j} 把概率限制在由 õ_t 计算的参考核集内并重归一化；若核集质量低于 10⁻³ 则回退到参考概率重归一化。
