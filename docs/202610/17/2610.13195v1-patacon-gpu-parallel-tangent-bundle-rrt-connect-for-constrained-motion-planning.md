## 摘要
快速全身运动规划使人形机器人能够在动态环境中持续重规划，同时满足避碰和运动学约束。然而，约束运动规划除了碰撞检测和最近邻搜索外，还需要反复进行约束投影，因而产生大量计算开销。近年来，已有研究提出基于GPU的大规模并行规划器以降低计算开销。尽管如此，这些规划器仍在环境构型空间中进行引导，因此对偏离流形的候选进行投影仍是显著的开销来源，尤其是在高度约束的高维问题中。在这项工作中，我们提出PATACON，一种GPU并行双向规划器，它通过探索切空间来利用由已知约束函数诱导的局部流形几何。在双臂闭链和人形全身约束规划任务上的实验表明，随着构型空间维度和约束余维数的增长，PATACON优于先前工作，最高实现11.25倍加速。这些结果表明，GPU并行切空间探索使约束全身运动规划更接近实时性能。

## Abstract
Fast whole-body motion planning enables continuous replanning for humanoid robots in dynamic environments while satisfying collision avoidance and kinematic constraints. However, constrained motion planning incurs substantial computational cost due to repeated constraint projection in addition to collision checking and nearest-neighbor search. Recently, GPU-based massively parallel planners have been proposed to reduce computational cost. Nevertheless, these planners still steer in the ambient configuration space, so projecting candidates that deviate from the manifold remains a significant source of overhead, particularly in highly constrained, high-dimensional problems. In this work, we introduce PATACON, a GPU-parallel bidirectional planner that explores tangent space to exploit the local manifold geometry induced by known constraint functions. Experiments on dual-arm closed-chain and humanoid whole-body constrained planning tasks show that PATACON outperforms the prior work as configuration-space dimension and constraint codimension grow, achieving up to an 11.25 times speedup. These results suggest that GPU-parallel tangent-space exploration brings constrained whole-body motion planning closer to real-time performance.

## 1. 核心问题与研究动机

- **背景**：人形机器人和双臂闭链机器人的全身运动规划需要在满足关节限位、避碰的同时维持任务相关的运动学等式约束（如相对末端位姿、足部固定、质心支撑等）。这些约束定义了嵌入高维构型空间中的低维**约束流形**。
- **瓶颈**：采样规划中碰撞检测与最近邻搜索本就是主要开销，约束规划还要在树扩展过程中**反复进行约束投影**（把偏离流形的候选点拉回流形），开销进一步放大；而动态环境下的连续重规划要求低延迟。
- **已有 GPU 并行方案（cpRRTC）的局限**：虽然把投影并行化，但**仍在环境构型空间中引导**，候选点大量偏离流形，投影开销只是被并行分摊、并未减少；在强约束、高维问题中，环境空间采样的投影沿流形方向进展很小，还损害 RRT 的 Voronoi 偏置。
- **切空间方法（TB-RRT）的局限**：切空间位移更易留在约束容差内，但 TB-RRT 逐节点扩展、切空间预处理与记账开销大，且采用惰性投影，切空间上的可行性在投影后需重新验证。
- **本文目标**：把切空间引导的探索与 GPU 大规模并行树扩展结合，减少无效投影，让高维强约束全身规划接近实时。

## 2. 方法论

### 2.1 问题形式化
- 约束流形 $\mathcal{M}=\{q\in\mathcal{C}\mid h(q)=0\}$，$h:\mathcal{C}\to\mathbb{R}^m$ 可微，雅可比 $J_h(q)$ 行满秩，流形局部维度 $d=n-m$。
- 切空间 $T_q\mathcal{M}=\{v\mid J_h(q)v=0\}$，用零空间正交基 $N(q)\in\mathbb{R}^{n\times d}$（$J_hN=0,\ N^\top N=I_d$）表示。
- 可行域 $\mathcal{M}_{\text{free}}=\mathcal{M}\cap\mathcal{C}_{\text{free}}$，求连接起止点的连续可行路径。

### 2.2 核心思想
用已知约束函数诱导的**局部切空间几何**替代环境空间引导，并借助"切空间候选更贴近流形"这一性质，让**一次采样 + 一次最近邻查询产出多条候选边**，在 GPU 上并行投影验证，从而摊销切空间管理与记账开销。三大贡献对应三个组件：

### 2.3 关键技术

**（1）切空间引导采样（TGS）——并发探索**
- 切空间投影算子 $P_{T_r}=N(q_r)N(q_r)^\top$，切空间 $T_r=\{q_r+N(q_r)c\mid c\in\mathbb{R}^d\}$。
- 每个树节点存储：投影后的流形构型 $q_i$、父节点索引、所属切空间索引 $\tau(q_i)$、切空间局部表示 $\bar q_i$。$q_i$ 用于可行性与路径验证，$\bar q_i$ 用于切空间探索与**切空间内局部最近邻**。
- **共享切空间库（Tangent-space Bank）**：起、止树各维护一个位于 GPU 全局内存的库，由多个 CUDA 块共享；新切空间在其根节点与数据初始化完成后才可被选中。
- **动态选择**：每轮迭代 CUDA 块按树规模选择生长树（规模相近时交替，差距超阈值时优先扩展较小树，遵循平衡双向搜索）；随后在对应库中循环扫描，动态选取就绪切空间，而非静态绑定到块。
- **块内 Halton 采样** + 采样位移限制在关节空间边界内；并沿用 TB-RRT 的**反向回溯抑制**：若采样位移与新切空间前向方向 $d_r$ 内积为负则翻转方向，限制在前半空间。
- **切空间内最近邻**：$q_{\text{near}}=\arg\min_{q_i\in V(T_{\text{grow}},r)}\|\bar q_i-\bar q_{\text{rand}}\|_2$，块内线程级距离计算 + 块级归约并行实现。

**（2）切空间多边扩展（TGMP）——推测式多边生成**
- 位移 $v_{\text{ext}}=\bar q_{\text{rand}}-\bar q_{\text{near}}$，若 $\|v_{\text{ext}}\|\le\epsilon_{\text{dir}}$ 返回 Trapped；否则归一化 $u=v/\|v\|$，生成 $K$ 个候选：$\bar q_k=\bar q_{\text{near}}+k\xi u,\ k=1..K$（$K\le K_{\max}$）。
- 用约束残差 $E_M(\bar q_k)=\|h(\bar q_k)\|_2$ 判断切空间线性近似的有效性；当 $E_M>\epsilon_M$ 或达到 $K_{\max}$ 即停止生成（越界候选仍保留送入投影验证）。论文强调 $E_M$ 只是**切空间更新判据**，不是到流形的几何距离。

**（3）GPU 并行边投影与验证**
- 不同候选边分配给不同协作线程组并行处理；**单条边内部航路点仍按原顺序串行投影**（后一步依赖前一步投影结果），保证收敛语义不变。
- 边的有效性：投影在容差内收敛 + 全部投影构型满足关节限位与碰撞约束（CONNECT 时还需满足进度条件）。
- **只插入从第一条边开始的最长连续有效前缀**；首边无效则返回 Trapped。切空间更新需整批候选被接受且末端候选满足 $E_M(\bar q_{\text{end}})>\epsilon_M$。

**（4）目标导向连接与桥接验证**
- 探索性 EXTEND 成功后，在对方树全部节点中取最近构型作为固定目标 $q_{\text{tar}}$，反复对其施加 EXTEND；连接方向为 $v_{\text{con}}=P_{T_r}(q_{\text{tar}}-q_{\text{cur}})$（投影到当前切空间）。
- 进度约束：$\text{dist}(q_k,q_{\text{tar}})<\text{dist}(q_{k-1},q_{\text{tar}})-\epsilon_{\text{prog}}$，防止数值投影改变方向后不向目标推进。
- 距离小于 $\epsilon_{\text{con}}$ 后对剩余桥接段做串行投影与碰撞验证，通过才判定 Connected 并回溯路径；CONNECT 失败则继续，直至 Trapped 或达到 $J_{\max}$。

**算法流程（Algorithm 1）**：初始化双树与切空间库 → 各 CUDA 块并行循环：平衡选树 → 选切空间 → 采样 → 切空间内最近邻 → EXTEND（多候选生成 → 并行投影验证 → 插入最长有效前缀）→ 选目标 → CHECK CONNECTION → 失败则进入 CONNECT 循环。

## 6. 主要结论与发现

- **维度与约束强度越高，PATACON 优势越明显**：7-DoF/14-DoF 上与 cpRRTC 相当或略慢（Franka OR：1.65 ms vs 0.52 ms；双臂 BK：4.77 ms vs 3.94 ms），但在 15–35-DoF 上全面领先。
- **最大加速 11.25×**：固定基座 FFW

-SG2 的 BK+OR(8D) 基准上取得 **11.25×** 加速；移动基座 18-DoF 与 G1 35-DoF 上也保持数倍级领先，且随约束维度升高（如 BK+OR+FT 的 20D 约束）优势进一步扩大。
- **切空间引导本身不足，需与多边扩展协同**：累积消融显示，单独加入 TGS 时因切空间库管理、局部最近邻与记账开销，性能甚至略逊于 cpRRTC；叠加 TGMP 后，一次采样产出多条候选边、并行投影验证摊薄了上述开销，成功率与时间同步改善，完整 PATACON 为最优变体。这说明论文的核心增益来自“切空间几何 + 推测式多边 + GPU 并行验证”的组合，而非任一单项。

- **成功率-时间曲线整体占优**：图 5 显示 PATACON 在多数 regime 的整条曲线位于 cpRRTC 左上方，即不仅平均时间更短，达到相同成功率所需时间也更少；在低维基准上二者曲线接近，差距主要体现在高维强约束区间。

## 7. 局限与讨论

- **依赖可微约束与雅可比**：方法要求约束函数 $h$ 可微且雅可比行满秩，切空间正交基 $N(q)$ 需实时计算；对不可微约束（如接触切换、摩擦锥边界）或奇异构型需额外处理，论文未深入讨论秩亏时的数值策略。
- **不等式约束的处理较简化**：CoM 等不等式约束被纳入统一投影框架，但切空间构造本质面向等式流形；不等式活跃集变化时切空间几何可能不连续，论文未给出专门分析。
- **线性近似的局部有效性**：TGMP 用残差 $E_M$ 控制切空间更新，属于启发式判据而非几何距离保证；在流形曲率大或约束强非线性时，候选边可能频繁越界，多边生成的收益会下降。
- **对比覆盖不完整**：高维 regime 仅与 cpRRTC 比较，McVAMP/TB-RRT 因超时被排除；消融只在 G1 上完成，组件贡献在其他维度/约束类型上的普适性缺乏验证。
- **超参数与稳健性**：$N_{\text{blk}}$、$K_{\max}}$、$\epsilon_M$、$G$、$\xi$ 均固定，缺少敏感性分析与自适应策略；计时对同机并发负载敏感（附录的 GPU 争用事件即是例证），测量稳健性仍需更严格的隔离与重复实验。
- **理论性质未展开**：论文侧重系统与实验，未给出概率完备性、收敛性或复杂度方面的形式化结论；切空间库的并发调度正确性也主要依赖实现约束而非证明。

## 8. 总体评价

PATACON 是一篇以**系统设计与工程加速**为主的约束运动规划工作。其洞见清晰且合理：约束规划的低效根源在于“在环境空间采样、再反复投影回流行”，而切空间引导能从源头减少偏离；GPU 大规模并行则恰好适合摊销切空间管理与多候选验证的开销。二者结合形成了 TGS、TGMP 与并行投影验证三个相互支撑的组件，方法叙述完整、算法流程明确。

实验方面，统一模型、环境、起止对与容差的设置较为严谨，成功率-时间曲线与累积消融提升了结论可信度，附录主动披露并修正计时偏差也体现了较好的学术诚实。主要不足在于高维基准的对手覆盖有限、消融范围偏窄、超参数敏感性缺失，以及缺少理论性质与不等式约束的深入处理。总体而言，该工作对高维强约束全身规划（尤其是人形与双臂闭链系统）具有明确的实用价值，其“切空间采样 + 多边推测 + GPU 并行验证”的组合思路也可为后续约束规划器设计提供参考。
