# Minimum-Energy Control for Stochastic Linear Systems 

Vaishnavi Sharma 1 and Vaibhav Katewa 2

Abstract — The open-loop minimum-energy control (MEC) problem asks for control inputs that minimize the control energy while ensuring the terminal state reaches a desired value. In this paper, we study the open-loop MEC problem for stochastic linear time-invariant systems. We consider avariety of stochastic constraints that enforce the terminal error to be small , and show that Stochastic MEC (SMEC) problem can be formulated as a QCQP. We obtain the optimal solution for SMEC and show that it generalizes the well-known Deterministic MEC problem by introducing novel stochastic variants of controllability and Gramian matrices. Finally, we show that there exists a fundamental lower bound on the optimal control energy which cannot be overcome by increasing the time horizon of the problem. 

I. I NTRODUCTION 

Minimum-energy control is a classic open-loop control problem that involves steering a dynamical system from an initial state to a final desired state within some finite horizon 

T with minimum control energy (often represented using weighted norm of input u). For deterministic linear systems, this problem admits a closed-form solution, and has been extensively studied in the literature [1]. Prior works have studied stochastic variants of this problem. For example, in [2], the problem of steering the state of a linear stochastic system from one Gaussian distribution to another is solved, and closed-loop optimal control is obtained. [3] solves the problem of steering a stochastic linear system between two desired Gaussian distributions while restricting to the feedback controller to the affine class. Further, the authors in [4] enforce a constraint on the terminal state distribution using Gromov-Wasserstein distance for affine feedback policies. In another work [5], a variant of the LQG problem is studied in which penalties on the terminal state are replaced by the specification of the terminal state distribution. A recent work [6] presents a unified framework to find probabilistic reachable sets for stochastic systems by decoupling stochastic and deterministic disturbances. Also, data-driven approaches to find minimum-energy control when accurate dynamics are unavailable have been developed in the deterministic setting [7]. All the above works (except [7]) focus on obtaining the optimal closed-loop controller with different objectives. In contrast, we focus on obtaining the optimal open-loop control inputs in the presence of terminal constraints. To the best of our knowledge, ours is the first paper to address this problem. Note that for the linear Gaussian systems with affine feedback, closed-loop control inputs are random and can alter

Further, enforcing terminal constraint in stochastic systems is non-trivial since the terminal state is random and the notion of exact reachability is no longer meaningful. The main contributions of the paper are as follows. First, we show that the Stochastic MEC (SMEC) problem can be formulated as a QCQP for a wide variety of terminal constraints. We then obtain an explicit feasibility condition and explicit solution to the QCQP along with its spectral representation. Second, we introduce the notion of stochastic Gramian and stochastic Controllability matrix for open-loop SMEC problem, which is a counterpart of the standard Gramian for deterministic systems. Using this, we show that the solution structure of Stochastic and Deterministic MEC problems are similar, and in fact, the DMEC problem is a special case of SMEC problem. Third, we show that there exists a fundamental limitation on the minimum achievable cost for the SMEC problem that cannot be overcome by increasing the time horizon.

We studied the open-loop MEC problem for stochastic linear systems. The study of this problem led us to propose the novel stochastic controllability matrix and stochastic Gramian. We conjecture that these quantities should play a role in other types of stochastic control problems as well. Future works include investigating this point, generalizing the problem to include state cost as well, and studying the problem in a data-driven setting where the system model is unknown. APPENDIX
