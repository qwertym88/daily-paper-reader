## 摘要
近年来，视觉Transformer（ViT）在图像分类领域受到越来越多关注。然而，ViT因对数据的巨大需求而著称，通常只有在大型数据集上训练时才能取得高性能结果。本文研究ViT在数据有限的小规模数据集上的具体表现，而在实际中图像数据的可得性往往受到限制，尤其是在医学影像等领域。为缓解该问题，我们设计了一种多阶段残差ViT，称为ReSEViT，并结合自集成方法利用中间特征的多层次信息。由于分类决策边界复杂，依赖单一分类器可能导致预测误差。因此，我们提出一种新的ViT学习方法，称为自集成学习，它在单一模型中对多阶段分类器进行集成。我们的自集成包含一种新方法——动态学习器选择（DLS），用于自适应选择不同阶段的重要性。ReSEViT引入了残差令牌嵌入，这是一种类ResNet模块，在每个阶段与Transformer模块一起建模有效的局部结构。将残差令牌和自集成学习集成到多阶段ViT中，可在保持小规模图像数据集上高效模型规模的同时，降低冗余、预测误差和方差。

## Abstract
Vision Transformer (ViT) has garnered increased attention for image classification in recent years. However, ViT is notorious for its data-hungry problem as it achieves high-performance results when only trained on large-size datasets. In this paper, we study how ViT specifically works on small-scale datasets with limited data where the availability of image data is often constrained in practice, especially in fields such as medical imaging. To mitigate the issue, we designed a multi-stage residual ViT, dubbed ReSEViT, with the self-ensemble method to utilize multi-level information from intermediate features. Due to the complex decision boundaries for classifications, relying on a single classifier can lead to prediction errors. Hence, we propose a new learning method for ViT, named self-ensemble learning, which ensembles multi-stage classifiers in a single model. Our self-ensemble comprises a novel approach, Dynamic Learner Selection (DLS), to adaptively select the importance of different stages. ReSEViT incorporates residual token embeddings which is a ResNet-like block to model effective local structures alongside with transformer blocks in each stage. The integration of residual tokens and self-ensemble learning into a multi-stage ViT highlights the reduction in redundancy, prediction error and variance while maintaining an efficient model size for small-scale image datasets.

## 1. 核心问题与研究动机

- **背景**：ViT 在图像分类上表现突出，但其缺乏 CNN 固有的局部归纳偏置（局部感受野、平移不变性、空间下采样），因此高度依赖大规模数据；在中等规模数据（如 ImageNet-1K）上从零训练时甚至不如 CNN，在小数据场景下更易过拟合。
- **现实痛点**：医学影像、边缘/IoT/可穿戴设备等场景数据稀缺且算力受限，纯 ViT 难以部署；而传统集成方法（多模型平均、Bagging 等）虽能提升精度，却成倍增加参数量与训练/推理开销，不适合实时与轻量应用。
- **核心问题**：如何在**单个模型**内、以**低参数量与低计算开销**缓解 ViT 的小数据困境，同时降低预测误差与方差？
- **整体含义**：作者提出多阶段残差 ViT（ReSEViT），将“局部信息流”（每阶段的残差 token 嵌入）与“全局信息流”（跨阶段自集成学习）结合，用多出口（multi-exit）架构实现“一次训练、单模型集成”，为小数据图像分类提供高效方案。

## 2. 方法论

### 2.1 核心思想
- 以 CvT 的三阶段层次结构为骨架，每个阶段由**残差 token 嵌入**（类 ResNet 块）与**卷积 Transformer 块**组成；每个阶段挂一个分类器（多出口），通过**自集成学习**融合多层级预测。
- 直觉：每阶段局部归纳偏置越强（残差 token），自集成的全局融合收益越大，形成“局部增强 → 全局复合”的效应。

### 2.2 关键技术细节
- **残差 token 嵌入**：用 ResNet 式残差块替换 CvT 的卷积 token。卷积部分为两次 Conv2D+BN+ReLU 堆叠（式 1：F(x,{W}) = Conv(Conv(x))），再加跳跃连接（式 2：y = x + F(x,{W})），以保留低层特征、缓解深层抽象化与优化困难；因含卷积，可去除位置编码，降低计算量。
- **卷积 Transformer 块**：对 Q、K、V 分别施加深度可分离卷积（DWS）注入局部空间上下文（式 3），再做标准多头自注意力（式 4：Softmax(QKᵀ/√d)V）。
- **阶段分类器**：每阶段取 CLS token，经 LayerNorm + 全连接层输出类别分布；不引入额外卷积层，额外参数仅来自各阶段 FC 层。
- **自集成推理（朴素版）**：对 N 个阶段分类器的概率取平均后 argmax（式 5）。
- **方差理论分析**：Var(Ẑ) = σ²(ρ + (1−ρ)/N)（式 6），说明阶段间相关性 ρ<1 时，增加阶段数 N 可降低预测方差，从而改善小数据下的泛化。
- **多阶段集成损失（ML）**：对每个阶段分类器都用真实标签监督（式 7：L_SE = (1/N)Σ L_CE(Z_n, y)），避免早期分类器缺乏监督而沦为噪声。
- **动态学习器选择（DLS）**：以各阶段分类器的**训练准确率**计算归一化优先级分数 β_n = acc_n / (Σ acc_n + ε)（式 8），ε 防止早期 epoch 除零；用 β 加权损失（式 9：L_WSE = Σ β_n·L_CE）与加权推理（式 10：argmax Σ β_n^f·Z_{n,k}）。β 每个 epoch 顺序更新，训练结束后固定为 β^f 用于推理；DLS 无额外参数、无额外计算。
- **模型变体**：ReSEViT-T（3.88M 参数 / 0.56G FLOPs）、ReSEViT-S（4.13M / 0.68G）、ReSEViT-L（12.43M / 4.08G），均为三阶段、三分类器。

## 6. 主要结论与发现

- **精度提升显著且高效**：ReSEViT-T 在三张小分辨率数据集上平均 78.39%，较 CvT-13†（73.78%）高 4.61 个百分点，且参数更少（3.88M vs 19.65M）；ReSEViT-S 平均 79.65%；ReSEViT-L 在 ImageNet100 上达 85.23%，优于 CvT-13（81.57%）且参数更少（12.43M vs 19.69M）。
- **抗数据饥饿**：仅用 50% 训练数据时 ReSEViT-L 达 79.17%，而 ViT-B 仅 37.66%；ViT-B 精度随数据量呈凹形下降，混合 ViT 呈凸形上升。
- **医学场景有效**：MedMNIST 平均 AUC 0.8996、Top-1 0.8879，优于 CvT-13†/CCT/NesT-T；ISIC 2018 上 ML+DLS 达 AUC 0.9176、Top-1 0.7066，为对比中最佳（但并非每个子集都最优，如 BreastMNIST Top-1、OCTMNIST AUC 略逊）。
- **自集成优于传统集成**：CIFAR-100 上仅用 1 个模型（4.13M 参数、1.01× 训练/推理耗时）即超过双模型平均（79.89%）与 FiLM（80.07%），显著优于 Bagging/SSE/FGE 的性价比。
- **组件贡献可量化**：残差 token 使 CIFAR-100 提升 2.43%、ImageNet100 提升 2%；ML 修复早期分类器监督后集成由 76.62% 升至 80.33%，DLS 再升至 81.05%；β 同时用于损失与推理效果最佳；三分类器集成最优。
- **稳定性与校准**：DLS 与残差 token 显著平抑各阶段梯度范数失衡；ML+DLS 降低预测方差；类别不平衡下 DLS 明显改善 ECE 校准。
- **模型无关性**：自集成可迁移至 SqueezeNet、ResNet、PreAct-ResNet1001、CvT、ConvNeXt、PoolFormer、NesT、Conv2Former 等，平均提升 2.71%，仅增 0.06M 参数、<0.01G FLOPs。

## 7. 优点

- **架构与训练协同设计**：残差 token（局部）与自集成（全局）互补，形成“局部强 → 全局更强”的清晰叙事，并有特征可视化（Fig. 3、Fig. 8）与梯度/方差分析支撑。

## 8. 不足与局限

- **结构假设较强**：固定三阶段、三分类器，阶段数与分类器数未与数据规模/任务难度自适应；更浅或更深网络的收益边界未系统探讨（仅 Table 13 做了 1/2/3 分类器对比）。
- **DLS 的权重依据较粗糙**：β 仅依赖训练集准确率，未使用验证集或置信度/损失信息；在小数据下训练准确率易饱和或过拟合，可能导致权重偏差；ε 仅缓解早期 epoch 数值问题，未讨论权重震荡与收敛性。
- **收益不均衡**：部分医学子集（BreastMNIST Top-1、OCTMNIST AUC、Organ_A_MNIST）未见提升甚至略降；ChestMNIST 各

ChestMNIST 各阶段分类器的单独表现波动较大，说明在类别数较多、样本极不均衡的子集上，多出口融合的稳定性有限；此外，ISIC 2018 仅采用单次 80/20 划分，未报告交叉验证或置信区间，小样本下的结论稳健性有待加强。

- **缺少与“预训练 + 微调”范式的对比**：全部模型均为从零训练，而实际小数据场景最常用的强基线是 ImageNet/自监督预训练后微调（或 Linear Probe、Adapter/Prompt 调优）。论文未与此类范式比较，也未讨论 ReSEViT 与预训练结合后是否仍有增益，这在一定程度上削弱了“小数据可用性”主张的实践说服力。
- **未与数据层面方法对照**：Mixup/CutMix、AutoAugment、RandAugment、知识蒸馏、标签平滑之外的正则化等手段未纳入对比，难以判断“架构内集成”相对于“数据增广/蒸馏”的边际收益大小。
- **理论分析偏定性**：式 (6) 建立在各出口误差同方差、两两相关性均一的简化假设上，而三阶段特征层级差异显著，ρ 未必恒定、误差方差也非齐性；因此该公式更适合作为趋势解释，而非严格界。作者未给出偏差项分析或更细的“偏差—方差—协方差”分解。
- **DLS 缺少敏感性与收敛性讨论**：ε 取值、β 的更新频率（每 epoch 一次）、β 是否平滑/动量更新、早期训练准确率噪声对权重的影响均未做敏感性实验；也未分析 β 在训练中是否出现震荡或退化（如某阶段长期主导）。
- **融合策略探索有限**：除朴素平均与 DLS 加权外，可学习的门控/注意力融合、按置信度或熵加权的融合、温度标定后的概率平均等均未尝试，无法确认当前方案是否已接近该架构的上限。
- **效率评估口径不完全统一**：主实验的精度—参数量/FLOPs 对比未约束在等算力预算下；推理吞吐（images/s）与相对耗时受实现、算子融合、batch 设置影响，且部分基线为作者复现或直接引用，跨实现比较存在噪声；未报告训练总 GPU 小时与能耗。
- **部署验证缺位**：论文以边缘/IoT 为动机，但未在真实边缘设备（如 Jetson、手机 NPU）上给出延迟、内存占用、功耗实测，仅有 FLOPs 与 RTX 3090 吞吐，动机与验证之间存在落差。
- **可解释性偏定性**：逐阶段 GradCAM（Fig. 8）与 PCA（Fig. 7）以可视化展示为主，缺少定量定位指标（如 pointing game、IoU）或与单出口模型的系统性对比。

## 9. 启示与可拓展方向

- **权重信号的升级**：DLS 以训练准确率为权重是“零成本”的巧妙简化，但可自然扩展为验证集准确率、预测熵/置信度、损失下降速率或校准误差驱动的动态加权，从而缓解小数据下训练准确率饱和导致的权重失真。
- **自适应出口与动态推理**：当前固定使用全部三个出口；可引入基于置信度阈值的早退（early-exit）机制，在简单样本上只走浅层出口，把“精度冗余”兑换为推理算力节省，这与边缘端自适应计算的研究脉络高度契合。
- **与预训练/自监督结合**：将残差 token 嵌入与多出口自集成叠加到 MAE、DINO 等预训练骨干上，检验“归纳偏置 + 集成方差削减”能否在微调范式中继续成立。
- **融合层可学习化**：用轻量门控网络替代固定 β，或对出口概率做温度标定后再融合，有望进一步改善校准与不平衡场景表现。
- **理论精细化**：将式 (6) 拓展为含偏差项的分解，并允许阶段间异方差与异相关，可更准确刻画“增加出口”的收益边界与饱和点。
- **任务外延**：多出口结构天然适配需要不确定性估计的场景（医学筛查、故障检测、开放集识别），可用出口间分歧度作为弃权/转人工的信号。

## 10. 总体评价

- **定位**：本文属于“架构—训练—推理”一体化的小数据高效视觉骨干工作，核心贡献不在于提出全新的注意力算子，而在于把**残差式局部归纳偏置**与**多出口自集成**两条已知思路以极低成本耦合，并用 DLS 解决了多出口训练中“浅层出口监督不足”的关键工程问题。
- **贡献强度**：方法简洁、复现门槛低、增益可量化（小分辨率平均 +4.61 个百分点、参数量约为 CvT-13 的 1/5），且模型无关性在 8 种骨干上得到验证，实用价值明确；理论部分为定性支撑而非严格证明。
- **证据质量**：实验矩阵覆盖面在同类工作中属较充分（自然/医学、多分辨率、数据规模曲线、不平衡与校准、集成方法对照、完整消融），主要短板是缺少预训练范式与数据增广类基线、效率对比口径未完全对齐、以及缺少真实边缘设备实测。
- **适用建议**：适合数据规模中等偏小、算力受限、且不便维护多模型集成管线的部署场景；若目标数据可获取强预训练权重，建议先验证 ReSEViT 相对“预训练 + 微调”的增量收益，再决定是否采用。
- **一句话总结**：ReSEViT 用“每个阶段都带残差局部先验、每个出口都被动态监督”的单模型设计，以接近基线的开销换取了接近集成的稳健性，是小数据视觉分类中性价比突出的工程化方案，但在理论严谨性与部署验证上仍有明确的补强空间。
