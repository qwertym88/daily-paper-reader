A B S T R A C T 

Vision Transformer (ViT) has garnered increased attention for image classification in recent years. However, ViT is notorious for its data-hungry problem as it achieves high-performance results when only trained on large-size datasets. In this paper, we study how ViT specifically works on small-scale datasets with limited data where the availability of image data is often constrained in practice, especially in fields such as medical imaging. To mitigate the issue, we designed a multi-stage residual ViT, dubbed ReSEViT, with the self-ensemble method to utilize multi-level information from intermediate features. Due to the complex decision boundaries for classifications, relying on a single classifier can lead to prediction errors. Hence, we propose a new learning method for ViT, named self-ensemble learning, which ensembles multi-stage classifiers in a single model. Our self-ensemble comprises a novel approach, Dynamic Learner Selection (DLS), to adaptively select the importance of different stages. ReSEViT incorporates residual token embeddings which is a ResNet-like block to model effective local structures alongside with transformer blocks in each stage. The integration of residual tokens and self-ensemble learning into a multi-stage ViT highlights the reduction in redundancy, prediction error and variance while maintaining an efficient model size for small-scale image datasets. 

## 1. Introduction 

Recent advancements in deep learning models, particularly Transformers [53], have significantly impacted various vision tasks i.e. , image classification [11, 60, 59], object detection [72], and image processing [4]. Among these, image classification is a fundamental building block that supports the development of more complex applications [42, 18]. ViT [11] introduced the first fully transformer-based model that attains competitive results on large-scale image classification benchmarks. Despite these advances, the performance of ViT is still inferior to that of CNN-based models when trained from scratch on medium-sized datasets, e.g. , ImageNet-1K. This disparity arises as the transformers lack the locality inductive biases (local receptive field, translation invariance, and spatial subsampling [31]), which are inherent in CNNs. Consequently, training ViT from scratch with limited data yields suboptimal performance, while its high computational cost further challenges deployment on resource-constrained edge devices, IoT devices, consumer electronics, and wearable medical devices that rely on lightweight models [52, 55, 61, 27, 1, 62, 67]. Several works [70, 16, 12, 34] have introduced strategies for training ViT from scratch on small datasets with either model architecture modifications or self-supervised techniques to solve the data-hungry problem. It takes place when ViT underperforms due to a limited amount of data. A recent work, Compact Convolutional Transformer (CCT) [16], introduced a simple CNN-Transformer hybrid approach that can be well-trained from scratch on small-scale datasets ( e.g. , CIFAR) by employing convolutional tokenization and a transformer encoder with sequence pooling. This architecture design aims to take advantage of the inductive biases from CNNs and integrate them with a transformer. To further improve the ViT model, one straightforward strategy is to use the existing ensemble methods [2, 17, 26].

However, ensemble methods typically lead to a significant increase in the number of parameters, which is often impractical for real-time applications, especially for large models. For example, CCT-14/7 ×2 is a single-stage type model requiring 22.36M parameters for the ImageNet dataset [16], which may expand to more than 100M if we ensemble five models with similar sizes in a parallel way. Therefore, we proposed ReSEViT, a residual vision transformer with the self-ensemble method. The self-ensemble method is a novel ensemble method using only one deep learning model for an image classification task. Such a hierarchical structure ensemble strategy has been explored previously on object detection tasks, i.e. , FPN [33], but research on image classification has barely been touched. In our approach, we first design a ViT backbone with a multi-stage structure to enable self-ensemble learning. Specifically, inspired by CvT [60], it adopts a three-stage model consisting of convolutional token embedding and a convoluted transformer block in each stage. In our method, a residual token embedding [19] is adopted to model effective local structures in each stage. Notably, the ResNet block is not a new architecture. However, it is employed to provide an efficient strategy for ViT’s data hunger on small image datasets. Similar to the works of [40, 54, 64], parts of the architecture are replaced by existing methods, such as the MobileNet block, shift operation, and pooling layer, to demonstrate the effect on the model for a specific purpose. We hypothesize that the residual token enables our self-ensemble to perform better and more efficiently for small-scale datasets since the local inductive biases for the transformer are denser in each stage. Intuitively, stronger feature representations at each stage lead to a compounding effect in the self-ensemble method resulting in high performance while preserving computational efficiency. To effectively ensemble the results from different stages, one naïve approach averages the prediction results obtained by classifiers of different stages during inference. However, the performance is degraded since the classifiers of different stages are not of the same importance. To address this issue, we propose a multistage ensemble loss to cultivate the learning in each stage classifier. Specifically, the multistage ensemble loss forces all stage classifiers to learn from the true label, making each stage classifier’s outputs meaningful for our self-ensemble method. We then introduce Dynamic Learner Selection (DLS) to adaptively select the best classifiers based on the training performance of each stage classifier. DLS is a simple non-parametric weighting scalar that has no additional computation. We can apply the DLS to both the ensemble inference and the multistage ensemble loss. The goal of DLS is to maximize the utilization of the best stage classifiers and minimize the stage classifiers with inferior performance. Finally, we illustrate our approach compared with the traditional ensemble for an efficient ensemble in Fig. 1. ReSEViT maintains the efficiency of ViT in less data-intensive domains. The main research contributions of this study are highlighted as follows: 1. To mitigate the Vision Transformer’s data-hunger on small image datasets, we provide a new perspective by marrying a multi-stage ViT model with self-ensemble learning via a multi-exit architecture, improving data efficiency. While the traditional methods ensemble multiple models, we present a unified model strategy with residual token and self-ensemble learning for local and global information flows.

## 2. Related Works 

2.1. Transformer in Vision 

The variants of Transformer have not only dominated in natural language processing (NLP) tasks [8, 63], but also in speech processing [9], and various vision tasks, such as classification [11, 49], object detection [3], unsupervised semantic segmentation [29], and human state recognition [56]. Specifically, ViT [11] introduces a pure transformer-based model [53] that can attain competitive performance against CNNs [19, 46] for image classification on large-scale datasets ( e.g. , ImageNet-22k and JFT-300M). It partitions an image into fixed-size patches (so-called token embeddings) and adds positional embedding to provide spatial information for each patch embedding. Afterward, the self-attention mechanism is applied to encode the embeddings. However, ViT heavily relies on a large amount of data to learn the global structures of images. Several works have tried various model architecture designs to better capture the local structures without requiring large amounts of data. For example, DeiT [49] explores data-efficient training with distillation from other CNN models. T2T-ViT [65] overcomes the tokenization problem on ViT by adopting a soft split operation. The soft split operation concatenates multiple tokens within a sliding window into a token, which allows the network to model the local image structures, such as edges and lines. However, the use of multiple tokens concatenation increases computational complexity. As such, PVT [59] introduces a progressive spatial reduction technique on attention with multiple stages, which is able to generate feature maps at different scales and reduce computational complexity and memory costs. Another way to capture the local structures is to leverage the convolution. For example, CvT [60] introduces convolutions on both token embedding and Multihead Self-Attention to model local spatial context for three stages. In this architecture, the positional embedding can be safely removed since the convolution token is able to encode position information for the Transformer. Furthermore, CCT [16] outperforms CNN-based models by using the single-stage vision transformer architecture (isotropic [36]) consisting of a convolution token embedding layer, a transformer layer, and a sequence pooling layer. The sequence pooling layer is used to pool the tokens into a representative token with an attention mechanism in the last layer. Compared with CCT, CvT is a hierarchical three-stage model with local inductive bias applicable to our self-ensemble learning. Henceforth, we extend CvT with residual token embeddings and our self-ensemble methods to aggregate the learned multi-level features obtained from the early into the deepest classifier.

2.2. Ensemble Learning 

The main idea of ensemble learning is to generate multiple weak classifiers and fuse the multiple results, e.g. ,majority voting, to obtain a better final result [10, 71]. The improvements from the fusion of multiple classifiers are due to the following two reasons [41]. First, if the performance of different classifiers is effective and complementary to each other, the ensemble would fundamentally improve the performance and reduce the risk of a poor prediction. Second, finding the decision hyperplanes for different classes may be too complex for a single classifier; in contrast, ensemble learning effectively finds separation hyperplanes with multiple classifiers. As such, ensemble methods have been widely adopted in improving the performance of learning tasks, e.g. ,Bagging [2], Adaboost [17], prediction voting [26, 44], and Mixture-of-Experts [25]. Among them, Bagging is one of the earliest ensemble methods, taking bootstrap samples of the training data and learning them independently with several classifiers of the same kind. The individual classifiers are further mixed and voted upon by a simple majority voting scheme for the final decision. In the generation of modern ensemble learning, there is a growing interest in reducing the enormous computation costs associated with fusing multiple neural networks. SnapShot Ensemble (SSE) [22] is an efficient approach that ensembles several sub-models of the same architecture in different local minima by using a cyclical learning schedule rate at no additional training cost. Similar to SSE, Fast Geometric Ensemble (FGE) [13] can achieve better performance by finding minima along high-accuracy pathways. Recently, FiLM-Ensemble [51] introduced a feature-wise linear modulation to construct an ensemble with conditional activation functions under a single monolithic design. However, the monolithic design is slow in practice for mimicking multiple models. BranchyNet [47] introduced the idea of network-based ensembles and implemented it by introducing multiple exit branches. For each multi-exit branch, joint optimization is applied to prevent overfitting and improve the accuracy of the network. A fixed weighting strategy is further introduced to increase the accuracy by setting a high value for the first branch and a low value for the last branch. As such, they achieve an approximate 1% accuracy improvement over the uniform weight. However, the fixed weighting strategy may limit its performance. Another related work that uses the idea of self-distillation [68] for information boosting has been studied by exploiting the multi-exit architecture. The definition of self-distillation is to transfer knowledge from a teacher part to a student part within the same network. The teacher could be either the deepest stage classifier or the strongest one. Unlike self-distillation, we aim to build a self-ensemble method that integrates different stages instead of forcing every stage to imitate the deepest stage classifier or the strongest one. The differences between our self-ensemble method and existing ensemble learning methods are twofold. First, the proposed method ensembles the predictions from different stages of one single model. Second, the proposed method introduces dynamic weighting scalars based on the performance of the training data for better ensemble predictions. 3.1.1. Residual Token Embedding 

We replace the convolution token of CvT [60] with the residual token, which is a ResNet block [19] for effective local structures where the stronger local representations constitute the locality inductive bias provided to the Transformer. Convolution is an important factor in extracting local structures related to small-scale design in ViT. Generally, convolution layers transform the features by using a deep structure. Given the input image, the first convolutional layer extracts low-level features of the object. When the second or subsequent convolution layer is piled, the features transformed into higher-level features. Based on the convolution output characteristics, the skip connection ensures the network does not forget the lower-level feature. Otherwise, the feature representation becomes too abstract due to deep convolutions. In Fig. 3, the residual token captures clearer edges, contours, and texture patterns highlighted in stage 1. Moreover, compared with the convolution token, the residual token increasingly focuses on the object and highlights distinct parts, such as the head and body, rather than the background in stage 2. In stage 3, activations in residual token form more coherent patterns corresponding to regions of the object, not only scattered pixels. Based on the learned feature visualization, the convolution layers are employed shown in Eq. (1).

3.1.3. Stage Classifier Design 

The stage classifier of the proposed ReSEViT is shown in Fig. 2 (d). First, the CLS token is added to each transformer block as a feature representation. The CLS token is then fed to the stage classifier. For general purposes, we also design early-stage classifier architectures for other deep learning models, whose architectures are similar to their deepest-stage classifiers. For example, the ResNet18 stage classifier consists of global max pooling followed by a fully connected (FC) layer. In general, the entire structure of the stage classifiers remains identical. As such, the additional parameters are from the FC layer of each stage classifier when the self-ensemble method is applied. For efficiency, no convolution layer is involved in all stage classifier designs, including our model and other general models, to explore its effects on the base classifiers. 

3.2. Self-Ensemble Learning 

Similar to the motivation of skip connections, the self-ensemble method ensures that the model prediction result keeps the essential part of the early-stage classifier prediction results if the early-stage classifiers are also supervised during training. The earlier stage classifier prediction results are influenced by the lower-level feature, while the subsequent stage classifier prediction results are influenced by the higher-level feature. Implicitly, the self-ensemble is responsible for global information flow ( all stages ), while the residual token embedding is responsible for local information flow ( each individual stage ). In this sense, when the local information flow is stronger, it will be beneficial for the global information flow. 4.5. Gradient Norm Analysis for Model Interpretation 

By comparing gradient norms across token variants and learning methods in the ReSEViT model throughout training, we examine whether certain methods yield more stable gradient magnitudes, potentially facilitating more effective gradient propagation and optimization. In Fig. 5, we observe that across most methods, gradient norms peak in Stage 1 and then decrease progressively in subsequent stages as the earlier stages are more sensitive to the input and receive stronger gradient signals. This indicates a problem when the gradients are excessively large and unstable. The ML method can further increase the gradient magnitude by accumulating gradients from multiple exit losses. To address this issue, the imbalance in gradients can be substantially reduced by the residual token and the DLS module indicating that the gradients are effectively stabilized and regulated without making them vanished. This effect is crucial particularly for small datasets, where ViT models receive less diverse supervision and are more sensitive to optimization instability. By maintaining a balanced gradient propagation across stages, residual token and DLS can improve the reliability of feature learning under limited data.

To facilitate small-scale image classification, we present ReSEViT, a multi-stage residual ViT with self-ensemble learning. It arises when ViT performs poorly on limited image data. Our self-ensemble learning alleviates the issue by leveraging information from the intermediate classifiers for global information flow. Self-ensemble learning reduces

As the importance of multi-stages is not the same, we introduced DLS to optimize our ensemble performance by decision fusion weights. Unifying residual tokens and self-ensemble learning into a multi-stage ViT facilitates a more efficient computational framework reducing redundancy, prediction error, and variance. A.4. Roadmap Design for Small Dataset 

In this section, we present a detailed projection for multi-stage ViT design from CvT-13 to ReSEViT-T that is used for small-data image classification in Table 18. As shown, the design retains its final shape from ResNet18 to ReSEViT-T, bridging the gap between the ResNet and the Transformer. Moreover, it has been acknowledged that when the deep learning model’s performance improves, the model size will also be larger. In this work, we optimize our multi-stage ViT design to achieve the ideal equilibrium between accuracy and efficiency. 

A.4.1. Patchify 

Originally, the CvT-13 [60] was designed for large resolution images and had an original convolutional stem of 7 ×7kernel size with 4 strides to reduce the input from 224 ×224 to 56 ×56. For the small-resolution input design (32 ×32), we replace it with a 3 ×3 kernel size with 1 stride to increase the effective receptive fields. As a result, the accuracy is drastically improved by 15.08% showing that stem design is important for a small-resolution input size. 

A.4.2. Stage Ratio 

Afterward, the stage ratio between convolution channel size and transformer depth into the base form is shrunk as the parameter size and the FLOPs are excessive for small-scale datasets compared with CCT-7/3 ×1 and Nest-T (around 3-6M parameter size). Specifically, the convolution channel size is reduced from [64,192,384] to [64,128,256], and the transformer depth is reduced from [1,2,10] to [1,1,1]. The base network becomes super fast and light, but the performance reduces by 5.87%. 

A.4.3. Local Information Flow 

To compensate for the ideal computational budget, we substitute the convolution token with the residual token. As the 4 𝑡ℎ stage of ResNet18 with 512 channel size is redundant for small-scale design (significantly increases the parameters to 11.22M), we reconstruct it with the same design principle of CvT-13 to the three-stage model. Notably, the trade-off between accuracy and efficiency is decent. Specifically, the parameter size and FLOPs are comparable with other ViTs [16, 70], and the accuracy increases by 9.96%. Afterward, residual tokens and convolution tokens with wider channel sizes from [64, 128, 256] to [128, 256, 512] are also compared. We observe that the residual token outperforms wider convolution token as the Transformer is able to process stronger local structures more effectively. 

A.4.4. Global Information Flow 

Finally, self-ensemble learning leverages the multi-level predictions from different classifiers. By applying the self-ensemble, the performance improves by 1.84% while maintaining a similar model size and speed. Comparing upstream and downstream, ReSEViT-T performs 5.93% better than CvT-13, with faster inference time and a smaller model size. This demonstrates the advantages of our method for improving CvT-13 in an efficient manner for small-scale data.
