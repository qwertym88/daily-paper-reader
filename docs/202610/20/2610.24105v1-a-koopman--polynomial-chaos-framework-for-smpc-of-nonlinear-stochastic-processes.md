## 摘要
本文提出一种多项式参数化Koopman算子（PPKO）框架，用于具有参数不确定性和时变随机扰动的非线性系统的随机模型预测控制（SMPC）。Koopman算子由多项式混沌展开（PCE）参数化，使数据驱动的非线性动力学能够与基于PCE的不确定性传播和控制相结合。我们表明，除PCE截断外，多项式参数化不会引入不可约的近似差距。随后，我们推导出一种紧凑的确定性SMPC重构形式，可同时处理时不变参数不确定性和时变扰动，同时保持在线优化维数仅依赖于控制时域和输入维数，而与提升状态维数和PCE维数无关。所得形式产生具有期望约束和二阶矩约束的凸规划，可使用标准优化方法求解。针对Duffing振子和电热冷却系统的数值研究验证了所提框架的准确性、可扩展性和闭环性能。

## Abstract
This paper develops a polynomial parametric Koopman operator (PPKO) framework for stochastic model predictive control (SMPC) of nonlinear systems with parametric uncertainty and time-varying stochastic disturbances. The Koopman operator is parameterized by polynomial chaos expansions (PCEs), enabling data-driven nonlinear dynamics to be integrated with PCE-based uncertainty propagation and control. We show that the polynomial parameterization introduces no irreducible approximation gap beyond PCE truncation. We then derive a condensed deterministic SMPC reformulation that handles both time-invariant parametric uncertainty and time-varying disturbances while retaining an online optimization dimension that depends only on the control horizon and input dimension, independent of the lifted-state and PCE dimensions. The resulting formulation yields convex programs with expectation and second-moment constraints that can be solved using standard optimization methods. Numerical studies on the Duffing oscillator and the electrothermal cooling system demonstrate the accuracy, scalability, and closed-loop performance of the proposed framework.

## 1. 核心问题与研究背景

- **应用背景**：大量实际控制系统（化工反应、机械系统、建筑温控等）同时存在**时不变参数不确定性**（如动力学系数、传热系数）与**时变随机扰动**（如环境波动、随机外力）。
- **SMPC 的核心困难**：
  - 非线性动力学下的 SMPC 通常被表述为**非线性规划（NLP）**，需在每个采样时刻在线求解，计算代价高，难以满足实时性。
  - 代价函数与约束中的**期望与二阶矩**需要对不确定性和扰动历史进行传播，直接做法（Monte Carlo、场景法）随预测时域增长而迅速不可行。
- **现有 PCE 方法的缺陷**：
  - 随机 Galerkin 投影（SGP）**不保证稳定性**，且截断误差会沿预测时域传播。
  - PCE 存在**维数灾难**：固定阶数下基函数数量随不确定维数组合式增长；在时变扰动情形下不确定维数随 SMPC 时域**线性增长**，问题进一步恶化。
- **现有 Koopman 方法的缺口**：Koopman 可将非线性 MPC 化为紧凑 QP/QCQP，但已有工作（tube-based、chance-constrained Koopman MPC）**未能把时不变参数不确定性与时变随机扰动同时直接嵌入 Koopman 表示**，从而无法结合 PCE 传播与 condensation 技术。
- **整体含义**：论文试图把 **Koopman 算子（数据驱动、线性提升）** 与 **多项式混沌展开（结构化不确定性传播）** 融合为统一框架，使非线性随机系统的 SMPC 既保持统计精度，又获得与提升维数/PCE 维数解耦的在线计算复杂度。

## 2. 方法论

### 2.1 核心思想：多项式参数化 Koopman 算子（PPKO）

- 将联合不确定性记为 **ξ = (w, θ)**（w 为时变扰动，θ 为时不变参数），对每个固定 ξ 定义参数化 Koopman 算子 `K(ξ)ψ(x) = ψ(f(x,ξ))`，其在可观测函数上线性。
- 用有限维字典 Ψ(x)（含常数项与原始状态坐标）近似，得到 **LPV 预测器**：
  - `K(u,ξ)Ψ(x) ≈ A(ξ)Ψ(x) + B(ξ)u`
- 关键在于把 A(ξ)、B(ξ) 的依赖关系用**截断 PCE** 表示：
  - `Ap(ξ) = Σ_{k=0}^{Np−1} A_k Φξ_k(ξ)`，B 同理；基函数为 w 与 θ 各自正交多项式基的张量积（Legendre 用于参数、Hermite 用于高斯扰动）。
- 提升空间动力学：`z_{t+1} ≈ Ap(ξ_t) z_t + Bp(ξ_t) u_t`，`x_t = C z_t`，其中 C 选取原始状态分量。

### 2.2 近似性质的理论保证

- 定义**总体一步预测误差**下的最优 LPV 矩阵 `[A*(ξ) B*(ξ)]`（最小二乘闭式解，涉及 Gramian Σ）。
- 证明 A*、B* 关于 ξ **连续**（Lemma 4.5，用控制收敛定理），且**平方可积**，故存在收敛的 PCE 表示。
- **Theorem 4.6**：有限阶 PCE 约束下的最优误差满足 `lim_{p→∞} J(M^{p,*}) = J(M*)`，即多项式参数化**除 PCE 截断外不引入不可约近似差距**；作者还指出实践中 2–5 阶通常足够（系数呈次指数衰减）。

### 2.3 训练：EDMD-DL 联合学习

- 损失为一步预测的均方误差，**同时优化**：PCE 系数矩阵 `{A_k, B_k}` 与神经网络参数化的可观测字典权重 `w_Ψ`。
- 采用**交替最小化**：Adam 更新字典网络参数（小批量），每个 epoch 结束时用**闭式岭回归**在全训练集上更新 PCE 系数块；可扩展为多步预测损失。

### 2.4 紧凑确定性 SMPC 重构（Condensed PPKO-SMPC）

- 原问题（式 34）含期望约束与二阶矩约束 `E[(a_t^T x_t − b_t)^2] ≤ c_t^2`（可作为双侧概率约束的 Chebyshev 型保守近似）。
- **Theorem 5.1**：将预测状态写成 `X = G(θ,w)η`，`η = [z_0^T, U^T]^T`，则原随机问题等价于（差一个与输入无关的常数项）关于**堆叠输入 U** 的确定性 QCQP：
  - 目标：`U^T S_UU U + 2 s(x_0)^T U`
  - 均值约束：`x_t^min ≤ Ē_t z_0 + F̄_t U ≤ x_t^max`
  - 二阶矩约束：`U^T M_UU,t U + 2 m_t(x_0)^T U + d_t(x_0) ≤ c_t^2`
  - 输入盒约束：`1_H ⊗ u_min ≤ U ≤ 1_H ⊗ u_max`
- **在线决策维数仅为 H·n_u**，与 Koopman 可观测维数 n_ψ 和 PCE 基函数数 N_p **无关**。

### 2.5 离线递归矩凝聚算法（Algorithm 1）

- 避免对整条扰动轨迹 `(w_0,…,w_{H−1})` 采样或做 SGP，转而利用 **w_t 的 IID 结构**与 PPKO 的 PCE 结构：
  - 把 A_p、B_p 按扰动基函数重排为**模态矩阵** `A_α(θ)`、`B_α(θ)`。
  - **条件一阶矩递归**（Prop. 5.2）：`Γ_{t+1} = A_0(θ)Γ_t + B_0(θ)P_{u_t}`，只用到 0 阶模态。
  - **条件二阶矩递归**（Prop. 5.3）：引入算子 `Q(·), N(·), R(·)`，需要全部扰动模态；Corollary 5.4 给出算子迭代的展开形式。
  - 对 θ 使用**高斯求积**节点 `(θ^{(r)}, ω_r)` 加权求和，得到 S、Ḡ_t、M_t、c_t。
- **Theorem 5.5**：若求积规则对次数 ≤ 2Hp 的多项式精确，则 Algorithm 1 **精确**计算凝聚矩阵；θ 各分量独立时每维需 Hp+1 个节点（离线，不影响在线）。

## 6. 主要结论与发现

- **开环精度**：PPKO 的均值与二阶矩轨迹与 Monte Carlo 真值高度吻合；确定性 EDMD-DL 明显无法捕捉一、二阶统计量；侵入式 SGP 精度相当但展开系统维数大（Duffing 48 维、电热 936 维），推理与优化昂贵。
- **闭环性能（Duffing）**：四种控制器均能调节到原点附近且无约束违反，状态/输入 RMS 接近；但**平均求解时间**差异显著：PPKO **2.05 ms**，EDMD-DL 1.64 ms，Scenario 4.73 ms，SGP **23.77 ms**。
- **闭环性能（电热）**：PPKO 热 RMS（0.0162）接近随机基线（0.0155），优于 EDMD-DL（0.0306）；PPKO **零二阶矩约束违反**（0/1800），而 EDMD-DL 违反 97/1800、Scenario 23/1800、SGP 24/1800；求解时间 PPKO **18.26 ms**，远低于 Scenario 289.40 ms 与 SGP 72.31 ms，但高于 EDMD-DL 的 4.72 ms（因其 QCQP 含二阶矩约束）。
- **总体结论**：PPKO-SMPC 在"随机建模精度"与"在线计算效率"之间取得有利折中；**在线复杂度与提升维数、PCE 基函数数解耦**，在高维 PDE–ODE 案例中优势尤为明显；确定性 EDMD-DL 在随机场景下可能违反随机约束，说明引入不确定性建模的必要性。

- **方法可组合、可扩展**：EDMD-DL 的交替最小化（网络参数用 Adam、PCE 系数用闭式岭回归）结构简单，损失可自然推广到多步预测；字典可换成其他参数化族，框架不依赖特定网络结构。

## 8. 局限性与可质疑之处

- **闭环理论保证缺失**：论文给出了 PPKO 的**逼近性**证明（Theorem 4.6）与凝聚的**精确性**证明（Theorem 5.5），但**未证明**闭环系统的递归可行性、约束满足性或稳定性。由于 LPV 预测器存在结构偏差、PCE 存在截断，实际闭环约束满足只能依赖经验统计（实验中的"零违反"是数值证据而非定理）。这是该方法相对 tube-based / 鲁棒 MPC 文献的主要理论短板。
- **模型误差未被显式鲁棒化**：凝聚矩阵由 PPKO 模型计算，而真实系统与 PPKO 之间的偏差未被纳入约束收紧（constraint tightening）或鲁棒管，因而"零违反"在分布外初始条件或参数区间边缘可能不成立。
- **二阶矩约束的保守性与非凸性**：采用 Chebyshev 型二阶矩约束作为双侧概率约束的保守替代，保守度依赖分布形状；同时 QCQP 中的二阶矩约束为 `U^T M U + … ≤ c²`，M 未必半正定，问题一般**非凸**，论文未讨论求解器的全局性保证与局部解对闭环性能的影响。
- **分布假设较强**：要求 θ 的各分量独立（以便张量积基与逐维求积）、w 为 IID，且其分布形式（均匀/高斯）已知。实际系统中参数相关、扰动有色（时间相关）时，PCE 维数与求积节点数会显著上升，离线成本可能失控。
- **离线成本未量化**：Algorithm 1 的节点数为每维 Hp+1，随预测时域 H 与阶数 p 增长；论文报告了在线时间，却未报告离线建模、PCE 系数拟合与求积凝聚的实际耗时，因而"实时性优势"的完整代价不可评估。
- **超参数敏感性未知**：p（取 2）、n_ψ（28/97）、H、岭系数、网络宽度均固定为单一配置，缺少消融；对"2–5 阶通常足够"的论断仅有定性说明（系数次指数衰减），无本系统上的实证曲线。
- **基线不完全对等**：SGP 用总阶 1、PPKO 用总阶 2，二者精度/耗时对比存在阶数混杂；Scenario 路径数固定且未做敏感性分析；未与 chance-constrained Koopman MPC、tube-based Koopman MPC 等更接近的文献基线比较。
- **统计报告不一致**：Duffing 报告 30 次仿真的统计量，电热案例的 Table 2 仅为单条代表性轨迹，缺少均值±方差与显著性检验，削弱了跨方法比较的统计可信度。
- **可复现性依赖外部资源**：算力描述仅到笔记本型号，未给训练时长、随机种子、代码/数据可得性说明（若正文或补充材料未提供，复现成本较高）。

## 9. 可借鉴的思想与后续研究方向

- **"结构化不确定性传播 + 数据驱动线性提升"的组合范式**可迁移到其他需要在线求解随机最优控制的场景（如建筑能耗 MPC、微电网调度、机器人随机接触），核心是把随机性从"在线采样"转移到"离线矩凝聚"。
- **把 PCE 系数作为可学习参数、与字典联合训练**（EDMD-DL 的交替最小化）是一种低成本融合手段：既保留 Koopman 的线性结构，又让模型对不确定性显式参数化。
- **condensation 与矩递归的结合**是本文最具方法学价值的技巧：利用 w 的 IID 性把"轨迹维不确定性"降解为"单步模态递推"，从而绕开 PCE 在时域上的维数爆炸；该思路可推广到其他具有马尔可夫结构的随机系统。
- **后续可做的直接工作**：
  1. 引入约束收紧或鲁棒管，将 PPKO 的模型偏差纳入可行性保证，并给出递归可行性与输入-状态稳定性分析；
  2. 对非凸 QCQP 给出凸松弛（如 SDP/半正定松弛）或序列凸化，并分析松弛间隙；
  3. 系统消融 p、n_ψ、H、字典结构，给出精度–在线时间–离线时间的帕累托前沿；
  4. 放松 IID 与独立参数假设，研究有色扰动下的模态递推与稀疏 PCE（如基于稀疏回归的系数选择）以抑制维数增长；
  5. 与 chance-constrained Koopman MPC 在同等阶数、同等约束违反率下做公平对比。

## 10. 一句话总结

论文提出 PPKO-SMPC：用 PCE 参数化的 Koopman 提升模型统一刻画时不变参数不确定性与时变随机扰动，并通过离线递归矩凝聚把随机 SMPC 精确转化为仅含 H·n_u 个决策变量的确定性 QCQP，在保持统计精度的同时使在线复杂度与提升维数、PCE 基函数数解耦——理论逼近性与凝聚精确性论证扎实、高维 PDE–ODE 案例的实时性优势明显，但闭环可行性与稳定性的理论保证、非凸求解的全局性以及超参数敏感性仍是待补的空白。
