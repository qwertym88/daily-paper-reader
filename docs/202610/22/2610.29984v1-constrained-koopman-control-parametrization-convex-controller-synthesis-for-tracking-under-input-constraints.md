## 摘要
Koopman算子理论利用状态与输入可观测量中的线性项和双线性项来表示非线性系统，从而极大简化了控制器设计。然而，将输入约束纳入基于Koopman的控制器综合仍具挑战性，限制了其在跟踪等约束控制任务中的适用性。本文提出一种约束Koopman控制参数化（cKoCoP）框架，用于综合满足给定输入约束的状态反馈控制器，并保证所辨识的提升闭环具有Lyapunov意义下的稳定性。cKoCoP通过可观测量线性反馈实现非线性状态反馈，从而能够进行线性控制器设计。所提出的控制器通过凸优化获得：我们利用S-procedure或基于Farkas引理的条件，引入椭球或多面体输入约束。我们还引入了一种用于轨迹跟踪且包含输入约束的控制Lyapunov函数（CLF）。该方法在两个典型非线性系统——双摆和独轮车——上进行了验证，展示了在遵守输入约束的同时实现数据驱动跟踪。实验验证了该方法对测量噪声的鲁棒性，以及相对于Koopman模型预测控制（KMPC）基线的运行时间改进。结果表明，cKoCoP在显著降低在线计算成本的同时取得了具有竞争力的跟踪性能，支持其在实时约束跟踪应用中的潜力。

## Abstract
Koopman operator theory represents nonlinear systems with linear and bilinear terms in the state and input observables, greatly simplifying control design. However, incorporating input constraints into Koopman-based controller synthesis remains challenging, limiting their applicability to constrained control tasks such as tracking. This paper develops a constrained Koopman Control Parametrization (cKoCoP) framework for synthesizing state-feedback controllers that satisfy prescribed input constraints with Lyapunov-certified stability of the identified lifted closed loop. The cKoCoP offers nonlinear state-feedback via linear-in-observables feedback, enabling linear controller design. The proposed controller is obtained through convex optimization: we incorporate ellipsoidal or polytopic input constraints with the S-procedure or Farkas-lemma-based conditions. We also introduce a Control Lyapunov Function (CLF) for trajectory tracking which incorporates input constraints. The approach is validated on two canonical nonlinear systems, a double pendulum and a unicycle, demonstrating data-driven tracking while respecting input constraints. Experiments validate the method's robustness to measurement noise, and runtime improvements over Koopman Model Predictive Control (KMPC) baselines. The results demonstrate that cKoCoP achieves competitive tracking performance with substantially reduced online computational cost, supporting its potential for real-time constrained tracking applications.

## 1. 核心问题与研究动机

- **背景**：非线性系统（机器人、流体、电力系统等）的控制与稳定性分析远比线性系统困难；Koopman 算子理论通过一组非线性可观测函数（observables）把非线性动力学提升到高维（可能无限维）线性空间，从而复用 LQR 等线性设计工具。
- **现实困难**：
  - 实际中只能通过 EDMD 等数据驱动方法获得有限维、含噪的 Koopman 近似，存在模型失配；
  - 现有 Koopman 控制多采用 MPC（KMPC），每个控制步都要在有限预测域上求解优化，在线计算负担重；
  - **输入/执行器约束难以嵌入 Koopman 控制器综合**：即便原状态空间的容许集是凸的，经非线性提升映射后的像可能非凸或难以显式刻画。
- **前期工作局限**：作者此前的 Koopman Control Parametrization（KoCoP）用"可观测量线性反馈"构造非线性状态反馈，可离线凸优化求解一次、在线极便宜，但**不处理执行器饱和，且只能稳定到原点**。
- **本文目标**：提出 **cKoCoP（constrained Koopman Control Parametrization）**，在保持凸优化综合与低在线成本的前提下，保证提升闭环的 Lyapunov 稳定性并满足椭球/多面体输入约束，同时支持非零平衡点调节与时变轨迹跟踪。

## 2. 方法论

### 2.1 双线性 Koopman 模型与闭环参数化
- 考虑控制仿射系统 `x⁺ = F(x) + G(x)u`，采用双线性 Koopman 模型：
  `ψx⁺ = Kxx ψx + KB u + Kxu (Sψx ⊗ u)`，其中 `S` 为选择矩阵，用于抑制 Kronecker 积带来的维度爆炸。
- 控制律取**可观测量的线性反馈**：`u = Ku ψu`。
- **假设 1**：存在矩阵 `H`、`C` 使 `Sψx ⊗ ψu = Hψx`、`ψu = Cψx`（可精确构造，非近似）。
- **定理 1**：闭环提升动态为 `ψx⁺ = K̃ψx`，其中
  `K̃ = Kxx + KB Ku C + Kxu (I ⊗ Ku) H`。
- 与旧版相比，显式引入线性输入项 `KB u`，不再需要常数可观测分量。

### 2.4 输入约束的凸化（核心贡献）
- 约束形式化为集合包含：`ψu ∈ Pψ ⟹ Kuψu ∈ Pu`。
- **椭球约束（S-procedure）**：得 `τQψ − KuᵀQuKu ⪰ 0`、`qu − τqψ ≥ 0`，再用 Schur 补转为 LMI（式 46）。

### 2.5 非零平衡点与跟踪
- 反馈-前馈律：`u = Ku(ψu − ψu^ref) + kff`；误差动态可写成参考相关闭环矩阵 `K̄(ψref, kff) = K̃ − Kxu(I ⊗ Kuψu^ref) + Kxu(kff ⊗ I)S`，即 `ex⁺ = K̄ ex`。
