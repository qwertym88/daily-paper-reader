Abstract 

Finite-horizon optimal control becomes difficult when a dynamical model can be simulated reli-ably but its derivatives are unavailable, discontinuous, or unreliable. Hamiltonian Primal–Dual Pol-icy Optimization (HPDPO) is introduced as a derivative-free, model-based reinforcement-learning framework for this setting. The control is represented as a time-indexed finite-horizon policy. Can-didate actions are evaluated by deterministic suffix rollouts of the supplied transition model, while a regularized Hamiltonian dual formulation supplies structured future-cost information through block-coordinate multiplier updates. No differentiation of the state dynamics or learned critic is required. The method is validated on nonsmooth problems with exact solutions, an analytical and learned ReLU biomarker cascade, an amyloid Neural ODE trained from longitudinal ADNI data, and three multidimensional-control problems with up to five simultaneous controls. Across these examples, HPDPO closely reproduces exact or reference objective values, trajectories, and control structures. The results show that forward simulation and Hamiltonian dual structure can be combined to solve deterministic finite-horizon control problems involving nonsmooth, learned, or black-box dynamics. 

Keywords: model-based reinforcement learning; optimal control; Hamiltonian methods; derivative-free optimization; Neural ODEs

We formulate the time-discretized finite-horizon control problem as a deterministic model-based policy-optimization problem while separating the role of discretization from the policy-update mechanism. 2. The remainder of the paper develops the connection between Hamiltonian optimal control and model-based RL, derives HPDPO, and examines its numerical behavior on analytical and learned dynamical systems.

Dimension-adaptive derivative-free action search. The finite-set formulation above is used for both low- and higher-dimensional controls; only the construction of the candidate set changes with the control dimension. For small m, a Cartesian-product grid gives simple and systematic coverage of the admissible control set. If q values are used for each control component, however, the number of joint candidates grows as 

qm,

so a dense tensor grid becomes expensive as m increases. In this case, we replace the tensor grid by a Sobol quasi-Monte Carlo (QMC) set of joint control vectors. Independent Monte Carlo sampling could also be used, but finite random samples may cluster in some regions and leave other regions less well covered, and they introduce additional run-to-run variation. Sobol points provide a more regular, 10 reproducible coverage of the bounded control box. QMC sampling can also be used when m is small, but a Cartesian grid is preferred there when exhaustive structured coverage is still inexpensive. For box-constrained controls, a minimizer may occur in the interior, on the boundary, or at a corner of the admissible region. Therefore, in the higher-dimensional QMC search we augment the Sobol candidates with the 2 m corners of the current search box. Both search strategies use the same coarse-to-fine idea, with a global joint search followed, when needed, by local joint searches in smaller regions around the current best action. Thus, Cartesian grids and Sobol/QMC sampling are two numerical realizations of the same HPDPO action minimization; the rollout, saddle objective, and primal–dual block updates are unchanged. The finite candidate evaluation remains an m-dimensional action search at each time point, rather than a grid search over the full policy sequence U [29–32]. A prescribed terminal condition λM = ∇xΦ( xM ) may instead be imposed when appropriate. In the bounded dual formulation used here, λM is optimized as part of the multiplier sequence. Algorithm 1 summarizes the default iteration. We use Rk(xk, U ) to denote the suffix rollout from stage k to the terminal time. The forward-policy/backward-dual order reflects the causal propagation of the state and the backward orientation of dual information in classical optimal control. The finite-dimensional block-coordinate formulation does not require this specific order, however. Alternating or reversed Gauss–Seidel sweeps may also be used [31, 32]. In the numerical experiments, the alternative ordering produced essentially the same policies and state trajectories, indicating that the reported solutions were not artifacts of one particular sweep direction. 

# 4 Numerical examples and Validation Studies 

We first evaluate HPDPO in four numerical examples. Examples 1 and 2 compare the numerical solution with exact solutions of nonsmooth scalar problems. Example 3 considers a four-state non-12 linear ODE cascade model of Alzheimer’s disease. The corresponding optimal-control problem is first solved using both the forward–backward sweep (FBS) method and HPDPO. A neural network with ReLU activation functions is then trained to approximate the analytical right-hand side of the ODE system. Because the resulting learned dynamics are generally nondifferentiable, the neural-network-based optimal-control problem is solved using HPDPO. The control and state trajectories obtained from the analytical FBS model, the analytical HPDPO model, and the learned ReLU HPDPO model are then compared. Example 4 applies the proposed method to a fully data-driven setting. After preprocessing the ADNI data and normalizing the amyloid-β measurements to the interval [0 , 1], we train a ReLU neural ODE on the longitudinal observations using the disease progression score as the independent variable. The resulting learned system is then used as the state equation in an optimal-control problem, which is solved with HPDPO. To assess consistency with an adjoint-based approach, the learned neural right-hand side is approximated by a smooth Legendre expansion, and the corresponding optimal-control problem is solved using the forward–backward sweep method as a reference. Two additional examples are then used to evaluate the multidimensional action search. Multi-dimensional Example 1 is a two-state compartmental system with two simultaneous controls and a known exact switching solution. Multidimensional Example 2 is a five-state nonlinear Alzheimer’s disease model with two simultaneous treatment controls, for which the HPDPO result is compared with the numerical solution reported in the original model study.

# 5 Discussion and Conclusions 

This work introduced HPDPO, a finite-horizon policy-optimization method that combines determin-istic model rollout with a regularized Hamiltonian primal–dual objective. The method evaluates candidate controls through forward simulation and updates the multiplier sequence through bounded block-coordinate maximization, avoiding both differentiation of the transition dynamics and approxi-mation of a global value function. Across two nonsmooth benchmarks, an analytical and learned nonlinear cascade, and an ADNI-trained Neural ODE, HPDPO produced control and state trajectories that closely agreed with exact solutions or derivative-based references. In the two benchmark comparisons, it also achieved smaller errors and substantially shorter computation times than the tested PPO and SAC implementations. The three additional multidimensional-control examples show that the same formulation can optimize simultaneous control components. HPDPO reproduces the exact switching structure of the two-state compartmental problem, closely matches the published objective and treatment doses of the five-state Alzheimer’s disease model, and matches the same-grid HJB reference for the six-state, five-control flood problem using the QMC action search. These results support HPDPO as a practical approach for deterministic finite-horizon problems in which the transition model is reliable for simulation but un-suitable for derivative-based optimization. The present implementation produces a trajectory-specific control sequence for a prescribed initial condition; changes in the observed state would require re-optimization or a receding-horizon implementation. Its computational cost also increases with the horizon, candidate-set size, and control dimension. For a fixed policy, the dual block-coordinate sweep converges to the unique bounded dual maximizer under the conditions of Proposition 4. Convergence of the full alternating primal–dual iteration, however, remains to be established. Future work will 32 therefore focus on receding-horizon implementation, scalable action search, and theoretical analysis of the full discrete saddle iteration.

# S3 Reinforcement-Learning Baseline Implementation Details 

The PPO and SAC comparisons were implemented with Gymnasium and Stable-Baselines3. For each scalar benchmark, the reinforcement-learning environment uses the same finite horizon, time step, RK4 transition map, physical control bounds, and discrete objective used for the corresponding HPDPO calculation. The observation contains the physical state together with normalized time, and the trained policy is evaluated deterministically from the prescribed initial condition. PPO and SAC were each trained for 250 ,000 environment transitions for every reported random seed. 

S3.1 Example 1: constructed nonsmooth benchmark 

For the constructed benchmark, the observation is ( xk, k/M ), and the action space is the physical interval [0 , 0.2]; no additional action rescaling is applied by the environment. The training reward is the negative of the original one-step cost multiplied by 100. This reward scaling affects optimization only; all reported objectives and errors are evaluated in the original physical units. PPO uses learning rate 3 × 10 −4, rollout length 2000, batch size 100, 10 optimization epochs per rollout, discount factor γ = 1, GAE parameter 0 .95, clipping range 0 .2, entropy coefficient 0, value-function coefficient 0 .5, and maximum gradient norm 0 .5. The policy and value networks each contain two hidden layers of 64 units. SAC uses learning rate 3 × 10 −4, replay-buffer capacity 250 ,000, 2000 initial transitions before learning, batch size 256, γ = 1, soft target-update coefficient τ = 0 .005, one gradient step per environ-ment step, and automatic entropy tuning. The policy network contains two hidden layers of 64 units. All PPO and SAC runs are performed on CPU with one PyTorch thread. Five independent seeds, 0 , 1, 2, 3, 4, are used for each algorithm. # S4 Example 3: Learned ReLU Approximation of the Four-State Cascade

# S7 Multidimensional Example 1: Two-State, Two-Control Bench-mark 

The compartmental benchmark uses T = 1, ∆ t = 0 .01, and M = 100 policy intervals. The state trajectory is propagated by classical RK4 with the same time step. The two control components are optimized jointly at every policy coordinate. A 21 × 21 Cartesian-product grid over the full admissible 42 rectangle is evaluated first, followed by two 11 × 11 local joint refinements around the current best action. The reported HPDPO calculation uses 12 outer iterations, βu = 0, βλ,s = 1, βλ, 2 = 0 .05, multiplier bound 25, and a backward multiplier sweep per outer iteration. A relaxation factor 0 .20 is used in the numerical multiplier update. The initial control is the interior constant pair ( α, β ) = (2 .5, 2.5), and the multiplier sequence is initialized to zero. The known switching time is not supplied to the optimizer. The global and local candidate evaluations always vary both control components simultaneously. Thus, the multidimensional calculation is a joint two-dimensional action search at each time point rather than two independent component-wise updates. 

# S8 Multidimensional Example 2: Five-State CMO Alzheimer’s Dis-ease Model 

For the controlled monomer–oligomer model, the treatment policy is piecewise constant over intervals of ∆ t = 5 s on T = 1000 s, giving 200 policy intervals. Within every policy interval, the five-state nonlinear dynamics and the accumulated running cost are integrated together by RK4 using internal substeps no larger than 0 .5 s. This ensures that the running-cost quadrature used during candidate selection is the same as that used for the final reported objective. Both treatment components are varied jointly. The reported calculation uses a 21 × 21 global Cartesian-product grid followed by two 11 × 11 local joint refinements. HPDPO is run for 12 outer iterations with no additional control-smoothing penalty, βλ,s = 1, βλ, 2 = 0 .05, multiplier bound 25, three backward multiplier sweeps per outer iteration, and multiplier relaxation factor 0 .20. The treatment sequence is initialized at the constant interior pair ( v, w ) = (0 .01 , 0.01), and the multipliers are initialized to zero. The no-treatment and maximum-treatment objectives are evaluated with the same forward solver as implementation checks against the published CMO study. The main comparison is made with the published forward–backward numerical solution; it is not interpreted as comparison with a known analytical global optimum. 

# S9 Multidimensional Example 3: Six-State, Five-Control Flood-Management Problem 

The flood-management benchmark uses T = 12 and ∆ t = 0 .1, giving 120 policy intervals. State propagation uses classical RK4 on this common time grid. Because a tensor-product action grid is impractical in five control dimensions, the candidate set is constructed by a dimension-dependent Sobol/QMC search. At each policy coordinate, the reported global search uses 512 scrambled Sobol candidates over the full five-dimensional admissible control box, augmented by all 2 5 = 32 box corners and the current action. Two local five-dimensional refinements are then performed, each using 256 Sobol candidates over a shrinking hyperrectangle around the current best action. The initial local radius is 0 .20 times the componentwise control range and is multiplied by 0 .35 after each refinement. The reproducible QMC base seed is 20260921; the implementation deterministically changes the scrambled design across outer iterations, policy coordinates, and local refinement levels. The HPDPO calculation uses 12 outer iterations, βv = 0, βλ,s = 1, βλ, 2 = 0 .05, multiplier bound 25, three backward multiplier sweeps per outer iteration, and multiplier relaxation factor 0 .20. The control 43 sequence is initialized at the midpoint of each admissible control interval and the multiplier sequence is initialized to zero. All five control components are varied jointly in every candidate evaluation. For the reference calculation, the HJB auxiliary system is solved backward with an adaptive RK45 integrator using relative tolerance 10 −11 , absolute tolerance 10 −13 , and maximum internal step 0 .005. The resulting HJB control is then sampled on the same ∆ t = 0 .1 grid used by HPDPO so that objective, state-RMSE, and control-RMSE comparisons use a common temporal discretization.
