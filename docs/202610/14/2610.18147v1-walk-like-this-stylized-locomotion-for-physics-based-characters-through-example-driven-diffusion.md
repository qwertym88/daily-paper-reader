## 摘要
我们提出了一个用于富有表现力的腿部运动的实时框架，可实现对速度和风格的独立控制。与通常需要显式风格标签进行训练的现有数据驱动控制器不同，我们的方法高效地利用大规模非结构化运动数据，并能泛化到未见过的风格。我们通过一种定制的采样策略将风格与功能性运动解耦，该策略用于训练一个风格编码器，其输出对自回归扩散模型进行条件化。在推理时，用户提供风格参考片段和摇杆速度命令。随后，扩散模型生成一个运动学参考，并由强化学习控制器进行跟踪。为提高用户可控性和风格化强度，我们提出了注意力偏置机制和速度命令校正策略。我们在仿真中的基于物理的人形角色和实体机器人上展示了该方法，展现了鲁棒的实时控制和连续风格调制。结果可在我们的补充视频中最佳呈现（https://www.youtube.com/watch?v=roFnS6N7nJ4）。

## Abstract
We present a real-time framework for expressive legged locomotion that enables independent control over velocity and style. Unlike existing data-driven controllers, which typically require explicit style labels for training, our method efficiently leverages large-scale unstructured motion data and generalizes to unseen styles. We disentangle style from functional locomotion through a tailored sampling strategy used to train a style encoder whose output conditions an autoregressive diffusion model. During inference, the user provides a style reference clip and a joystick velocity command. The diffusion model then generates a kinematic reference tracked by a reinforcement learning controller. To improve user controllability and stylization strength, we propose an attention biasing mechanism and a velocity command correction strategy. We demonstrate our method on a physics-based humanoid character in simulation and on a physical robot, showcasing robust real-time control and continuous style modulation. The results can be best seen in our supplemental video (https://www.youtube.com/watch?v=roFnS6N7nJ4).

  - CAMDM 虽实现实时风格化角色控制，但依赖**显式离散风格标签**进行条件化，只能处理训练中见过的风格，且输出纯运动学、无风格强度与过渡控制。

  - 物理扩散类方法（PhysDiff、CLoSD、RobotMDM 等）可接地物理，但缺少表达性风格控制，且多局限于仿真。

## 2. 方法论

### 2.1 总体架构
- 框架由两个模型组成：**自回归运动扩散模型**（运动学生成器）+ **RL 跟踪控制器**（物理执行器）。
- 训练阶段：风格编码器与扩散模型在非结构化运动数据上**联合训练**。
- 推理阶段：用户提供风格参考片段与摇杆速度指令 → 扩散模型生成运动学参考 → RL 控制器跟踪输出到物理角色。

### 2.2 运动学扩散模型
- 在 CAMDM 基础上扩展，条件化公式为：
  - `M0_fut = M(Md_fut, d; Mpst, Dpst, Cfut, csyl)`
  - 其中 `Mpst` 为过去 P 帧状态，`Dpst` 为过去运动差分，`Cfut` 为未来根状态，`csyl` 为风格条件。
- **与 CAMDM 的两点关键差异**：
  - `Cfut` 仅包含期望的根偏航角（而非完整旋转），使角色的滚转/俯仰完全由风格决定。
  - 额外引入过去运动差分 `Dpst`（位置与旋转差分），虽信息冗余但显著提升自回归 rollout 的连贯性（如手臂摆动方向一致）。
- **运动表示**：每帧状态含根位置/朝向、关节朝向、连杆位置/朝向，全部使用 6D 旋转表示；除关节朝向外，所有量变换到角色朝向坐标系，使模型与全局状态无关。
- **网络结构**：Transformer 编码器，各输入逐时间步独立 token 化（线性映射），扩散步 d 用可学习查找表；8 步扩散、余弦噪声调度。

### 2.3 风格编码器
- `csyl = E(Msyl)`，用 Transformer 编码器将整段风格片段压缩为潜在表示。
- 采用**归一化约束 `∥csyl∥ = 1`**，便于泛化并支持通过**球面线性插值**混合风格。
- 借鉴 ViT register token 思想，引入与输入无关的寄存器 token 作为"工作空间"，取最后一层输出作为风格嵌入。
- 相比离散标签，连续风格嵌入包含显式风格信息，支持训练集外风格泛化。

### 2.4 训练采样策略（核心创新之一）
- 从同一运动序列中**分别采样两个窗口**：`P+F` 连续帧用于 `Mpst/Mfut`，另一长度 `S ∈ [Smin, Smax]`（1–5 秒）的窗口用于 `Msyl`。
- **定义**：内容 = 地面投影的根轨迹；风格 = 所有残差运动动力学。
- 双采样迫使风格编码器学习将风格与内容解耦；若使用相同窗口，模型会坍缩为重复参考运动（关节角多样性从 5.5° 降至 0.8°）。
- 损失函数：重建损失 + 速度损失 + 关节一致性损失 + 脚滑损失（沿用 CAMDM）。

### 2.5 推理时技术
- **注意力偏置（Attention Bias）**：
  - 注意力公式改为 `attention(Q,K,V;B) = softmax(QKᵀ/√D + B)V`。
  - 对所有 query 指向风格 token 的注意力分数加正偏置 `wsyl ≥ 0`，指向过去运动 token 的加负偏置 `wpst ≤ 0`，迫使模型尊重风格条件、支持风格快速切换。
  - 默认 `wsyl = 2.0, wpst = −1.0`。
  - 相比 CFG：偏置只修改 softmax 前的权重，注意力仍是归一化分布，更接近训练分布；CFG 需两次模型评估且插值结果可能偏离训练分布。
- **速度校正（Velocity Correction）**：
  - `˜vx,y = vx,y + kp Rψ(ψcur)ᵀ(pdes_xy − pcur_xy)`
  - `˜vψ = vψ + kψ(ψdes − ψcur)`
  - 反馈增益 `kp = kψ = 1/(FΔt)`，保证误差在一次扩散预测跨度内修正完成。
  - 期望位置裁剪到距当前位置 0.5 m 内，期望偏航裁剪到 0.5 rad 内，防止过度修正。
  - 使用过去 P 帧的平均偏航误差，避免修正依赖扩散触发时机。
- **运动平滑**：每隔 `F−K` 帧触发扩散，相邻预测重叠 K 帧（K=3），重叠帧用线性/球面插值混合。

### 2.6 RL 跟踪控制器
- 策略 `π(at|ot, gt)` 输出 PD 控制器关节设定点。
- 目标 `gt` 含参考运动特征、目标根线/角速度、校正后的速度指令；观测为本体感受信息（关节角/速度、根角速度、投影重力、前两个动作）。
- 奖励 = 跟踪奖励 + 正则化奖励 + 任务奖励（摇杆速度跟随、防卡死）；任务奖励帮助化解扩散模型产生的不物理目标（如脚滑）。
- **训练数据离线生成**：对训练集每个运动片段生成 10 分钟带随机指令的 rollout；另生成 10 小时跨风格切换数据；避免 RL 训练时在线查询扩散模型。
- **开环部署**：扩散模型以自身过去预测（而非机器人真实状态）为条件，提升风格质量并保持生成流不被恢复状态污染。
