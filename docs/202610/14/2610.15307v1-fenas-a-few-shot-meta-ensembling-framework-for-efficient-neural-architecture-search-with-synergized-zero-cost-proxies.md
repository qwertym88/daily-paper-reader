## 摘要
高效的神经架构搜索（NAS）需要在有限评估预算下进行准确的性能估计。现有的零成本代理（ZCP）能够提供快速的免训练信号，但每个代理通常仅捕捉架构的部分特性，导致其在不同数据集和搜索空间上的排序不稳定。相比之下，基于GNN的预测器可以提高准确性，但往往依赖有标注的架构、图编码器和昂贵的表示学习，这使其不太适合极端小样本场景。我们提出FENAS，一种与拓扑无关的小样本预测框架，可将互补的初始化先验转化为稳健的排序信号。其核心组件CAST是一个结合Copula对齐与协同变换的特征流水线。CAST将异构ZCP映射到紧凑的特征流形，使轻量级元学习器能够从稀缺监督中产生可靠排序。在NAS-Bench-201上，仅使用0.5%的有标注样本，FENAS取得了0.70的Kendall's Tau（$τ$），在该低标注场景下优于代表性的基于拓扑的小样本预测器。在闭域搜索中，FENAS在约1138秒内评估完NAS-Bench-201空间，并取得具有竞争力的测试准确率。通过提供快速、可靠且结构简单的评估机制，FENAS支持在有限评估预算下设计自动化神经架构。

## Abstract
Efficient neural architecture search (NAS) requires accurate performance estimation under limited evaluation budgets. Existing zero-cost proxies (ZCPs) provide fast training-free signals, but each proxy usually captures only a partial property of an architecture, leading to unstable rankings across datasets and search spaces. In contrast, GNN-based predictors can improve accuracy, but often depend on labeled architectures, graph encoders, and costly representation learning, which makes them less suitable for extreme few-shot settings. We propose FENAS, a topology-agnostic few-shot prediction framework that turns complementary initialization priors into robust ranking signals. Its core component, CAST, is a feature pipeline that combines copula alignment and synergy transformation. CAST maps heterogeneous ZCPs into a compact feature manifold, enabling lightweight meta-learners to produce reliable rankings from scarce supervision. On NAS-Bench-201, with only 0.5% labeled samples, FENAS achieves a Kendall's Tau ($τ$) of 0.70, outperforming representative topology-based few-shot predictors in this low-label regime. In closed-domain search, FENAS evaluates the NAS-Bench-201 space in approximately 1138 seconds and achieves competitive test accuracy. By providing a fast, reliable, and structurally simple evaluation mechanism, FENAS supports the design of automated neural architectures under limited evaluation budgets.
