## 摘要
视觉Transformer（ViT）在图像识别方面取得了很强的性能，但其自注意力会随输入Token数量的增加呈二次增长，导致计算开销高昂。ViT模型的标准实现会在模型的每一层中同等对待所有图像块Token。这种统一处理会引入冗余计算，并可能削弱模型对最具判别性目标区域的关注。本文提出ConvRoute-ViT，一种用于高效视觉Transformer的卷积Token路由机制，通过卷积路由实现Token缩减。我们的模型在选定层根据类别Token注意力保留最相关的图像块Token，同时其余Token在空间上被重组并压缩为一组紧凑的卷积汇总Token。该设计在缩短序列长度的同时，不会完全移除信息量较少Token的上下文信息。通过分层应用路由过程，所提框架能够为更深层构建紧凑且具有判别性的表示。在CIFAR-100和TinyImageNet上的实验表明，与基础ViT相比，ConvRoute-ViT在保持分类精度的同时提升了计算效率。

## Abstract
Vision Transformers (ViTs) achieve strong image recognition performance, but their self-attention increases quadratically with the number of input tokens and makes them computationally expensive. The standard implementation of ViT models treats all patch tokens with equal importance across every layer of the model. This uniform treatment introduces redundant computation and may reduce the model's focus on the most discriminative object regions. In this paper, we propose ConvRoute-ViT, a convolutional token routing mechanism for efficient vision transformers that performs token reduction through convolutional routing. Our model preserves the most relevant patch tokens according to class-token attention at selected layers, while the remaining tokens are spatially reorganized and compressed into a compact set of convolutional summary tokens. This design reduces the sequence length without completely removing the contextual information of the less informative tokens. By applying the routing process hierarchically, the proposed framework constructs compact and discriminative representations for deeper layers. Experiments on CIFAR-100 and TinyImageNet show that ConvRoute-ViT improves computational efficiency while maintaining classification accuracy compared with the base ViT.

## 一、核心问题与整体含义

- **背景**：视觉Transformer（ViT）通过自注意力建模全局关系，在图像识别上表现优异，但自注意力计算量随Token数量呈二次增长，标准ViT对所有图像块Token在所有层中“一视同仁”，带来大量冗余计算，并可能分散模型对最具判别性目标区域的注意力。
- **现有方法的缺口**：
  - Token剪枝类方法（DynamicViT、A-ViT、Evo-ViT、SPViT、ATS、IA-RED²、Heat-ViT等）证明大量Token可被削减而不严重掉点，但**直接丢弃**的Token仍可能携带重要上下文。
  - Token重组/合并/池化类方法（EViT、ToMe、TokenLearner、Token Pruning and Pooling、DeepCompress-ViT、TinyNeXt等）虽提升效率，但EViT把全部非关注Token做注意力加权平均融合为单一表示，**丢失了空间排列信息**。
- **论文定位**：提出ConvRoute-ViT，在“保留重要Token”与“压缩次要Token”之间取得折中——不丢弃、不做全局池化，而是把次要Token**还原到原patch网格并用轻量卷积压缩**为若干ConvSummary Token，从而在缩短序列的同时保留空间结构化上下文。整体含义是：高效ViT的Token缩减不应只是“删”，还应“保结构地压”。

## 二、方法论

### 2.1 核心思想
- 在Transformer的**两个深度层 k 和 l**（0 < k < l < L）插入“ConvRoute Token Routing Module”，形成**两阶段分层路由**：
  - 用CLS Token的注意力分数衡量patch重要性，保留Top-R重要Token；
  - 其余低重要性Token不丢弃，而是空间重组后经卷积压缩成少量摘要Token；
  - 序列长度逐级下降：M_l ≤ M_k ≤ N。

### 2.2 关键流程与公式（文字说明）
1. **输入与基础ViT**：图像划分为 P×P 不重叠patch，线性投影为D维Token，加CLS Token与位置编码，得到 Z₀ ∈ R^{N×D}（N = n+1）。第r层按标准MHSA+FFN更新：Ẑ_r = Z_r + MHSA(Z_r)，Z_{r+1} = Ẑ_r + FFN(Ẑ_r)。
2. **Token重要性估计**：在第k层，对第i个patch token，在全部 h_A 个注意力头上平均“CLS→该patch”的注意力值，作为重要性分数 s_i^(k)（式3）。该设计无需额外参数，直接复用注意力图。
3. **重要Token保留**：按保留率 ρ_k，取 R_k = ⌊ρ_k(N−1)⌋ 个最高分Token组成 T_imp^(k) ∈ R^{R_k×D}；其余记为 T_low^(k)。
4. **空间重组**：把 T_low^(k) 按原始patch网格位置还原为特征图 T_map^(k) ∈ R^{D×H_p×W_p}（H_p=H/P，W_p=W/P），恢复被Token序列化打散的空间邻接关系。
5. **ConvRoute Compressor（式4–5）**：对 T_map 依次做 3×3 深度卷积 → 1×1 逐点卷积 → 3×3 深度卷积，再经自适应平均池化到 p_h×p_w 并展平，得到 S_k = p_h×p_w 个ConvSummary Token T_conv^(k) ∈ R^{S_k×D}。深度卷积负责局部空间邻域聚合，逐点卷积负责通道交互。
6. **序列重组（式6）**：Z̃^(k) = [z_cls^(k), T_imp^(k), T_conv^(k)] ∈ R^{M_k×D}，M_k = 1 + R_k + S_k ≤ N。之后继续送入后续Transformer层，并在第l层重复同一路由过程，最终由MLP Head分类。

### 2.3 设计要点
- 压缩器为**深度可分离卷积结构**，参数量与计算开销很小，符合“高效”目标。
- 路由层位置与保留率（ρ_k, ρ_l）是需人为设定的超参数，论文通过网格搜索确定较优组合。

## 八、局限与讨论

- **超参数依赖较强**：路由层位置 (k,l) 与两级保留率 (ρ_k,ρ_l) 均需通过网格搜索确定，且论文只在CIFAR-100/TinyImageNet上给出经验最优。不同分辨率、不同骨干深度、不同任务下最优配置是否稳定，尚缺少可迁移的选取准则。
- **重要性度量较单一**：仅用CLS对各patch的平均注意力作为重要性分数，容易偏向与类别强相关的主体区域；对多目标、小目标、细粒度判别区域或背景本身含语义的数据集，可能低估“低注意力但有用”的Token。论文未与基于范数、梯度、可学习门控等重要性度量做对照。
- **压缩过程不可逆且信息有损**：低重要性Token被卷积压缩为少量摘要Token，虽然保留了空间邻接结构，但具体细节被池化与卷积核感受野平滑；当被压缩区域包含关键小目标或边界信息时，误差无法在后续层恢复。论文缺少对“压缩损失上界”或“恢复机制”的分析。
- **空间重组假设较强**：方法依赖规则patch网格与固定输入分辨率，将Token序列还原为二维特征图。对非规则划分、变分辨率输入、视频/多模态Token序列，空间重组与自适应池化的语义需要重新定义。
- **两阶段路由的协同性未充分解释**：论文验证了双阶段优于单阶段的经验结果不足，未系统比较单阶段、双阶段及不同阶段组合的收益来源；第二级路由是在第一级已压缩序列上再次筛选，其重要性分数是否仍与原始patch语义对齐，缺少分析。

  - 与ToMe、EViT等Token合并方法组合时，是互补还是冲突？能否形成“保留—压缩—合并”的统一框架？

## 十、总体评价

ConvRoute-ViT的核心贡献在于提出了一种“保留重要Token、结构化压缩次要Token”的折中路由思路：它避免了直接剪枝造成的信息硬丢失，也避免了全局池化造成的空间结构破坏，并以轻量深度可分离卷积实现较低额外开销。实验表明，在CIFAR-100与TinyImageNet上，合理选择路由层与保留率可在降低GFLOPs的同时取得小幅精度提升，定性可视化与部署指标也支持其机制解释。作为一篇短文，方法简洁、工程可取、分析维度较丰富；但其优势目前主要建立在特定数据集与网格搜索配置上，缺少组件消融、统计稳定性、大规模/下游任务验证与完整效率核算，对比公平性和数字口径也需进一步规范。总体而言，这是一项有实用启发的中等力度工作：思想方向合理，但距离“通用、稳健、可自动配置的高效ViT路由方案”仍有明显距离。

（完）
