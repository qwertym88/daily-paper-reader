## 摘要
人形全身控制器如今能够跟踪多种动态运动，但它们通常离线训练后被冻结，因此教给此类控制器一项新技能往往会削弱其已掌握的技能。我们研究人形全身运动的持续学习，其中单个控制器必须从顺序任务流中获取技能，且不能重访过去的数据。我们提出 Similarity-guided LoRA-PNN，一种渐进神经网络（PNN）策略，它通过构造方式防止灾难性遗忘，同时通过轻量级低秩适配在技能之间复用知识。一种由动态时间规整经最优传输聚合构建的两级运动相似度度量，决定基于哪个先前技能进行构建以及分配多少新容量，从而带来强前向迁移和大幅效率提升。在六个顺序学习的技能类别上，我们的相似度引导 LoRA 策略在所有方法中取得最佳前向迁移（0.125 对 0.079）和最高平均准确率，同时最多节省 94.5% 的可训练参数和 40.8% 的训练时间。所得控制器达到 96.13% 的仿真到仿真迁移，并部署在实体 Unitree G1 上。我们的代码可在 https://anonymous.4open.science/r/continual-humanoid-learning-35D3 获取。

## Abstract
Humanoid whole-body controllers can now track a diverse set of dynamic motions, but they are typically trained offline and then frozen, so teaching such a controller a new skill tends to erode the skills it already mastered. We study continual learning for humanoid whole-body motion, where a single controller must acquire skills from a sequential task stream without revisiting past data. We introduce Similarity-guided LoRA-PNN, a progressive neural network (PNN) policy that prevents catastrophic forgetting by construction while reusing knowledge across skills through lightweight low-rank adaptation. A two-level motion-similarity measure, built from dynamic time warping aggregated by optimal transport, decides which prior skill to build on and how much new capacity to allocate, yielding strong forward transfer and large efficiency gains. Across six sequentially learned skill categories, our similarity-guided LoRA policy attains the best forward transfer (0.125 vs. 0.079) and the highest average accuracy among all methods, while saving up to 94.5% of trainable parameters and 40.8% of training time. The resulting controller reaches 96.13% sim-to-sim transfer and is deployed on a physical Unitree G1. Our code is available at https://anonymous.4open.science/r/continual-humanoid-learning-35D3.

# Continual Humanoid Motion Learning 论文总结

## 1. 核心问题与研究背景

- **研究动机**：基于学习的人形全身控制器已能跟踪大量动态动作（行走、跑步、跳跃、舞蹈、格斗等），但通常采用"离线训练—冻结部署"范式。一旦用新动作微调，就会出现**灾难性遗忘（catastrophic forgetting）**，导致已掌握技能严重退化。
- **核心矛盾**：这与人类"边学新技能、边保留旧技能"的能力形成鲜明对比，本质上对应持续学习（Continual Learning, CL）中的**稳定性—可塑性困境**。
- **领域空白**：CL 在计算机视觉、NLP 中研究充分，在机器人领域也主要局限于操作（manipulation）与导航，而**人形全身运动控制的持续学习此前未被系统研究**。
- **任务设定**：单一控制器从顺序任务流 {D₁, …, D_K} 中逐次学习技能，**不重访过去数据**（无 replay），更新形式为 θ_k = ACL(θ_{k−1}, D_k)；作者指出，由于方法从结构上消除了遗忘，问题重心从"是否遗忘"转向"**迁移多快、扩展多省**"。
- **整体含义**：为"不断成长的通才控制器（ever-growing generalist）"提供一条可行路径，并首次给出该方向的统一评测协议。

## 2. 方法论：Similarity-guided LoRA-PNN

### 2.1 核心思想
- 以 **渐进神经网络（PNN）** 为骨架：每个任务实例化一个独立 actor "列"，**旧列永久冻结**，新列通过横向连接复用旧列表示 → **遗忘为零是结构性保证，而非优化目标**。
- 瓶颈在于 PNN 参数量随任务线性增长、每列从零训练代价高。因此用 **LoRA 低秩适配**替代新列的全量训练，并用**运动相似度**同时决定"继承哪一列"和"分配多大容量"。

### 2.2 关键技术细节
- **任务形式化**：每个任务建模为关节空间的目标条件强化学习；actor π_θ(s_t, g_t) → a_t ∈ R²³（Unitree G1），PD 控制器转力矩；奖励为跟踪项与正则项加权和，用 PPO 优化，共享一个目标条件 critic V_φ(s_t, g_t)（训练后丢弃）。
- **PNN 前向传播**（第 k 列第 i 层）：
  h_i^(k) = f( W_i^(k) h_{i−1}^(k) + Σ_{j<k} U_i^(k:j) h_{i−1}^(j) )
  其中 W 为列内前馈权重，U 为来自旧列的横向连接，f 为逐元素非线性；迁移发生在**每一层**，而参数冻结 + 有向连接保证列 1…k−1 不变。
- **父列继承（parent inheritance）**：
  p(k) = arg max_{l<k} S(l, k)
  即选运动学上最相似的已学列作为父列，**复制其参数作为初始化**（而非随机初始化），提供更强归纳偏置。
- **相似度引导的 LoRA 秩分配**：每个非首列的线性层用 LoRA，W′ = W + ΔW，ΔW = W_B W_A，W 冻结，仅学低秩增量（W_A ∈ R^{r×d_in}，W_B ∈ R^{d_out×r}，r ≪ min(d_in, d_out)）。
  - 令 r_k = f(S(p(k), k))，且 ∂f/∂S < 0：**越相似 → 秩越小**（训练更快）；**越不相似 → 秩越大**（容量更强）。
  - 三种秩规则（允许秩 {4, 8, 16}）：Fixed（固定）、Binned（按归一化相似度分档）、Linear（r_k = clip(r_max − α·S̄_k, r_min, r_max)）。
  - 超参数统一固定：τ_s = 1.0（binned 为 1.5）、γ₁ = 0.7、γ₂ = 0.4、α = 12.0、α_LoRA = 1.0、无 dropout。
- **两级运动相似度度量**（离线计算一次，不占训练预算）：
  - **逐帧特征**：平移不变、朝向归一化——局部平面速度 v_t、偏航角速度 ω_t、各关节增量旋转幅度 α_{t,j}（SO(3) 测地距离）、可选接触信号 c_t。
  - **加窗**：以 L 秒窗长、S 秒步长切分为重叠窗口，并记录归一化中心时刻 τ。
  - **窗口代价（DTW）**：加权逐帧代价 δ(t,s)（速度 ℓ₂ + 偏航 |·| + 关节幅度 + 接触 ℓ₁），在 Sakoe–Chiba 带约束下对齐，取路径长度归一化的 DTW 代价 c_{kℓ}。
  - **动作—动作距离（OT）**：窗口代价加软时序惩罚 c̃ = c_{kℓ} + β|τ^A_k − τ^B_ℓ|，用均匀质量的熵正则最优传输（Sinkhorn）求解。
  - **集合—集合距离（OT）**：在动作—动作代价矩阵上再做一次均匀质量 OT。
  - 两阶段均用均匀权重，故距离反映**运动模式及其覆盖差异，而非集合大小**；对 4 组窗长/步长配置取平均以增强鲁棒性（f₀ = 30 Hz）。
- **教师—学生蒸馏**：教师用特权信息（基座速度、关键体姿态、接触、域随机化参数）在 Isaac Gym 训练；学生用 DAgger 仅从可部署观测（本体感知历史 + 参考动作条件）学习，最小化 ‖a_tea − a_stu‖²；共享编码器在教师阶段训练后冻结，蒸馏只更新学生动作预测网络。

### 2.3 相似度矩阵的定性发现
- **run 最独特**：与所有任务距离最大（run–fight 2.32、run–dance 2.23）。
- **walk 最中心**：walk–dance 1.45、walk–fall&up 1.48。
- 非跑步任务距离集中在 1.56–1.82 的窄带内，说明矩阵能有效区分"移动主导"与"多样化全身技能"。

## 3. 实验设计

- **任务套件与协议**：K = 6 个任务，按难度从易到难顺序学习：**walk → run → jump → dance → fight → fall and up**；动作来自 **LAFAN1** 与 **Kungfu 运动数据集**并重定向。采用**任务增量协议，且测试时提供任务标识（task ID）**。所有方法共享同一优化预算（50K 迭代、1024 并行环境）与评测预算（每任务 100 回合）。
- **评测指标**：
  - 持续学习指标：AA（平均精度）、AIA（平均增量精度）、FM（遗忘度量）、BWT（后向迁移）、IM（与联合训练上界的刚性差距）、FWT（相对单任务从零训练的前向迁移）。
  - 性能实例化为 **成功率** 与 **−MPJPE**；另报告 E_mpjpe、E_gmpjpe、E_mpbpe、E_mpjve、E_mpjae、E_pbve、E_pbae 等模仿误差作为追踪质量检查。
- **对比基线**：
  - 适配到统一增量协议的多动作人形模仿方法：**KungfuBot2、ASAP、HumanoidVerse**（在单一网络上顺序微调）。
  - 标准 CL 方法：**EWC、PackNet**（其 IM/FWT 因需联合训练与单任务参照而标记为 --）。
  - 自身变体：**PNN 全量微调**、**PNN + LoRA（无相似度初始化）**、固定/分档/线性秩规则。
  - 所有方法均**不使用 replay**，只在当前任务数据上训练。
- **迁移验证**：Isaac Gym → MuJoCo 的 sim-to-sim（每动作 50 回合、共 1500 次试验），再到**实体 Unitree G1**（23 个驱动自由度，手腕锁定以保证安全；30 个动作 × 10 回合）。
- **训练配置**：actor MLP [512,512,256]，critic [768,512,256]（LayerNorm），Conv1D 编码器，PPO（lr 1e−4、clip 0.2、γ 0.99、GAE 0.95、熵 0.01、24 步、4 mini-batch、5 epoch），含较完整的域随机化（质量/惯量/质心/PD 增益/摩擦/延迟/推力扰动等）。

## 6. 主要结论与发现

- **零遗忘是结构性保证**：所有 PNN 类变体 FM = BWT = 0；去掉 PNN 后退化为单骨干，FM 升至 0.137、AA 从 0.945 降至 0.843，证明**列隔离是免遗忘的来源**。
