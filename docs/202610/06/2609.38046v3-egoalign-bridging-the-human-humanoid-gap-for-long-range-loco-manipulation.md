## Abstract
Egocentric human demonstrations offer an accessible source of task experience, but differences in body scale and controller response, together with missing robot states, limit their value as humanoid training supervision. We present EgoAlign, a data-construction framework that converts these demonstrations into action and state supervision compatible with a general-purpose, continuous whole-body controller, without collecting physical-robot demonstrations. Using the target-robot model and simulator, EgoAlign guides demonstration collection through execution feedback. It preserves locomotion references for visually guided periodic stepping while adapting upper-body interaction geometry through scale alignment and controller-in-the-loop refinement. A final causal replay reconstructs the corresponding robot states and motion-token labels for training with the human observations. We assess the resulting supervision by fine-tuning a vision--language--action model solely on adapted human demonstrations and deploying it zero-shot on a physical humanoid. The resulting policies perform long-range object relocation, navigation to unseen goal positions, and independently evaluated foot interaction. Refinement improves simulated hand alignment and physical pickup success over kinematic alignment alone, while human collection reduces on-site acquisition time relative to teleoperation. https://lambdahumanoid.github.io/EgoAlign/

## 1. 核心问题与研究背景

- **研究动机**：扩展视觉-语言-动作（VLA）模型需要大量、多样、有效的训练数据，但真机遥操作采集成本高且易造成机器人交互失败。以自我为中心（egocentric）的人类演示无需操作真机即可提供导航与交互经验，理论上可作为大规模混合数据训练的补充。
- **核心矛盾**：人类演示的价值取决于**目标具身监督质量**——一次成功的人类动作并不直接构成合适的机器人训练样本。
  - **身体尺度差异**：人类（SMPL 规范身高 1.55 m）与目标机器人（Unitree G1，参考身高 1.25 m）的肢体比例不同，导致实际手部轨迹偏离人类参考。
  - **控制器响应差异**：全身控制器（WBC）对低幅动作的跟踪可能被抑制（如小幅迈步、轻微抬腿在机器人上几乎无可见运动）。
  - **机器人状态缺失**：人类录制数据只提供运动参考，缺少解码该参考所需的机器人本体状态历史（因果状态历史）。
- **任务挑战**：长程移动操作（long-range loco-manipulation）同时要求远距离导航、行走过程中的持续交互以及局部接触操作，上述三类差距在长程任务中被放大。
- **总体定位**：论文提出 EgoAlign——一个**无需真机演示的机器人数据构建框架**，把第一人称人类演示转换为与通用、连续全身控制接口（SONIC）兼容的动作与状态监督，并用"仅人类数据训练 + 零样本真机部署"作为监督有效性的功能测试。

## 2. 方法论

### 2.1 核心思想与训练接口

- 学习目标为 VLA 策略：π_θ(a_{t:t+49} | I^down_t, I^level_t, s^G_t, ℓ)，即在语言指令 ℓ 与当前机器人状态 s^G_t 条件下，预测 50 步动作块。
- VLA **不直接预测关节目标**，而是预测 64 维运动 token：
  - 编码：m^S_t = E_S(r^H_{t−K+1:t}, R^G_t) ∈ R^64，K = 10，r^H_t 为 SMPL 关节、根朝向与手腕目标，R^G_t 为用于锚定的当前机器人基座朝向。
  - 解码：u^G_t = D_S(m^S_t, H^G_t) ∈ R^29，其中因果状态历史 H^G_t = {ω^G, q^G, q̇^G, g^G}_{≤t} ∪ {u^G}_{<t}（基座角速度、关节位置/速度、投影重力、历史动作）。
- 前提条件：需要目标机器人模型与支持**运动编码、状态历史条件解码、仿真回放**的连续 WBC（论文使用 SONIC + MuJoCo）。

### 2.2 因果状态重建（Causal State Reconstruction）

- 问题：人类片段提供运动参考，但不提供解码所需的机器人状态历史。故需在回放动力学下重建机器人本体状态并与运动 token 配对，分三步：
  - **Replay Staging**：将同步的人类片段转为确定性回放参考（身体运动 + 手部指令），以零状态历史作为占位符。
  - **SONIC–MuJoCo Rollout**：在仿真中以 50 Hz 执行；控制节拍 t 先读取仿真状态更新 H^G_t，再计算解码动作。形式化：x^G_t = Φ_t(x^G_0, a_{0:t−1})，s^G_t = O(x^G_t)；O 提取 43 维本体状态（29 个身体关节位置 + 左右各 7 维手部状态）。因此输入 VLA 的状态是**动作执行前**的状态。
  - **Feedback Injection**：校验行对应关系，将实测的动作前反馈注入训练片段。最终学习动作 a_t = [m^S_t, h^L_t, h^R_t] ∈ R^76（64 维 token + 左右各 6 维手部指令）。

### 2.3 人类演示采集

- PICO 4 Ultra 头显 + 5 个追踪器（双腕、双踝、腰部），经 SONIC 的 PICO→SMPL 管线得到 24 关节 SMPL 运动参考，保留手腕朝向与手部指令；手部抓取/非抓取为 PICO 视觉识别给出的离散指令。
- 双视角：胸口佩戴两台 GoPro Hero 13，一路 60° 下视（近场手部、物体与工作区），一路水平（远距离导航线索）；人机相机**地面相对高度匹配**（约 1.3 m），下视仅覆盖前方约 2 m，因此需要水平视角。

### 2.4 人→人形机器人的运动适配

- **(1) 动力学引导的演示采集**：实时把恢复的 SMPL 运动流经 SONIC 并在 MuJoCo 中回放，演示者依据仿真视觉反馈重复或放大被抑制的动作，直到预期机器人运动可见；不操作真机。
- **(2) 尺度对齐（离线）**：
  - 区分**人类尺度参考骨架 M_H**（身高 η_H = 1.55 m，从下足关节到头关节测量）与**仅用于优化的机器人尺度代理 M_G**（拟合 G1 躯干与四肢长度，η_ref = 1.25 m）。
  - 交互坐标系：N(P_t)_j = P_t,j − o(P_t)，原点取骨盆水平坐标与两足关节较低者高度；人类参考的手部端点目标在共享交互系中保持固定。
  - 在 M_G 上优化有界姿态残差 Δq_t = b ⊙ tanh(z_t)（b 为逐关节角度上界），端点损失 L_x 衡量 N(P^G_t)_e 与目标端点 ˆp^H_{t,e} 的平方误差；总损失 L = λ_x L_x + λ_pose L_pose + λ_vel L_vel + λ_acc L_acc，正则化残差幅度与时间平滑（零/一/二阶差分），用 Adam 求解。
  - 优化仅限任务选定的**锁骨、肩、肘**关节；脊柱、手腕局部旋转及其他关节保持逐帧基线轨迹（脊柱跟随原始运动而非固定）。每个手部端点用其 4 个非拇指 MCP 根的均值表示。
- **(3) 控制器在环精修**：
  - 从运动学对齐结果 q^(0) 出发，SONIC–MuJoCo 回放 RS 给出第 k 轮端点 y^(k) 与残差 e^(k) = ˆp^H − y^(k)。
  - 补偿逐片段、逐轮的**常值滞后**（由 ±20 帧内的端点速度估计，剔除未匹配边界），仅对反馈残差做 21 帧三阶 Savitzky–Golay 平滑，不移动图像、标签或源索引。
  - 有界目标修正：d^(k) = clip_ρs(β·ẽ^(k) ⊘ κ^(k)_e)，c^(k+1) = clip_ρc(c^(k) + d^(k))，其中 β = 0.65、ρ_s = 0.08 m、ρ_c = 0.12 m；逐轴响应增益 κ^(k)_e 初始为 1，可用有界对角割线估计更新。随后以 ˆp^H + c^(k+1) 为目标重解损失并回放。
  - 输入补偿不改变期望的人类参考目标；最多两轮精修，第 2 轮后仍不满足闭环端点与回放验收标准的轨迹**从训练中剔除**。梯度只经过优化骨架，不经过 SONIC 或 MuJoCo。

### 2.5 仅人类数据的 VLA 微调与真机执行

- 用原始人类图像、指令与来自最终因果回放的**动作前状态**微调 VLA，监督目标为配对的 SONIC 运动 token 与人类手部指令。
- 部署时 VLA 从实时机器人图像与当前状态预测动作；SONIC 用实时状态历史解码 token，手部指令单独执行。
