## 摘要
部署人形机器人任务策略需要可靠的运行时监控器，能够及时预判不可恢复的跌倒并触发回退。我们将该任务建模为学习给定回退策略的随机有限时域可恢复性包络。合成该监控器具有挑战性：现有方法假设训练数据自然覆盖可恢复性包络，然而对于富接触系统，获取此类数据仍是主要瓶颈。因此，它们仅能恢复真实包络的一小部分，导致其容易对分布外（OOD）输入产生乐观幻觉。我们通过一个在值学习与主动探索之间迭代的统一框架来解决这一问题。数据探索被重新表述为到达-规避问题，其中不确定性引导的探索器系统地发现未见状态，同时避开确信不可恢复的区域。该循环进一步由结合时序差分与蒙特卡洛的目标函数支持，以实现准确的分布内值预测和可靠的不确定性估计。通过将剩余高不确定性区域显式视为不可恢复，该监控器缓解了乐观的 OOD 幻觉。在随机基准测试和 29 自由度 Unitree G1 人形机器人上评估，我们的方法大幅提高了监控器覆盖率和准确性，并成功零样本迁移到真实硬件。

## Abstract
Deploying humanoid task policies requires reliable runtime monitors that anticipate unrecoverable falls in time to trigger a fallback. We formulate this task as learning the stochastic, finite-horizon recoverability envelope of a given fallback policy. Synthesizing this monitor is challenging: existing methods assume training data naturally covers the recoverability envelope, yet acquiring such data remains a major bottleneck for contact-rich systems. Consequently, they recover only a fraction of the true envelope, leaving them prone to optimistic hallucinations for out-of-distribution (OOD) inputs. We resolve this via a unified framework that iterates between value learning and active exploration. Data exploration is reframed as a reach-avoid problem, where an uncertainty-guided explorer systematically uncovers unseen states while avoiding confidently unrecoverable regions. This loop is further supported by a combined Temporal Difference and Monte Carlo objective for accurate in-distribution value prediction and reliable uncertainty estimation. By explicitly treating the remaining high-uncertainty regions as unrecoverable, the monitor mitigates optimistic OOD hallucinations. Evaluated on stochastic benchmarks and a 29-DoF Unitree G1 humanoid, our approach drastically improves monitor coverage and accuracy and successfully transfers zero-shot to real-world hardware.
