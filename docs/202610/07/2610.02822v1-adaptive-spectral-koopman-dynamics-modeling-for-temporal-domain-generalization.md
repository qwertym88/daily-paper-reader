## 摘要
时间域泛化（TDG）旨在应对随时间发生分布偏移的真实世界流式数据。然而，现有方法要么容易在数据空间中过拟合于特定域的噪声，要么在参数空间中变得过于复杂且可解释性较差。为弥合这些差距，我们提出 AdaSpecK，一个面向 TDG 的、具有自适应上下文提取能力的谱-Koopman 框架。为缓解对不规则采样域的噪声拟合，我们引入谱正则化 Koopman 动力学建模，该方法在潜在空间中应用谱感知滤波，以提取去噪后的低频轨迹，并学习 Koopman 算子以在线性化空间中建模系统动力学。为对非平稳条件下的复杂历史环境进行建模，我们设计了一种上下文信息引导的异构模式提取机制。具体而言，我们采用目标条件化注意力模块来关注不同的历史窗口，生成动态的、目标特定的历史摘要。通过从当前演化模式构建环境签名，我们的模型经由学习到的路由器自适应地感知过去上下文中的哪些方面对未来预测最具信息量。在八个不同的分类和回归基准上的大量实验表明，AdaSpecK 达到了最先进的性能。代码和数据集可在 https://anonymous.4open.science/r/Ada-Spec-K 获取。

## Abstract
Temporal Domain Generalization (TDG) has emerged to address real-world streaming data with distribution shifts over time. However, existing methods are either prone to overfitting to domain-specific noise in the data space or become overly complex and less interpretable in the parameter space. To bridge these gaps, we propose \textbf{AdaSpecK}, a spectral-Koopman framework with adaptive context extraction for TDG. To mitigate noise fitting to irregularly sampled domains, we introduce spectral-regularized Koopman dynamics modeling, which applies spectral-aware filtering in the latent space to extract denoised low-frequency trajectories and learn a Koopman operator to model the system dynamics in a linearized space. To model complex historical environments under non-stationarity, we design a context-informed heterogeneous pattern extraction mechanism. Specifically, we employ a target-conditioned attention module to attend to distinct past windows, producing a dynamic, target-specific historical summary. By constructing an environmental signature from the current evolutionary pattern, our model adaptively perceives which aspects of the past context are most informative for future prediction via a learned router. Extensive experiments on eight diverse classification and regression benchmarks demonstrate that AdaSpecK achieves state-of-the-art performance. The code and datasets are available at \href{}{https://anonymous.4open.science/r/Ada-Spec-K}.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究场景**：时间域泛化（Temporal Domain Generalization, TDG）。训练数据是随时间演化、按任意时间戳采集的域序列 $\{\mathcal{D}(t_1),\dots,\mathcal{D}(t_T)\}$，目标是在未来未见（OOD）域 $t' > t_T$ 上取得良好泛化。典型应用包括金融市场交易行为漂移、社交媒体语言/话题演化、流感推文监测、房价与能耗预测等。
- **现有方法的两条路线及其缺陷**：
  - **数据/特征中心方法**（数据增强、生成式模拟未来分布、域不变表征学习、域共享/特有特征解耦）：直接在数据空间建模，容易过拟合稀疏、不规则采样域中的**域特有噪声**。
  - **模型/参数中心方法**（梯度插值、概率隐空间、循环生成时变参数、连续时间参数演化、参数轨迹频域分析）：参数空间更抽象、维度更高，性能与预测器结构强耦合；参数跨不规则时间步的演化高度非线性且缺乏结构先验，**不稳定、易累积误差、可解释性差**。
- **两大核心挑战**（论文图 1）：
  - **挑战 1**：训练域在时间上**不规则、稀疏、不均匀分布**，直接建模易拟合域噪声，损害对 OOD 域的可靠性。
  - **挑战 2**：**非平稳性**使周期性、季节性等稳定结构被掩盖或剧烈波动；且不同未来目标域关注的上下文不同（有的重长期趋势/宏观模式，有的重近期短期动态），需要模型自适应地选择历史信息。
- **整体含义**：论文主张把「连续动力学建模」与「频率感知表征」结合——在隐空间做谱滤波去噪，再用 Koopman 算子在**线性化空间**中建模演化，同时用目标条件注意力 + 专家路由自适应利用异构历史上下文。核心卖点是**兼顾鲁棒性、稳定性和可解释性**。

## 2. 方法论：核心思想与关键技术细节

整体框架（图 2）：聚合特征编码 → 谱感知滤波 → Koopman rollout → 目标条件注意力 → 环境签名路由专家 → 预测头。

### 2.1 谱正则化 Koopman 动力学建模（去噪 + 线性化演化）

- **域级隐表征聚合**：共享编码器 $f_\psi$ 编码域内所有样本，再经 Aggregate(·) 池化为域级表示 $h_t$，得到隐轨迹 $h_{1:T_c}\in\mathbb{R}^{T_c\times d}$。
- **隐空间谱感知滤波**：
  - 对轨迹沿时间维做 DFT：$\tilde h = \mathcal{F}(h_{1:T_c})$；
  - 设谱比例 $\beta$，保留频段数 $k=\lfloor \beta T_c\rfloor$，构造二值掩码 $M$（论文表述为选取 **k 个最低幅值频率**）；
  - $\tilde h_{low}=M\odot\tilde h$，$\tilde h_{high}=(1-M)\odot\tilde h$，经逆 DFT 得去噪低频轨迹 $h_{1:T_c,low}=\mathcal{F}^{-1}(\tilde h_{low})$；
  - 动机：高频分量多对应采样噪声/域特有扰动，丢弃后可获得平滑、全局一致、缓慢演化的内在动态。
- **Koopman 算子演化**：用可学习编码器 $\phi$ 把 $h_{t,low}$ 映射到 Koopman 空间，$z_{t,low}=\phi(h_{t,low})$，演化 $\hat z_{t+1,low}=K_{env}z_{t,low}$，再经 $\phi^{-1}$ 解码回隐空间；$K_{env}$ 为可训练 Koopman 算子，将非线性动力学在充分高维函数空间中线性化。
- **三项互补损失**：
  - $\mathcal{L}_{koop}$：Koopman 空间单步预测误差（局部保真）；
  - $\mathcal{L}_{rec}$：解码 rollout 与真实隐状态的重构误差（保证演化状态不脱离原特征流形）；
  - $\mathcal{L}_{consis}$：从任意锚点 $j$ 传播到步 $i$ 的状态与真实 $h_{i,low}$ 的一致性约束（路径无关、抑制长时域误差累积，全局稳定）。

### 2.2 上下文信息引导的异构模式提取（自适应历史利用）

- **上下文嵌入**：$E_{ctx}=g_{ctx}(\mathrm{concat}[h_1,\dots,h_{T_c}])$，轻量 MLP 聚合历史域级表示。
- **目标条件注意力**：对每个未来预测步 $\tau$，用 Koopman rollout 得到 $\hat z_\tau$ 与位置嵌入 $p_\tau$ 拼接成动态 query $E_{\tau,q}=[\hat z_\tau, p_\tau]$，与 $E_{ctx}$ 做缩放点积交叉注意力，得到 $E_{history}$——**动态、目标特定**的历史摘要（而非全局固定摘要）。
- **环境签名**：从预测未来步的低频表示中提取幅值 $a_\tau=\mathrm{Amp}(h_{\tau,low})$ 与相位 $\phi_\tau=\mathrm{Phase}(h_{\tau,low})$，并用 $\sin/\cos$ 投影避免角度不连续、保证可微：$E_{\tau,sig}=[a_\tau,\sin\phi_\tau,\cos\phi_\tau]$。
