## 摘要
流策略已成为从演示中学习机器人行为的标准策略类别，但强化学习对于改进预训练流策略或通过交互从头学习流策略仍然至关重要。我们提出 QF3（Fast Flow RL with Filtered Q-Gradients，带过滤 Q 梯度的快速流强化学习），一种在线异策略强化学习算法，它通过流匹配加上 critic 的动作梯度来训练流策略，该梯度经由对流输出的一步预测进行反向传播。为了让更新保持在 critic 和该预测均可靠的区域，QF3 仅将 critic 梯度应用于那些保持接近回放动作的动作维度。据我们所知，QF3 是首个从头训练人形机器人运动策略并将其零样本迁移到硬件的异策略流强化学习方法。结合高吞吐量异策略训练方案，它训练人形机器人运动和运动跟踪策略时，相比近期的一种同策略流强化学习方法 FPO++，实现了 10 倍的墙钟时间加速。我们进一步将 QF3 应用于在 ABC-Sim 和 Robomimic 任务上微调预训练的基于流的操作策略。这些结果表明，QF3 既能从头学习机器人策略，也能改进从演示中获得的策略。网站：https://qf3-rl.github.io/

## Abstract
Flow policies have become a standard policy class for learning robot behaviors from demonstrations, but reinforcement learning is still critical for improving pre-trained flow policies or learning them from scratch through interaction. We introduce QF3 (Fast Flow RL with Filtered Q-Gradients), an online off-policy RL algorithm that trains a flow policy with flow matching plus the critic's action gradient, backpropagated through a one-step prediction of the flow's output. To keep updates where the critic and this prediction are reliable, QF3 applies the critic gradient only to action dimensions that stay near the replay action. To our knowledge, QF3 is the first off-policy flow RL method to train humanoid locomotion policies from scratch and transfer them zero-shot to hardware. Paired with a high-throughput off-policy training recipe, it trains humanoid locomotion and motion-tracking policies with a 10x wall-clock speedup over FPO++, a recent on-policy flow RL method. We further apply QF3 to fine-tune pretrained flow-based manipulation policies on both ABC-Sim and Robomimic tasks. These results suggest that QF3 can both learn robot policies from scratch and refine those acquired from demonstrations. Website: https://qf3-rl.github.io/

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **背景**：流（Flow）/扩散策略已成为机器人学习（尤其是从演示中学习操作技能）的主流策略类别，并逐步扩展到人形机器人运动与全身控制（如 BeyondMimic、OmniXtreme）。但纯模仿学习不足以解决所有问题：有些任务缺乏专家轨迹，需从零通过奖励学习；有些预训练策略需要通过与环境的交互进一步提升可靠性或效率。
- **核心问题**：如何对**流策略**进行高效的**在线异策略（off-policy）强化学习**，既能从头训练，也能微调预训练策略。现有方案各有缺陷：
  - **同策略策略梯度方法**（FPO、FPO++、ReinFlow、πRL）：样本效率低；
  - **对采样器反向传播的异策略方法**：需要穿过整个采样 ODE 链回传，代价高且不稳定；
  - **冻结流 + 残差/噪声策略**：未直接训练流策略，改进受限；
  - **FlowRL**（最接近的工作）：用 tanh 压缩流端点，导致流匹配目标与执行动作不匹配，且破坏预训练策略的初始化（微调不再从原行为出发）。
- **整体含义**：QF3 提出一种可直接嵌入 TD3 式训练循环的、简单稳定的流策略异策略 actor 更新，首次实现**异策略流 RL 从零训练人形运动策略并零样本迁移到真机**，同时可微调预训练流操作策略。

## 2. 论文提出的方法论

### 2.1 核心思想
- 将**标准条件流匹配（CFM）** 与**评论家（critic）动作梯度 Q 最大化**结合，Q 梯度经由流输出的**单步欧拉预测**回传，**无需对采样器积分或反向传播**。
- 引入**速度空间裁剪（velocity-space clipping）**，形成回放局部的信任区域：只有当策略-缓冲速度差落在 `[-α, α]` 内时，该维度才接收 Q 梯度；否则 Q 梯度被掩码，仅由 CFM 损失将速度拉回回放条件目标。

### 2.2 关键技术细节与公式
- **流策略与采样**：actor 为速度场 `v_θ(s, x_τ, τ)`；评估时从 `x_0 = ε ~ N(0,I)` 出发，用 N 步欧拉法积分 `dx_τ/dτ = v_θ` 从 τ=0 到 τ=1。
- **CFM 锚定项**：对回放转移 `(s, a_buf, r, s')`，采样 `ε ~ N(0,I)`、`τ ~ U(0,1)`，构造
  - `x_τ = (1-τ)ε + τ·a_buf`，`u_buf = a_buf − ε`（回放条件速度）
  - `L_cfm = ||v_θ(s, x_τ, τ) − u_buf||²`
- **一步预测与直接 Q 目标**：
  - `x̂_1 = x_τ + (1−τ)v_θ(s, x_τ, τ)`
  - `L_direct = −Q(s, x̂_1) + λ_cfm·L_cfm`
  - 问题：一步预测可能偏离 critic 可信区域，导致追高估计、速度幅值发散。
- **速度空间裁剪（核心贡献）**：定义策略-缓冲差 `δ_θ := v_θ(s,x_τ,τ) − u_buf`，逐坐标裁剪：
  - `v̂_θ,clip = u_buf + clip(δ_θ, −α, +α)`
  - `x̂_1,clip = x_τ + (1−τ)v̂_θ,clip = a_buf + (1−τ)·clip(δ_θ, −α, +α)`
  - 即 critic 只在回放动作各坐标 `(1−τ)α` 范围内被查询。
  - 最终 actor 损失：`L_actor = −Q(s, x̂_1,clip) + λ_cfm·L_cfm`
- **过滤 Q 梯度（式 5）**：
  - `∂Q/∂v_θ = (1−τ)·m ⊙ ∇_a Q(s,a)|_{a=x̂_1,clip}`，其中 `m_i = 1[|δ_θ,i| < α]`
  - 每个速度分量只有在信任区域内才收到 Q 梯度；饱和分量的 Q 梯度被屏蔽，但 CFM 仍作用于**未裁剪**的速度，将其拉回回放目标。
- **信任区域解释**：与 PPO 的 ratio clip 类似，通过"扣留"策略改进梯度实现信任区域；附录 A.2 借 Kingma & Gao 的 CFM–ELBO 对应关系，将裁剪解释为回放动作 ELBO 代理上的信任区域（局部代理下界 `E[ELBO_CFM(v̄_θ)] ≥ C − α²`）。

### 2.3 算法流程（文字）
1. 用 TD3 式方式存转移、训练 critic（Bellman 备份、目标网络、双 Q / 分布式分类 critic）；
2. 从回放采样 `(s, a_buf)`，采样 `ε, τ` 构造 `x_τ, u_buf`；
3. 计算速度预测 `v_θ`，裁剪得到 `v̂_θ,clip` 与 `x̂_1,clip`；
4. 最小化 `L_actor = −Q(s, x̂_1,clip) + λ_cfm·L_cfm`（Q 梯度经被裁剪的一步预测回传）；
5. 微调时额外加入对冻结基策略的速度锚定项 `λ_base·||v_θ − v_base||²`。
