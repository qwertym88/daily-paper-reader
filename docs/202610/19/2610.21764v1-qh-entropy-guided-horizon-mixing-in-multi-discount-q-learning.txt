Abstract. A fixed discount factor in Q-learning imposes a single planning horizon throughout training, despite the differing demands of early exploration and long-term credit assignment. We propose Q( 𝛾 𝐻 ), a multi-horizon Q-learning framework that maintains multiple discount-specific heads and adaptively combines them at control time using an entropy-derived confidence signal. The resulting state-dependent mixing weights shift control from shorter- to longer-horizon heads as policy confidence increases, enabling adaptive horizon mixing without modifying individual Bellman updates. Across classical control and deep reinforcement-learning benchmarks, Q( 𝛾 𝐻 ) shows its strongest improvements on delayed-credit tasks relative to strong fixed-discount baselines. By decoupling horizon adaptation from the underlying learning updates, Q( 𝛾 𝐻 ) provides a lightweight framework for adaptive planning-horizon control in reinforcement learning, avoiding the need for manual discount-factor selection while remaining compatible with standard value-learning methods.

# 1 Introduction 

Choosing the discount factor 𝛾 in reinforcement learning is challenging. A short horizon can stabilise early learning by limiting bootstrap error propagation, but may prevent solving tasks requiring long-range credit assignment [4,15]. No single fixed 𝛾 resolves this tension, and per-task tuning [7] does not address changes in the required planning horizon during training. Neuroscience evidence also suggests that dopaminergic neurons encode reward prediction errors across multiple discount time constants [9]. Recent methods address this through adaptive or multi-horizon discounting [13,1,12,11], but require modified Bellman targets, global rather than state-dependent mixing, reward decomposition, or added deep-RL infrastructure. These approaches do not provide state-dependent control-time mixing across discount-specific Q-heads while preserving their standard Q-learning updates. We propose Q( 𝛾 𝐻 ), which maintains 𝐾 heads with discounts 𝛾 𝑘 ∈ Γ and mixes them using state-dependent confidence. Low confidence favours shorter horizons, while high confidence favours longer ones. # 2 Related Work 

Q( 𝛾 𝐻 ) builds on multi-horizon value learning, adaptive discounting, and entropy-based uncertainty signals. Unlike prior work, it performs state-dependent mixing across planning horizons only at control time, preserves standard Bellman updates, and extends to deep RL through discount-specific Q-heads. Parallel value prediction across planning horizons is central to the GVF frame-work [19] and discount-indexed value learning [4,15]. Related deep-RL methods use multiple discount-indexed Q-heads [1], reward-component-specific discounts [2], multi-discount PPO advantages [12], or time-weighted horizon heads in distributional RL [11]. Q( 𝛾 𝐻 ) also uses discount-specific heads, but couples them only at action selection: it requires no reward decomposition [2], uses per-state rather than global mixing [12], and avoids distributional RL machinery [11]. Prior work has formalised transition- and state-dependent discounting 𝛾 (𝑠, 𝑎, 𝑠 ′)

[22,16], used discounts to model termination or continuation values [23,18], and adapted 

𝛾 online using critic loss or entropy-based uncertainty [13,3]. In contrast, Q( 𝛾 𝐻 )does not modify Bellman targets or learn 𝛾 (𝑠 ) directly; it performs state-dependent control-time mixing while each head keeps a standard fixed-𝛾 𝑘 update. The resulting ¯𝛾 (𝑠 ) = Í𝑘 𝑤 𝑘 (𝑠 )𝛾 𝑘 is used only as a descriptive summary of the mixing weights. Entropy is commonly used in RL as an objective [5,24], while ensembles use model diversity for uncertainty estimation and exploration [14,8], and mixture-of-experts methods use input-dependent gating [17]. In contrast, Q( 𝛾 𝐻 ) uses reference-policy entropy as a lightweight signal for decision ambiguity. Its head diversity is temporal rather than epistemic, and the gate interpolates across planning horizons rather than averaging to reduce variance. Table 1 summarises the closest comparisons. A complementary motivation comes from neuroscience: dopaminergic neurons have been shown to encode reward prediction errors across multiple discount time constants [9]. This supports the use of parallel fixed-𝛾 estimators, while Q( 𝛾 𝐻 ) adds an adaptive aggregation mechanism through entropy-guided control-time mixing.

3.7 Complexity and Practical Considerations 

Each head in Q( 𝛾 𝐻 ) uses a standard off-policy Q-learning update under its own Bellman operator, where sufficient exploration is the key practical requirement [21,20]. The mixing weights are bounded, non-negative, and sum to one, so 𝑄 agg is a well-defined convex combination of the heads:

Thus, state-dependent mixing affects action selection but not the individual Bellman targets. The overhead of Q( 𝛾 𝐻 ) is linear in the number of heads 𝐾 . Maintaining 𝐾 heads requires 𝑂 (𝐾 |A| 𝑑 ) memory, and dense linear evaluation and updates cost 𝑂 (𝐾 |A| 𝑑 ) per step. The reference, entropy, and weighting computations add only 𝑂 (𝐾 |A|) operations. In tabular and linear settings, no replay buffer, target network, or neural component is required. In the deep-RL extension, the same confidence-gated mixing is implemented on top of standard DQN and DDQN machinery using discount-specific output heads.

# 5 Discussion and Limitations 

The results show a task-dependent pattern across tabular, linear, and deep settings: Q( 𝛾 𝐻 )is most useful when the planning horizon is difficult to fix in advance. The strongest gains occur in MountainCar and Acrobot, where short horizons support stable early learning but longer horizons are needed for delayed credit assignment. Q( 𝛾 𝐻 )addresses this trade-off by shifting control from shorter- to longer-horizon heads as confidence increases, producing a gradual shift in horizon emphasis within a single run. When a single fixed discount is already effective, as in CartPole and LunarLander, horizon mixing provides limited benefit. In the cliff environments, SARSA remains competitive because its on-policy updates encourage safer behaviour near hazardous states; horizon mixing does not remove this on-policy advantage. The deep Q( 𝛾 H) results demonstrate that the same control-time mixing mechanism can be applied with neural function approximation, with the largest gains on MountainCar-v0 and Acrobot-v1 and little improvement on CartPole-v1. However, the current deep-RL evaluation is limited to three classic discrete-action control tasks and a shared-trunk multi-head architecture, so these results establish applicability rather than broad deep-RL generality. Further work should evaluate larger benchmark suites, separate-head architectures, continuous-action actor–critic variants, and the theoretical properties of the coupled multi-head system. The tabular and linear experiments isolate the horizon-mixing mechanism without replay buffers, target networks, or neural optimisation effects. The comparison is conservative because fixed-𝛾 baselines use oracle-selected 𝛾 ∗, whereas Q( 𝛾 𝐻 ) adapts its horizon mixture online. In the deep setting, DDQN uses 𝛾 = 0.99, the strongest fixed discount considered. Scale-adaptive temperatures or normalised confidence signals are therefore important directions for future work. 

# 6 Conclusion 

We introduced Q( 𝛾 𝐻 ), a multi-horizon Q-learning framework that avoids choosing a single fixed discount factor by maintaining discount-specific Q-heads and mixing them at control time using a state-dependent confidence signal. The resulting mixing weights adapt horizon emphasis during training while each head retains a standard fixed-𝛾 𝑘 

Q-learning update. For analysis, ¯ 𝛾 (𝑠 ) = Í𝑘 𝑤 𝑘 (𝑠 )𝛾 𝑘 provides a descriptive summary of this horizon mixture. Across eight tabular and linear benchmarks, Q( 𝛾 𝐻 ) is most effective on delayed-credit tasks, achieving the best mean AUC on MountainCar and Acrobot against oracle-tuned fixed-discount baselines. Mechanism and ablation analyses show state-dependent horizon mixing and improved learning efficiency from the entropy-guided gate, while sensitivity analysis identifies reward/Q-value scale as a limitation of the current fixed-temperature confidence signal. The deep-RL extension, Deep Q( 𝛾 H), shows the same qualitative pattern across the three evaluated classic-control tasks, with the largest gains on MountainCar-v0 and 14 A. Albelaihi and A. Acrobot-v1 and little improvement on CartPole-v1. Overall, the results suggest that adaptive horizon mixing is a lightweight and interpretable alternative to manual selection of a single discount factor, especially when delayed credit assignment makes horizon choice difficult. Future work will examine larger benchmarks, continuous-action settings, alternative multi-head architectures, and scale-robust confidence mechanisms.
