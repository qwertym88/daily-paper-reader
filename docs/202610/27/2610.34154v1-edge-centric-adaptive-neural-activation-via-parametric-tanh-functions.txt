# Edge-Centric Adaptive Neural Activation via Parametric Tanh Functions 

Andreas Falkenberg 

Abstract —This paper introduces a compact, edge-centric neural architecture that resolves the computational bottlenecks of modern edge-activated paradigms like Kolmogorov-Arnold Networks (KANs) while retaining their expressiveness over traditional Multi-Layer Perceptrons (MLPs). While KANs demonstrate remarkable representational capacity by placing learnable univariate functions on connection edges rather than hidden nodes, their reliance on non-local B-splines introduces severe optimization hurdles, high memory overhead, and poor hardware scaling. To bridge this gap, we propose the Parametric Tanh Connection Function, a smooth, bounded architectural primitive defined as atanh (x, δ, α, β, γ ) = δ + α tanh( βx + γ). This formulation unifies offset, amplitude, local slope, and horizontal displacement into a lightweight, 4-parameter differentiable mapping optimized edge-by-edge via backpropagation. Evaluated on dense architectures using MNIST and CIFAR-10, our parametric tanh connection model achieves significant absolute accuracy gains over traditional affine baselines—reaching 95.63% ± 0.08% on MNIST and 44.74% 

± 0.18% on CIFAR-10. Crucially, it matches or exceeds the expressiveness of unconstrained 7-parameter exponential connection baselines while requiring up to 85% less training runtime. By replacing complex splines or hyper-flexible exponents with a bounded, analytically smooth hyperbolic tangent kernel, this work delivers a highly scalable, hardware-friendly compromise for heterogeneous connection-level deep learning. 

Index Terms —Kolmogorov-Arnold Networks (KAN), connection-level nonlinearities, edge-centric architectures, parametric tanh, trainable activation functions.

1 INTRODUCTION 

Conventional neural networks attach a scalar weight to each connection and apply a shared non-linear activation after the weighted inputs have been combined. This separation is computation-ally convenient, but it limits the learnable behav-ior of an individual connection to affine scaling. A connection-level function instead permits each input branch to learn its own nonlinear response before aggregation. The resulting model can adapt not only the magnitude and offset of a connection, but also its local slope and saturation behavior through the same optimization process. 2.2 Overview of the Following Chapters 

The following sections progress from conventional affine models and gradient-based optimization to learned nonlinear connection functions. 3.7 Complexity and Conclusion 

A rectangular least-squares problem is commonly solved by QR decomposition or singular-value de-composition rather than by explicitly forming an ordinary matrix inverse. Cholesky or LDL ⊤ fac-torization may be applied to suitable symmetric positive-definite systems, although forming normal equations directly can worsen conditioning. LU and Gauss–Jordan methods apply primarily to square systems. Consequently, the computational cost can-not be summarized by a single cubic bound without specifying matrix dimensions, rank assumptions, and the differentiation paradigm (analytic, auto-matic, or finite differences). For an affine model, changing one matrix ele-ment affects the output through the corresponding input component, making the loss gradient inher-ently input-dependent. Finite-difference gradients are computationally expensive because each param-eter perturbation requires an additional full forward loss evaluation, whereas analytic differentiation or automatic differentiation computes the complete gradient vector far more efficiently. 

Lemma 3. If every activation function in a feed-forward network is linear or the identity, the composition of all layers is equivalent to a single affine transformation. Gradient descent can still optimize the resulting model, but adding depth does not increase its representational power or enable it to represent nonlinearly separable boundaries. A multilayer extension replaces the single-layer update with backpropagation, which applies the chain rule recursively to propagate the loss gradient through each preceding layer [6]. Section 4 derives this recursion for the proposed connection-level nonlinear functions.

4.1 Context within Trainable Activation Litera-ture 

The proposed architecture belongs to the broader family of trainable activation models, but differs fundamentally by placing the trainable nonlinear function directly on each individual connection link rather than applying a single activation func-tion to the aggregated output of a node [1], [2], [9]. Learning an activation shape alters both the representational capacity and model parameteri-zation [1]. Recent evolutionary approaches such as PANGAEA [13] discover functional forms au-tomatically, while fixed parameterization scaling rules [14], [16] alter the topology of the loss func-tion to accelerate convergence. Properties such as smoothness, curvature, range, and gradient flow heavily influence optimization trajectories and over-all convergence rates. Earlier parametric activa-tions typically introduced a small number of train-able degrees of freedom while retaining standard node-level placement (e.g., PReLU [3]). In contrast, Kolmogorov–Arnold Networks (KAN) [4] place learnable univariate functions on edges and sum their outputs at nodes, demonstrating the mod-ern relevance of connection-level nonlinear formu-lations. The present work adopts an edge-centric placement but focuses on a compact, smooth ana-lytic tanh parameterization.

4.5 Proposed Parametric Tanh Connection Function 

The parametric tanh connection function is the pri-mary contribution evaluated in this work. It sim-plifies the generalized seven-parameter family into 8

a compact, four-parameter analytic formulation. For an input variable x and a localized parameter vector 

q = ( δ, α, β, γ ) ∈ R4, the connection response is defined as: 

atanh (x; q) = δ + α tanh( βx + γ), (36) where δ is an additive offset, α controls output amplitude, β controls input scaling and local slope, and γ shifts the core argument. This model builds on a rich lineage of adaptive bounded functions. While traditional static con-figurations suffer from gradient saturation issues, parameterized formulations such as the Parametric Leaky Tanh [15] mitigate these effects by preserv-ing non-zero gradients under extreme inputs. Sim-ilarly, smooth bounded functional adaptations [17] demonstrate that tailoring the activation envelope at a fine grain can yield superior empirical perfor-mance on multi-class classification tasks. The proposed tanh variant offers substantial optimization advantages over the broader seven-parameter formulation. Most notably, it avoids trainable real-valued exponents entirely, making it natively well-defined over the complete real in-put domain ( R) without requiring the numerical guardrails or positive projection constraints estab-lished under Policy 1. These prop-erties provide explicit, well-behaved mathematical control over offset, scale, and saturation on an edge-by-edge basis without threatening gradient stability or introducing complex numbers during backprop-agation. 

5 EXPERIMENTAL EVALUATION 

The proposed connection-level configurations are evaluated against an affine baseline on the MNIST handwritten digit benchmark [10] and the CIFAR-10 image dataset [11]. 

5.1 Experimental Setup 

To isolate the functional impact of connection-level placement, all architectures are optimized under a controlled environment using PyTorch v2.3 exe-cuted on an NVIDIA RTX 4090 GPU hardware back-end. Mini-batch sizes are fixed at 64, and optimizing parameters relies on the Adam algorithm with a fixed starting learning rate η = 10 −3, β1 = 0.9,and β2 = 0.999 . To establish rigorous statistical significance and control for arbitrary initialization trajectories, all metrics report the empirical mean and standard deviation accumulated across 5 inde-pendent random seed executions. 

5.2 Fully Connected Network 

The first architecture is a two-layer fully connected classifier. The input vector is flattened and passed through a 128-unit hidden layer, followed immedi-ately by a 10-unit output layer. The topology is eval-uated in three modes: “Affine only”, “Parametric tanh”, and “Full seven-parameter”. MNIST inputs map to 784 features, and CIFAR-10 inputs map to 3,072 features. Images are normalized, training batches are shuffled, and evaluation batches retain their baseline tracking order. Training is conducted for 15 epochs. 

5.3 Convolutional Network 

The second architecture is a compact convolutional network containing two feature-extraction blocks. Each block comprises a 3 × 3 convolutional layer, a standard ReLU activation, and a 2 × 2 max pool-ing layer. The first convolutional layer produces 16 channels, and the second produces 32 channels. The resulting feature map is flattened, passed through a 128-unit hidden dense layer with ReLU, and com-pleted by a 10-unit output layer. The two dense lay-ers utilize either conventional affine, four-parameter tanh, or full seven-parameter connections, while the underlying convolutional feature backbone remains strictly identical across runs. Training is conducted for 8 epochs. 9

6 CONCLUSION 

This paper introduced an edge-centric neural archi-tecture that learns heterogeneous nonlinear trans-formations directly on individual connection links before aggregation. Its primary functional prim-itive is the compact, four-parameter parametric tanh connection function, defined as atanh (x) =

δ + α tanh( βx + γ), which jointly optimizes offset, output amplitude, local slope, and horizontal dis-placement. While a broader seven-parameter ana-lytic formulation motivated the structural design space, our empirical benchmarks identify the sim-pler, bounded tanh parameterization as the superior choice for scalable, stable deep models. The parametric tanh configuration demon-strates a compelling architectural compromise when framed against modern edge-activated paradigms like Kolmogorov-Arnold Networks (KANs). By re-placing non-local, computationally expensive B-splines or hyper-flexible trainable exponents with an analytically smooth, bounded hyperbolic tangent kernel, our model preserves connection-level func-tional heterogeneity while isolating the network from gradient explosion. On fully connected topolo-gies, the parametric tanh model achieved an aver-age test accuracy of 95.63% ± 0.08% on MNIST and 44.74% ± 0.18% on CIFAR-10, yielding substantial absolute improvements of 3.98 and 4.80 percentage points over traditional affine baselines. Crucially, it outperformed the full seven-parameter variant 11 

across both datasets while consuming only 20.6% and 14.8% of its total training runtime, proving that targeted analytic boundaries accelerate non-convex landscape optimization. Furthermore, our evaluations expose an impor-tant structural limit regarding edge-centric place-ment: while edge-level activations dramatically en-hance representational power in dense coordinate networks, they introduce redundant parameteri-zation when appended to structurally translation-invariant backbones, such as convolutional feature extractors. Future work will focus on scaling the para-metric tanh connection framework into modern deep architectures, exploring automated parameter-sharing mechanisms to reduce runtime overhead, and evaluating its efficiency on sequential tasks like natural language processing. By providing a sta-ble, hardware-friendly alternative to spline-based edges, this work establishes a viable trajectory for the next generation of heterogeneous, connection-level deep learning models.
