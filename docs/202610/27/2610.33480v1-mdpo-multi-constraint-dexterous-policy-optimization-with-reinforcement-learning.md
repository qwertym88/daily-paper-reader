## 摘要
灵巧操作需要高维控制策略来完成复杂的接触密集型任务，同时满足多种安全要求，例如关节限位、不安全的手指构型、手臂碰撞以及不稳定的物体交互。约束强化学习（RL）为将这些要求纳入灵巧操作策略学习提供了一个有原则的框架。然而，现有的面向灵巧操作的约束 RL 方法主要关注累积成本约束，难以在灵巧策略学习过程中同时处理多种异构约束。在这项工作中，我们提出了多约束灵巧策略优化（MDPO）用于安全灵巧操作。我们首先将灵巧操作建模为一个多约束策略优化问题，同时涉及累积成本约束和逐状态成本约束。基于该建模，我们将多约束投影集成到灵巧操作策略优化过程中。具体而言，我们采用约束特定的策略投影，将最大化任务性能的中间策略映射到由累积成本约束和逐状态成本约束定义的可行域上。在 ReDMan 上的大量实验，包括安全关节控制、手指安全性和抓取任务，表明与基线相比，MDPO 在保持有竞争力的任务性能的同时实现了更优的约束满足。我们的代码可在该链接获取。

## Abstract
Dexterous manipulation requires high-dimensional control policies to accomplish complex contact-rich tasks while simultaneously satisfying multiple safety requirements, such as joint limits, unsafe finger configurations, arm collisions, and unstable object interactions. Constrained reinforcement learning (RL) provides a principled framework for incorporating these requirements into dexterous manipulation policy learning. However, existing constrained RL methods for dexterous manipulation primarily focus on cumulative cost constraints and struggle to simultaneously handle multiple heterogeneous constraints during dexterous policy learning. In this work, we propose Multi-constraint Dexterous Policy Optimization (MDPO) for safe dexterous manipulation. We first formulate dexterous manipulation as a multi-constraint policy optimization problem involving both cumulative cost constraints and state-wise cost constraints. Based on this formulation, we integrate multi-constraint projection into the dexterous manipulation policy optimization process. Specifically, we employ constraint-specific policy projections to map the intermediate policy that maximizes task performance onto the feasible regions defined by the cumulative cost constraint and the state-wise cost constraint. Extensive experiments on ReDMan, including safe joint control, finger safety, and grasping tasks, demonstrate that MDPO achieves superior constraint satisfaction while maintaining competitive task performance compared with the baselines. ## 二、方法论

### 1. 问题建模

- 在 CMDP 基础上引入统一的安全代价函数 c(s,a)，构造两个可行域：
  - 累积约束：`E[Σ γ^t c_t] ≤ c̄`，对应可行域 `Π_cum`；
  - 逐状态约束：`∀t, E[c_t] ≤ D̄`，对应可行域 `Π_state`。
- 最终目标：`max E[Σ γ^t r_t]  s.t. π ∈ Π_cum ∩ Π_state`。
- 论文进一步分析了两个可行域的关系：一般情形下二者只是**部分重叠**（图 1a）；当 `D̄ ≤ (1-γ)c̄` 时，可证明 `Π_state ⊆ Π_cum`（图 1b，利用几何级数与"累积增量 ≥ 每步代价"的上界关系），此时联合可行域退化为 `Π_state`。

### 2. 逐状态约束的可处理化（关键技巧）

- 逐状态约束天然不是轨迹级累积形式，无法直接嵌入策略优化。论文引入**运行最大代价** `M_t` 与**状态增广** `ŝ_t = (s_t, M_t)`，定义代价增量：
  - `D(ŝ_t, a_t) = max{c(s_t, a_t) - M_t, 0}`
  - `M_{t+1} = M_t + D(ŝ_t, a_t), M_0 = 0`
- 由此 `Σ_{k≤t} D_k = M_{t+1} = max_{k≤t} c_k`，于是"每步代价有界"被等价改写为轨迹级约束 `E[Σ D_t] ≤ D̄`，从而可用优势估计与策略梯度优化。
- 两类约束的安全语义仍保持区分：累积约束管"总量"，逐状态约束管"峰值"。

### 3. 两阶段优化框架

- **阶段一：性能改进（Performance Improvement）**
  - 用 PPO 裁剪代理目标 `L_PI(θ)` 最大化奖励优势 `Â^R`，得到中间策略 `π_{θ_{k+1/2}}`。
  - 此阶段**不引入任何安全代价信号**，避免奖励与异构安全信号在同一更新中相互竞争。
  - 同时监控新旧策略 KL，偏离过大则提前终止本阶段更新（防策略突变）。
- **阶段二：联合多约束投影（Joint Multi-constraint Projection）**
  - 目标是把中间策略投影回 `Π_cum ∩ Π_state`，同时尽量不远离中间策略：概念上 `min D_KL(π_θ ‖ π_{θ_{k+1/2}})`。

- **三套 critic**：奖励 critic `V_R`、累积代价 critic `V_C`、逐状态增量 critic `V_D`，均基于增广观测 `ŝ`，用同一 GAE 参数分别估计三类优势。

## 六、主要结论与发现

- MDPO 在 5 个任务上总体取得**更优的约束满足 + 有竞争力（部分任务更高）的成功率与回报**，在 `ArmJoint`、`ArmFinger`、`Grasp` 等强协调/接触丰富任务上优势更明显，收敛更快更稳。
- 部分基线虽能满足累积代价上限，却出现明显的**逐状态违规**——说明仅靠累积约束不足以保证瞬时安全，验证了引入逐状态约束的必要性。
- 消融显示两类约束**互补且不可替代**：仅累积修正能压住 episode 总代价，但代价率（瞬时违规）偏高；仅逐状态修正能压低瞬时违规，但性能提升更慢更不稳定；二者联合才取得最佳性能-安全折中。
- 理论层面给出可判定的充分条件 `D̄ ≤ (1-γ)c̄`，此时满足逐状态约束即自动满足累积约束，为阈值设定提供指导。
- 学到的抓取策略可迁移到真实"机械臂 + 灵巧手"平台并完成安全感知的抓取，初步证明方法的 sim-to-real 潜力。

## 七、优点

- **问题建模有新意**：明确区分累积约束与逐状态约束两种异构安全语义，并首次将灵巧操作表述为二者的联合约束优化问题，切中现有安全灵巧操作研究"只用单一累积约束"的实际短板。
- **转换技巧干净有效**：用"运行最大代价 + 非负增量"把难以处理的逐状态约束等价改写为轨迹级累积量，使其能直接复用 GAE 与 PPO 式策略优化，工程可实现性强。

- **实验链条较完整**：多任务对比 + 针对性消融 + 真机部署，且改造为连续代价使安全信号更稠密、更利于学习。

- **增广状态带来的分布偏移未讨论**：将运行最大代价 `M_t` 并入观测 `ŝ_t` 会改变策略的输入分布与可达状态集，可能影响表示学习与泛化；论文未分析 `M_t` 对策略网络容量、训练稳定性以及 sim-to-real 迁移的具体影响。

- **两阶段投影只有近似保证**：阶段一完全不考虑安全，可能在中间策略上已产生严重违规；阶段二仅通过 KL 惩罚做"软投影"，没有可行性恢复的理论保证，也无"投影后约束违反量上界"的分析。极端情况下若阶段一偏离过远，阶段二可能无法拉回可行域。

- **自适应机制超参偏多且缺少敏感性分析**：`η_C, η_D, z_C^max, z_D^max, ρ_C, h_k` 及其裕度/趋势调制规则共同决定有效系数，虽然作者声称跨任务通用，但未给出各超参的消融或敏感度曲线，调参负担实际上从"多乘子"转移到了"多自适应超参"。

- **统计严谨性不足**：仅 3 个随机种子，未报告置信区间、显著性检验或方差分析；曲线比较以均值为准，难以判断任务间差异是否显著。

- **基线覆盖偏窄且为作者自实现**：只对比 LAG、P3O、CRPO 三个基线，未与 CPO、安全层/控制屏障函数（CBF）、多约束拉格朗日或分布式约束 RL 等方法比较；三个基线的双约束扩展均由作者完成，缺少与原始实现的对照，公平性存疑。

- **计算开销未对比**：MDPO 需要三套 critic 且每步含两个阶段，计算与显存开销明显高于单 critic 基线，但论文未报告训练时间、样本效率或推理开销的对比，无法判断性能收益是否以显著算力为代价。

- **真机验证停留在定性层面**：仅展示 Grasp 任务的抓取截图/视频式描述，没有成功率、违规次数、代价统计，也未量化 sim-to-real 的性能落差与安全退化。

## 九、总体评价与适用场景

- **贡献层级**：本文的核心贡献是**问题重述 + 一个干净的约束转换技巧 + 一套工程上可落地的两阶段优化流程**。其中"运行最大代价 + 非负增量"把逐状态约束等价转为轨迹级累积约束，是最具复用价值的技术点；两阶段解耦与双系数独立自适应则是围绕该转换设计的配套机制。理论部分（可行域包含关系的充分条件）属于辅助性刻画，深度有限但方向正确。

- **方法定位**：MDPO 更适合**安全语义异构、且存在"必须每步抑制"的硬风险**的连续控制任务（如灵巧操作、接触丰富操作、人机共融场景），而不只是"总量有界即可"的常规 CMDP 场景。相比多乘子 Lagrangian，它在"避免过度保守"和"避免瞬时违规"之间提供了更细粒度的调节手段。

- **证据强度**：实验链条（多任务对比 + 针对性消融 + 真机展示）足以支撑"两类约束互补、不可替代"这一核心主张，但**尚不足以支撑"全面优于现有安全 RL 方法"的强结论**——受限于基线自实现、种子数少、无算力对比、真机无定量指标。

- **可借鉴点**：① 用"峰值统计量 + 增量累积"处理逐状态/瞬时约束的建模思路；② 性能阶段与安全阶段解耦、用 KL 分别锚定不同参考策略的两阶段范式；③ 用高分位数而非均值刻画最坏情形风险；④ 系数按安全裕度与风险趋势双向调制（风险上升提前加强、裕度充足则衰减）的工程技巧。

- **后续可研究方向**：给出投影后可行性恢复的理论界；研究 `D̄` 的自适应设定或与 `c̄` 的联合标定；将两阶段推广到在线/离线混合设定；在更多真实平台与更多基线（含 CBF、CPO）上做定量 sim-to-real 评估；降低三 critic 带来的算力开销（如共享表征、单critic 多头的设计）。
