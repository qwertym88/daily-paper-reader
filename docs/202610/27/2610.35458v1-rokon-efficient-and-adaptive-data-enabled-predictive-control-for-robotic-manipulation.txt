# RoKON: Efficient and Adaptive Data-Enabled Predictive Control for Robotic Manipulation 

Akshun Sharma 1, Zhongqi Wei 2, Buqing Ou 2, Frederike D¨ umbgen 2

Abstract — Data-enabled predictive control has recently emerged as a promising control paradigm, enabling a trans-parent optimal-control formulation without the need to learn an explicit dynamics model. This paper presents a number of extensions paving the path towards its use in real-time robotics tasks. Following recent work, we utilize a nonlinear predictor based on Gaussian kernels to represent the relationship between input and output data. We propose a damped Gauss–Newton method that enables real-time control by efficiently exploiting the least-squares structure of the control problem. In addi-tion, we introduce a hybrid buffer management strategy that incorporates informative online data while retaining relevant offline data, allowing the predictor to account for changes in the dynamics. We demonstrate the tracking performance and computational suitability of the proposed method in MuJoCo using a Franka Research 3 arm pushing a block across surface, without prior knowledge of its changing friction values. 

I. INTRODUCTION Robotic systems increasingly operate in settings where an accurate model of the environment is difficult to obtain. Contact, friction, and actuator dynamics can introduce be-haviors that are expensive to model and identify, particularly when a robot interacts with previously unseen objects or surfaces [1]. Data-driven control is a control paradigm that either identifies a system model from measured data and subsequently uses it to determine control actions (indirect data-driven control) [2], [3], or directly constructs control actions from measured input–output data without identifying an explicit model (direct data-driven control) [10]. Large-scale robot-learning efforts have demonstrated the benefits of aggregating diverse datasets [4]. Collecting such datasets on physical robots, however, requires substantial time, supervision, and hardware access, while exploratory actions may result in task failures or hardware damage [5], [6]. In such cases, the controller must extract useful dynami-cal information from a comparatively small number of input– output measurements. Prior work has demonstrated that data-driven control can achieve accurate closed-loop performance using only a small number of training samples [7]–[9]. A prominent framework for direct data-driven control is Data-enabled Predictive Control (DeePC) [10]. DeePC builds on Willems’ fundamental lemma, which states that, for a controllable linear time-invariant (LTI) system driven by a sufficiently persistently exciting input, the columns of a Hankel matrix constructed from one measured trajectory

DeePC embeds this data-based trajectory representation into a con-strained finite-horizon optimization problem and solves it in a receding-horizon manner without explicitly identifying a state-space model. Despite extensive developments in the control community, DeePC has only recently begun to receive attention for robotic systems. Existing studies have demonstrated that DeePC can achieve effective closed-loop control in sev-eral robotic settings, including trajectory tracking in aerial robotics [12], soft-robot control [13], and simulated robotic-arm tasks [14]. Although these studies demonstrate its prac-tical potential beyond strictly linear systems, the trajectory parameterization underlying standard DeePC is exact only for controllable linear time-invariant systems. Its application to nonlinear robotic systems therefore commonly relies on locally linear representations constructed around the current operating condition [15], or on lifting the measured variables into a feature space in which the nonlinear dynamics admit an approximately linear representation [16]. A more recent extension, Robust and Kernelized DeePC (RoKDeePC) [18], addresses nonlinear behavior differently by representing the multistep input–output mapping in a reproducing kernel Hilbert space (RKHS) [17]. Kernel eval-uations measure similarity between recorded trajectories and provide an implicit representation of the nonlinear mul-tistep predictor without constructing an explicit nonlinear state-space model or selecting a finite-dimensional set of lifting functions. RoKDeePC embeds this kernelized pre-dictor directly into a constrained receding-horizon control problem. However, the resulting optimization is noncon-vex and requires more computational effort compared to DeePC. Furthermore, the original formulations of DeePC and RoKDeePC use a fixed offline dataset, and its computational cost increases as that dataset (buffer) grows. To address these limitations, we introduce RoKON, an adaptive kernel-ized DeePC framework designed for real-time control under changing dynamics. RoKON retains the nonlinear depen-dence of the Gaussian kernel on the future inputs and updates a fixed-capacity hybrid data buffer using informative online measurements. We evaluate RoKON on a robotic pushing task across surfaces with varying friction. The contributions of this work are threefold:  

> •

We propose a damped Gauss–Newton method to solve the nonconvex RoKDeePC problem efficiently. Com-pared with the original projected-gradient method used in RoKDeePC, our method exploits the least-squares structure of the control problem, making it significantly arXiv:2610.35458v1 [cs.RO] 26 Oct 2026 faster.  

> •

We introduce a hybrid data buffer strategy in which a small offline recorded dataset initializes a fixed-capacity buffer and online trajectories progressively replace a subset of prior data. The buffer admits informative sam-ples only, allowing the predictor to adapt to changing friction surfaces while maintaining bounded memory and computation.  

> •

We validate RoKON in MuJoCo simulation on a robotic pushing task under varying friction conditions, and show favorable performance compared with MPC and state-of-the-art data-enabled predictive control base-lines. B. Implementation 

The parameters are manually tuned and set to Q = 8 ×

10 3IN , λk = 5 × 10 6, λg = 1 , WU = 10 −4, and W∆U =3. The Gaussian-kernel parameters are manually tuned and fixed to σ2 = 4 and γ = 0 .02 .For (IV-A.2) the initial offline trajectory contains T = 300 

samples. With Tini = 2 and N = 5 , this produces Hc =

T −Tini −N +1 = 294 overlapping trajectory columns. These columns initialize the hybrid buffer. The total buffer capacity and number of protected columns are Hmax = 350 , H p =100 . The oldest replaceable column is replaced only when the one-step prediction residual satisfies (26), with εonline =10 −3 m/s.

Reconstructing the predictor after every admitted column would introduce unnecessary and irregular computation for real-time implementation. Therefore, newly admitted Hankel matrix columns are accumulated into a small batch. Once a fixed number of columns get accumulated, the current buffer is copied into an immutable snapshot and passed to a non-real-time background worker on the CPU. The worker reconstructs the trajectory matrices, evaluates the kernel Gram matrix, forms the matrix used in the closed-form solution for g⋆, and calculates Mr and Mk using optimized BLAS/LAPACK matrix operations and linear solves. The previous complete buffer and matrices continue to be used while this reconstruction is in progress. After the worker finishes, the newly constructed matrices are installed together through an atomic model swap at an update boundary. Con-sequently, one control decision cannot combine trajectory matrices from one buffer version with kernel or solver matrices from another. The buffer capacity bounds the re-construction cost, while batching and background execution prevent the dense matrix operations from delaying the online optimization or other time-critical control computations. Low-Level Controller: A desired Cartesian pushing force cannot be commanded directly to the arm’s joints. The desired force must first be represented as a Cartesian wrench and then mapped to joint torques. The low-level arm con-troller operation at 1 kHz performs this mapping while also maintaining the end-effector position and orientation in the directions that do not contribute to pushing.
