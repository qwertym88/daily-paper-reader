## 摘要
本文针对未知非线性系统的最优控制，提出了一种新的预定义时间积分强化学习框架。首先，未知漂移由径向基函数（RBF）神经网络逼近，并结合数据驱动的在线辨识律来更新相应的神经网络权重。当辨识器收敛到真实动态的足够小邻域后，将学习到的模型纳入积分强化学习（IRL）问题。与传统的基于强化学习的最优控制不同，期望收敛时间被直接引入控制目标：由设计者指定 Lyapunov 函数及其预设衰减行为，然后利用逆最优控制构造一个兼容的运行代价，其最优策略继承预定义时间镇定性质。值函数由第二个 RBF 神经网络逼近，并提出一种新的评判器更新律，使评判器权重实现预定义时间收敛。有限的信息性学习数据存储在经验回放缓冲区中，并在评判器更新期间重复使用，从而避免在整个闭环运行过程中需要持续激励。理论分析证明，评判器权重误差在分配的学习时域内进入预设残差集，而闭环状态在整体设计者指定的截止时间内到达原点的小邻域。对未知非线性系统的数值仿真验证了精确的漂移重构、预定义时间评判器学习和闭环收敛。

## Abstract
This paper develops a new predefined-time integral reinforcement learning framework for optimal control of unknown nonlinear systems. The unknown drift is first approximated by a radial basis function (RBF) neural network, together with a data-driven online identification law for updating the corresponding neural weights. After the identifier converges to a sufficiently small neighborhood of the true dynamics, the learned model is incorporated into the integral reinforcement learning (IRL) problem. Unlike conventional reinforcement-learning-based optimal control, the desired convergence time is introduced directly into the control objective: a Lyapunov function and its prescribed decay behavior are specified by the designer, and inverse-optimal control is then used to construct a compatible running cost whose optimal policy inherits the predefined-time stabilization property. The value function is approximated by a second RBF neural network, and a new critic update law is developed to impose predefined-time convergence on the critic weights. Finite informative learning data are stored in a replay buffer and reused during the critic update, thereby avoiding the need for persistent excitation throughout the closed-loop operation. Theoretical analysis proves that the critic-weight error enters a prescribed residual set within the allocated learning horizon, while the closed-loop state reaches a small neighborhood of the origin within the overall designer-specified deadline. Numerical simulations on an unknown nonlinear system verify accurate drift reconstruction, predefined-time critic learning, and closed-loop convergence.

## 1. 核心问题与整体含义（研究动机与背景）

- **应用背景**：现代信息物理系统与网络化控制系统普遍面临**未知非线性动态**、模型信息有限以及严格的性能要求，传统基于模型的最优控制难以直接应用。
- **理论难点**：
  - 非线性最优控制受 **Hamilton–Jacobi–Bellman（HJB）方程**支配，一般无解析解；
  - 当漂移动态未知时，最优反馈律无法直接构造；
  - 许多控制任务要求**提前指定收敛时间**，且该时间界应**与初始条件无关**（即预定义时间/固定时间控制）。
- **现有方法的缺口**：
  - 强化学习（RL）与自适应动态规划（ADP）可数据驱动逼近 HJB 解，积分强化学习（IRL）进一步降低对未知漂移的依赖，但传统 RL 最优控制**不保证指定时间收敛**；
  - 固定/预定义时间评判器学习（Kokolakis 等）虽建立了收敛性质，但其 Bellman 残差仍**显式包含系统动态项**，漂移未知时难以直接实现；
  - 经典并发学习/积分并发学习（ICL）可在有限激励下实现参数收敛，但**自身不构造预定义时间最优控制器**；
  - 逆最优预定义时间方法可从指定 Lyapunov 衰减构造运行代价与反馈律，但**直接实现仍需要模型信息**。
- **整体含义**：本文试图弥合"未知动态重构—积分最优学习—设计者指定预定义时间收敛"三者之间的鸿沟，在**完全不依赖漂移先验知识**的前提下实现近似最优且具有预定义时间保证的控制。

## 2. 方法论：核心思想与关键技术细节

### 2.1 总体架构（三阶段统一框架）

1. **在线漂移辨识阶段**：用 RBF 神经网络逼近未知漂移 `f(x)`，通过积分并发学习（ICL）在线更新权重；
2. **逆最优构造阶段**：基于辨识模型，由设计者指定 Lyapunov 函数 `V_d` 及其预设衰减行为，反推运行代价 `L1(x), L2(x)`，使最优策略继承预定义时间镇定性质；
3. **仅评判器 IRL 阶段**：用第二个 RBF 网络逼近值函数，设计预定义时间评判器更新律，配合有限信息回放栈避免持续激励。

### 2.2 关键公式与算法流程

- **预定义时间比较定理（Theorem 1）**：若 `V` 满足
  `\dot{V} ≤ -(γ_{p,q,r}/T_s)[αV^p + βV^q]^r`，且 `0<p<q`、`pr<1<qr`，
  则原点全局预定义时间稳定，且 `T(x_0) ≤ T_s`，其中 `γ_{p,q,r}` 为 Gamma 函数给出的归一化系数。

- **漂移辨识（式 8）**：
  `\dot{\hat{W}}_f = Γ_f [φ_f(t)e_f^T(t) + k_f Σ_{ℓ} φ_{f,ℓ} e_{f,ℓ}^T(t)]`，
  同时利用当前移动窗口数据与历史栈中的信息性积分数据；
  用最小二乘批解 `\hat{W}_{f,LS}` 作为知情初始化，而非精确模型。
  Lemma 1 证明权重误差一致最终有界：`\dot{V}_f ≤ -c_f V_f + Δ_f`。

- **逆最优运行代价（Theorem 2）**：
  在最小控制努力意义下求解约束 `∇V_d^T g u + σ_d = 0`，得到
  `u_c = -(σ_d/D_d) R^{-1} g^T ∇V_d`，
  并反推
  `L_1^T = [2σ_d/D_d - 1] g^T ∇V_d`，`L_2 = -∇V_d^T \hat{f} + σ_d^2/D_d`，
  从而保证 HJB 方程的最小化策略与预定义时间镇定策略一致。

- **小控制与原点连续延拓（Lemma 3–4, Corollary 1）**：
  引入充分条件 `mpr > m-1`，保证 `u_c`、`L_1`、`L_2` 在原点可连续延拓（`u_c(0)=0` 等）。
  若 `V_d = ½x^T Px`，则设计条件退化为 `½ < pr < 1 < qr`。

- **预定义时间评判器更新律（式 57）**：
  `\dot{\hat{W}} = -α_W Γ \bar{Ω}(t)[k_1 sig_{γ_1}(e) + k_2 sig_{γ_2}(e)] - α_W Γ Σ_j \bar{Ω}_j[k_1 sig_{γ_1}(e_j) + k_2 sig_{γ_2}(e_j)]`，
  其中 `γ_1 = pr`、`γ_2 = 2qr-1`，`e` 与 `e_j` 为归一化 Bellman 残差。
  - **精确逼近情形**：若 `α_W ≥ γ_W/T_W`，则 `\tilde{W}(t)=0` 在 `t ≥ T_E+T_W` 时严格成立；
  - **非零残差情形**：`V_W` 在 `T_E+T_W` 内进入前向不变集 `B_W`，权重误差有显式上界。

- **闭环联合稳定性（Theorem 4, Corollary 2）**：
  定义复合 Lyapunov 函数 `J(t) = ∫_{t-T}^{t} V^*(x) dτ + V_W(t)`，导出
  `\dot{J} ≤ -C_1 J^μ - C_2 J^ν + Δ_J`，
  在显式增益与时间分配条件下，`J` 在总截止时间 `T_p = T_E + T_W + T + T_X` 内进入不变集，状态与权重误差均获显式界。Corollary 2 给出 `T_s` 与 `T_p` 一致选取的充分条件。

- **统一性**：将在线漂移辨识、积分并发学习、逆最优设计、仅评判器 IRL 融合为**单一架构**，并给出统一的状态–评判器联合分析。

- **实验覆盖不足**：
