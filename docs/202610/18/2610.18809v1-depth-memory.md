## 摘要
残差连接通过逐层加性累积层输出在网络中传播信息。近期提出的替代方案，如流形约束超连接（Manifold-Constrained Hyper-Connections, mHC）和注意力残差（Attention Residuals, AttnRes），则使用更具表达力的深度聚合机制，在规模化语言建模中提升了性能。在本工作中，我们将深度上的表示混合视为跨层存储与检索信息的问题。形式化这一视角，我们引入深度记忆（Depth Memory, DM），一个统一框架，用携带表示通过网络的数据流来描述标准前置层归一化（pre-layer-norm, PreLN）Transformer、mHC 和 AttnRes。例如，其中一种流可以是一个显式记忆流，通过查询该流来丰富每一层的输入，随后其输出被写回记忆以供后续层使用。对于 AttnRes，该记忆流是显式层表示的不断增长的缓存。对于 mHC，它是扩展后的残差流。基于这一观点，我们提出线性深度记忆（Linear Depth Memory, LDM），它将跨深度的信息检索形式化为一个使用递归最小二乘求解的回归问题。所得架构在深度上传播三种流：标准残差流、线性联想记忆流和逆协方差流。面向高吞吐训练与推理，我们提出一种硬件感知的 LDM 实现，可降低峰值激活内存和内存流量。在 400M 和 1.5B 参数规模下，LDM 在 PreLN、mHC 和 AttnRes 基线中始终取得最低的困惑度，同时具有有竞争力的零样本准确率。

## Abstract
Residual connections propagate information through a network by additively accumulating layer outputs. Recently proposed alternatives, such as Manifold-Constrained Hyper-Connections (mHC) and Attention Residuals (AttnRes), instead use more expressive depth aggregation mechanisms that improve language modeling performance at scale. In this work, we consider the mixing of representations over depth as a problem of storing and retrieving information across layers. Formalizing this perspective, we introduce Depth Memory (DM), a unified framework that describes the standard pre-layer-norm (PreLN) transformer, mHC, and AttnRes in terms of streams that carry representations through the network. One such stream, for example, could be an explicit memory stream that is queried to enrich the input to every layer, and whose output is subsequently written back into the memory for use by later layers. For AttnRes, this memory stream is a growing cache of explicit layer representations. For mHC, it is an expanded residual stream. Building on this view, we propose Linear Depth Memory (LDM), which formulates information retrieval across depth as a regression problem solved using recursive least squares. The resulting architecture propagates three streams across depth: the standard residual stream, a linear associative memory stream, and an inverse covariance stream. For high-throughput training and inference, we propose a hardware-aware implementation of LDM that reduces peak activation memory and memory traffic. LDM consistently achieves the lowest perplexities among PreLN, mHC and AttnRes baselines at the 400M and 1.5B parameter scales, alongside competitive zero-shot accuracy.

## 1. 核心问题与整体含义（研究动机与背景）

- **残差连接的“停滞”**：自 ResNet（He et al., 2016）以来，Transformer 跨深度传播信息几乎一直依赖单一的加性残差流（PreLN），即 `x_l = x_{l-1} + δ_l`，各层输出被等权累加。
- **新近的深度聚合尝试**：Hyper-Connections（HC）、Manifold-Constrained Hyper-Connections（mHC）维护扩展残差流；Attention Residuals（AttnRes）对历史层输出做 softmax 注意力。二者在规模化语言建模中带来性能提升，但彼此孤立、缺乏统一解释。
- **论文的核心视角**：将“跨深度表示混合”重新表述为**跨层存储与检索信息**的问题——每一层用 Read 操作从若干“流”中取出输入，用 Write 操作把层输出写回这些流。
- **整体含义**：作者提出 **Depth Memory（DM）** 统一框架，把 PreLN、mHC、AttnRes 纳入同一“流 + 读写”语言，并据此从第一性原理设计出 **Linear Depth Memory（LDM）**，为深度混合提供可扩展的新范式。

## 2. 方法论

### 2.1 Depth Memory 统一框架

- 设每层维护一个流元组 `S_l = (S_l^(1), …, S_l^(P))`，通过 `Read(S_{l-1}, q_{l-1})` 形成层输入，通过 `Write(S_{l-1}, k_l, v_l)` 更新流，其中 `v_l = δ_l` 为子层输出。
- **PreLN**：单一流即残差流 `x_l`；Read 直接取流，Write 为加性更新。
- **AttnRes**：单一流为不断增长的键值缓存 `(K≤l, V≤l)`；Read 为注意力，Write 为追加（显式深度混合，内存随深度增长）。
- **mHC**：单一流为扩展残差流 `X_l ∈ R^{D×N}`；Read 为 `X_{l-1} q_{l-1}`，Write 为 `X_{l-1}H_res + v_l k_l^T`（隐式深度混合，状态定长）。

### 2.2 Linear Depth Memory（LDM）

- **双流基础版**：维护标准残差流 `x_l` 与矩阵值记忆流 `M_l`，读写为
  - Read：`x_{l-1} + M_{l-1} q_{l-1}`
  - Write：`(x_{l-1}+v_l, M_{l-1}+v_l k_l^T)`
- **与线性注意力的联系**：该外积更新等价于对深度做无归一化线性注意力，`M_{l-1} = Σ v_i k_i^T`，即把“不断增长的历史表示集合”压缩为定长矩阵摘要。
- **深度回归视角**：把外积更新视为如下回归问题的近似解
  `M*_l = argmin_M Σ_{i=0}^{l} ||v_i − M k_i||²`
  并推广为带**逐层遗忘因子 λ_j、动态重要性权重 ω_i、加权岭惩罚 α⁻¹** 的加权版本。
- **递归最小二乘（RLS）精确求解**：利用 Sherman–Morrison 公式在线维护精确解，引入第三流——逆协方差流 `P_l`：
  - 增益与伪值：`κ_l = P_{l-1}k_l / (λ_l + k_l^T P_{l-1}k_l)`，`u_l = v_l − M_{l-1}k_l`
  - 状态更新：`M_l = M_{l-1} + u_l κ_l^T`，`P_l = (P_{l-1} − κ_l k_l^T P_{l-1}) / λ_l`
- **多组机制**：将 `M_l` 按值维度分为 G 组，每组独立维护 `P` 与查询，读出拼接；实验取 G=16。
- **高效参数化**：由共享潜在表示 `h = SiLU(Aff(RMSNorm(x)))` 生成查询、键、读门 `g`、写权重 `ω`、读增益 `γ`；查询/键做 L2 归一化。
- **边界处理**：嵌入 `e` 也写入初始记忆，最后一层后额外做一次 Read 再送入 LM head。

### 2.3 硬件感知实现

- **状态展开（Unwinding）**：RLS 更新可逆，`M_{l-1} = M_l − u_l κ_l^T`；前向原地更新状态，反向从最终状态逐步“展开”，每层只保存小尺寸上下文 `c_l`（`u_l, κ_l, P_{l-1}, k_l, λ_l` 等），避免存储每层 `M_l`。
- **窗口化写入（Windowed Writes）**：将连续 E 层（主实验 E=4）组成窗口，窗口内所有 Read/Write 均由窗口起始状态 `M_b` 加窗口内 rank-1 修正计算，不物化中间状态，降低访存；反向同样按窗口展开。
- 使用 **CuTe DSL** 为 Hopper/Blackwell GPU 编写内核。

## 6. 主要结论与发现

- **困惑度全面领先**：LDM 在 400M 与 1.5B 上均取得最低的验证、WikiText-2、LAMBADA 困惑度；1.5B 时平均零样本准确率最高（59.71），400M 时排名第二（50.46）。
- **小记忆矩阵仍有竞争力**：Dk=4（记忆条目数与 mHC 扩展残差流相同）仍优于 mHC，说明收益并非单纯来自状态容量。
- **训练收敛更快**：1.5B 训练曲线上，LDM 达到基线最终损失所需 token 更少（相对 PreLN 约 ×1.22、相对 mHC 约 ×1.09）。
- **吞吐可接受**：LDM 在所有设置下超过 Full AttnRes，训练与多数推理设置超过 mHC，与 Block AttnRes 接近（decode 尤具竞争力）。
- **宽深比泛化**：LDM 在 400M 所有测试比例上优于 PreLN，1.6B 所有比例上困惑度最低；HC 随规模增大稳定性下降，LDM 随深度单调改善。
- **消融关键发现**：
  - 保留独立残差流至关重要（去掉任一恒等路径均差于 PreLN）；
  - RLS 优于 delta rule 与外积更新，印证“更精确的回归求解器”有益；
  - 存储 `δ_l` 优于存储 `x_l`（避免冗余）；查询/键取自 `x_l` 优于取自 `δ_l`；静态查询明显变差；
  - 分组有小幅稳定收益；读增益、读门有小幅贡献；写权重与遗忘因子在该设置下影响可忽略。

## 7. 优点

- **视角统一且具生成性**：Depth Memory 框架把 PreLN、mHC、AttnRes 统一为“流 + 读写”，并清晰区分显式（AttnRes）与隐式（mHC/LDM）深度混合，为后续设计提供分类学基础。
- **理论推导严谨**：将深度混合形式化为加权回归问题，并用 Sherman–Morrison 给出精确 RLS 解，推导完整（附录 E.1），与序列维的 test-time regression 形成漂亮的类比。
- **系统工程扎实**：状态展开 + 窗口化写入是针对“逐层顺序执行”这一深度轴特性设计的，CuTe DSL 内核使方法在实际吞吐上可用，而非仅停留在理论。
- **实验公平性较好**：backbone 匹配、学习率逐方法调优、数据顺序固定、参数量增量与基线可比，并额外做等状态大小对照。
- **多维度验证**：除困惑度外，还覆盖零样本、宽深比泛化、训练/prefill/decode 吞吐与峰值内存，结论较立体。

## 8. 不足与局限

- **规模与领域有限**：最大仅 1.6B 参数、100B token，且仅语言建模；作者自述未验证更大规模及图像分类等其他领域，规模化收益仍属外

推结论，需要更大规模验证。

- **与强基线的差距幅度有限**：尽管 LDM 在困惑度和零样本上稳定领先，但相对 mHC / Block AttnRes 的提升幅度通常在小数点量级（如 1.5B 困惑度、平均准确率差距），是否能在更大模型上转化为下游任务的实质收益仍待观察。
- **额外超参与结构复杂度**：LDM 引入记忆维度 `Dk`、分组数 `G`、遗忘因子 `λ`、读增益/门控/写权重等多组超参，且消融显示部分组件（写权重、遗忘）在当前设置下几乎无影响，说明超参配置尚未被充分理解或简化，实际使用存在调参成本。
- **依赖定制内核**：性能优势部分建立在 CuTe DSL 手写内核与窗口化写入之上，缺少通用框架（如 PyTorch/Triton）下的即插即用实现，复现与迁移到其他硬件（非 Hopper/Blackwell）的门槛较高。
- **理论保证的边界较窄**：RLS 的“精确解”仅针对所设定的加权最小二乘目标，而该目标本身是对深度信息检索的启发式建模；论文未给出为何该回归目标能刻画语言模型跨层信息流的理论依据，理论与实际收益之间仍有解释缺口。
- **基线覆盖不全**：Full AttnRes 在 1.5B 因成本未测，mHC 仅用官方实现的一种配置（4 流、20 次 Sinkhorn），未探索其超参最优情形；宽深比实验部分沿用 DepthBench 已发布结果而非统一重跑，跨实验比较的严格控制略弱。
- **披露不足**：未报告总算力、GPU 小时与碳排放等资源信息，也未给出多次随机种子的方差/误差棒，单次运行的结论稳健性无法从文中直接评估。

## 9. 总体评价与启示

- **定位**：这是一篇“框架 + 方法 + 系统”三位一体的工作。其最大贡献未必是某一个具体模块，而是把分散的深度混合技术统一到“跨层记忆读写”的语言下，并由此系统性地推导出一个可落地的新方法。
- **方法论价值**：将序列维线性注意力 / test-time regression 的思路平移至深度维，并用 RLS 替换启发式外积更新，是一条清晰且可复用的设计范式；即便读者不采用 LDM，也可借该框架重新审视残差连接的设计空间。
- **工程价值**：状态展开与窗口化写入表明，深度轴的顺序依赖并非不可优化的瓶颈，这为后续“深度方向可扩展”的架构研究提供了可行性证据。
- **适用建议**：若关注小到中等规模（≤2B）语言模型的预训练效率与困惑度，LDM 是值得尝试的残差替代方案；若目标是超大规模或非语言领域，建议先在小规模上验证其相对 mHC 的增益是否随规模保持，并评估内核移植成本。
- **未来方向（作者与本文隐含的）**：扩展到更大模型与更多模态；简化超参（如去掉无效组件）；探索自适应遗忘/写权重；将该框架与 MoE、长上下文、循环深度（looped transformer）等结构结合。
