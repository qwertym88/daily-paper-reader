## ABSTRACT 

Residual connections propagate information through a network by additively ac-cumulating layer outputs. Recently proposed alternatives, such as Manifold-Constrained Hyper-Connections (mHC) and Attention Residuals (AttnRes), in-stead use more expressive depth aggregation mechanisms that improve language modeling performance at scale. In this work, we consider the mixing of repre-sentations over depth as a problem of storing and retrieving information across layers. Formalizing this perspective, we introduce Depth Memory (DM) , a uni-fied framework that describes the standard pre-layer-norm (PreLN) transformer, mHC, and AttnRes in terms of streams that carry representations through the net-work. One such stream, for example, could be an explicit memory stream that is queried to enrich the input to every layer, and whose output is subsequently written back into the memory for use by later layers. For AttnRes, this memory stream is a growing cache of explicit layer representations. For mHC, it is an expanded residual stream. Building on this view, we propose Linear Depth Mem-ory (LDM) , which formulates information retrieval across depth as a regression problem solved using recursive least squares. The resulting architecture propa-gates three streams across depth: the standard residual stream, a linear associative memory stream, and an inverse covariance stream. For high-throughput training and inference, we propose a hardware-aware implementation of LDM that reduces peak activation memory and memory traffic. LDM consistently achieves the low-est perplexities among PreLN, mHC and AttnRes baselines at the 400M and 1.5B parameter scales, alongside competitive zero-shot accuracy.

(c) mHC generates its three mappings from the current expanded state and applies them around one transformer branch. In this work, we approach depth mixing from a different angle. Viewing it as a problem of storing and retrieving information across layers, we introduce Depth Memory , a framework that interprets the propagation of information across depth as a problem of managing layer representations using a set of streams . At each layer, and independently for each token, a Read operation forms the layer input from these streams, and a Write operation updates the streams using the layer output. This framework encompasses the standard residual stream, AttnRes’s growing cache of layer representations, and mHC’s expanded residual stream, covering both explicit and implicit forms of depth mixing (Figure 2). Besides taxonomizing existing residual methods using our depth memory framework, we propose instantiating it as a Linear Depth Memory (LDM) . LDM maintains three streams: the standard resid-ual stream, a fixed-size matrix-valued memory stream, and an inverse covariance stream (Figure 2a). Analogous to test-time regression for sequence mixing (Wang et al., 2025), we formulate matrix-valued memory stream updates as the solution to a depth regression problem, which fits a linear map to reconstruct previous layer outputs from their corresponding keys. LDM solves this optimization problem optimally through recursive least squares (RLS, Section 3.2). Our hardware-aware implementation of LDM addresses efficiency challenges posed by a naive in-stantiation of the framework. First, we implement an unwinding mechanism that does not require storing each layer’s memory stream. Second, we employ a windowed Write algorithm that defers parts of the memory updates. Implemented as efficient CuTe DSL kernels, LDM achieves compara-ble speed to the baselines (Figure 5). We evaluate LDM on language modeling benchmarks across 400M Llama-like (Touvron et al., 2023) and 1.5B Qwen-like (Yang et al., 2025a) transformer backbones. LDM achieves lower perplexity than a standard pre-layer-norm (PreLN) transformer, mHC and AttnRes at both scales, along with competitive zero-shot accuracy. These gains hold across standard aspect ratios. We furthermore perform extensive ablations to isolate the contributions of different LDM architectural components. In summary, our main contributions are: 1. We introduce depth memory, a framework that describes the propagation of information across depth through a collection of streams and their Read and Write operations. 2. We instantiate this framework in the form of LDM, a linear depth memory that solves a depth re-gression problem using recursive least squares to store layer representations in a fixed-size state. 3. We provide an efficient implementation of LDM that combines unwinding and deferred writing techniques to reduce activation memory overhead and memory traffic of LDM. 4. We show that LDM consistently achieves the lowest perplexities among tuned PreLN, mHC, and AttnRes baselines at the 400M and 1.5B scales, while maintaining competitive zero-shot accuracy, and that these gains hold across standard model aspect ratios. 2Preprint

4.1 MAIN RESULTS 

Setup. We compare LDM with PreLN, mHC, and AttnRes using matched backbone configurations. At both 400M and 1.5B, LDM adds approximately 1% more parameters than PreLN, comparable to the overhead of mHC (Table 4). Our main LDM configuration uses Dk = 8 at both scales, and we additionally evaluate Dk = 4 at 400M. We train both Full and Block AttnRes at 400M, but only Block AttnRes at 1.5B because of the higher training cost of Full AttnRes. Following Kimi Team et al. (2026b), we target approximately eight depth blocks for Block AttnRes, using eight at 400M and seven at 1.5B to avoid splitting transformer blocks across depth blocks. All models use AdamW with a weight decay of 0.1 and linear warmup followed by cosine decay to 10% of the peak learning rate. We sweep the peak learning rate for each method and scale using a grid spaced by factors of two, selecting the value with the lowest held-out validation loss. We report held-out validation, WikiText-2 (Merity et al., 2016), and LAMBADA (Paperno et al., 2016) perplexity, together with zero-shot accuracy on ARC-Easy, ARC-Challenge (Clark et al., 2018), HellaSwag (Zellers et al., 2019), PIQA (Bisk et al., 2019), WinoGrande (Sakaguchi et al., 2019), OpenBookQA (Mihaylov et al., 2018), and LAMBADA. Full implementation details are in Appendix B. 

Lower perplexity and competitive accuracy. Table 2 reports our main pretraining results. It reveals that our main LDM configuration ( Dk = 8 ) achieves the lowest validation, WikiText-2, and LAMBADA perplexity at both model sizes. It also achieves the highest average zero-shot accuracy at 1.5B and ranks second at 400M. Figure 4 shows the training loss at 1.5B. 

Matched memory matrix size. Both mHC and LDM maintain states of fixed size across depth, whereas Full AttnRes retains a growing cache of layer outputs. With Dk = 8 , LDM’s memory matrix contains 8D entries per token, twice the 4D entries in mHC’s expanded residual state. We therefore also evaluate LDM with Dk = 4 at 400M, matching the number of entries in its memory matrix to mHC’s expanded residual state (note that LDM additionally maintains a classic residual stream and an inverse covariance stream). This smaller configuration still achieves lower validation, WikiText-2, and LAMBADA perplexity than mHC, alongside higher average zero-shot accuracy. Thus, LDM remains competitive with other baselines even with a smaller memory matrix.

Results and shape preferences. LDM improves over PreLN at every evaluated aspect ratio at both scales (Figure 7). ## 5 DISCUSSION AND CONCLUSION 

In this work, we introduce Depth Memory, a framework that interprets the propagation of infor-mation over depth as a problem of managing layer representations using a set of streams. This perspective unifies standard residual connections, AttnRes, and mHC, while distinguishing methods that retain explicit layer representations from those that mix them into a fixed-size state. It also pro-vides a starting point for designing new depth mixers. Building on this view, we then propose Linear Depth Memory (LDM), which formulates memory updates as a depth regression problem, solving it exactly using recursive least squares. To do so, LDM maintains a standard residual stream, a memory stream, and an inverse covariance stream. Each token thus carries a compressed, queryable representation of earlier layer outputs, which enriches the inputs to subsequent layers. Our imple-mentation uses state unwinding and windowed updates to reduce activation storage and memory traffic, making LDM feasible in practice. At both 400M and 1.5B, trained on 50B and 100B tokens, respectively, our main LDM configuration achieves the lowest reported perplexities among the tuned PreLN, AttnRes, and mHC baselines, alongside competitive zero-shot accuracy. These gains hold across standard aspect ratios. 

Limitations and future work. In this work, we focus on language models with up to 1.6B param-eters that are trained on up to 100B tokens. Future work could evaluate LDM at larger scales and in other domains such as image classification. Moreover, LDM can add peak memory during train-ing, which other stable formulations of the backward recurrence or checkpointing (as used in mHC) could reduce. Finally, our Depth Memory framework admits a plethora of different instantiations, such as alternative linear recurrences or memories with nonlinear read and write operations. ## A EXTENDED RELATED WORK 

Our work sits at the intersection of two lines of research: mechanisms that enrich information flow across transformer depth, particularly through depth mixing, and associative memory mechanisms developed primarily for sequence modeling. We discuss both connections below. A.1 INFORMATION FLOW ACROSS TRANSFORMER DEPTH 

Enriching the residual representation. The standard transformer propagates information across depth through a single additive residual stream. A number of works have explored richer alter-natives to this formulation. SiameseNorm (Li et al., 2026) maintains two streams that comple-ment each other with different normalization approaches. Moreover, residual matrix transformers (Mak & Flanigan, 2025) propagate a matrix-valued residual representation. Hyper-Connections (Zhu et al., 2025) introduce multiple residual channels along with learned mappings between them, and Manifold-Constrained Hyper-Connections (mHC) (Xie et al., 2026) (and its follow-up mHC-lite (Yang & Gao, 2026)) enhance their stability. xHC (Zhang et al., 2026a) expands the residual stream further, updating only a subset of its streams in each layer and enriching what each layer writes back. Related approaches include Deep Delta Learning (Zhang et al., 2026b), which uses a delta-like rule to update a (possibly matrix-sized) residual stream, and other architectures that increase the capacity or flexibility of the representations propagated between layers. These methods modify the residual representation itself. LDM instead preserves the standard addi-tive residual stream and introduces a separate recurrent associative state. 

Explicit depth mixing. A second family of methods directly combines representations produced at different depths. We refer to this general class of mechanisms as explicit depth mixing. Unlike ordi-nary residual accumulation, depth mixing methods allow the computation at one layer to selectively incorporate representations produced at earlier layers. Several works have explored representation aggregation across layers. DenseFormer (Pagliardini et al., 2024) combines preceding hidden representations using learned depth-dependent weights. Cross-Layer Retrospective Retrieving via Layer Attention (Fang et al., 2023) uses attention to re-trieve representations from earlier layers. Although this work considers a formulation similar to our memory, its final methods are different from ours. DeepCrossAttention (Heddes et al., 2025) consid-ers richer cross-layer mixing, including input-dependent mechanisms. MUDDFormer (Xiao et al., 2025) similarly constructs layer inputs by dynamically combining representations across depth, and LIMe (Gerasimov et al., 2025) also revisits the use of intermediate transformer representations. Ear-lier work also introduced Vertical Attention (AlKhamissi et al., 2021) and Depth-Wise Attention (ElNokrashy et al., 2024), likewise exploring attention or fusion across network layers. Most closely related to our framing, Attention Residuals (AttnRes) (Kimi Team et al., 2026b) re-places fixed residual accumulation with softmax attention over representations from the embedding and the preceding layers. Figure 2b illustrates Full AttnRes. Its blockwise variant applies the same operation to coarser groups of layers. Subsequent work has considered alternative parameterizations of attention-based residual mixing (Su, 2026; Luo et al., 2026). LDM differs from these approaches in how previous depth representations are made available. Ex-plicit depth mixing mechanisms retain or otherwise expose a collection of previous representations and directly form a mixture over them. LDM instead recurrently compresses key–value associations from the embedding and the previous layers into a fixed-size state. A later layer retrieves from this state using a content-dependent query. As shown in the main text, the simplest LDM recurrence can therefore be interpreted as implementing linearized attention over depth implicitly , without explicitly materializing the collection of previous depth representations. 

Use in large-scale runs. Richer mechanisms for information propagation across depth have also be-gun to appear in large-scale language models. Recent models, including DeepSeek-V4 (DeepSeek-AI et al., 2026), Kimi K3 (Kimi Team et al., 2026a), and Qwen3.8-Flash-Next (Qiu et al., 2026), 17 Preprint incorporate variants of enriched residual or cross-layer routing mechanisms. This provides addi-tional evidence that modifying information flow across transformer depth works at large scale and appears to be a promising scaling axis. A.2 ASSOCIATIVE MEMORIES , L INEAR ATTENTION AND REGRESSION 

Our second connection is to the literature on linear attention and associative memory. A linear associative memory (Kohonen, 1972) stores key–value associations through a matrix-valued state and retrieves values using a query. Under the simplest outer product update, this recurrence is informally equivalent to unnormalized linear attention (Katharopoulos et al., 2020; Schlag et al., 2021). Recent work has further interpreted such memories as online regression problems in the context of sequence mixing. In particular, Test-Time Regression (Wang et al., 2025) provides a regression per-spective on sequence models with associative memory. From this view, delta rule models (Schlag et al., 2021; Yang et al., 2024; 2025b; Kimi Team et al., 2025), whose update goes back to the Widrow–Hoff rule (Widrow & Hoff, 1960), take one online gradient step on the regression ob-jective per token. DeltaProduct (Siems et al., 2025) takes several steps per token, and the later Preconditioned DeltaNet (Tumma et al., 2026) accounts for the curvature of the least squares loss with a (diagonal) preconditioner. Closely related ideas appear in work on mesa-optimization. The original MesaLayer (von Oswald et al., 2024) uses a recursive least squares update implemented through the Sherman–Morrison identity, maintaining the exact regression solution recurrently along the sequence axis. This recurrence is inherently sequential, which makes efficient sequence training challenging. To address this, subsequent MesaNet work (von Oswald et al., 2026) instead develops iterative solvers that permit efficient parallel training over the sequence dimension. LDM transfers this perspective from the sequence axis to the depth axis. Each layer gives a key– value observation, and the memory stream propagated through the network maintains a regression solution over representations produced by preceding layers. This distinction removes an important systems constraint. In particular, transformer layers are naturally evaluated sequentially in depth, so the memory update does not need to be parallelizable along that axis. We can therefore use a Sherman–Morrison rank-one recursive least squares update directly, obtaining the exact solution to the weighted depth regression objective described in the main text. We note, however, that using techniques like unwinding or windowing (Section 3.3) might have additional constraints. A.3 RELATION OF OUR HARDWARE -A WARE IMPLEMENTATION TO PAST WORK 

During training, our hardware-aware implementation avoids storing intermediate states during the forward pass by “unwinding” the memory, as explained in Appendix F. Although different, this has some connections to past work. Reversible residual networks (Gomez et al., 2017) split the residual stream into two halves that update each other additively, so that the input of a layer can be recom-puted from its output and no activations have to be stored for the backward pass of “reversible” layers. Reversible recurrent networks (MacKay et al., 2018) use a similar technique along the se-quence axis to reconstruct earlier hidden states from later ones. Since forgetting makes their update not exactly invertible, they store the information it discards. Windowed writes also have a counterpart along the sequence axis, although only for inference, since training generally uses chunkwise-parallel algorithms. ReplaySSM (Liou & Dao, 2026) recently used a similar idea to speed up decoding in Mamba-2 and Gated DeltaNet by caching the most recent rank-one updates and writing the state back only when the cache is full. Our windowed writes apply the same idea across depth, during training as well as inference.

## C EFFICIENCY MEASUREMENTS 

We measure different notions of efficiency for every method on Qwen3 models (1.7B to 14B param-eters; we retain the native vocabulary size of 151936 for all of them) on NVIDIA B200 GPUs, in BF16 with compiled models, and report measurements as a percentage of the corresponding PreLN baseline. The models follow the 1.5B Qwen-like configuration of Table 4, with the changes listed in Table 5. Every point in the plots below represents the median over three rounds. We made several adjustments to increase the fairness of the measurements. Before inference, we fold normalization weights into the mHC controllers (Xie et al., 2026). “mHC (released kernels)” denotes DeepSeek’s TileKernels as released (though with several adaptations around the exact kernels to make them compatible with our codebase). The mHC row replaces their projection backward with a faster matmul operation and splits the projection at inference, both of which we found to work better in terms of efficiency (with exact improvements varying per setting). “mHC, no recompute” keeps every stream instead of recomputing them (recomputation follows the approach in Xie et al. (2026)). Our main figures, for fairness, always report the “mHC” setting. Here we report the entire set for completeness. Still, it is possible that other optimizations might produce different results. 

Training (Figure 8). We measure the optimizer step of about 1M tokens on 8 GPUs with FSDP and PyTorch’s efficient implementation of scaled dot product attention (SDPA). We use the largest microbatch at which every method fits at 2K tokens, and half at 4K tokens (with half the sequences per step, so each step still covers about 1M tokens).
