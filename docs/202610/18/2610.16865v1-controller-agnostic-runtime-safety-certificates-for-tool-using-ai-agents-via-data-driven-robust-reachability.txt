# Controller-Agnostic Runtime Safety Certificates for Tool-Using AI Agents via Data-Driven Robust Reachability 

Ali Baheri 1 and Peng Wei 2

Abstract — Software agents built on large language models act by issuing tool calls, some of which cannot be undone. To control theory the model is an opaque feedback controller, replaced every few months, whose closed loop cannot be analyzed directly. We propose a runtime filter, or shield, between any such controller and its environment that certifies a bound on the probability of reaching an unsafe condition during a bounded task. Given a predicate abstraction and candidate successor sets, everything else comes from logs: the loop becomes a finite controlled Markov chain, the estimated kernel is surrounded by a distribution-free confidence region, and robust reach–avoid value iteration runs over it. The certificate is probably approximately correct and uniform over controllers respecting the filter, so one model may replace another without recomputation. In all tested datasets the true risk stayed within certificate and budget; in a file-system sandbox the filter stays sound against a hazard the logs barely covered, where a plug-in baseline certifies safety and fails; and it holds seven controllers, three of them open-weights models, to zero unsafe outcomes in 1050 episodes. 

Index Terms — Data-driven control, Markov processes, reach-ability analysis, safety filters, learning for control. 

I. I NTRODUCTION 

A new kind of autonomous system is asking for the control community’s attention. Agents built on large language models [1], [2] take a goal in plain language and pursue it by acting: pick a tool call, see what comes back, pick again until done. A control engineer recognizes the loop: the model is a feedback controller, the surrounding software the plant. Two things make the loop awkward for the classical toolbox. First, some actions are irreversible: a deleted database or a wired payment cannot be taken back, so what must be bounded is the probability one is ever triggered before the task ends, a finite-horizon reach–avoid requirement. Second, the controller is opaque and replaced within months, so any argument tied to its identity is obsolete almost as soon as written. Together they rule out most existing machinery. Barrier-function and predictive safety filters [3]–[5] and Hamilton– Jacobi reachability [6] start from a dynamical model, super-visory control [7] gives only logical guarantees, and policy-specific verification must be redone when the controller changes [8]. What agents do offer is data: every one logs state, action and outcome, inviting a data-driven treatment as in [9].

Contributions. This letter makes the following contributions. 1) A plant model for an agent: a few engineer-chosen Boolean facts turn the agent loop into a finite controlled Markov chain with a reach–avoid specification (Sec. II). 2) A certificate from ordinary logs: a robust reach–avoid bound on the risk of irreversible harm, computed over a distribution-free confidence set and valid with chosen confidence for every controller the filter admits (Sec. III). 3) A synthesis procedure that seeks the least restrictive filter meeting the risk budget (Sec. IV). 4) Validation: comparison with ground truth and four alternative filters, and one filter, built from a scripted agent’s logs, tested with that agent and three open-weights language models [10] (Sec. V). Proofs of all results are given in the Appendix.

A. From transcripts to a finite state machine 

The controller is a language model whose natural state is the whole transcript ht ∈ H , every prompt, call and reply so far, an unbounded object. We replace it with a short list of Boolean predicates chosen for the application, such as “holds write capability,” “inside a protected directory,” “an irreversible call has executed.” The map φ : H → S sends a transcript to the truth values of these predicates, so the abstract state st = φ(ht) lives in a finite set with |S| = n.Actions a ∈ A are a finite catalog of tool-call types , |A| = m,one of which, HALT , hands control to a human and ends the episode safely. An action may refine a tool name by safety-relevant argument classes; any dependence left out of a must appear in the abstract state instead. 

Assumption 1 (Abstract Markovness) . There is a kernel P

with P[st+1 = s′ | ht, a t] = P (s′ | st, a t), st = φ(ht), at every t and for any history-dependent at: given the current abstract state and action, the next is independent of the rest of ht, with a kernel independent of t.That is, once the predicates and the action are known, the rest of the transcript says nothing more about where the system goes next, even though the controller may have used it to choose the action. The analysis rests on this assumption, so the predicates must be rich enough to make it hold; Experiment 4 tests it on logs, and Prop. 2 bounds the cost of a violation.

every result below concerns, immediate HALT substitution being the case of no second attempt. The shield is thus a supervisory controller [7], [8] between a stochastic plant and a black-box decision maker.

III. D ATA -D RIVEN ROBUST REACH –A VOID CERTIFICATE 

We replace the unknown kernel by a confidence set built from the logs, the analogue of an uncertainty set in robust control, and run value iteration against its worst kernel; the result bounds (2) with high probability. 

A. Estimating the kernel from adaptively collected logs 

The data are M logged episodes of abstract state, action and next state. Each pair (s, a ), a row of the transition matrix 

Pa, is visited N (s, a ) times; Xs,a j is the successor recorded at the j-th visit, and the natural estimate of P (· | s, a ) is their empirical distribution. The difficulty is that the logs are collected in closed loop: as in closed-loop identification, which rows are visited, and how often, depends on earlier outcomes. Hence N (s, a ) is random and correlated with the very successors being averaged, and a confidence bound for a sample of fixed size cannot simply be evaluated at N (s, a ).We avoid this by construction. We treated a language-model agent as an unknown feedback controller and placed a supervisory filter between it and its environment. The filter carries a certificate: a robust reach– avoid bound on the probability of an irreversible action within the task, computed over an uncertainty set that is learned from ordinary logs. The bound holds with confidence 1 − δ for every controller the filter admits, so the language model can be replaced without recomputation, provided the environment, interface, permissions, abstraction and notion of harm stay the same. No failure need appear in the logs: an action never observed in a state is treated as maximally uncertain and is blocked if it could lead to harm, so the data must cover normal operation, not the hazards. The main assumption is that the Boolean predicates defining the abstract state make the loop Markov, which the logs can test but not prove. Future work should learn the abstraction from data held out from certification, tighten the filter online, and pool logs across agents sharing an environment. APPENDIX
