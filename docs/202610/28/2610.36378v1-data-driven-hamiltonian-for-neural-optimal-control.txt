# ABSTRACT 

Reinforcement learning (RL) has emerged as a prominent data-driven approach to optimal control, but often requires substantial amounts of data and provides limited guarantees when encountering out-of-distribution state-action pairs. In this paper, we propose an alternative approach grounded in the well-established Hamilton-Jacobi framework in optimal control theory. Rather than requiring an explicit analytical model of the system dynamics to evaluate the Hamiltonian, we replace this with a data-driven Hamiltonian (DDH), which we generalize to a broad class of optimal control problems. In contrast to standard RL approaches, the DDH provides a principled mechanism, requiring only minimal prior system information such as a Lipschitz constant, for quantifying and accounting for un-certainty in regions not covered by the data, enabling the derivation of controllers with performance guarantees. Additional prior system knowledge, when avail-able, can be readily incorporated to improve performance. For high-dimensional systems, we further introduce a physics-informed neural approximation of the value function, trained using a novel procedure that generates worst-case ficti-tious rollouts evaluated through the DDH. On an LQR problem, the DDH reaches near-optimal cost on every dataset we test, including random data on which offline RL methods remain far from optimal, and needs far fewer samples than online RL. On a nonlinear lunar lander benchmark, the DDH achieves an optimality gap to a trajectory-optimization reference more than 3× smaller than CQL and FQL, and matches the performance of SAC with approximately 37 × fewer samples. These results establish the DDH as a promising framework for data-driven optimal con-trol, particularly in settings where available data are limited in quantity or quality. 

# 1 INTRODUCTION 

While optimal control is important across a wide range of applications, including autonomous driv-ing, aeronautics, robotics, HVAC regulation, and chemical process control, the dynamics of such complex systems are often challenging to model accurately. Reinforcement learning (RL) provides a prominent approach to control under unknown dynamics, as it can learn policies through interac-tions with the system without requiring an explicit dynamics model. However, RL is often sample inefficient, requiring substantial interaction data to learn an effective policy. Moreover, learned poli-cies can perform poorly when encountering states and actions that are insufficiently represented in the training distribution, despite extensive efforts to mitigate such distribution shift (Fujimoto et al.,

This limitation is particularly relevant in offline RL, where the performance still remains strongly dependent on the quality and coverage of the available data (Park et al., 2024). At the same time, even when constructing an accurate analyti-cal model is difficult, coarse prior information about the system—such as smoothness properties or bounds on the dynamics—is often readily available. Standard model-free RL formulations, however, provide limited mechanisms for directly incorporating such information to improve data-efficiency, out-of-distribution behavior, or performance guarantees. To address these limitations of existing approaches, we propose an alternative data-driven approach for optimal control problems. Our approach builds on the Hamilton-Jacobi-Bellman (HJB) frame-work for continuous-time optimal control, where the value function, representing the optimal cost-to-go, is characterized as the solution of the HJB partial differential equation (PDE) (Bardi et al., 1997). The optimal policy is then derived from this value function. Standard solution methods for the HJB-PDE require an explicit model of the system dynamics to evaluate the Hamiltonian, whose optimization objective depends directly on the dynamics. Thus, when the dynamics are unknown, the Hamiltonian cannot be evaluated directly, limiting the applicability of the HJB framework to data-driven control. Previous work addressed this challenge for reachability problems, a particular class of optimal control problems concerned with reaching or avoiding sets of states, by deriving a direct data-driven conservative bound on the Hamiltonian called the Data-Driven Hamiltonian (DDH) (Choi et al., 2025). The DDH quantifies the worst-case uncertainty consistent with the avail-able dataset through a min–max formulation, using only minimal prior system information such as a verified Lipschitz constant of the vector field. Through this formulation, DDH values at unseen state-action pairs provide conservative bounds on the unknown true Hamiltonian. This conserva-tive Hamiltonian can then be incorporated into the HJB-PDE, producing an estimated safe set from which the reachability task is guaranteed to be achievable. We first extend the DDH to a broader class of optimal control problems by incorporating running costs , which are common in RL problems but absent from reachability problems. To scale our approach to high-dimensional systems, we further incorporate the DDH into the learning of neu-ral value functions that approximate solutions to the HJB-PDE. Crucially, the PDE residual, which serves as the primary training signal for these value functions (Karniadakis et al., 2021), can be eval-uated at arbitrary states using the DDH. This enables dense supervision throughout the entire state space, including regions not covered by the available data, and thereby facilitates learning a reliable value function. This stands in sharp contrast to standard model-free deep RL, where Bellman-based training signals are evaluated only on sampled transitions, and are thus fundamentally tied to states and actions represented in the collected experience or offline dataset. Similarly, rollouts in model-based RL methods (Janner et al., 2019; Yu et al., 2020), which use learned dynamics models, are typically initialized from observed states and kept short to limit the effect of out-of-distribution model error. Next, to further improve the accuracy of the learned solution, we propose a novel algorithm that augments the PDE residual loss with an additional supervised training signal, analogous to Monte Carlo targets commonly used in RL to improve the reliability of value function learning (Sutton & Barto, 2018). By exploiting the min–max formulation underlying the DDH, we generate long-horizon fictitious rollouts that capture the effect of worst-case dynamics uncertainty consistent with the available data, and use the resulting trajectories to construct empirical value targets for direct supervision. This idea is inspired by MPC-guided value-function training in Feng et al. (2025); crucially, however, our fictitious rollouts require neither an explicit dynamics model nor access to a simulator and can be initialized from arbitrary states in the state space. We validate our approach on a two-dimensional LQR problem and compare the DDH’s performance to a variety of RL algorithms. We find that the DDH performs robustly across datasets of different qualities, especially outperforming the offline RL algorithms on suboptimal demonstrations. This supports our intuition that the DDH is well-suited to tasks where the state-action distribution in the dataset differs substantially from the one the optimal policy visits. With a dataset consisting of random trajectories, the DDH is within 0.1% of the optimal cost, whereas the offline RL methods CQL (Kumar et al., 2020), IQL (Kostrikov et al., 2021), and FQL (Park et al., 2025) remain 13% ,

26% , and 61% worse than optimal. Against online RL, SAC (Haarnoja et al., 2018a) and PPO (Schulman et al., 2017), the DDH matches their best performance on every dataset with at least 25 × and 100 × fewer samples, respectively. We 2also evaluate the neural DDH on a 6-D lunar lander system. We find that the neural DDH reduces the optimality gap to a trajectory-optimization reference by more than 3× compared to CQL and FQL, and matches the performance of SAC with approximately 37 × and PPO with 2,300 × less data.

Extending Choi et al. (2025), we approach our problem by upper-bounding our Hamiltonian. This conservative estimate of the Hamiltonian results in a conservative value function that upper-bounds the true value function. We will loosely refer to any function bH(x, p) that provides an upper bound on the Hamiltonian from the data, without requiring the exact system dynamics, as a data-driven Hamiltonian (DDH). Grid-based solvers for the HJB-PDE scale exponentially with the state dimension, so for high-dimensional systems, we use a neural network to approximate the solution of the PDE. This resem-bles minimizing a Bellman residual, except that the residual comes from differentiating the network rather than from a sampled next state. Because the DDH is defined at every state, this residual can be evaluated anywhere in the state space, not only at states in the dataset, which is a key advantage over most model-free RL methods. We start by introducing a parameterized approximation of the value function, the solution to the HJB-PDE, Vθ (x, t ). Since we want the learned value function to be a solution to the HJB-PDE, it needs to satisfy both the terminal condition and PDE given in Equa-tion (2). This motivates two components of the loss function: a PDE loss and a terminal condition loss inspired by Bansal & Tomlin (2021): 

LPDE (x, t ) = ∂V ∂t (x, t ) + bH(x, p) − γV (x, t ) , Lterminal (x) = |V (x, t f ) − cf (x)|

(2025) addressed this in reachability by supervising the network with returns from MPC rollouts, which require a dynamics model. Through this case study, we are able to explore how the type of data the DDH has affects its performance, and how this differs from offline RL methods: the DDH appears to benefit from random (less optimal) demonstrations, whereas offline RL algorithms suffer from that randomness. Results . Figure 1 shows each method’s cost as the dataset grows. At n = 20 ,000 the DDH (rectan-gular, k = 10 ) is within 0.2% of J⋆ on every dataset, while on random trajectories CQL, IQL, and FQL remain 13% , 26% , and 61% above it. The two families favor opposite datasets. The DDH is within 1.5% of J⋆ from n = 75 on uniform random (within 4% in each of five dataset re-draws, Section A.4) and within 1% from n = 1 ,000 on random trajectories , but needs 

n ≈ 5,000 to come within 2% on optimal , whose datapoints concentrate along optimal trajecto-ries. CQL is the reverse: within 1% of J⋆ by n = 500 on optimal , but not converging on random trajectories by n = 20 ,000 . IQL and FQL show the same pattern (Figures 1 and 2). One possible explanation lies in how each method uses its data. The DDH uses each datapoint as evidence of how the system responds near that state and control, regardless of whether the recorded action was optimal. Even if an action was suboptimal in that state, it might be useful for neighboring states, and the DDH allows for this extrapolation in a structured way. As a result, while both families benefit from state coverage, the DDH benefits more from coverage of the control space. CQL, IQL, and FQL instead tend to keep their policies closer to the recorded actions (through a value penalty on unseen actions, advantage-weighted regression onto dataset actions, and a behavior-cloning term, respectively), which helps when those actions are optimal and hurts when they are random. Among the DDH variants at n = 500 (Figure 7), the rectangular uncertainty set and tightening each lower the cost on most datasets, and the neural DDH is comparable to the grid solution. Even the spherical set, which uses only scalar Lipschitz constants, outperforms every offline RL base-7line on random trajectories from n = 500 (Table 2). In addition, we implemented a trajectory-optimization baseline that has access to the true dynamics. We treat the performance of the trajectory optimizer as an oracle that we can then compare each method against. We define each method’s optimality gap as its average cost minus that of the trajectory optimizer. We evaluate all methods by rolling out 15 s long trajectories from a set of 20 ,000 random initial conditions and compare their average costs. Figure 3b compares the DDH to these baselines. We observe that the DDH substantially outper-forms the offline RL algorithms, reducing the optimality gap by 67% compared to FQL and 72% 

compared to CQL. The model-based baseline, whose learned dynamics model uses no structural prior, outperforms the DDH. It must, however, solve an optimization problem online at every re-planning step, whereas the DDH controller evaluates the value gradient and selects among recorded controls. It also lacks the DDH’s guarantee and its well-characterized degradation away from the data. Online RL given a comparable budget of about 30 k environment steps performs substantially worse; matching the performance of the DDH takes SAC 1.1M steps and PPO 69 M steps, 37 × and 

2,300 × as much data respectively. We see that the single integrators clearly improve the DDH, but are less essential than supervision, without which the DDH drastically deteriorates. # 5 CONCLUSION AND FUTURE WORK 

In this work, we extended the data-driven Hamiltonian (DDH) to a broader class of optimal control problems with running costs, and introduced a neural approximation to the solution to the HJB-PDE we call the neural DDH. In comparison to most model-free RL algorithms, which only train on states in their dataset, the neural DDH is able to train its network across the entire state space by using the DDH to handle previously unobserved state-action pairs. # A APPENDIX 

A.1 RELATED WORK 

There are a variety of data-driven approaches for controlling systems with unknown dynamics. Re-inforcement learning is one of the richest fields concerning the optimal control of unknown systems. In model-free RL, online approaches, such as proximal policy optimization (PPO) (Schulman et al., 2017) and soft actor-critic (SAC) (Haarnoja et al., 2018a;b), explore the state-action space while learning state or state-action value functions. Offline RL approaches rely on a fixed pre-collected dataset of system transitions. Conservative Q-Learning (CQL) (Kumar et al., 2020) learns a state-action value function while penalizing out-of-distribution (OOD) actions to avoid an overoptimistic value function on OOD data. Implicit Q-Learning (IQL) (Kostrikov et al., 2021) avoids querying OOD actions altogether by fitting the value function with expectile regression over dataset actions. Flow Q-Learning (FQL) (Park et al., 2025), a more recent approach which learns a state-action value function, a one-step policy, and a flow-matching model of the behavior policy, effectively incorporates information from near-optimal demonstrations from the dataset. However, in all of these approaches, the value function supervision is fundamentally done at observed state transitions, leaving the behavior outside the support of the collected data only indirectly constrained. Other offline methods, such as AWR (Peng et al., 2019) and TD3+BC (Fujimoto & Gu, 2021), similarly regularize the policy toward the data; we compare against CQL, IQL, and FQL as widely used representatives with strong reported performance. Model-based RL tackles the same problem, and typically consists of (i) a model-learning stage, where an explicit dynamics model is learned, and (ii) the development of a controller using this model (Janner et al., 2019; Chua et al., 2018). However, model-based RL can also suffer from OOD issues when the dynamics model is used outside of its training data, particularly when restricted to an offline dataset. Model-Based Offline Policy Optimization (MOPO) (Yu et al., 2020) attempts to mitigate this by penalizing state-action pairs with higher uncertainty. There is also a body of work in direct data-driven model predictive control (MPC). However, the majority of this work focuses on linear systems in order to leverage Willems’ fundamental lemma (Berberich et al., 2020; Coulson et al., 2019), which restricts its generalizability. The approach that we build on, the Data-Driven Hamiltonian (DDH), proposed by Choi et al. (2025) and extended by Bajelani et al. (2026), provides a conservative bound on the Hamiltonian, which allows Hamilton-Jacobi Reachability problems (Bansal et al., 2017) to be solved for systems whose dynamics are unknown. We directly extend this approach to the broader class of optimal control problems involving running costs, as well as to higher-dimensional systems, while retaining its key insights that (i) the Hamiltonian is where the system dynamics enter, and (ii) data and minimal system information can be used to bound this Hamiltonian. Finally, recent advances in physics-informed machine learning are applied to solve Hamilton-Jacobi reachability problems (Bansal & Tomlin, 2021; Feng et al., 2025; Li & Chen, 2025), where a model-based Hamiltonian is used to evaluate the PDE residual. A.9 LUNAR LANDER TRAINING DETAILS (DDH AND BASELINES )For details on the chosen configuration of the lunar lander environment, cost function, and shared parameters between our approaches, see Table 4. 

Neural DDH . We train the neural DDH with Algorithm 1. For the first 5,000 gradient steps, the network is trained on the PDE loss LPDE alone ( λ2 = 0 ). After that, we add the rollout supervision loss Lrollout with weight λ2 = 3 . The supervision set Dsup holds 25 ,000 rollouts and is regenerated every 240 gradient steps, and the rollout horizon τ grows linearly from 0.5 to 4 s between steps 

5,000 and 15 ,000 . Rollout start states are sampled from Xsup = [ −7.5, 7.5] × [−6, 6] × [−7.5, 7.5] ×

[−6, 6] × [−π, π ] × [−7.1, 7.1] over (x, v x, y, v y , θ, ω ). Note that about 4.8% of the dataset is contained within the supervision region. The lander uses the IO uncertainty set without tightening, so the controller applied at run time is the recorded control selected by the DDH. The uncertainty set for single integrator (“SI”) variants of the DDH incorporates the knowledge that the dynamics of x, y, and θ are given by single integrators of other states, so there is no uncertainty in those dimensions.
