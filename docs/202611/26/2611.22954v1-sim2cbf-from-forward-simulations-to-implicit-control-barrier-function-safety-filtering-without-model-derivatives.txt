# Sim2CBF: From Forward Simulations to Implicit Control Barrier Function Safety Filtering without Model Derivatives 

Luzia Knoedler, Yihan Liu, Shaohang Han, Yifei Dong, and Jana Tumova 

Abstract — Failure avoidance in complex robot–environment interactions is challenging because the underlying dynamics are difficult to model accurately, and available predictive models may not provide reliable derivatives. We present Sim2CBF, a failure-avoidance framework that solves the Control Barrier Function (CBF)-Safety Filter (SF) optimization problem using only forward-model evaluations, thereby avoiding differenti-ation of the predictive model. Specifically, we approximate the CBF constraint using finite differences and local linear interpolation over sampled control inputs while preserving failure-avoidance guarantees. The underlying CBF is implicit and constructed from backup-policy rollouts, enabling the use of expressive predictive models such as physics-based simulators and learned world models. Compared with purely sampling-based SFs, our formulation requires fewer control samples and yields less conservative behavior than direct nominal–backup blending. We evaluate Sim2CBF in simulation, hardware box-toppling, and vision-based control tasks, demonstrating its applicability to contact-rich and learned dynamics, as well as its adaptability to changes in the predictive model. 

I. INTRODUCTION As robots become capable of performing increasingly complex tasks, the range of potential failures they must avoid also grows. For example, a household robot may need to retrieve an object from a shelf without causing a cereal box to topple over or carry a cup of tea without spilling its contents. Despite arising from different physical interactions, these failures can all be avoided by keeping the system state outside a corresponding set of failure states. For failures such as a cereal box toppling, as shown in Fig. 1, failure avoidance is often enforced through con-servative proxies such as collision avoidance, contact-force limits, or speed limits. While these avoid modeling how the robot affects the failure variable, such as the box tilt angle, they may unnecessarily restrict interactions and require hand-tuned thresholds. Instead, failure avoidance can be expressed directly in terms of the representation that characterizes failure, from low-dimensional variables such as box tilt angle to high-dimensional latent states inferred from images [1], as we will demonstrate in this work. This requires a predictive model that captures both the failure representation and how robot actions affect its evolution. Increasingly capable sim-ulators [2], [3] and learned World Models (WMs) [4] can provide such models of robot–environment interaction.

Assuming access to a model and information on the model mismatch, Control Barrier Functions (CBFs) [5], [6], [7] provide a principled way to prevent the system from entering failure states. A CBF defines a set of states, i.e., CBF-set, and imposes a constraint on the system’s control input such that, if the constraint is satisfied, the system remains within this set, rendering it forward invariant. By choosing this set to exclude failure states, forward invariance prevents the system from failing. In practice, these constraints are typically enforced online by solving an optimization problem that minimally modifies a nominal, potentially unsafe, control input while ensuring constraint satisfaction; this procedure is commonly referred to as a Safety Filter (SF). Despite these appealing guarantees, constructing a CBF such that a feasible control input exists for every state in the CBF-set is challenging, particularly under input constraints and for systems with high relative degree, where the control input does not directly affect the failure-relevant state. Approaches to constructing CBFs that address these chal-lenges can broadly be divided into implicit and explicit 

methods. Implicit approaches do not represent the CBF directly as a function of the system state; instead, its value is obtained through forward simulation under a backup policy. Examples include backup CBFs [8], [9] and finite-horizon Policy Control Barrier Functions (PCBFs) [10]. In contrast, explicit approaches represent the CBF directly as a function of the system state, enabling direct evaluation of its value. Examples include High-Order Control Barrier Functions (HOCBFs) [11], which require the derivative of the dynamics for their construction, and neural CBFs [12], where the CBFs are parameterized using a neural network. Neural CBFs have recently been combined with learned arXiv:2611.22954v1 [cs.RO] 17 Nov 2026 WMs to handle complex robot–environment interactions and failure avoidance in latent spaces [13]. The rollout-based construction of implicit CBFs makes them naturally compat-ible with expressive predictive models such as physics-based simulators or learned WMs, although, to our knowledge, this combination has not yet been demonstrated. In both cases, solving the SF typically requires derivatives of the predictive model, which may be unavailable, unreliable, or expensive for physics-based simulators and WMs [14], [15], [16]. In this work, we thus present an approach for solving the SF problem without requiring derivatives of the predictive model, using a finite-difference CBF condition and local linear interpolation over sampled control inputs. We apply this approach to implicit CBFs, specifically Robust Policy Control Barrier Functions (RPCBFs) [10]. Compared with neural CBFs, implicit CBFs allow changes to the predictive model, input constraints, or failure set to be incorporated without retraining. This facilitates transfer across robots, tasks, environments, and updated models. Together, these components form Sim2CBF, a flexible failure-avoidance framework for complex robot–environment interactions. An overview of the proposed framework is shown in Fig. 1.

RELATED WORK We review related work on constructing CBFs, failure avoidance in complex robot–environment interactions, and safety filtering without model derivatives. 

A. Constructing Control Barrier Functions 

The difficulty of constructing CBFs has motivated ex-tensive research on broadly applicable construction meth-ods. HOCBFs have been proposed for high relative degree systems [11], but their construction requires derivatives of the model, and feasibility under input constraints depends on careful auxiliary-function design. Neural CBFs approx-imate the CBF with a neural network to handle complex dynamics [13], [17], [18], [19], [20], but require additional verification for formal guarantees. Backup CBFs [8], [9] instead define the CBF implicitly through backup-policy rollouts toward a known invariant set, guaranteeing feasibility but requiring domain knowledge to design both. Motivated by Model Predictive Control (MPC) without terminal sets, PCBFs [10] define a CBF from the worst-case failure over a finite rollout under an arbitrary policy, generally guaranteeing safety only over that horizon; this has also been extended to robust settings under disturbances. However, enforcing such rollout-based CBFs with conventional SFs requires differen-tiating through the rollout and predictive model, which can be costly or may not be possible when model derivatives are unavailable. 

B. Safety Filtering Without Dynamics Gradients 

Rather than solving the SF optimization with gradient-based methods, a purely sampling-based approach can be used, where control inputs are sampled, checked for con-straint satisfaction, and the feasible input closest to the nominal control is selected [13], [21]. However, its per-formance depends strongly on the sampling strategy and scales poorly with the dimension of the control input. For implicit CBFs, the nominal control input can be blended with the backup control by gradually increasing the contribution of the backup policy as the system approaches the CBF-set boundary, and applying the backup policy fully on the boundary [22], [23], [24]. We instead approximate the original SF optimization problem so that it can be solved without model derivatives, while remaining sample-efficient. 

C. Safety Under Complex Interaction Dynamics 

More recently, CBF-based failure avoidance has addressed failures such as spilling by defining failure sets in the latent space of generative WMs [1] and learning neural CBFs therein [13]. However, these learned CBFs require retraining when the model or failure specification changes. We show that implicit CBFs can be applied in the latent space of learned WMs and can readily accommodate model changes. III. P RELIMINARIES

D. Problem Formulation 

We assume access to a predictive model M of the robot-environment dynamics that generates forward rollouts of the robot-environment state x under robot control inputs u. The model may be a physics-based simulator or learned WM, and its derivatives with respect to the state or control input may not be available. Given a nominal input unom , we aim to construct a RPCBF-SF that minimally modifies the nominal control while avoiding F, using only forward evaluations of 

M. The backup policy π is treated as a design parameter, as its choice influences the conservativeness of the resulting SF. The formulation should also remain applicable when 

M is updated or replaced, without requiring the CBF to be retrained. IV. M ETHOD 

We address the problem of CBF-based safety filtering for tasks involving complex robot–environment interactions when derivatives of the predictive model are unavailable or unreliable. To this end, we develop a method for solving the SF optimization using only forward-model evaluations, with-out requiring derivatives of the predictive model. To enable adaptation to changes in the predictive model, we employ implicit CBFs, specifically RPCBFs [10]. Together, these components form Sim2CBF, our rollout-based framework for failure avoidance involving robot–environment interactions. Rather than blending directly between unom and the backup control input ub, as done in [22], we first compute a control input from an approximation of the original SF optimization problem and then blend this control input with 

ub. This requires substantially fewer control samples than a purely sampling-based SF, yields less conservative behavior than direct nominal–backup blending, as we show in Sec. V, and retains failure avoidance guarantees through the blending mechanism. An overview of the proposed method is shown in Fig. 1, with further details provided in Fig. 2 and Alg. 1. 

A. Rollout-Based Safety Filter Optimization 

We begin by computing the control input that will sub-sequently be blended with ub. When applied to RPCBFs, the SF in (4) requires derivatives of the dynamics at two stages. Evaluating the CBF constraint (4b) involves differen-tiating the RPCBF with respect to the state, which requires differentiating through the finite-horizon policy rollout and underlying model. Solving the resulting optimization with gradient-based methods further requires derivatives of the constraint with respect to the control input. To avoid computing the CBF derivative, we approximate the Lie derivative in (4b) by 

∇V (x)⊤F (x, u) ≈ V (xt+∆ t) − V (xt)∆t , (20) yielding 

V (xt+∆ t) − V (xt)∆t ≤ − α(V (xt)) . (21) This condition is equivalent to a discrete-time CBF con-dition with γ(r) = ∆ tα (r), ensuring failure avoidance at the prediction instants. It approximates the continuous-time condition as ∆t → 0 and guarantees safety at t + ∆ t, but not necessarily throughout the interval (t, t + ∆ t) [21]. The finite-difference approximation (21) avoids explicitly computing the CBF derivative, but generally results in a constraint that is nonlinear in the control input u. To solve the nonlinear SF optimization problem efficiently without differentiating through the dynamics, we construct affine approximations of the objective and constraints by evaluating them at sampled control inputs and interpolating between these samples using convex combination weights. At the current state x0 = x, consider M candidate control inputs {u(m)}Mm=1 , selected as described in Sec. IV-B. C. Approximation Error and Failure Avoidance Guarantees 

We considered two approximations: the finite-difference approximation (20) of the CBF derivative and the linear interpolation of the resulting nonlinear constraint over the convex hull of the sampled control inputs. The linear constraint in λ only approximates the nonlinear constraint over the convex hull of the sampled inputs. Hence, 

c⊤λ ≤ 0 does not necessarily imply c(U⊤λ) ≤ 0, and the interpolation error typically grows with the size of the sampled convex hull. The implication holds if c(u) is convex over the sampled convex hull, and the approximation is exact if c(u) is affine [26]. A rigorous interpolation bound would require a Lipschitz constant for c(u), which is difficult to obtain for black-box dynamics. This is unnecessary here, since failure avoidance follows from a separate argument. We adopt the blending approach of [22] to establish the failure avoidance properties of the proposed controller. In contrast to the original formulation, we replace the nominal input unom with the optimized input u⋆ obtained from the approximate SF problem. The safe control input is therefore defined as

C. Simulation Experiments for Box Toppling Task 

We conduct simulation experiments on a joint-torque-controlled 7-DoF Franka Panda manipulator performing a box-toppling task. The box mass is assumed unknown but bounded within [1 .3, 1.7] Kg. We account for this uncertainty when constructing the RPCBF by considering rollouts at the minimum and maximum admissible masses. Interpolation and Blending achieves a safety rate of 0.92 over 50 trials.

Overall, Interpolation with Blending provides flexible failure avoidance under changing models. VI. CONCLUSION We presented Sim2CBF, an adaptable rollout-based failure-avoidance framework for settings involving com-plex robot–environment interactions. By combining finite-difference approximations with local interpolation over sam-pled controls, Sim2CBF approximates the original Control Barrier Function (CBF)-Safety Filter (SF) as a Quadratic Program using only forward evaluations of the predictive model, without differentiating through the dynamics. This enables implicit CBFs, evaluated through model rollouts rather than available in closed form, to be used with non-differentiable predictive models or models whose derivatives are unreliable, including contact-rich simulators and learned World Models (WMs). Experiments, including box-toppling tasks, demonstrate effective failure avoidance. Future work includes online model adaptation to better exploit implicit CBF adaptability, evaluation in richer sim-ulations with more complex and semantically meaningful failures, and studying failure avoidance between discrete control updates under zero-order hold.
