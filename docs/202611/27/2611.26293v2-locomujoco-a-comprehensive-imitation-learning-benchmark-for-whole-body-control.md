## 摘要
LocoMuJoCo 是一个用于全身控制中模仿学习（IL）与强化学习（RL）的开源基准。该库在单一 API 下将 MuJoCo（CPU）与 MJX 及 MjWarp 后端（GPU）集成，提供 9 种人形、3 种（肌肉）骨骼和 4 种四足具身形态，并为每个人形机器人提供精选的原生动作捕捉数据集，还可将 AMASS 和 LAFAN1 重定向到这些机器人上。模块化插件架构使观测、奖励、控制模式、地形和域随机化完全可互换，而许多 RL 和 IL 算法的紧凑 JAX 实现可提供 JIT 编译的端到端训练，配套的 loco-mujoco-real 仓库提供 sim-to-real 部署。我们描述了设计、SMPL 到机器人以及机器人到机器人的重定向流程，并给出一个使用示例。LocoMuJoCo 以 MIT 许可证发布，地址为 https://github.com/robfiras/loco-mujoco。

## Abstract
LocoMuJoCo is an open-source benchmark for imitation learning (IL) and reinforcement learning (RL) on whole-body control. The library couples MuJoCo (CPU) with MJX and the MjWarp backend (GPU) under a single API, exposes 9 humanoid, 3 (musculo-)skeletal, and 4 quadruped embodiments, and ships a curated native motion-capture dataset for every humanoid, to which it can also retarget AMASS and LAFAN1. A modular plug-in architecture makes observations, rewards, control modes, terrains, and domain randomization fully interchangeable, while compact JAX implementations of many RL and IL algorithms provide JIT-compiled end-to-end training, and the companion loco-mujoco-real repository provides sim-to-real deployment. We describe the design, the SMPL-to-robot and robot-to-robot retargeting pipeline, and a usage example. LocoMuJoCo is released under MIT at https://github.com/robfiras/loco-mujoco.

- **背景**：人形机器人硬件快速进步，sim-to-real 迁移日益可行；人类与仿人机器人形态相近，因此人类动捕数据是天然的示范来源。

- **前期工作局限**：LocoMuJoCo v1（2023）只提供真实感人形模型 + 动捕数据集 + 统一评测协议，但仅支持 CPU MuJoCo；v1.0 围绕 JAX 重建，加入 GPU 并行 MJX 后端、重定向管线与新本体；本文版本再增 MjWarp 后端、更多算法与 `loco-mujoco-real` 实机部署管线。
- **整体含义**：论文的定位是**系统/基准论文**（benchmark & library），而非单一算法创新，目标是把“双后端仿真 + 自动重定向 + 生物力学模型 + 轨迹相似度指标 + sim-to-real”整合进一个 MIT 开源库。

## 2. 方法论

### 2.1 双（三）仿真后端，单一 API
- 每个环境可用**串行 NumPy/MuJoCo** 或**向量化 JAX/MJX** 执行；环境组件只针对一个“数值后端”参数实现一次，因 `jax.numpy` 与 NumPy 高度一致，绝大部分代码逐字共享，仅后端特有算子分支。
- 可选 `use_mjwarp=True` 启用 MjWarp 后端，单张消费级 GPU 上可达 **7.3×10⁵ steps/s**。

### 2.2 模块化插件架构
- 仿真核心 `loco_mujoco/core` 拆分为可互换插件：**观测、奖励、控制模式（直接电机/肌肉/PD）、域随机化、地形（平地/粗糙高度场）、初始状态分布、终止条件**。
- 关键设计：**插件无状态**，每个环境的私有状态放在显式 Flax dataclass 中随 `step` 传递，因此整个环境步可被 `jax.jit` / `jax.vmap` 编译，无隐藏全局状态；同一训练循环可跨机器人、跨 RL/IL 复用。
- 奖励从 `NoReward`、速度跟踪类到 `MimicReward`（DeepMimic 式），切换只需改一个参数。

### 2.3 本体、数据与三阶段重定向
- **本体**：9 个人形（Unitree H1/H1v2/G1、Atlas、Talos、Apollo、Booster T1、ToddlerBot、Fourier GR1T2）、3 个 SMPL 派生（肌）骨骼模型（MyoSkeleton、SkeletonTorque、SkeletonMuscle，支持体型缩放）、4 个四足（A1/Go2、Spot、ANYmal C）。
- **数据**：原生重定向数据集（HuggingFace）、LAFAN1、AMASS（需用户接受 SMPL 许可）。
- **重定向三阶段**（15 个 mimic site 与 15 个 SMPL 关节一一对应，映射写在 `defaults.yaml`，全机器人复用）：
  - **Stage 1（每机器人一次）**：机器人摆成 T-pose，拟合 SMPL 形状参数 β 与各向同性尺度 s，最小化 15 个 site 的位置误差（式 1）；Adam 1000 次迭代、lr=0.05；同时记录每 site 的刚体偏移 (R,t)∈SE(3)、足高修正 Δz、头脚身高比。
  - **Stage 2（SMPL→机器人）**：对每帧做 SMPL 前向运动学，施加每 site 偏移得到世界坐标目标位姿 (τ, Q)（式 2、3）；用 MuJoCo **软 `mjEQ_WELD` 约束**（而非仅位置的 `mjEQ_CONNECT`）连接 mocap body 与机器人 site，从上一帧热启动积分 N_sub=25 个物理子步（式 4）。软约束使碰撞、关节限位与约束满足**联合求解**，避免刚性 IK 常见的穿地/自穿模；可选按式 5 做整条轨迹的统一足底高度偏移。速度用中心差分恢复。
  - **Stage 3（机器人→机器人，可选）**：先用源机器人前向运动学去除其 site 偏移（式 6、7），再以固定 β_src 用 Adam（400 次迭代、lr=0.005）优化 SMPL 姿态轨迹拟合目标（式 8，λ_p=1.0、λ_r=0.1），每步对体姿态做 1D 高斯平滑（kernel=3, σ=0.5），得到“合成 SMPL 片段”后再走 Stage 2 用目标机器人 β_tgt 生成轨迹。

### 2.4 算法与评测
- 算法实现于 `loco_mujoco/algorithms/<algo>_jax.py`，训练循环与策略更新用 `lax.scan` 融为**单个 JIT 编译函数**，环境步进、优势计算、梯度更新全程在设备上，无 Python 开销。
- 核心：**PPO、GAIL、AMP、DeepMimic、SuperMimic**（世界模型 + 短 rollout 反传）、**BPTT-PPO**；扩展：**SAC、TD3、S2PG、History-aware PPO（MLP/Transformer）、DAgger 蒸馏**（把逐片段专家压缩为多任务学生）。
- 评测：`metrics` 模块基于 JAX 原生 **metrx**，提供 **欧氏距离、DTW、离散 Fréchet 距离**三种轨迹相似度，覆盖 11 种关节/刚体/site 量（qpos、qvel、root 相对的 site 位置/朝向/速度等）。

## 3. 实验设计

- **数据集/场景**：原生 LocoMuJoCo 数据集的 **13 个片段**（walk、run、squat、stepinplace1–3、onestepleft/right、onestepside1–2、onesteplong、onehopforward、highknee）；实机实验用 **40 个 LAFAN1 片段**；硬件演示用 BONES-SEED 舞蹈片段（43 s）。
- **Benchmark 定位**：与 HumanoidBench、MyoSuite、mjlab、ProtoMotions、MimicKit 做五轴定性对比（双后端、内置生物力学、轨迹重定向、指标、sim-to-real），LocoMuJoCo 是唯一五项全有者；与 Brax / MuJoCo Playground 在仿真栈层面比较吞吐。
- **实验 1**：PPO + DeepMimic，11 个本体 × 13 片段 × 5 seeds 的逐片段专家，报告训练回报/回合长度与最终欧氏/DTW/Fréchet 误差（另含 qvel、site rpos/rrotvec/rvel 四类量的分布，及误差随训练变化）。
- **实验 2**：UnitreeH1 上 **PPO vs SAC vs TD3**，13 片段 × 5 seeds（每算法 65 次运行），同一超参文件、同一 DeepMimic 奖励、同一 1000 步时域。
- **实验 3**：UnitreeH1 上 **PPO vs GAIL**，12 片段（去掉 onestepside1，因 GAIL 少一个 seed）× 5 seeds。
- **实验 4**：`loco-mujoco-real` 两个真机环境（AgiBot X2 Ultra、Unitree G1）上 **SuperMimic**，每机器人一个策略覆盖全部 40 个 LAFAN1 片段，统计归一化回报、失败片段数、完成帧比例。
- **吞吐/显存基准**：在 Unitree G1 上重建 mjlab 的平地速度任务与 MuJoCo Playground 的 joystick 任务（声称在 float32 舍入误差内复现原任务的观测/奖励/终止），四个 block 比较 MjWarp/MJX/CPU 与两框架的 steps/s 与峰值显存。

## 4. 资源与算力

- **吞吐基准**：单卡 **NVIDIA RTX 4090 (24 GB)** + Intel Core i9-13900KF；mjlab 1.6.1（MuJoCo Warp 3.11.0、Warp 1.19.0、PyTorch 2.14.1），LocoMuJoCo 1.2.1（MJX 3.11.0、Warp 1.14.0、JAX 0.10.1）；每配置 5 次测量 × 2 轮反序。
- **SuperMimic 训练**：4096 个并行 MjWarp 环境、1.53×10⁸ 环境步、域随机化 + 推力 + 自碰撞，**单张 RTX 6000 Ada 约 50 分钟**。
- **硬件演示策略**：4.56×10⁸ 环境步（未说明所用 GPU），真机 50 Hz 运行，策略单步约 2 ms、状态延迟约 2 ms。
- **未明确说明**：实验 1–3 共约 1000 次训练运行的**总 GPU 数量、总机时、总能耗**均未报告；除吞吐基准外未给出各实验所用 GPU 型号。这是资源透明度上的明显缺口。

## 5. 实验数量与充分性

- **规模**：正文称附录 H 共 **715 次运行、11 个本体**（实验 1）；实验 2 每算法 65 次（合计 195）；实验 3 每算法 60 次（合计 120）；实验 4 为 2 机器人 × 3 seeds；另有 4 组吞吐/显存对比。
- **充分性亮点**：
  - 本体覆盖广（人形 + 骨骼 + 四足），跨本体泛化得到实际检验。
  - 指标维度多（3 种相似度 × 5 类量），并用 Spearman ρ 检验指标间一致性（site 位置/朝向与 qpos 约 0.9，速度量约 0.6）。
  - 用中位数/IQR 而非均值，明确指出少数失败 seed 的误差是典型 seed 的 50–500 倍，避免均值被污染。
  - 吞吐基准做了**任务等价性校验**（重放记录步、注入物理结果，逐项复现到 float32 精度），公平性较好；并区分“双方跑同一任务”与“各自跑自己任务”，只在 block 内比较。
- **不够充分/公平性风险**：
  - 算法对比只在**单一本体（UnitreeH1）**上做，且仅 5 seeds，跨本体算法排序未验证。
  - **GAIL 未调参**（同一超参文件、同一 1000 步时域），作者自己也承认判别器在高维全身轨迹上难训，因此“PPO 约为 GAIL 两倍”更接近“默认配置对比”而非算法上限对比。
  - 实验 3 因 seed 不足丢掉一个片段，说明实验管理上存在小疏漏。
  - 只比较 PPO/SAC/TD3/GAIL，**未把自家 AMP、SuperMimic、BPTT-PPO、DAgger 蒸馏纳入统一对比**（SuperMimic 只在实机环境单独报告）。
  - 重定向管线**没有任何定量对比实验**（未与 GMR、OmniRetarget、ProtoMotions 的 PyRoki 比较误差或可行性），只有 G1 上“112.1 mm → 21.8 mm”的拟合误差示例。
  - 域随机化、地形、控制模式等插件维度**没有消融**，插件化的收益仅靠“同一训练循环可复用”的定性论述支撑。
  - 实验 1 全部是**逐片段专家**，而非多任务/通用策略，与“benchmark”宣称的评测覆盖面之间仍有距离。

## 6. 主要结论与发现

- **默认配方**：PPO + DeepMimic 是推荐的默认 IL 训练方案，在 11 个本体上均能收敛并跟踪 13 个原生片段。
- **算法排序**：UnitreeH1 上 PPO 回报最高（约 1530），SAC 约 1260，TD3 约 1080；三者回合长度均收敛到约 900–925。
