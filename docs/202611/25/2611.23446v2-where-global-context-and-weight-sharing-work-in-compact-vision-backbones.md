## 摘要
像 EfficientNet 这样的紧凑卷积骨干网络通过局部深度可分离卷积实现了很强的参数效率，但两个结构性问题仍是混合设计的核心：全局自注意力在何处能相较纯卷积提升识别性能？重复模块能否在不损失表征能力的情况下共享权重？我们使用受控的 EfficientNet-B0 实验在 ImageNet-1k（50,000 张图像验证集）上研究这两个问题。首先，我们表明，将分类骨干网络包裹于多尺度特征金字塔（BiFPN）中，若不与阶段注意力结合，其性能无法超过普通 MBConv 主干（69.99%–71.81% 对 72.86% 的普通 B0）；与阶段注意力结合后达到 73.15%。相比之下，保持 MBConv 主干完整，并在阶段 P3（28x28 窗口化）、P4（14x14 全局）和 P5（7x7 全局）插入轻量零门控残差自注意力适配器，可单独达到 74.02%，并在 88 个 epoch 的无状态重放调度下，以 +0.954 个百分点超过逐位匹配的普通 B0 对照（73.88% 对 72.92%），且学到的注意力幅度随语义深度单调上升（P3 为 27.2% -> P4 为 45.4% -> P5 为 66.3%）。其次，我们评估在重复 MBConv 模块之间进行循环权重共享，并使用各 pass 特定的 BatchNorm 统计量（每个 pass 增加 1,536 个参数）。事后核平均会将准确率降至 17.03%，单模板阶段绑定（参数减少 27.6%）在 66.10% 处停滞；而在 Stage 6 中交替使用两个共享模块模板（[B1, A, B, A]）使模型总参数减少 10.9%（582K 权重），并在单个 epoch 内回升 +10.82 个百分点至 70.92%（相比不共享对照低 1.84 个百分点）。

## Abstract
Compact convolutional backbones such as EfficientNet achieve strong parameter efficiency through local depthwise separable convolutions, yet two structural questions remain central to hybrid design: where does global self-attention improve recognition over pure convolution, and can repeated blocks share weights without losing representational capacity? We investigate both questions on ImageNet-1k (50,000-image validation) using controlled EfficientNet-B0 experiments. First, we show that wrapping a classification backbone in multi-scale feature pyramids (BiFPN) fails to outperform a plain MBConv trunk (69.99% - 71.81% vs. 72.86% plain B0) until paired with stage attention (73.15%). In contrast, keeping the MBConv trunk intact and inserting lightweight zero-gated residual self-attention adapters at stages P3 (28x28 windowed), P4 (14x14 global), and P5 (7x7 global) reaches 74.02% standalone and outperforms a bit-for-bit matched plain-B0 control by +0.954 percentage points (73.88% vs. 72.92%) across an 88-epoch stateless replay schedule, with learned attention amplitude rising monotonically with semantic depth (27.2% at P3 -> 45.4% at P4 -> 66.3% at P5). Second, we evaluate recurrent weight sharing across repeated MBConv blocks with pass-specific BatchNorm statistics (+1,536 parameters per pass). While post-hoc kernel averaging degrades accuracy to 17.03% and single-template stage tying (-27.6% parameters) plateaus at 66.10%, alternating two shared block templates ([B1, A, B, A]) in Stage 6 cuts total model parameters by 10.9% (582K weights) and recovers by +10.82 points in a single epoch to 70.92% (-1.84 points vs. unshared control).

## 1. 核心问题与研究动机

- **背景**：EfficientNet 等紧凑卷积骨干通过局部深度可分离卷积（3×3/5×5）实现高参数效率，但局部卷积难以建模长程依赖；而 Vision Transformer 类模型擅长全局建模，却缺乏归纳偏置。混合架构（如 MobileViT、EdgeViTs、CoAtNet）成为折中方向。
- **两个悬而未决的结构性问题**：
  1. **全局自注意力应插在何处**，才能真正比纯卷积提升识别性能？此前混合架构多采用“替换整段卷积”或“重架构主干”的粗放方式，缺乏受控的定位证据。
  2. **重复的 MBConv 块能否共享权重**而不损失表征能力？NAS 中的权重共享（ENAS、DARTS）与隐式循环 CNN 表明可行，但在紧凑骨干的倒残差块上如何共享仍不清楚。
- **研究意义**：对紧凑骨干做“非针对性结构修改”可能沿两条路径损害精度——检测常用的 BiFPN 特征金字塔在整图分类中会引入额外缩放/投影层与分类头竞争；而把阶段内所有重复块强行绑定为单一模板（[B1, A, A, A]）会限制层级特征细化。作者试图以**受控、可复现**的实验回答“注意力放哪”与“权重怎么共享”两个设计问题。

## 2. 方法论

### 2.1 稀疏零门控阶段注意力（Sparse Zero-Gated Stage Attention, P3/P4/P5）

- **核心思想**：**不替换、不重架构** EfficientNet-B0 的 MBConv + SE 主干，仅在其阶段输出处插入轻量残差注意力适配器。
- **插入位置**：
  - Stage 3 输出 **P3**：28×28，40 通道 → 采用 **7×7 窗口化**自注意力（控制二次复杂度）；
  - Stage 5 输出 **P4**：14×14，112 通道 → **全局** MHSA；
  - Stage 7 输出 **P5**：7×7，320 通道 → **全局** MHSA。
- **适配器公式**（文字描述）：每个适配器依次执行 Pre-LN 层归一化 → 多头自注意力 → 线性投影，再经一个**零初始化可学习门控 αs** 加权后残差加回主干：
  - `y_s = x_s + α_s · Proj_s(MHSA_s(LN(x_s)))`，且 `α_s(0) = 0`。
- **零初始化门控的作用**：训练第 0 步网络与普通 B0 **函数完全等价**，避免未校准的注意力梯度扰动早期卷积特征学习，实现“渐进式引入”。

### 2.2 Stage 6 循环权重共享（交替双模板 ABAB）

- **共享粒度**：重复 MBConv 块之间共享卷积核与 SE 权重，但**每个重复 pass 保留独立的 BatchNorm 统计量与仿射参数**（特征分布随残差步演化），每个 pass 仅增加 **1,536 个输出通道参数**（约 6 KB FP32，<0.03% 总参数）。
- **两种共享模式对比**：
  - 单模板绑定 `[B1, A, A, A]`（A = B2 的拷贝，或块权重算术平均）；
  - **交替双模板** `[B1, A, B, A]`（Block 4 复用 Block 2 的 A，Block 3 保留 B），让奇偶残差步分别专精互补变换。
- **初始化策略**：以成熟 B0 checkpoint 为起点，采用“拷贝现有块 + 1,000 张图像 BN 重校准”的零样本初始化，再做单 epoch GPU 续训（5,004 步，batch=256，约 128 万样本）。

- **BiFPN 在分类任务中无益**：单独加 BiFPN neck 反而低于普通 B0（69.99%–71.81% vs 72.86%），只有叠加注意力才到 73.15%（+1.34 pp）。

- **权重共享的三条结构性要求**：
  1. **不可用算术平均合并卷积核**（通道置换/符号不一致），准确率崩至 **17.03%**；
  2. **单模板绑定不足**：Stages 4–6 单模板（−27.6% 参数）续训后仅 66.10%（−6.66 pp）；
  3. **交替双模板最优**：Stage 6 `[B1, A, B, A]` 减参 **10.9%（582,384 权重）**，零样本 BN 重校准后 60.10%，单 epoch 回升 **+10.82 pp 至 70.92%**（仅比不共享低 1.84 pp），比单模板高 +4.82 pp，单 epoch 内弥合 85.5% 的初始差距。

- **算力信息缺失**：未披露 GPU 型号、数量与总训练时长，复现成本难以估计。
- **增益幅度有限**：+0.954 pp 与 −1.84 pp 均属小幅变化，实际部署收益需结合具体场景权衡。
- **部分结论依赖特定实现**：如“核平均不可行”的结论与通道置换/符号对齐问题相关，换用置换对齐（permutation alignment）等更

更精细的对齐方法（如基于匈牙利匹配的通道对齐、符号翻转校正）可能改变“核平均不可行”这一结论的普适性；同理，“1-epoch 恢复即可弥合 85.5% 差距”依赖于 B0 checkpoint 的成熟度与 BN 重校准质量，换用不同预训练来源时结论可能漂移。

- **门控幅度指标的可解释性**：以“门控分支更新/输入 RMS 比”刻画注意力贡献是合理代理，但它混合了 α 幅值与 MHSA 输出尺度两个因素，不能直接等同于“该阶段对全局上下文的依赖度”。

## 9. 启示与可延伸方向

- **设计原则层面**：论文给出两条可复用的经验规则——(i) 全局注意力宜以**轻量残差适配器 + 零初始化门控**的方式“叠加”在成熟卷积骨干上，而非替换整段卷积；(ii) 重复块的权重共享应采用**交替多模板 + 每 pass 独立 BN**，避免单模板绑定压缩层级细化能力。
- **工程落地层面**：+0.954 pp 精度换取 5.5% 吞吐下降与 9.2% 显存增加，属于“可接受的边际成本”，适合对精度敏感、对时延有一定余量的边缘部署；权重共享带来的 10.9% 参数削减则对存储受限场景更有价值。
- **可直接延伸的实验**：
  1. 多种子（≥3 seed）重复匹配对，给出置信区间以检验 +0.954 pp 的显著性；
  2. 在 B1/B2 与 256²/320² 分辨率上复现“注意力位置”实验，检验门控幅度单调性是否稳健；
  3. 将 1-epoch 恢复扩展为 5–10 epoch 微调与从零训练，判断 1.84 pp 差距是“恢复预算不足”还是“共享本身的上限”；
  4. 在检测/分割下游任务上验证 P3 窗口注意力与 P4/P5 全局注意力的组合是否同样优于 BiFPN neck；
  5. 与 MobileViT、EdgeViTs、CoAtNet 在同等参数/FLOPs 预算下做直接对比，明确该“最小侵入式改造”相对“重架构混合”的性价比。

## 10. 总体评价

这是一篇**问题驱动、控制严谨、结论克制**的结构性实证论文。其最大价值不在于刷新精度，而在于用逐位匹配的受控实验把“全局注意力放哪”“重复块能否共享权重”这两个长期靠直觉回答的设计问题，转化为有量化证据的工程规则；零初始化门控与“每 pass 独立 BN”是两个简洁且可复用的技巧。主要短板在于**单种子、单一骨干、短训练预算**导致结论的统计稳健性与外推范围受限，算力披露亦不足以评估复现成本。总体而言，作为一篇“设计空间定位”研究，其证据链完整、结论表述诚实，适合作为紧凑混合骨干设计的参考锚点，但不宜直接外推为跨尺度、跨任务的普遍定律。
