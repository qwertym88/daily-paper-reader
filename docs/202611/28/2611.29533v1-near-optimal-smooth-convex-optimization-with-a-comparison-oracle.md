## Abstract
We study the minimization of a convex $d$-dimensional function with $L$-Lipschitz gradient when the only available information is a comparison oracle that reports which of two points has the smaller objective value. Given an initial point within distance $R$ of a minimizer, the constants $L$ and $R$, and $A = LR^2/\varepsilon$, we give a deterministic method that returns an $\varepsilon$-optimal point using $O(\sqrt{A}\,[d\log(2dA)+\log^2(2A)])$ comparisons for $A\ge1$, counting all comparisons spent in inner subroutines. The method is based on a normalized variant of Nemirovski's subspace method: each iteration performs a line search along an estimated gradient direction followed by a minimization over a two-dimensional affine subspace, and both subroutines rely on a comparison oracle and basic arithmetic operations only. With exact function values, combining finite-difference gradients with an accelerated method gives the well-known bound of $O(d\sqrt{A})$ evaluations; our bound shows that one bit per query suffices to match it up to logarithmic factors. Since two function values determine one comparison, the exact function-value lower bound of Dorn et al. implies that our bound is optimal up to logarithmic factors when $32\le A\le d^2$.
