## 摘要
本文研究利用Koopman生成元进行非线性连续时间观测器的数据驱动设计。对于无输入系统，设计了一种由线性系统部分和非线性输出注入构成的观测器。其中，输出注入引入了额外自由度，以确保字典不变性或较小的投影误差。随后，将该观测器推广到含输入系统。这些结果构成了利用生成元扩展动态模态分解进行数据驱动非线性观测器设计的基础。针对数据驱动观测器误差动力学中的观测器误差以及相应的稳态观测误差，推导了概率有限数据误差界。具有不变字典和非不变字典的非线性系统示例说明了这种新颖数据驱动观测器设计过程的有效性。

## Abstract
This paper deals with the data-driven design of nonlinear continuous-time observers using the Koopman generator. For systems without inputs, an observer is designed that consists of a linear system part with a nonlinear output injection. Therein, the output injection introduces additional degrees of freedom to ensure an invariant dictionary or a small projection error. Subsequently, this observer is extended to systems with inputs. These results form the basis for a data-driven nonlinear observer design using generator extended dynamic mode decomposition. Probabilistic finite-data error bounds are derived for the observer error w.r.t. the data-driven observer error dynamics and for the corresponding steady-state observation error. Examples of nonlinear systems with invariant and non-invariant dictionaries illustrate the effectiveness of the novel data-driven observer design procedure.

## 2. 方法论

### 2.1 核心思想

- 在观测函数空间 $\mathcal{O}$ 中设计降阶观测器，结构为“**线性系统部分 + 非线性输出注入**”：
  $$\dot\zeta = F\zeta + \alpha(y,u) + \beta(\zeta,u),\quad \hat x = C\zeta + \gamma(y)$$
  其中 $\alpha,\gamma$ 为非线性函数，$\beta$ 为双线性函数。
- 通过精心构造字典 $\Psi(x,y)=[\varphi(x);\theta(y)]$（含状态 $x$、输出 $y$ 及非线性观测函数），使观测器误差动态在自治情形下为**线性**、在有输入情形下为 **Lipschitz 非线性**，从而可直接套用成熟观测器设计工具。
- 关键设计自由度：观测器阶数 $n_o=\rho_x$ **仅由 $\varphi(x)$ 决定，与 $\theta(y)$ 的维度无关**；因此可自由增加仅依赖输出的观测函数，用于保证字典 Koopman 不变性或减小投影误差。

### 2.2 关键技术细节

- **Koopman 生成元**：对自治系统，$\mathcal{L}_0\psi=\lim_{t\to0^+}(K_0(t)\psi-\psi)/t=L_f\psi$，观测函数演化满足 $d_t\psi=(\mathcal{L}_0\psi)(x)$；对有输入系统，利用仿射输入结构 $\mathcal{L}_u=\mathcal{L}_0+\sum_i u_i(\mathcal{L}_{\bar u_i}-\mathcal{L}_0)$。
- **不变字典假设**：
  - 假设 1（自治）：$\mathcal{L}_0 V\subseteq V$，$V=\mathrm{span}\{\Psi_i(x,h(x))\}$；
  - 假设 2（非自治）：字典扩展为 $\tilde\Psi=\mathrm{col}(1,\Psi)$，要求 $\mathcal{L}_{\bar u}W\subseteq W$。
- **降阶观测器推导（自治）**：令 $z=\varphi(x)$，由提升动力学得 $\dot z=A_{11}z+A_{12}\theta(y)$、$d_t\theta(y)-A_{22}\theta(y)=A_{21}z$；构造含 $d_t\theta(y)$ 的观测器后，经变换 $\zeta=\hat z-L\theta(y)$ 消去输出导数，得
  $$\dot\zeta=(A_{11}-LA_{21})\zeta+H\theta(y),\quad \hat x=[I_n,0](\zeta+L\theta(y))$$
  误差动态 $\dot e=(A_{11}-LA_{21})e$ 指数稳定（定理 1：$(C,A)$ 可检测即可）。

## 6. 主要结论与贡献

- **理论贡献**：将 Koopman 生成元从“数据驱动建模工具”推进到“非线性观测器设计工具”，提出了一套连续时间、降阶、数据驱动的观测器构造框架，并给出无输入与有输入两类系统的可检测性/Lipschitz 型增益存在条件。
- **方法贡献**：通过字典构造与状态变换消去输出导数，使自治情形误差动态线性化、非自治情形化为 Lipschitz 非线性误差动态，从而把数据驱动观测器设计转化为成熟线性观测器/LMI 设计问题；观测器阶数仅由状态相关字典决定，输出相关字典可自由扩展以改善不变性或投影误差，这是该框架的一个关键设计自由度。
- **保证贡献**：在字典不必严格 Koopman 不变的条件下，给出观测器误差动态的 ISS 瞬态与稳态界，并借助 gEDMD 的有限数据概率误差界得到显式的概率稳定性保证；数据量需求随字典维度与置信参数缩放，说明学习误差可通过增加数据压低。
