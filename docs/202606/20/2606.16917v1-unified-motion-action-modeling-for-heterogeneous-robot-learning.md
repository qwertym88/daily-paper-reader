## 摘要
我们提出了统一运动-动作（UMA）模型，该方法利用3D物体运动轨迹作为共享接口，连接视觉运动控制和动力学建模。UMA将物体运动和机器人动作视为在掩码生成目标下共同演化的变量，其中掩码模式决定了预训练期间的监督机制和部署时的推理模式。利用事后重新标记的运动上下文和对比目标（将任务意图与场景几何解耦），UMA能够在无需手动标注任务指令的情况下，跨异质数据源进行多任务预训练。在部署时，相同的预训练参数支持运动条件视觉运动控制、基于运动的动力学建模以及从少量示范中进行的任务自适应。通过在机器人示范、人类视频和模拟数据的混合集上预训练，UMA在每种推理模式下都持续优于专门针对该模式的最新基线方法。

## Abstract
We present Unified Motion-Action (UMA) Model, an approach that uses 3D object motion trajectories as a shared interface to bridge visuomotor control and dynamics modeling. UMA treats object motion and robot actions as co-evolving variables under a masked generative objective, in which the mask pattern determines both the supervision regime during pretraining and the inference mode at deployment. Using hindsight-relabeled motion contexts and a contrastive objective that disentangles task intent from scene geometry, UMA enables multi-task pretraining across heterogeneous data sources without requiring manually annotated task instructions. At deployment, the same pretrained parameters support motion-conditioned visuomotor control, motion-based dynamics modeling, and task adaptation from few-shot demonstrations. Pretrained on a mixture of robot demonstrations, human videos, and simulated data, UMA consistently outperforms state-of-the-art baselines specialized for each inference mode.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究动机**：机器人基础模型希望从广泛数据中学习并泛化到多种场景。然而，现有方法（如视觉-语言-动作模型、世界模型）通常将视觉运动控制与动力学建模分离，难以跨域迁移，且无法有效利用无动作标签的异构数据（如人类视频）。
- **核心挑战**：需要一个足够结构化（支持样本高效学习）又足够通用（支持多种设置）的物理交互表征。现有基于物体运动的方法（如运动条件策略、运动预测模型）各司其职，但无法在单一框架内同时利用有/无动作标签的数据。
- **整体含义**：UMA通过3D物体运动轨迹作为共享接口，统一了视觉运动控制与动力学建模，实现了跨异质数据源的联合预训练和多种部署模式。

## 2. 方法论

### 核心思想
- 将物体运动（3D点轨迹）和机器人动作视为共同演化的变量，在掩码生成目标（flow matching）下联合建模。
- 通过掩码模式决定预训练时的监督方式和部署时的推理模式，使同一模型支持运动条件动作生成、动作条件运动预测和任务推断。
- 引入事后重新标记的运动上下文（hindsight relabeling）和对比学习目标，解耦任务意图与场景几何，无需人工标注任务指令。

### 关键技术细节
- **运动-动作建模**：条件概率 \( p_\theta(x^{P_x}, a^{P_a} | o_t, c, x^{G_x}, a^{G_a}) \)，其中 \( c \) 为任务隐变量，由任务编码器 \( h_\psi(o_0, x^c) \) 从参考运动 \( x^c \) 和初始观察 \( o_0 \) 提取。
- **联合标记化**：观察（RGB-D）、物体运动和机器动作都投影为统一 token 序列，任务隐变量以少量 task token 插入。
- **掩码扩散Transformer（Masked DiT）**：采用结构化时空注意力（空间-时间-上下文），每个DiT块内使用两组独立的自适应层归一化（adaLN）参数分别处理目标（掩码）token和给定（未掩码）token，保留清洁条件信号的同时对目标进行去噪。
- **跨域训练**：通过随机掩码采样，有动作标签的数据同时监督运动重建损失 \( L_x \) 和动作重建损失 \( L_a \)；无动作数据仅监督 \( L_x \)。对比损失 \( L_c \) 通过关键点子采样、时间子采样和SE(3)增强保证任务隐变量对场景姿态不变性。
- **多种推理模式**：仅改变掩码模式，参数不变。
    - 运动条件视觉运动控制：给定目标参考运动，预测动作。
    - 运动动力学建模：给定候选动作，预测物体运动。
    - 任务推断（软提示微调）：将 \( c \) 作为可优化变量，冻结其余参数，从少量示范优化 \( c \)。

## 3. 实验设计

### 数据集与场景
- **预训练数据**：混合来源，不与测试环境重叠。
    - 人类视频：HOI4D、Xperience（约10M步）。
    - 真实机器人数据：DROID（约10M步）。
    - 仿真机器人数据：随机初始化和运动轨迹（约10M步，使用Franka FR3机器人，资产来自YCB、PartNet-Mobility等）。
- **测试场景**：真实桌面操作（DROID环境），三个任务：
    - Insertion（精确6-DoF插入餐具）
    - Sweeping（工具使用：扫垃圾）
    - Folding（变形物体：折叠牛仔裤）
    - 额外三个仿真任务用于消融实验。

### 对比方法
- **零样本视觉运动控制**：COIL（3D运动条件流匹配策略）、UVA（联合视频-动作掩码模型）。
- **动力学预测**：PointWorld（动作条件关键点动力学模型）。
- **少样本自适应（动作监督）**：π0.5（LoRA微调）、UVA（动作监督微调）。
- **少样本自适应（运动监督）**：UVA（像素重建损失微调）。

### 评估指标
- 操作任务：成功率（每个任务20次试验，随机化场景和相机配置）。
- 动力学预测：MSE（3D关键点坐标均方误差，预测10步，16个关键点）。

## 4. 资源与算力
- 论文明确说明：使用8块NVIDIA A100 GPU训练，训练16个epoch，batch size 16，学习率1e-4，AdamW优化器，线性预热10,000步。总参数量600M（最大配置）。

## 5. 实验数量与充分性
- **零样本实验**：3个真实任务 × 20次试验 = 60次试验，与两个基线对比；动力学预测报告MSE。
- **少样本实验**：两个监督设置（动作/运动），3个任务，每个任务25个示范，与对应基线对比。
- **消融实验**：
    - 数据消融：移除仿真 / 移除人类视频。
    - 架构消融：动作仅监督、独立解码头、密集注意力（在仿真任务上各100次试验）。
    - 对比学习消融（w/o CL）。
- **可扩展性分析**：不同数据量（25%/50%/100%）和参数规模（150M/300M/600M）在仿真任务上平均成功率。
- **失败分析**：对82%执行失败、18%抓取失败进行了分类。
- **补充实验**：语言条件控制、目标条件控制（定性示例）。
- **充分性评价**：实验覆盖了零样本、少样本、动力学预测、消融和扩展性分析，对照组设计合理，统计量（20次试验）一般，但总体结论可信。缺少与更多最新端到端模型的横向对比（如RT-2等，但UMA专注于运动-动作联合，对比已涵盖专用模型）。

## 6. 主要结论与发现
- **零样本**：UMA在三个任务上超越最强专用基线20-25个百分点（COIL、UVA）。
- **动力学预测**：MSE从0.054（PointWorld）降低到0.042，移除仿真数据导致MSE增加5倍，表明仿真数据提供正则化。
- **少样本自适应**：在动作监督下，UMA匹配或超越π0.5/UVA（仅更新任务隐变量而非全部参数）；在运动监督（仅人类视频）下，UMA超越UVA约25个百分点。
- **数据消融**：仿真数据对运动-动作耦合至关重要，人类视频提供任务多样性。
- **对比学习至关重要**：移除后少样本成功率下降30-60个百分点。
- **结构化注意力优于密集注意力**（相同预算下）。
- **失败主因**：执行错误（82%），而非任务推断或抓取错误。

## 7. 优点
- **统一框架**：首次在单一模型中同时建模物体运动和机器人动作，支持有/无动作标签的异构数据。
- **任务表示解耦**：通过对比学习和SE(3)增强，任务隐变量对场景几何和参考运动细节不变，实现跨场景转移。
- **灵活的部署模式**：仅改变掩码模式，无需重新训练即可切换功能（控制、预测、自适应）。
- **可扩展性**：随着数据和参数规模增加，性能持续提升，验证了扩展性。
- **完整的数据管线**：从单目RGB视频自动提取3D关键点轨迹，无需真实深度或相机内参。

## 8. 不足与局限
- **新本体动作头仍需有动作标签数据**：虽然运动表征是本体无关的，但针对新机器人执行动作仍然需要来自兼容机器人数据的动作头监督。
- **依赖相机外参标定**：所有表示在每集相机帧中，部署时需要相机到机器人基座的标定。
- **单帧观察条件**：当前每步仅用一个视觉观察，未利用多帧历史或密集点对应。
- **实验范围限制**：真实评估仅三个桌面操作任务，未涉及移动操作、多机器人协作或更复杂的动态环境。
- **零样本性能仍有 gap**：尽管优于基线，绝对成功率（如Folding约75%）仍有提升空间。
- **仅报告了平均成功率**：未提供方差或置信区间，未分析随机初始化对结果的影响。
