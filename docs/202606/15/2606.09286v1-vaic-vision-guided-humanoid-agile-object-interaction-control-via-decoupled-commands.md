## 摘要
仿人机器人在现实世界的辅助任务中具有巨大潜力，但在非结构化环境中与物体的敏捷交互需要紧密耦合的全身协调。尽管最近取得了进展，当前的控制器仍面临关键的部署差距。它们严重依赖密集的参考轨迹和完美的状态可观测性，这固有地限制了物理泛化。我们提出了视觉引导的敏捷交互控制（VAIC），这是一个统一的框架，通过仅依靠机载深度、历史本体感觉和解耦的用户命令界面来弥合这一差距。VAIC采用两阶段蒸馏范式。首先，特权教师策略利用精确的物体运动学和精确的环境状态掌握多种交互技能。其次，可部署的学生策略通过用多轴速度目标和每帧交互指示器替代全身跟踪来蒸馏这些能力。学生利用循环物体适应模块从原始深度流和本体感觉中隐式推断不可观测的物体动态。在仿人机器人上的评估和实际部署表明，单一VAIC策略成功执行了高度多样化的动态任务。这些任务包括搬运箱子、推车互动和滑板，始终优于基线，并推动了自主仿人机器人的部署。

## Abstract
Humanoid robots hold immense potential for real-world assistance, yet agile interaction with objects in unstructured environments demands tightly coupled whole-body coordination. Despite recent advancements, current controllers face a critical deployment gap. They rely heavily on dense reference trajectories and perfect state observability, which inherently limits physical generalization. We present Vision Guided Agile Interaction Control (VAIC), a unified framework that bridges this gap by operating exclusively on onboard depth, historical proprioception, and a decoupled user command interface. VAIC employs a two-stage distillation paradigm. First, a privileged teacher policy masters diverse interaction skills using precise object kinematics and exact environmental states. Second, a deployable student policy distills these capabilities by replacing full body tracking with velocity targets across multiple axes and an interaction indicator for each frame. The student utilizes a recurrent object adaptation module to implicitly infer unobservable object dynamics from raw depth streams and proprioception. Evaluations and real-world deployments on the humanoid robot demonstrate that a single VAIC policy successfully executes highly diverse dynamic tasks. These tasks include box carrying, cart interaction, and skateboarding, consistently outperforming baselines and advancing autonomous humanoid deployment.

## 1. 论文的核心问题与整体含义

- **研究动机**：仿人机器人在非结构化环境中执行敏捷物体交互（如搬运箱子、推拉推车、滑板）需要全身协调，但现有控制器存在严重部署鸿沟：
  - 依赖**密集的关节级参考轨迹**（需完整运动捕捉数据），不适用于高层意图（如速度命令）的人机交互或自主导航。
  - 依赖**完美的状态可观测性**（如物体6D位姿、精确地形），在真实场景中常被自身携带的物体遮挡、传感器噪声干扰。
- **核心目标**：构建一个**仅靠机载深度摄像头、历史本体感觉、以及解耦的高层用户命令**即可实现多种动态物体交互的统一控制框架，弥合仿真训练和物理部署之间的差距。

## 2. 论文提出的方法论

### 核心思想：两阶段蒸馏 + 解耦命令接口

- **解耦命令接口**：定义用户命令 \( u_t = (v_t, c_t) \)：
  - \( v_t \in \mathbb{R}^3 \)：多轴速度目标（\(v_x, v_y, v_{\text{yaw}}\)），表示导航意图。
  - \( c_t \in \{0,1\} \)：每帧二进制交互指示符（0=接近/导航，1=主动接触/交互）。
  - 训练时从参考运动提取，部署时由用户或导航系统给出，彻底消除对密集参考轨迹的依赖。

- **两阶段蒸馏**：
  - **阶段一（教师训练与学生预热）**：
    - 在仿真中训练一个**特权教师策略**（使用PPO），该策略可以访问精确物体状态、环境几何、参考运动等特权信息。教师通过“Privilege Encoder”压缩为潜变量 \( z_t^{\text{priv}} \)，然后由Teacher Actor输出动作。
    - 同时，利用教师rollout数据通过监督学习预热学生模块：
      - **Object Adapter**：学习从（零填充的深度图+本体感觉+命令）预测物体状态 \( \hat{s}_t^{\text{obj}} \)。
      - **Privilege Adapter**：学习从预测的几何特征重构教师潜变量 \( \hat{z}_t^{\text{priv}} \)。
      - **Student Actor**：通过行为克隆（BC）学习输出动作 \( a_t^{\text{stu}} \)，但仅依赖解耦命令，不依赖参考轨迹。
  - **阶段二（视觉引导的学生探索）**：
    - 完全移除参考运动和特权状态，学生策略使用PPO在实际环境中探索，优化任务完成和命令跟踪奖励。
    - **Object Adapter**：使用CNN-GRU深度编码器处理实时深度流 \( d_t \)，结合本体感觉和命令推断物体状态。
    - **Privilege Adapter**：利用预测物体状态和几何模板 \( \mathcal{P} \) 重构教师潜变量，驱动Student Actor。
    - 两个适配器继续通过学生自己的rollout数据在线更新，防止表示漂移。

- **关键技术细节**：
  - **深度处理**：模拟RealSense D435i的真实噪声（延迟、像素噪声、偏移、dropout），并做量化归一化。
  - **动作空间**：输出23维关节位置残差，由低层PD控制器（200Hz）转换为力矩。
  - **网络架构**：深度编码器（CNN+GRU，64维）、Object Adapter（MLP）、Privilege Adapter（GRU+残差连接，256维）。

## 7. 优点

  - **解耦命令设计**优雅地分离“去哪”和“如何交互”，支持直观遥操作和自主导航。
  - **两阶段蒸馏架构**有效利用了仿真中的特权信息，同时仅靠低成本传感器部署。
  - **循环适应模块**从历史序列中隐式重建物体状态，对传感器噪声和遮挡具有强鲁棒性。
- **实验设计亮点**：
  - 覆盖多种极端动态（冲击、非完整约束、严重自遮挡），展示了统一策略的泛化性。

## 8. 不足与局限

- **感知限制**：深度适应模块对透明或高反射物体可能失效（传感器噪声极端）。
- **突发扰动**：极端质量偏移等突然大幅变化可能导致表示崩溃，机器人来不及调整平衡。
- **命令粒度**：解耦命令无法表达精细的手指操作，仅适用于宏观交互；未来需结合触觉反馈和更丰富的语义命令。
- **实验覆盖**：真实实验虽然展示泛化，但没有大规模定量统计真实成功率；主要结果在仿真中定量评估。
- **计算成本**：两阶段训练需要仿真和渲染资源，阶段二15小时在单GPU上尚可，但大规模训练可能需更长时间。
- **偏差风险**：所有演示来自运动捕捉重定向，可能存在与真实机器人动态差异；依赖特定机器人形态，迁移到其他本体需重新训练。
