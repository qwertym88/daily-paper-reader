## 摘要
旋转位置嵌入（RoPE）使注意力分数具有位置相对性，但值路径仍对位置不敏感：无论值令牌与查询之间的距离如何，其发送的消息都相同。我们提出RoVE，这是一种无参数修改，通过同时旋转键和值使值具有位置敏感性，并表明它将RoPE注意力转化为注意力卷积。这一新视角统一了计算机视觉、机器人和现代大语言模型架构中相同操作的多种独立表述。训练124M和354M参数的GPT-2模型在少样本上下文学习、分布外困惑度和长上下文检索中均显示出相对于RoPE的一致的经验提升，在需要长距离聚合的任务上改进最为明显。

## Abstract
Rotary Position Embeddings (RoPE) make attention scores position-relative but leave the value pathway position-blind: the message sent by a value token is the same regardless of its distance from the query. We propose RoVE, a parameter-free modification that makes values position-sensitive by rotating them simultaneously with keys, and show that it turns RoPE attention into attentive convolution. This new perspective unifies several independent formulations of the same operation across computer vision, robotics, and modern LLM architectures. Trained 124M and 354M GPT-2 models show consistent empirical gains over RoPE on few-shot in-context learning, out-of-distribution perplexity, and long-context retrieval, with the clearest improvements on tasks that require long-range aggregation.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：旋转位置嵌入（RoPE）使注意力分数基于相对位置（shift-equivariant），但值（value）路径仍然对位置不敏感——无论值 token 距离查询 token 多远，其经过值投影矩阵 \(W_V\) 变换后的消息始终保持不变。这种位置盲区导致模型在长距离信息聚合时性能受限，尤其在需要准确追踪和重组远距离信息的任务中表现不佳。
- **研究动机**：在 Transformer 电路中，RoPE 仅影响了 QK 电路（决定注意力权重），而 OV 电路（决定传输什么信息）仍然与位置无关。这类似于卷积核的位置不变性，但注意力本应具备动态调整的能力。作者提出，若在值路径上也引入相对位置旋转，可使 OV 电路同样获得位置敏感性，从而将 RoPE 注意力转化为“注意力卷积”（attentive convolution），统一不同领域（计算机视觉、机器人、LLM）中独立发现的类似构造。
- **整体含义**：本文提出的 RoVE（Rotary Value Embeddings）是一种无参数的修改，在旋转键的同时同步旋转值，使值路径依赖相对偏移，从而增强模型对长距离依赖的建模能力，且完全兼容现有的高效注意力实现（如 FlashAttention）。

## 2. 论文提出的方法论：核心思想、技术细节

### 核心思想
- RoVE 扩展了 RoPE 注意力：在聚合值之前，先将每个值 token 乘以位置旋转矩阵 \(R_j\)（将其转到查询的参考系），聚合后再乘以 \(R_i^{-1}\)（转回查询的局部帧）。最终得到偏移依赖的核 \(\psi_\delta = R_\delta W_V\)，其中 \(\delta = j - i\) 为相对偏移。

### 关键技术细节
- **定义**（公式 3）：
  \[
  \tilde{y}_i = R_i^{-1} \sum_{j \in \mathcal{N}(i)} A(X)_{ij} R_j W_V x_j = \sum_{j \in \mathcal{N}(i)} A(X)_{ij} \underbrace{R_{j-i} W_V}_{\psi_{j-i}} x_j
  \]
  其中 \(A(X)_{ij}\) 是 RoPE 注意力权重（与标准 RoPE 完全相同），\(R_t\) 是块对角旋转矩阵（与 RoPE 相同参数）。
- **注意力卷积视角**：RoVE 变为偏移索引的核族 \(\psi_\delta = R_\delta W_V\)，替换了标准 RoPE 中恒定的 \(W_V\)，从而实现注意力卷积结构。
- **矩阵混合器视角**：RoVE 的混合矩阵从 Kronecker 积结构（\(A(X) \otimes W_V\)）变为块 Toeplitz 结构（每个偏移对角共享相同的旋转后核）。
- **局部帧视角**：值先转到全局帧（乘以 \(R_j\)），聚合后转到查询帧（乘以 \(R_i^{-1}\)），几何上类似于多视图特征对齐。
- **效率**：旋转操作复杂度 \(O(nd)\)，与 \(O(n d^2)\) 的线性层和 \(O(n^2 d)\) 的注意力相比可忽略；不引入额外参数；兼容 FlashAttention（仅需在 kernel 调用前后对值进行旋转）。

## 6. 论文的主要结论与发现

- **RoVE 在训练长度内持续改进**：Core ICL 准确率在 124M 下从 0.1375 提升至 0.1416，354M 下从 0.1664 提升至 0.1856；训练长度内 PPL 略有降低（124M: 22.37→22.30；354M: 15.64→15.52）。
- **RoVE 显著降低 OOD 困惑度**：在 4k-16k 长度上，RoVE 的 PPL 比 RoPE 降低约 60-70%（如 354M 下 16k: 1630.72→583.84）；即使加上 YaRN，RoVE+YaRN 仍大幅优于 RoPE+YaRN（如 16k: 270.98→124.82）。
- **RoVE 提升长上下文检索**：RULER 平均 NLL 在 354M 下由 6.62 降至 4.33（+YaRN），在需要多信息组合的任务（NIAH、VT）上改进最大。
- **RoVE 与 YaRN 互补**：YaRN 对两种方法均有效，但 RoVE 的增益在 YaRN 基础上仍保留，说明值路径旋转和频率缩放解决的是不同问题。
- **理论贡献**：将 RoVE 与注意力卷积、块 Toeplitz 结构、电路框架联系起来，统一了先前在不同领域独立发现的操作。

## 7. 优点

- **无参数改进**：RoVE 不引入额外可学习参数，仅通过预定义的旋转操作改变值路径，即插即用。
- **兼容高效实现**：对 FlashAttention 友好，只需在 kernel 调用前后进行 token 级旋转，不增加 attention 内部计算。
- **理论清晰**：从注意力卷积、矩阵混合器、局部帧视角、Transformer 电路四个角度给出结构化分析，揭示了本质。
- **泛化性强**：不仅在训练长度内改善，在分布外长度上增益更显著，且与现有插值方法正交。
- **统一多领域**：证明计算机视觉（Miyato et al., 2024）、机器人（Klee et al., 2026）、LLM（DeepSeek-V4）中的独立工作本质是同一操作，促进交叉领域理解。

## 8. 不足与局限

- **机制理解不充分**：论文未完全解释为什么值路径旋转能改善 OOD 性能，仅提出假设（QK 和 OV 电路共享旋转族使 extrapolation 更一致），缺乏频率分量的定量分析。
- **实验覆盖有限**：仅验证 GPT-2 架构（124M/354M），未在更大模型、更现代架构（如 LLaMA、Mistral）上测试；未与其他位置编码变体（ALiBi、T5 相对偏置）对比；训练长度仅 1024，未知是否适应更长训练。
- **未考虑训练成本**：虽然操作计算量小，但未报告实际训练时间开销；未讨论在共享 KV 架构（如 DeepSeek-V4）中的特殊性。
- **消融不够深入**：仅对比有无 YaRN，未探索不同旋转频率方案对值路径的影响；未实验单独旋转值而不旋转键/查询的情况。
- **潜在偏差**：RoVE 与 RoPE 共享完全相同的注意力分数，但值旋转可能改变梯度流动，长期训练可能使模型依赖特定的旋转关系，需进一步研究稳定性。
- **应用限制**：RoVE 要求每层 attention 进行两次旋转（前后各一次），虽复杂度低但增加代码复杂度；若使用自定义稀疏 attention，需确保旋转位置正确。
