## 摘要
非结构化剪枝产生稀疏权重张量，但标准实现保持张量形状不变，因此部署的模型并不比剪枝前更小。我们提出了一种精确的结构重写，称为最小化，它将一个掩码网络转换为一个更小的密集网络，且前向函数在浮点舍入内保持一致。挤压-释放循环迭代进行剪枝和最小化，中间有一个释放步骤，将压缩张量内的精确零位置重新启用为小的校准噪声，将原本浪费的容量转变回可训练参数。连续的循环利用该容量来发现单次剪枝无法达到的结构冗余。我们还引入了CompensatedLayerNorm，这是对LayerNorm的一种保持功能的替换，将最小化扩展到具有LayerNorm的残差流中的通道缩减。在全连接模型网络上，挤压-释放将可部署网络压缩到比未剪枝模型小39倍，在现代CNN（ConvNeXt-Tiny）上小14.8倍，且精度相当。此外，我们证明该重写可以扩展到Transformer架构。

## Abstract
Unstructured pruning produces sparse weight tensors, but the standard implementation keeps tensor shapes unchanged so the deployed model is no smaller than before pruning. We present an exact structural rewrite, which we call minimization, that converts a masked network into a smaller dense network with the same forward function up to floating-point rounding. The Squeeze-Release cycle iterates pruning and minimization with an intermediate release step that re-enables the exact-zero positions inside the compacted tensors as small calibrated noise, turning otherwise wasted capacity back into trainable parameters. Successive cycles use that capacity to find structural redundancy a single pass cannot reach. We additionally introduce CompensatedLayerNorm, a function-preserving replacement for LayerNorm that extends minimization to channel reduction across LayerNorm-equipped residual streams. Squeeze-Release compresses the deployable network to 39x smaller than the unpruned model on a fully-connected model network and 14.8x smaller on modern CNN (ConvNeXt-Tiny), at comparable accuracy. In addition we prove that the rewrite can be extended to transformer architectures.

- **核心问题**：非结构化剪枝（unstructured pruning）虽然能使权重张量中大量元素为零，但标准实现（如PyTorch的`torch.nn.utils.prune`）不改变张量形状。所返回的模型在磁盘和内存中大小与未剪枝模型相同，前向推理仍执行完整稠密卷积/矩阵乘法，无法在通用硬件上获得实际加速。因此，论文中常用的“存活参数量”（mask-alive count）并不能反映可部署模型的真正大小，存在严重夸大。
- **研究动机**：需要一个精确的结构重写（exact structural rewrite），将稀疏掩码网络转换为更小的稠密网络，并且保证前向函数在浮点精度内一致。此外，现有方法在迭代剪枝中要么不改变网络形状（如Dense-Sparse-Dense），要么只做近似恢复（如SliceGPT对LayerNorm的处理），缺乏既能物理缩小网络又能恢复零位置训练能力的循环机制。
- **整体含义**：作者提出**Squeeze-Release**循环，将剪枝问题拆解为“决定删哪些参数”和“实际删除参数”两个子问题，专注于后者——通过精确最小化（minimization）实现结构压缩，并通过释放（release）步骤将压缩后残存的零重新激活为小噪声，使网络在更小形状下复用所有计算容量，最终达到比单次剪枝更小的可部署模型。

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：迭代执行四步循环：剪枝（prune）→ 挤压（squeeze，即精确最小化）→ 释放（release）→ 微调（fine-tune）。挤压步骤将网络中死输入/死输出单元（全零行/列/滤波器）移除，并折叠常数前向传播至后续层偏置，输出一个形状更小的稠密网络。释放步骤将压缩后稠密张量中的精确零位置用服从存活权重统计的小高斯噪声替代，恢复训练能力。后续剪枝循环利用这些新容量发现新的结构冗余。
- **关键技术细节**：
  1. **最小化（Squeeze）**：  
     - 对全连接层：若某神经元的输入行全零（dead-incoming），则其输出为常数 \(c_k = \phi(b_i[k])\)，将该常数乘以下一层对应列后加到下一层偏置中，然后删除该行和对应列；若某神经元的输出列全零（dead-outgoing），直接删除对应行和列。  
     - 对ConvNeXt块：分为三种模式：  
       - **Mode A**：减少倒置瓶颈内部的4C中间通道（PWConv1→GELU→PWConv2），相当于全连接重写。  
       - **Mode B**：减少残差流通道（DWConv→LayerNorm→PWConv1），难点在于LayerNorm统计依赖所有通道。引入**CompensatedLayerNorm**，存储被移除通道的三个标量统计量（数量K、和S、平方和Q），在推理时利用公式精确重建原始全宽度的均值和方差，输出与原始LN一致。  
       - **Mode C**：移除整个深度残差块（若所有DWConv滤波器全零），将块输出常数折叠回上游层的偏置。  
  2. **释放（Release）**：对压缩后稠密张量中所有精确为零的位置，用 \(\mathcal{N}(\mu, \sigma^2) \cdot 0.01\) 采样，其中 \(\mu, \sigma\) 由同一层/同一列的存活非零权重估计得到。论文指出分布不重要，零初始化也可达到类似效果。  
  3. **剪枝评分**：采用梯度×权重幅度 \(|\nabla_\theta L \cdot \theta|\)（synaptic saliency），对Conv2d以滤波器粒度（平均滤波器内得分）进行单位级剪枝，对Linear以元素粒度剪枝，不同粒度的单元按权重数量竞争。  
  4. **调度**：采用立方调度（cubic schedule）逐步达到目标稀疏度，若验证精度下降超过阈值则回滚。

- **公式**（CompensatedLayerNorm核心重建公式）：  
  \[
  \mu = \frac{m \mu_A + S}{m + K}, \quad \sigma^2 = \frac{m\left[\sigma^2_A + (\mu_A - \mu)^2\right] + \left[Q - 2\mu S + K\mu^2\right]}{m + K}
  \]
  其中 \(m\) 为保留通道数，\(K\) 为移除通道数，\(\mu_A, \sigma^2_A\) 为保留通道的均值和二阶中心矩，\(S, Q\) 为移除常数的和与平方和。

### 6. 论文的主要结论与发现

- **主要结论**：
  1. 精确最小化可以将任何非结构化剪枝器的结果转化为实际更小的可部署稠密模型，且**前向函数在浮点误差内完全一致**（最大logit差异 \(1.06\times10^{-6}\)）。
  2. **mask-alive与deployable存在巨大差距**（FC上5.4×，ConvNeXt上11.3×，ViT上5.0×），仅报告mask-alive会严重高估压缩效率。
  3. **释放步骤是迭代压缩的关键**：No-minimize基线平均3.6循环后终止，而Squeeze-Release Mode A达到97循环，Mode AB达到100循环上限，表明释放的容量被有效利用，持续发现新结构冗余。
  4. **全连接网络压缩39.2×**（从191,104参数到4,878参数，精度97.03% vs 基线95.99%，无显著差异）；**ConvNeXt-Tiny压缩14.8×**（从27.8M到1.88M参数，精度90.27% vs 基线90.81%，无显著差异）。
  5. **CompensatedLayerNorm** 实现了对LayerNorm的精确通道缩减，存储开销仅为每层3个标量。
  6. 最小化重写可扩展到Transformer架构（ViT PoC）。

### 7. 优点

- **方法创新性**：提出将非结构化剪枝与精确结构重写结合的迭代框架，释放步骤巧妙地将死参数转为可训练容量，突破了传统迭代剪枝“删掉就不再使用”的假设。
- **理论严谨性**：CompensatedLayerNorm的设计基于充分统计量的精确重建，而非近似，保证了前向等价性。
- **实践友好性**：最小化步骤可作为任何非结构化剪枝器的后处理模块，不改变训练流程；Mode A+C几乎不需要改动网络结构（仅减少内宽和移除整块）。
- **实验设计规范**：多随机种子、统计检验、报告mask-alive和deployable两种度量，公平揭示差距。
- **清晰的问题分解**：将剪枝分为“评分”和“结构重写”两个独立子问题，聚焦后者，使方法具有更广的适用性。

### 8. 不足与局限

- **实验覆盖不足**：主要在小规模数据集（MNIST, CIFAR-10）上验证，缺乏ImageNet-1k完整迭代实验和大语言模型（LLM）的验证（虽提出可扩展但未充分论证）。
- **算力开销**：Squeeze-Release需要大量循环（ConvNeXt上接近100循环），壁钟时间远高于单次剪枝，论文未提供具体GPU时数，实际部署中可能成本过高。
- **架构依赖**：最小化规则需针对不同架构手动设计（如FC、ConvNeXt、ViT的Attention），缺乏通用自动化工具。
- **精度略有下降**：Mode AB精度90.27%比基线90.81%低约0.5%，统计上不显著但存在趋势，可能需要在更大模型上验证是否保持。

- **释放步骤的分布选择**：论文称0初始化也能达到类似效果，但此结论仅基于未报告的少量测试，缺乏系统消融。
- **超参数敏感**：停止阈值（如验证精度下降10个百分点）、循环最大次数均需手动设定，可能需针对不同任务调整。
