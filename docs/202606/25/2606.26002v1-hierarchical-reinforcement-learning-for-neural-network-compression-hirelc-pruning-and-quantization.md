## 摘要
我们提出了HiReLC，一个用于深度神经网络自动联合量化与结构化剪枝的分层集成强化学习框架。该框架将压缩搜索分解为两个抽象层次：低层智能体（LLAs）在每个块内独立操作，在涵盖位宽、剪枝保留比率、量化类型和粒度的多离散动作空间上选择每核配置；而高层智能体（HLAs）则通过基于Fisher信息敏感性估计的集成投票来协调全局预算分配。为减轻策略评估的计算成本，一个迭代主动学习循环将代理引导的强化学习优化与压缩后微调交替进行，使用轻量级MLP代理来分摊昂贵的评估，并在冷启动阶段使用logit-MSE代理。代理用于奖励塑造，而非替代最终压缩后评估。控制器设计为架构无关，通过模块化层抽象将强化学习环境与底层网络拓扑解耦。在Vision Transformer和CNN基准上的实验表明，参数存储压缩比达到5.99-6.72倍，在一种设置下准确率提升3.83%，其他情况下准确率下降0.55-5.62%，支持分层策略分解和敏感性感知引导作为联合神经网络压缩的实用设计选择。

## Abstract
We present HiReLC, a hierarchical ensemble-reinforcement learning framework for automated joint quantization and structured pruning of deep neural networks. The framework decomposes the compression search across two levels of abstraction: low-level agents (LLAs) operate independently per block, selecting per-kernel configurations over a multi-discrete action space spanning bitwidth, pruning keep-ratio, quantization type, and granularity, while high-level agents (HLAs) coordinate global budget allocation via ensemble voting guided by Fisher Information-based sensitivity estimates. To mitigate the computational cost of policy evaluation, an iterative active learning loop interleaves surrogate-guided RL optimization with post-compression fine-tuning, using a lightweight MLP surrogate to amortize expensive evaluations and a logit-MSE proxy during cold-start. The surrogate is used for reward shaping rather than as a replacement for final post-compression evaluation. The controller is architecture-agnostic by design, with a modular layer abstraction decoupling the RL environment from the underlying network topology. Experiments across Vision Transformer and CNN benchmarks demonstrate effective parameter-storage compression ratios of 5.99 - 6.72$\times$ with a 3.83 % gain in one setting and 0.55 - 5.62 % accuracy drops elsewhere, supporting hierarchical policy decomposition and sensitivity-aware guidance as practical design choices for joint neural network compression.

深度神经网络在视觉识别任务中表现卓越，但参数量大、内存占用高、推理延迟长，难以部署在资源受限平台（如移动设备、边缘端）。Vision Transformer（ViT）和CNN均面临此效率瓶颈。现有压缩方法（如单轴策略、基于静态启发式或单目标优化的剪枝/量化）存在以下不足：
- 无法捕获跨层依赖；
- 缺乏自适应优化（如微调阶段的持续改进）；
- 强化学习方法在大动作空间中方差高、粒度粗、缺乏敏感性感知引导；
- 多数方法仅针对剪枝或量化单一维度，缺乏联合优化；
- 评估压缩配置需要完整微调，计算成本高昂。

本文提出HiReLC，旨在实现**架构无关的自动联合结构化剪枝与混合精度量化**，通过**分层强化学习**高效探索巨大组合空间，同时利用**Fisher信息敏感性**指导预算分配，并通过**代理模型（surrogate）和主动学习**降低评估成本。

## 2. 方法论：核心思想与关键技术

### 核心思想
- **分层强化学习（Hierarchical RL）**：将压缩决策分解为两个层级。
  - **高层智能体（HLA）**：负责全局预算分配，为每个块指定目标保留尺寸比例、策略类型（剪枝/量化/自动）等。
  - **低层智能体（LLA）**：在HLA给定的预算约束下，为每个内核选择具体的压缩配置（位宽、剪枝保留率、量化类型、颗粒度）。
- **集成学习**：每个层级由多个策略（PPO与A2C）组成的集成体，通过加权投票产生最终动作，降低方差。
- **Fisher信息敏感性**：利用块级Fisher信息得分初始化LLA状态、参与敏感性惩罚项（Psens）、引导HLA预算校正，使关键块获得更轻的压缩。
- **代理辅助主动学习循环**：轻量MLP代理在足够样本后替代昂贵的完整微调评估，冷启动阶段使用logit-MSE代理；代理仅用于奖励塑造，最终精度仍通过完整微调获得。

### 关键技术细节
- **动作空间**：LLA动作是多离散向量，每个内核包含4个维度（位宽、保留率、量化类型、颗粒度），HLA动作为每个块输出压缩级别和策略索引。
- **奖励函数**：
  - LLA奖励：`r_LLA = α·R_acc + β·R_comp + R_budget + γ·R_stab - Psens`，其中R_acc基于代理估计的精度保留，R_comp = 60×(1-ν̅)奖励压缩，R_budget惩罚偏离HLA预算，R_stab惩罚历史奖励波动，Psens为Fisher敏感性惩罚。
  - HLA奖励：`r_HLA = R_bal + R_sens + R_global + R_dyn`，分别惩罚预算不均匀性、奖励敏感性感知分配、惩罚全局保留率偏差、以及基于上一周期反馈的动态项。
- **主动学习循环**：每轮迭代（cycle）包括：HLA接收反馈→调整策略→HLA分配预算→LLA训练→提取配置→应用压缩→微调→更新代理→跟踪最佳模型。
- **压缩算子**：结构化剪枝基于L2范数重要性保留top通道；混合精度量化支持INT（对称）和FLOAT（非对称），颗粒度可选uniform/log/per-channel/learned。
- **压缩率计算**：`ν_i,k = (b_i,k/32)·ρ_i,k`，全局CR = 1/ν̅，ν̅为参数加权平均。

## 6. 主要结论与发现

- HiReLC在所有架构上实现了**5.99–6.72倍的有效参数存储压缩比**，除一个CIFAR-10场景（精度提升3.83%）外，精度下降为**0.55%–5.62%**。
- **分层策略+集成投票**优于单层控制器：移除HLA导致精度下降更严重（6.80% drop at 8.87× vs 1.72% at 6.23×）。
- **Fisher敏感性引导**提升精度保持率约1.30个百分点，并产生更结构化的块间压缩分配。
- **混合INT/FLOAT+log颗粒度**在DeiT-Small上比INT均匀配置获得更低的精度下降（1.17% vs 1.72%），说明类型灵活性有助于恢复。

- 主动学习循环能够跨周期改进配置（周期3达到最佳），但存在随机波动（周期4回退）。
