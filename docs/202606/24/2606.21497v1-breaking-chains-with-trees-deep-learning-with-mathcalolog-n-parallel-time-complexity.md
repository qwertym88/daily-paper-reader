## 摘要
现代深度神经网络架构通过反向传播进行训练，这要求在参数更新之前，误差必须顺序地传播通过所有层。这引入了两个限制：锁定（层间更新严格相互依赖，无法并行进行）和权重传输问题（需要对称的前向和反向路径以进行精确梯度计算）。这些约束限制了并行性，增加了内存和通信开销，并对可扩展学习提出了挑战。在这项工作中，我们提出了层次化局部块学习（HBLL），这是一个将深度神经网络分解为按层次链接的块的框架，使用从变分原理导出的局部学习目标进行训练，无需完整的端到端反向传播，同时保持网络中有效的信息传播。HBLL是第一个能够以$\mathcal{O}(\log N)$并行时间复杂度训练深度神经网络的算法，其中$N$是网络层数。我们表明，HBLL隐式定义了一系列对应于不同层次路径的子网络，实现了具有不同有效层数的灵活推理。我们在具有挑战性的视觉和语言建模任务上评估了HBLL，取得了有竞争力的性能。我们还将HBLL扩展到循环序列架构，应用于其他情况下依赖于时间反向传播的场景。

## Abstract
Modern deep neural network architectures are trained via backpropagation, which requires errors to be sequentially propagated through all layers before parameters can be updated. This introduces two limitations: locking, where layer-wise updates are strictly interdependent and cannot proceed in parallel, and the weight transport problem, which requires symmetric forward and backward pathways for exact gradient computation. These constraints restrict parallelism, increase memory and communication overhead, and pose challenges for scalable learning. In this work, we propose Hierarchical Block-Local Learning (HBLL), a framework that decomposes deep neural networks into hierarchically linked blocks trained using local learning objectives derived from variational principles, eliminating the need for full end-to-end backpropagation while maintaining effective information propagation across the network. HBLL is the first algorithm that is able to train deep neural networks in $\mathcal{O}(\log N)$ parallel time complexity, where $N$ is the number of network layers. We show that HBLL implicitly defines a family of subnetworks corresponding to different hierarchical paths, enabling flexible inference with different effective numbers of layers. We evaluate HBLL on a set of challenging vision and language modeling tasks, achieving competitive performance. We also extend HBLL to recurrent sequence architectures, applying to settings that otherwise rely on backpropagation through time.

- **整体含义**：本文旨在提出一种无需全局反向传播的局部学习框架，从根本上打破链式依赖，实现并行训练，同时保持甚至提升模型性能。作者引入**层次化块局部学习（HBLL）**，首次实现了 $\mathcal{O}(\log N)$ 的并行时间复杂度，为大规模深度学习提供了新的可扩展范式。

### 2. 方法论：核心思想与关键技术细节

- **核心思想**：将深度网络分解为按层次组织的块，每个块使用从变分原理导出的局部目标进行训练，消除全局梯度传播。
  - 将网络视为一阶马尔可夫链：$x \to z_1 \to \cdots \to z_{N-1} \to y$，其中 $z_n$ 为潜变量。
  - 关键的**定理1**证明：后验分布 $p(z_1,\dots,z_{N-1}|x,y)$ 可以等价分解为树状结构：  
    $p(z_1,\dots,z_{N-1}|x,y) = \prod_{n=1}^{N-1} p(z_n | z_{n-2^{d(n)}}, z_{n+2^{d(n)}})$，其中 $d(n)$ 为层次深度。该树状结构使得计算路径从 $\mathcal{O}(N)$ 降至 $\mathcal{O}(\log N)$。
- **变分局部学习目标**：引入变分分布 $q(z_{1:N-1}|x,y)$，并定义辅助损失：  
  $\mathcal{F} = \mathbb{E}_q\left[ \sum_{n=1}^{N-1} \log\frac{q(z_n|\text{pa}(n))}{p(z_n|z_{n-1})} - \log p(y|z_N) \right]$。  
  该目标可分解为局部项，且期望可通过 $M=1$ 次蒙特卡洛采样近似。
- **算法流程（算法1）**：
  1. 初始化边界激活 $z_0=x$, $z_N=y$，根块 $(0,N)$。
  2. 对于深度 $d=D,\dots,1$（$D=\log N$），并行处理每个活动块 $(i,j)$：
     - 计算中点 $n=\lfloor (i+j)/2\rfloor$ 的后验均值 $\mu_n$（通过贝叶斯反演或泰勒近似）。
     - 通过重参数化采样 $z_n = \mu_n + \epsilon$。
     - 计算块局部损失 $\ell_n(z_i,z_n,z_j)$ 并更新参数。
     - 创建子块 $(i,n)$ 和 $(n,j)$ 加入下一深度集合。
  所有同一深度的块完全并行，依赖深度仅为 $D=\log N$。
- **关键实现细节**：在线性高斯假设下，后验均值可通过一阶泰勒近似高效计算：$\mu_n \approx a_n + \frac{1}{4} \nabla \| a_{n+1}-z_{n+1} \|^2$。
- **扩展到RNN（HBLL-RNN）**：将时间步组织成树，训练时利用树结构并行，推理时仅使用因果的深度0单元展开。为缓解曝光偏差，引入一致性校正（parallel consistency stage）。

### 6. 主要结论与发现

1. **并行复杂度突破**：HBLL是首个实现$\mathcal{O}(\log N)$并行时间复杂度的深度网络训练算法，有效解决了锁定问题。
2. **竞争性能**：在MNIST、CIFAR-10、CIFAR-100上，HBLL达到或接近BP性能，且在短路径（子网络）上有时优于相同深度的BP。在WikiText-103上，HBLL稍逊于BP（困惑度22.22 vs. 18.17），但仍具竞争力。
3. **鲁棒性优势**：在缺失数据和标签噪声场景下，HBLL一致优于BP，表明局部学习可提供正则化效果。
4. **子网络灵活性**：HBLL隐式定义了一系列不同有效深度的子网络，可通过不同层次路径实现计算预算的灵活调整。
5. **RNN扩展有效**：HBLL-RNN在序列MNIST上匹配甚至超越BPTT，且随着序列长度增加，训练速度提升显著（深度8时达3.6倍加速）。

### 7. 优点

- **理论奠基扎实**：从变分推导出局部目标，并证明树状分解等价于原始后验，数学严谨。
- **实用价值高**：直接解决并行训练瓶颈，适合分布式和硬件加速；子网络机制便于推理阶段的灵活部署。
- **覆盖范围广**：方法不仅适用于前馈和Transformer，还扩展到循环架构，统一了框架。
- **鲁棒性好**：在数据损坏场景下表现稳健，暗示局部学习可作为一种隐式正则化。

### 8. 不足与局限

- **性能差距**：在WikiText-103上，HBLL困惑度比BP高约4点，表明在语言建模等复杂任务中仍有提升空间。
- **深度扩展问题**：在MNIST实验中，深度D=4时BP完全失效（11.32%），HBLL虽有效但准确率低于较浅模型；在RNN中，gateless Elman链在深度较大时变得不稳定，即使一致性校正也无法完全修复。
- **实验规模有限**：缺少在ImageNet等大规模图像数据集上的验证；语言建模仅使用参数较少的GPT-2风格模型（7层transformer），未测试更大模型（如LLaMA）。
- **效率对比不充分**：仅对RNN给出了训练时间加速的量化，对ViT和Transformer未报告实际并行加速比，且CFF+M基线结果来自他人论文，可能因实现差异导致不公平。
- **方法复杂度**：引入层次化树结构和额外后验计算，增加了实现和超参数调优的难度（如噪声尺度、一致性迭代次数K的选择）。
- **因果RNN的曝光偏差**：尽管提出一致性校正，但在长序列下部署链仍逐渐退化，稳定性有待改进。
