## 摘要
大型预训练的视觉-语言-动作模型主导着现代机器人操作基准测试，但模型规模对强语言条件控制究竟需要多大仍不清楚，或者根本不同的控制架构能否在远更小的参数预算下保持竞争力。我们提出了PredVLA，一种语言条件的预测编码策略，仅拥有68万个可训练网络参数且无需机器人数据预训练，其分层生成式循环动力学预测视觉特征和本体感觉，而观察仅通过由此产生的感觉预测误差的在线推断来影响潜在状态。在LIBERO上，PredVLA在三个短视野套件上达到86.9%的平均成功率，若包含长视野套件则为75.4%。在使用相同冻结前端、演示、动作解码器和评估协议的受控比较下，PredVLA的平均成功率分别是参数匹配的Transformer和LSTM策略的3.7倍和7.4倍。预测编码公式还使观察驱动校正的贡献可直接测量：因为观察仅通过基于预测误差的潜在推断影响循环状态，禁用此推断即产生精确的开环控制条件。综合而言，这些结果表明，一种亚百万参数的循环生成策略能在现代语言条件操作基准上实现强劲性能，同时提供由预测误差驱动的在线状态校正的明确机制。

## Abstract
Large pretrained vision-language-action models dominate modern robot-manipulation benchmarks, but it remains unclear how much model scale is necessary for strong language-conditioned control, or whether fundamentally different control architectures can remain competitive at much smaller parameter budgets. We present PredVLA, a language-conditioned predictive-coding policy with only 0.68 million trainable network parameters and no robot-data pretraining, whose hierarchical generative recurrent dynamics predict visual features and proprioception while observations influence latent state only through online inference from the resulting sensory prediction errors. On LIBERO, PredVLA achieves an 86.9% mean success rate across the three short-horizon suites and 75.4% when the long-horizon suite is included. Under a controlled comparison using the same frozen front end, demonstrations, action decoder, and evaluation protocol, PredVLA achieves 3.7x and 7.4x mean success rates of parameter-matched Transformer and LSTM policies, respectively. The predictive-coding formulation also makes the contribution of observation-driven correction directly measurable: because observations influence the recurrent state only through prediction-error-based latent inference, disabling this inference yields an exact open-loop control condition. Together, these results show that a sub-million-parameter recurrent generative policy can achieve strong performance on modern language-conditioned manipulation benchmarks while providing an explicit mechanism for prediction-error-driven online state correction.

## 2. 方法论

**核心思想**

PredVLA 遵循预测编码的经典思想：内部生成动力学"预测"感觉轨迹，而潜在状态通过最小化预测信号与实际观测之间的误差在线推断得到。关键区别在于，观测信息从不直接注入循环动力学，而是只通过预测误差间接影响潜在状态。

**总体架构**

由两部分组成：
1. **冻结的多模态前端**：语言用冻结的 MiniLM 句子编码器；双摄像头（第三人称 agentview + 腕部 eye-in-hand）分别用冻结 ResNet18 编码；语言与视觉特征均经固定 PCA 基投影降维；本体感觉（9 维：关节角+夹爪）直接使用。
2. **可训练的分层预测编码循环网络**（0.68 M 参数）：包含四个循环模块——共享顶层 T、视觉分支 V、动作分支 A_top 与 A_bottom，按 T → V → A_top → A_bottom 顺序依次计算。

**关键技术细节**

- **分层时间常数**：每个模块有不同时间常数 τ（短视界为 T:16、V:8、A_top:5、A_bottom:2；长视界加宽为 30/14/8/2），构成多时间尺度动力学层次，负责组织任务、视觉和运动层面的动态。
- **自由变量与前向-后验结构**：每个模块维护确定性状态 h、输出 d 和潜在自由变量 c。采用 PV-RNN 风格的前向-后验结构：前向由父模块输出或自身前一步输出产生；后验为在线推断的对象。
- **语言条件**：指令编码为固定向量 l，仅通过顶层模块 T 的加性项进入循环动力学，作为整个回合的顶层条件信号向下传播。
- **侧向通路**（均不含直接观测）：
  - 视觉→动作瓶颈（V→A_top）：低维（32 维）动态表示，类似 RNNPB 的 parametric bias 但每步动态计算；
  - 动作→视觉的传出副本通路（A→V）：反馈模型自身上一步的**预测**动作与预测本体感觉，而非实测值。
- **自由能目标**：训练时同时最小化视觉预测误差、本体感觉预测误差、后验相对前向的复杂度惩罚（二次形式替代 KL），以及演示动作的负对数似然。

**核心公式（文字版）**

- 非根模块的前向由父模块输出生成；根模块 T 的前向由自身前一步输出递归生成。
- 状态更新包含保真项（1 − 1/τ）与驱动项（1/τ），驱动项包含循环输入、自上而下输入、后验自由变量、侧向输入和偏置。
- 自由能 E(I) = Σ[λ_v·视觉误差 + λ_q·本体感觉误差 + 复杂度惩罚]。
- 训练目标 L = 自由能 + λ_a·动作负对数似然。后验自由变量在训练时作为模型参数，优化完毕即丢弃。

**测试时在线推断**

- 权重全部冻结，仅更新后验自由变量。
- 每个控制步在 40 步的滑动窗口上做 10 次 Adam 优化迭代（步长 0.05），每次迭代后重新生成整个窗口的确定性状态轨迹，然后从 A_bottom 解码当前动作。
- 输出为 5 分量对角高斯混合分布，执行时取权重最大分量的均值。

**精确开环条件**

设置推断迭代次数 nitr = 0 即完全禁用误差回归，此时后验等于前向，观测完全不影响循环状态，从而在不动网络、不改语言条件下，获得精确的开环控制对照。

## 6. 主要结论与发现

1. **亚百万参数策略可以取得强性能**：PredVLA 以 675,732 个可训练参数、无机器人数据预训练，在 LIBERO 三短视界套件平均成功率 86.94%，含 LONG 后全四套件平均 75.35%。
2. **远优于参数匹配基线**：受控比较下，PredVLA 三短视界平均成功率是参数匹配 Transformer（19.73% 四套件均值）的 3.7 倍、是 LSTM（10.26%）的 7.4 倍，也超过了参数更多的动作分块 Transformer。
3. **时间层次贡献突出**：将各模块时间常数统一后，短视界套件成功率下降 17–29 个百分点，且三套件一致退化。
4. **在线误差回归确有作用**：禁用在线推断（精确开环）使各套件成功率下降 6–13 个百分点。短视界套件的开环基线仍相对较高（73.79–78.50%），说明许多行为可由学习到的循环动力学独立生成；LONG 上在线校正的收益最明显。
5. **不同感觉通道的误差贡献存在任务差异**：OBJECT 套件对本体感觉误差高度敏感（移除后 −14.17 点），对视觉误差不敏感（−2.96 点）；SPATIAL 与 GOAL 上视觉和本体感觉贡献接近。任务级分析显示套件级平均会掩盖巨大的任务级差异。
6. **本体感觉通道被扰动时影响更大**：仅以 25% 比例扰动本体感受观测，OBJECT 成功率即下降 49.74 点；同等程度的视觉扰动影响显著较小。
7. **有趣发现**：在 OBJECT 上，仅移除本体感觉误差项造成的性能损失（−14.17）数值上大于完全禁用在线推断（−12.17），提示不完整的感官校正可能在某些情况下还不如完全开环执行。

## 7. 优点

- **架构创新性强**：将预测编码思想应用于语言条件操作任务，构造了"观测→误差→潜在状态推断→动作"的间接路径，从根本上区别于主流直接馈入观测的 VLA 架构。
- **参数效率极高**：以 0.68 M 参数达到 86.9% 的短视界平均成功率，比当前主流的数亿至数十亿参数模型低了数个数量级。
- **精确开环对照**：因架构本身设计（观测不直接进入循环状态），将推断迭代数设为零即可获得与闭环共享所有模型和语言条件但完全不受观测影响的精确开环条件，无需重训练任何额外模型。这一设计让闭环校正的贡献可以被精确测量，具有很强的可解释性。
- **受控比较规范**：在进行公平比较时，确保所有基线共享零样本前端、演示数据、动作表示和评估协议；且参数匹配范围严谨（偏差≤5%），基线训练步数更多，基线学习率做了超参搜索，方向偏袒基线。
- **推断速度快**：21.6 Hz 的端到端控制频率（含冻结前端和在线误差回归过程）具有实际部署价值。
- **可视化与任务级分析**：任务级热图展示了套件均值掩盖的任务差异，从而提供了真实有效的诊断信息。
