## 摘要
本文介绍了NepScript Genesis，一个用于自动生成对抗网络（GAN）发现的神经架构搜索（NAS）框架，应用于条件梵文手写数字合成。我们将五种NAS策略与精心构建的深度卷积生成对抗网络（DCGAN）基线（FID=332.28）进行比较。架构选择采用两阶段流水线，并由一种新颖的领域感知评估指标（Enhanced Score）引导。结果表明，自适应探索实现了最佳的质量-效率权衡，在不到一个GPU小时内获得了79.12的FID——比基线提高了76.19%——并在NAS策略中实现了最高的模式覆盖（召回率=0.531）。此外，我们证明了在搜索阶段引入特定于脚本的结构启发式可以防止早期模式崩溃。在后续的低资源评估中，使用来自最佳NAS模型的GAN生成数字增强每类250个真实训练样本，将CNN分类准确率从91.0%提高到96.5%（+5.5个百分点），这表明当真实数据稀缺时，NAS优化的合成产生的数字具有足够的质量，能够有益于实际识别流水线。

## Abstract
This paper introduces NepScript Genesis, a Neural Architecture Search (NAS) framework for automated Generative Adversarial Network (GAN) discovery, applied to conditional Devanagari handwritten digit synthesis. We compare five NAS strategies against a carefully constructed Deep Convolutional GAN (DCGAN) baseline (FID=332.28). Architecture selection utilizes a two-stage pipeline guided by a novel domain-aware evaluation metric (Enhanced Score). Results demonstrate that Adaptive Exploration achieves the optimal quality-efficiency trade-off, attaining an FID of 79.12 -- a 76.19% improvement over the baseline -- and the highest mode coverage among the NAS strategies (Recall=0.531) in under one GPU-hour. Furthermore, we demonstrate that incorporating script-specific structural heuristics into the search phase prevents early-stage mode collapse. In a downstream low-resource evaluation, augmenting 250 real training samples per class with GAN-generated digits from the best NAS model improves CNN classification accuracy from 91.0% to 96.5% (+5.5 percentage points), demonstrating that NAS-optimized synthesis produces digits of sufficient quality to benefit practical recognition pipelines when real data is scarce.

### 2. 方法论

#### 2.1 核心思想

提出两阶段流水线评估管道：

- **阶段一（架构筛选，30 epochs）**：每个候选架构短训30轮，用新颖的领域感知复合指标“Enhanced Score”对架构排序。该指标以多保真度原理捕捉训练动态，避免耗费500轮完整评估所有架构。
- **阶段二（完整训练与最终评估，500 epochs）**：从零开始重新训练每个策略的最优架构，用FID、IS、Precision、Recall四个标准指标评估最终性能。

#### 2.2 NAS搜索空间

搜索空间Λ覆盖五个体系架构维度，对生成器G和判别器D分别独立搜索：

| 维度 | 选择范围 | 应用对象 |
|------|---------|---------|
| 潜在维度（d_z） | {64, 100, 128, 200} | 仅生成器 |
| 归一化 | {BatchNorm, InstanceNorm} | G和D |
| 激活函数 | {ReLU, LeakyReLU} | G和D |
| Dropout（G） | {0.0, 0.1, 0.2, 0.3} | 仅生成器 |
| Dropout（D） | {0.0, 0.2, 0.3, 0.5} | 仅判别器 |
| 残差连接 | {False, True} | G和D |

生成器侧包含4×2×2×4×2=128种配置，联合生成器-判别器空间为**128×128=4,096种**配对配置，远超穷举评估能力，这正是引入NAS的原因。

#### 2.3 NAS算法（五种）

- **随机搜索**（Random Search）：均匀采样，无需代理模型，是NAS基线下限。
- **渐进式搜索**（Progressive Search）：三个复杂度递增阶段，分别用[4,5,6]个架构逐步扩大搜索空间（保守→激进）。
- **自适应探索**（Adaptive Exploration）：维护成功配置历史（Enhanced Score ≥ 0.5），以0.7概率突变已有成功配置，以0.3概率随机探索。概念上与开发偏置进化搜索相关。
- **多保真搜索**（Multi-fidelity Search）：三个逐步升高的保真度关卡（10/20/30 epochs），分别以0.5和0.7阈值为提升门槛，提前淘汰差候选。类似Successive Halving和Hyperband。
- **对抗梯度搜索**（AdversarialNAS）：按照DARTS方案，将离散架构选择松弛为连续架构参数（结合Gumbel-Softmax），采用双层优化：批量更新权重w，验证批更新架构参数α。

#### 2.4 Enhanced Score（增强评分）

这是一个两阶段流水线的领域感知评估指标，由五个子项加权构成：

```
Enhanced Score = 0.30 × Base + 0.20 × Diversity + 0.20 × Consistency 
                + 0.15 × Efficiency + 0.15 × Q_Nepali
```

其中：
- **Base = 0.4×Stability + 0.3×Balance + 0.3×Quality**：衡量基本训练健康度。Stability衡量训练时期稳定性；Balance衡量G与D损失与理想值1.0的接近程度；Quality通过像素强度与标准差衡量图像完整性。
- **Diversity**：通过生成的样本间平均成对距离惩罚模式崩塌。
- **Consistency**：衡量标签条件稳定性（同一类别在不同批次间生成一致数字的能力），与Diversity形成张力——两者权重相同（0.20），兼顾类内可辨识性与类间多样性。
- **Efficiency**：奖励快速收敛与紧凑潜在空间。
- **Q_Nepali**（Nepali质量）：领域启发式，通过Laplacian方差（S_sharp）与连通分量数（S_stroke）显式奖励拓扑完好的天城文笔划，在训练早期剔除拓扑不合格的架构。

#### 2.5 下游评估

- 设计一个轻量级单卷积层CNN分类器（5×5核、8滤波器→ReLU→2×2池化→32单元隐藏层，dropout=0.6）。
- **低资源场景**：仅用每类250个真实训练样本（共2,500个），对比“仅真实数据”与“真实+GAN生成数据”（约每类1,000个合成样本）两种条件下的CNN分类精度。

### 6. 主要结论与发现

1. **自动化搜索全面超越人工设计**：五种NAS策略全部显著降低FID（62%以上改善），即使随机搜索也将FID从332.28降至124.30（降幅62.59%），说明搜索空间存在大量优于手选方案的配置。
2. **自适应探索为最优质量-效率平衡方案**：在6种方法中取得最佳FID=79.12——较基线改善**76.19%**——且仅用56.56分钟搜索时间，与最简单策略几乎相同。其历史引导突变机制（0.7概率突变成功配置）让后续测试偏向高分区域，规避了早期不稳定与模式崩塌。
3. **无单一全能赢家（质量-多样性谱系）**：
   - FID最优：自适应探索（79.12）
   - IS最优：多保真搜索（2.08，超过手动基线2.00）
   - Precision最优：AdversarialNAS与多保真（均为1.00）——梯度/多阶段筛选积极压制低保真样本，但牺牲Recall
   - Recall最优（NAS组）：自适应探索（0.531），但手动基线（0.552）更高——其“多样性”实为低保真输出的反射而非高质量覆盖
4. **脚本特定启发式（Q_Nepali）在搜索阶段防止早期模式崩塌**。
5. **GAN增强在下游低资源识别场景中有实际效益**：将每类250个真实样本扩充至约1,250个（含GAN生成），CNN精度从91.0%提升至96.5%（+5.5个百分点），且分类器已经应用了常规图像增强，表明合成数据的价值在传统数据增强之上具有增量意义。

### 7. 优点

1. **领域感知的评估指标设计**：Enhanced Score将通用训练活跃度指标（稳定性、平衡）与天城文特定结构指标（连通分量笔划完整性、Laplacian方差锐度）组合，兼顾了脚本语义。这是一个可迁移到其他低资源文字合成场景的设计思想。
2. **两阶段管线的高效性**：30-epoch筛选+500-epoch完整训练的分离是实际且有效率的策略——避免了对每个候选进行昂贵完整训练，且代理指标能捕捉判别出候选好坏的关键训练动态信息。
3. **对多保真度原理的忠实理论引入**：将10/20/30轮门槛筛选与0.5/0.7阈值的“逐步提升”思想系统化纳入生成架构的筛选。
4. **方法论相对清晰透明**：完整公开了每种搜索算法的伪代码（算法1-5），对候选空间的定义和范围进行了准确的量化；开放源代码加强可复现性（https://github.com/M9star/NepScript-Genesis-Framework）。
5. **对质量-多样性权衡的处理较为细致**：不使用单一指标排序，而是用Precision/Recall区分保真与覆盖，并揭露IS与FID的背离特性。
6. **下游验证的设计务实**：用250个真实样本（每类）模拟低资源OCR场景，且与已应用常规增强的基线对比，结论具有实践参考意义。

### 8. 不足与局限

作者在5.4节自述的局限包括：

- **搜索空间范围有限**：仅覆盖五个架构维度（128生成器配置）。更深的网络、注意力机制和替代损失函数（Wasserstein、谱归一化等）被排除在搜索空间之外。
- **单种子结果**：受计算资源限制，每种架构仅评估一次。缺少多种子随机性估计，结果是显著差异还是噪声差异尚不确定。
- **适用性受限**：验证仅在天城文数字（10类）上；扩展到完整天城文字符集或其他婆罗米系文字需要额外验证。
- **评估指标敏感性**：FID已知对样本量和Inception网络选择敏感。文中所有FID均以20,000个样本计算以降低敏感性，但对底层特征空间的选择依然限定。

其他未被充分讨论的局限包括：

- **搜索候选数少**：每策略仅15个候选，搜索统计效率与终止准则未报告，是否因小数字样本产生的偶然性影响不明。
- **搜索策略间无法公平直接对比**：取样方法与AdversarialNAS评价协议不同（15个候选 vs 300个梯度步），时间-质量妥协关系不够清晰。
- **Enhanced Score的验证不足**：30-epoch Enhanced Score与最终500-epoch FID之间缺乏相关系数报告；跨策略的分数极度集中（0.976–0.989）却对应巨大FID差异，表明其严格上是**策略内**的选择标准，并非跨策略预测指标；与随机搜索等策略结合时的通用性未被验证。
- **无人类评估**：对于可读性这一核心要求，实际无人类评审者参与判断生成的Devanagari数字的逼真度。

### 总结性评价

论文在思路层面有明确价值——首次将NAS工具系统应用于天城文数字的GAN架构发现，并将其验证至下游识别任务增益层面。实验揭示了一个实践中相当有说服力的规律：即使最简单的原则性采样（随机搜索）也优于单点人工设计，而带历史引导的自适应策略能进一步显著优化FID。主要证伪点集中在单种子运行、有限搜索空间以及评价指标本身未充分消融验证等环节。最令人印象深刻的是其实际适用范围：不到1 GPU小时搜索就能将FID从332降到79，并提升低资源CNN精度达5.5个百分点——这一“效率-实用”组合具备较高的实用价值。
