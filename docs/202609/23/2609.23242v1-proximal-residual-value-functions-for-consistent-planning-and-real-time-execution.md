## 摘要
我们研究双时间尺度决策系统，其中规划层周期性地向实时优化器提供延续价值函数，该优化器负责分配到达的资源，并以库存放置作为我们的激励应用。我们提出一种端到端强化学习（RL）方法，利用近端残差价值函数来学习该函数，这些函数将决策后库存的严格凸势函数与学习得到的凸残差相结合。这种一般形式产生了一个适定的优化层，既支持端到端微分，又为实时执行保留了显式凸目标。我们刻画了光滑价值函数产生跨规划与执行时间尺度一致决策的充分必要条件。在一项使用来自大型电商零售商的历史库存到货与需求模式的离线模拟中，学习到的近端残差价值函数相对于历史生产系统代理，将总路由与调拨成本降低了5.0%。

## Abstract
We study two-timescale decision systems in which a planning layer periodically supplies a continuation-value function to a real-time optimizer that allocates arriving resources, with inventory placement as our motivating application. We propose an end-to-end reinforcement learning (RL) method for learning this function using \emph{proximal residual value functions}, which combine a strictly convex potential of post-decision inventory with a learned convex residual. This general form yields a well-posed optimization layer that supports end-to-end differentiation while preserving an explicit convex objective for real-time execution. We characterize the necessary and sufficient conditions under which a smooth value function yields decisions that are consistent across the planning and execution timescales. In an offline simulation using historical inventory arrival and demand patterns from a large e-commerce retailer, learned proximal residual value functions reduce total routing and transfer cost relative to a historical-production-system proxy by 5.0%.

## 1. 核心问题与整体含义（研究动机与背景）

- **应用背景**：现代电商多级库存网络需要在两个时间尺度上做决策——规划层（数天/数周一次）为每个商品产生一个凸的延续价值函数（估计"后决策库存"的未来成本，是 base-stock 目标在多仓网络上的类比）；执行层（秒/分钟级）在每次到货事件时结合当前成本与约束，把到达库存路由到仓库。
- **核心矛盾**：该架构可扩展且能精确执行约束，但插入其中的价值函数是**逐商品调参的经典规则**（如 newsvendor），并非针对它们所诱导的多期网络结果训练出来的。
- **本文主张**：把价值函数**学习**出来——共享策略在每个规划周期开始产生每个商品的凸价值函数，周期内保持固定，并**端到端穿过执行优化器**在真实多期成本上训练。
- **一致性难题**：按完整事件保真度训练需在每次到货后求解一次优化，计算上不可行；因此训练时把周期内到达聚合成一次调拨决策、之后再消耗需求。该近似带来三类误差：
  - **batching error**：多次固定环境求解与一次聚合求解结果不一致；
  - **solver error**：训练与执行优化不同程序，或同一程序求解精度不同；
  - **environment-perturbation error**：事件间成本、路由、需求发生变化。
- **论文定位**：明确只解决前两类（且主要解决 solver error 中的"目标不匹配"部分与 batching error），**不声称** solve-count 不变性可消除第三类误差。
- **三项贡献**：
  1. 提出**近端残差价值函数**（学习凸残差 + 后决策库存的严格凸势能），为训练与实时执行提供同一个显式凸目标；
  2. 在固定执行环境下刻画一致性：solve-count 不变性等价于"单调一次性预算路径"；对光滑严格凸目标等价于 **PCSP**；层状（laminar）指示耦合给出有保证的 PWL 子类；
  3. 开发结构化可微求解器（State-prox），并用 Gurobi 重编译声明式执行程序、在历史输入模拟器中回放评估。

## 2. 方法论

### 2.1 问题形式化（Exo-IDP）

- 内生状态 $X_t$ 含在手库存、在途库存与历史特征；外生记录 $\omega_t$ 含到达、需求、成本、网络连通性、提前期。回放时固定外生输入，但库存轨迹随策略重算。
- 规划动作：共享策略 $\pi_\theta$ 从商品特征 $S_{jt}$ 产生参数 $\eta_{t,j}$，定义凸延续价值函数 $V_{t,j}(x)=V(x;\eta_{t,j})$，$x\in\mathbb{R}^n_+$ 为商品在各仓的后决策库存。规划动作是整组函数 $\{V_{t,j}\}$，周期内固定。
- 实时执行（事件 $k$）：
  $$z^*_{t,j,k}=\arg\min_{z\ge0,\ \mathbf{1}^\top z=B_{t,j,k}}\left\{c_{t,j,k}^\top z+V_{t,j}(I_{t,j,k}+z)\right\}$$
- 经济目标：$J(\theta)=\mathbb{E}\left[\sum_{t=0}^{T-1}\gamma^t\left(C^{\text{ship}}_t+C^{\text{transfer}}_t\right)\right]$，实验中 $T=52,\ \gamma=1$；价值函数只引导分配，不计入实现成本。
- 训练近似：把周期内到达聚合为 $B_{t,j}=\sum_k B_{t,j,k}$ 一次求解，之后需求通过**可微 entropic 最优传输算子**消耗库存，推进到 $X_{t+1}$。

### 2.2 为什么正则化"状态"而不是"动作"

- PWL 价值函数对 $\eta$ 的梯度可能无信息或未定义（斜率变化可能不改变分配，或使分配跳变）。
- 但给**动作**加严格凸正则（如二次罚）会改变优化目标本身：
  - 执行时去掉它 → 决策规则与训练不一致；
  - 保留它 → 一次聚合调用收 $\Omega(z^{(1)}+z^{(2)})$，两次调用收 $\Omega(z^{(1)})+\Omega(z^{(2)})$，对任意拆分相等要求可加性，而连续可加函数必为线性、无法提供严格曲率。
- 因此把曲率放进**价值函数的状态部分**：
  $$V_\eta(x)=R_\eta(x)+\tau\Phi(x),\quad \Phi(x)=\sum_{i=1}^n\varphi(x_i),\ \tau>0$$
  其中 $\varphi$ 在 $\mathbb{R}_+$ 上连续严格凸（主实验用 $\varphi(x)=x\log x$，$0\log0=0$；也可用 $x^2/2$）。势能是延续价值的一部分，在每次求解中作用于**累计后决策库存**。

### 2.3 学习残差的结构

- $$R_\eta(x)=\sum_{i=1}^n f_{i,\eta}(x_i)+\sum_{\ell=1}^m h_{\ell,\eta}\left(w_{\ell,\eta}^\top x\right)$$
  每个 $f_{i,\eta},h_{\ell,\eta}$ 是标量凸 PWL 函数，例如 $f(u)=a+su+\sum_q\delta_q(u-b_q)_+$，$\delta_q\ge0$。
- 可分项刻画各仓的局部库存经济性；耦合项沿学习到的聚合方向 $w_\ell$ 表示交互。$w_\ell$ 可含符号项，因为"标量凸函数 ∘ 线性映射"仍保凸。
- 严格凸势能保证唯一最优（可行单纯形紧致 + 目标连续严格凸），即使残差存在平坦面。
