## 摘要
将人形机器人全身控制推向通用部署，需要大规模人体运动语料以及可跨机器人本体共享的训练经验。现有方法通常为每个机器人单独训练一个策略，导致运动经验在不同具身之间彼此孤立。我们提出 X-WBC，一个跨具身基础框架，它将相对共享的人体运动语义与具身特定的物理执行相分离。以人为中心的命令 token 对齐完整人体运动、机器人参考运动与稀疏 VR 观测。因果 Transformer 从混合的多机器人轨迹中学习可复用的时序结构，而轻量级的机器人特定模块将共享表示映射到各机器人的本体感知与动作空间。在九种仿真具身、外部运动以及四台真实机器人上的实验表明：联合训练提升了跟踪性能，对齐后的表示支持跨命令源的一致控制，且所学策略在训练语料之外仍保持竞争力。这些结果支持将异构人形机器人作为联合数据源，并确立跨具身联合训练作为迈向全身控制基础模型的可行路径。

## Abstract
Scaling humanoid whole-body control toward general-purpose deployment requires large human motion corpora and training experience shared across robot bodies. Existing methods usually train one policy per robot, leaving motion experience isolated across embodiments. We introduce X-WBC, a cross-embodiment foundation framework that separates relatively shared human motion semantics from embodiment-specific physical execution. Human-centered command tokens align full human motion, robot reference motion, and sparse VR observations. A causal Transformer learns reusable temporal structure from mixed multi-robot rollouts, while lightweight robot-specific modules map the shared representation to each robot's proprioception and action space. Across nine simulated embodiments, external motions, and four real robots, experiments show that joint training improves tracking, the aligned representation supports consistent control across command sources, and the learned policy remains competitive beyond the training corpus. These results support heterogeneous humanoids as joint data sources and establish cross-embodiment joint training as a practical route toward whole-body control foundation models.

# X-WBC 论文详细总结

## 1. 核心问题与整体含义

- **研究动机**：人形机器人全身控制（WBC）正借助大规模人体运动语料（如 AMASS、LAFAN1、BONES-SEED）向通用化部署推进，但现有方法的训练单元通常仍是**单一机器人**——每个平台各自重定向运动、训练策略、调优部署，导致运动经验在不同具身之间彼此隔离。
- **核心问题**：运动智能是否存在一种可跨身体迁移的表示？人类可通过观察他人学习技能，而不必拥有相同身高、肢体长度或关节范围；作者追问人形 WBC 能否学到类似的跨具身运动表示。
- **核心洞察**：人体运动数据携带**相对具身无关的运动语义**（行走、踢腿、下蹲、伸展共享时序结构与几何意图），而机器人用于执行这些语义的运动是**具身特定的**（受运动学、关节限位、驱动、身体布局影响）。因此跨具身 WBC 应分离“共享运动语义”与“机器人特定运动生成”。
- **整体含义**：将异构人形机器人视为联合数据源，把跨具身联合训练确立为通往全身控制基础模型的可行路径；同一人体运动在不同机器人上的重定向结果，可作为同一意图的不同实现，机器人多样性与运动多样性互补地监督共享主干。

## 2. 方法论

### 2.1 核心思想

- 将训练重新表述为**多机器人运动跟踪**问题，来自不同人形机器人的 rollout 共同监督一个共享策略主干，而非各自孤立训练。
- 关键设计：**以人为中心的命令 token 空间**，将完整人体运动、机器人参考运动、稀疏 VR 运动对齐为同一潜在运动意图的不同视图。
- 架构分工：共享时序 Transformer 学习可复用运动结构；轻量机器人特定模块负责将共享表示映射到各机器人本体感知与动作空间。

### 2.2 问题形式化

- 每个机器人 $i$ 定义一个 MDP $M_i = (S_i, A_i, T_i, R, \gamma)$，其中状态空间 $S_i$、动作空间 $A_i$、转移动力学 $T_i$ 为具身特定，奖励族 $R$ 与折扣因子 $\gamma$ 跨机器人共享。
- 使用 PPO 在所有机器人 rollout 上优化共享跟踪目标。
- **观测**：采用非对称 actor-critic。actor 观测 $s^i_t$ = 本体感知 $s^{p,i}_t$（关节位置/速度、基座角速度、体坐标系重力投影、上一动作）+ 一个运动命令 $s^c_t$；critic 额外接收特权信息（体坐标系下身体连杆位姿、基座线速度）。
- **动作**：策略输出在活动机器人的动作空间中解释，经低层 PD 控制器转为力矩。不同机器人的观测/动作维度在训练时填充至最大值以便混批，执行时机器人特定解码器仅保留有效维度。
- **奖励**：跨机器人语义一致，$r^i_t = R_{track} + P$，跟踪项含根朝向、身体连杆位姿、身体速度，惩罚项含动作变化率、关节限位违规、非期望接触（附录 Table A1 给出完整奖励表）。

### 2.3 以人为中心的命令编码

三条命令编码路径：

- **人体运动命令编码器（共享）**：将全身人体运动映射为人体运动 token，来自动捕，不绑定任何机器人关节定义，作为命令对齐的语义锚点。
- **机器人运动命令编码器（特定）**：将机器人身体空间中的参考运动映射为机器人运动 token，通常来自人体到机器人的重定向，也可来自机器人录制或生成运动。
- **稀疏 VR 命令编码器（共享）**：将人体运动的稀疏观测（头部 + 四个肢体末端共 5 个关键点）映射为稀疏 VR token；部署时可由 VR 设备实时获取，提供低带宽控制接口。

所有路径以身体位置、朝向、速度（而非仅关节角）表示目标运动，进入编码器前在根中心/机器人中心坐标系归一化，使 token 聚焦相对运动结构，对全局坐标偏移与操作者体型差异鲁棒。

### 2.4 共享主干与机器人特定模块

- 共享主干为**因果 Transformer**：每个控制步将选定命令 token 与机器人特定本体感知 token 组合为当前观测 token，在长度 $L$ 的因果历史窗口内聚合，输出动作 token：
  $$h^i_t = B_\theta(\{[z_c,\tau; z^i_{p,\tau}]\}^{t}_{\tau=t-L+1})$$
- 在线 rollout 时使用 **KV 缓存**，每步仅处理新观测 token 并更新缓存，显著降低实时控制计算量。
- 本体感知编码与动作解码由**机器人 ID 选择**的轻量特定模块完成：前者将填充后的本体感知映射到固定维 token，后者将动作 token 映射到有效关节动作。

### 2.5 训练流程

- **多机器人联合训练**：在 Isaac Lab 构建多机器人环境，各机器人保持自身状态、动作、接触、终止逻辑；每步后混合所有机器人转移进入同一 PPO 批次。
- **优化目标**：每个运动片段编码出机器人运动、完整人体运动、稀疏 VR 三种命令 token，rollout 时按 **1:1:1** 比例采样其一并在整个 episode 中使用。损失为：
  $$\mathcal{L} = \mathcal{L}_{PPO} + \lambda_{align}\mathcal{L}_{align}$$
  其中 $\mathcal{L}_{align}$ 计算同一运动片段三个归一化命令 token 进入主干前的成对 MSE（$\lambda_{align}=1.0$，三对等权）。
- **终止条件**：根垂直位置误差、根朝向误差、末端执行器垂直位置误差超阈值时终止，并作为自适应采样的失败统计来源。
- **自适应运动采样**：提高频繁触发早停的运动片段采样概率，并硬移除持续失败（可能为重定向伪影或物理不可行）的片段。
- **域随机化**：随机化接触参数、默认关节位置、基座质心偏移，并周期性施加根速度扰动（详见附录 Table A5）。

## 6. 主要结论与发现

- **联合训练有效**：G1 上 X-WBC 达 98.60% SR，优于 MLP 版（97.70%）与单机器人版（97.69%）；H2 上为 93.22% vs 91.33% / 92.22%，且两机器人上身体速度误差最低。H2 上更大差距说明共享监督在更难具身上价值更高。
- **命令源一致**：同一模型在 VR、机器人运动、完整人体三条命令路由上训练运动成功率相近，说明对齐编码器为共享主干提供兼容输入；人体命令在部分身体指标略优，机器人命令因已在目标参考空间故根旋转误差更低；稀疏 VR 仅用 5 个关键点仍接近。
- **组件必要性**：移除任一条稠密命令路由、对齐损失或机器人特定模块均降低两机器人 SR；H2 上移除稠密命令路由降幅最大；去掉机器人特定模块的结果相对不差，说明本体感知本身已携带有用具身信息。
- **外部运动具竞争力**：800 片段网格上 X-WBC（VR5）完成 729 片段（91.13% SR），SONIC 为 93.00%，TWIST 为 75.62%；SONIC 速度误差更低，TWIST MPKPE 更低但完成度显著落后（应结合其 15.51 个百分点的 SR 差距解读）。X-WBC 以小幅位置误差换取更广的 rollout 存活。
- **token 空间语义**：跨源检索同运动阶段 Recall@1 达 86.0%、同运动达 94.2%；跨机器人检索为 61.3% 与 76.1%，均高于随机基线（0.17% 与 1.04%）。同运动召回高于同阶段，说明运动身份比精确时序相位更稳定；跨机器人低于跨源，说明 token 中仍保留具身特定执行信息。
- **真机可行性**：同一人体中心命令接口与共享主干可支持尺寸和运动学结构差异显著的四台机器人（G1、R1、H1-2、H2），完成上半身姿态控制与下半身踢球、草地奔跑等动作。

## 7. 优点

- **问题表述新颖**：首次将人形 WBC 的训练单元从“单机器人策略”转为“跨多机器人联合训练”，把机器人多样性作为互补监督信号，视角清晰。
- **架构分工明确**：以人为中心的命令 token 空间 + 共享因果 Transformer + 轻量机器人特定模块，三层职责分离自然，且命令 token 对齐损失直接约束三种命令视图的一致性。
- **工程实用性**：KV 缓存使历史窗口推理可实时运行；1:1:1 命令路由采样使单一模型同时支持训练用的稠密参考与部署用的稀疏 VR；非对称 critic 与特权信息设计合理。
- **评估维度互补**：仿真内分布、外部语料冻结评估、token 空间检索分析、真机部署四角度交叉验证，token 检索实验为“共享语义 vs 具身特定信息”的分离假设提供了直接证据。
- **消融系统**：对三条命令路由、对齐损失、机器人特定模块逐一拆除，结论与设计动机对应。
- **可复现性**：附录详尽给出奖励、终止阈值、PPO 超参、采样参数、域随机化范围与网络结构，项目网站公开。

## 8. 不足与局限

- **具身范围受限**：研究聚焦人形机器人，向更多样形态、身体比例与关节布局的迁移能力未知。
- **机器人特定组件未消除**：仍依赖机器人特定的命令编码器、本体感知编码器、动作解码器、控制逻辑与逐机器人运动重定向，这些接口仍是部署管线的一部分，其削减尚未在不损失控制保真度的前提下验证。
- **真机验证有限**：仅 4 台 Unitree 机器人、有限的上/下半身行为，缺乏定量跨方法硬件对比与跨厂商部署；未评估更长任务序列、更多样接触与地形。
