## 摘要
现有的人形机器人运动系统主要关注稳定性和任务执行，而将表现力与显式运动控制相结合仍具挑战性。我们提出 EMoG，一种用于富有表现力的人形机器人运动的情感调制步态生成框架。EMoG 引入了一种具有连续可调强度的情感风格编码。以该编码和物理指令为条件，一个轻量级 MLP 实时生成富有表现力且与指令一致的周期性步态轨迹，并由统一的强化学习策略跟踪以进行物理执行。为支持训练，我们从专业表演者处收集了一个大规模情感标注步态数据集，并开发了一个自动化流程来提取物理一致的周期性步态周期。EMoG 还集成了一个基于 LLM 的解析器，可将自由形式的语言转换为情感风格和运动参数，以实现交互控制。实验表明，在保持指令跟踪的同时，可实现具有可感知表现力线索的连续步态风格调制。EMoG 为面向人机交互的参数化情感风格行走提供了一种实用方法。

## Abstract
Existing humanoid locomotion systems primarily focus on stability and task execution, while integrating expressiveness with explicit locomotion control remains challenging. We propose EMoG, an emotion-modulated gait generation framework for expressive humanoid locomotion. EMoG introduces an emotional-style code with continuously adjustable intensity. Conditioned on this code and physical commands, a lightweight MLP generates expressive, command-consistent periodic gait trajectories in real time, which are tracked by a unified reinforcement learning policy for physical execution. To support training, we collect a large-scale emotion-annotated gait dataset from professional performers and develop an automated pipeline to extract physically consistent periodic gait cycles. EMoG also integrates an LLM-based parser that converts free-form language into emotional style and motion parameters for interactive control. Experiments demonstrate continuous gait-style modulation with perceptible expressive cues while maintaining command tracking. EMoG provides a practical approach to parameterized emotional-style walking for human-robot interaction.

- **核心矛盾**：现有人形运动控制研究（LIPM/ZMP/MPC 等模型方法，以及 RL + 模仿学习的方法）主要优化**稳定性与任务执行效率**，步态本身缺乏情感风格与语义表达，机器人难以"感知用户情绪、表达自身意图、参与社交互动"。
- **已有工作的缺口**：
  - 语言/语义条件化的运动框架（如 LangWBC、TextOp 等）只回答"做什么动作、去哪里"，不回答"如何富有表现力地执行"；即使输入含情感词，其影响也是隐式、不可控的。
  - 通用文本到动作生成（MDM、SMooDi、DART、MotionGPT3、ARDY）与情感增强生成（FEEL、L3EM）在**语义对齐**上有进展，但无法独立调节"情感风格"与"物理运动参数（速度、朝向、步频）"。
- **目标**：在保持对行走速度、偏航角速度、步频等物理指令精确可控的前提下，实现**连续可调、可感知的情感风格步态生成**，并支持自然语言交互。

## 2. 方法论

### 2.1 总体框架

- **核心思想**：将"情感风格"与"物理指令"作为**两路独立输入**，由轻量 MLP 生成实时全身周期参考轨迹，再交给统一的强化学习运动跟踪器执行，形成"情感风格 ↔ 物理可控步态"的闭环管线。
- **流程**：自然语言 → LLM 解析 → （风格码 e, 物理指令 c）→ 步态生成器 Gθ → 周期参考轨迹 → 运动跟踪器 → 机器人底层动作。

### 2.2 情感风格表示

- 采用 5 种非中性风格 + 中性基线：**happy、confident、sad、scared、shy、neutral**。
- 正性情绪（happy/confident）对应躯干舒展、动作幅度大；负性情绪（sad/scared/shy）对应姿态收缩、动作幅度小。
- 风格码定义为连续标量向量：`e = [e_hap, e_con, e_sad, e_sca, e_shy]ᵀ ∈ [0,1]⁵`，每个分量表示对应情绪的调制强度，`e = 0` 即中性基线，从而实现从"subtle"到"salient"的连续调制。

### 2.3 数据采集与精炼流程（自动化管线）

- **动作采集**：8 名专业表演者，按 6 种情绪风格、多种行走方向与步频进行表演，用 SMPL 表示。
- **动作重定向**：使用 GMR 迁移到人形机器人；通过检测双脚线速度与偏航角速度低于阈值的帧确定支撑相，补偿根节点高度以抑制脚部悬空；上下半身独立运动学映射后再合并，避免大幅上半身动作破坏下肢稳定。每帧状态 `τt = {pt, rt, vt, ωt, qt, q̇t}`。
- **周期步态分割**：以关键参考关节（如髋关节俯仰）的局部峰值作为候选分割点，用**动态规划**在步频约束下提取最长有效峰值子序列，剔除违反物理规律的片段，得到完整双足行走周期 `τ_n^cycle`。
- **自监督特征提取与精炼**：对每段计算平均速度 `vx, vy, ω_yaw` 与步频 `fn`；依据生物力学原理（速度越快步频越高）做线性回归 `f = k·v_linear + b`，据此剔除离群点与低速非平稳片段。物理指令定义为 `cn = [vx, vy, ω_yaw, f_offset]`，其中 `f_offset = fn − (k·v_linear + b)` 为回归残差。
- **数据规模**：约 **225 万帧、12,243 个片段、100 fps、6 类情绪**。

### 2.4 情感标签平滑（离散标注 → 连续条件）

- 训练一个 Transformer 分类器（使用 CLS token 聚合序列），输入为 `τ_n^cycle` 与时间编码 `φn(t) = [sin ψ, cos ψ]`，`ψn(t) = (t−Bn)/(En−Bn)`。
- 对标注为风格 k 的片段，取其在 k 类上的 softmax 概率作为风格强度 `e_n^k`，其余分量置零；中性样本赋全零码。这样把离散标签转化为**连续概率流形上的监督信号**，使模型从数据分布中自动学习风格调制分数。

### 2.5 步态生成器与损失函数

- **生成器**：轻量 MLP `Gθ`，输入 `xt = [φn(t), en, cn]`，逐帧回归输出全身状态 `ŷt = [pz, θroll, θpitch, vt, ωt, qt, q̇t]`。
- **四项损失**：
  1. **重构损失 L_recon**：带权重矩阵 W 的加权 MSE，监督与参考真值的几何对齐。
  2. **一致性损失 L_con**：约束周期平均线速度与偏航角速度逼近输入指令 `vx, vy, ω_yaw`，保证长期物理对齐。
  3. **对称损失 L_sym**：镜像输入 `Mx` 后再镜像输出 `My` 应能还原原输出，抑制双侧不对称伪影。
  4. **平滑损失 L_diff**：对相邻时间步施加一阶差分惩罚，抑制高频抖动。

### 2.6 运动跟踪器与语言接口

- **运动跟踪**：生成参考由已有跟踪方法执行（SONIC 与 BeyondMimic），生成器只负责风格与指令条件化的参考轨迹。
- **语言接口**：使用 Qwen3-Omni-Flash（**不做任务特定微调**），通过**两步顺序提示**：①从文本与交互上下文推断 6 类风格之一；②将标签与文本映射为强度 `ek ∈ [0,1]` 与物理指令 `c = [vx, vy, ω_yaw, f_offset]`。无明确情绪时收缩到中性 `e = 0`；并引入最大线速度/角速度等物理约束保证可执行性。

## 6. 主要结论与发现

- **连续调制有效**：关节幅度（腰、肩俯仰）随风格强度平滑单调变化；t-SNE 中每种情绪形成清晰可分簇，簇内隐码随强度沿一致方向平滑移动，说明风格被编码为**连续位移而非离散切换**；中性构成紧凑的中心簇。
- **识别率随强度提升**：五路识别整体准确率 49.1%（0.3）→ 57.0%（0.6）→ **73.3%（0.9）**；Sad 最高（78.8%→100%），Happy 提升最快（30.3%→81.8%），Shy 最低（30.3%→45.5%）。六路实验中 confident 与 shy 易与 neutral 混淆，说明**风格可辨识度存在类别依赖性**。
- **表达性与可控性的权衡**：所有方法在执行后识别率均下降；直接重定向动作识别率最高（Ref. 77.28 / Exec. 65.25）但**完全缺乏物理指令控制**；EMoG 从这些动作中学习风格特征，同时保持指令级可控性并取得最高完成率（99.83 / 99.75）。MotionGPT3 与 DART 难以从文本捕捉情感风格，也不支持精确物理指令控制。
- **跟踪器影响表现力**：SONIC（S）识别率高于 BeyondMimic（B），推测因其大规模动作训练更能保留参考中的风格线索。
- **损失函数有效**：去除 L_con 后指令跟踪变差（Evx 0.0284→0.0333，Evy 0.0470→0.0649，Eyaw 0.0063→0.0132），去除 L_sym 后不对称度上升（0.0019→0.0113），两者均导致路径漂移显著增大（Etraj 0.1214 → 6.4446 / 4.4144）。
- **语言接口可用**：平均延迟 2.18 s，同输入重复查询输出几乎一致，可在跟踪回路之外做可重复的高层更新；真机多地形

演示中能够在草地、塑胶地板、地毯等不同地面条件下保持稳定行走，并对外部扰动具有一定鲁棒性；整个"文本 → 风格码 + 物理指令 → 参考轨迹 → 跟踪器"的管线可在真机上闭环运行，验证了语言作为人形机器人表达性运动高层接口的可行性。

- **数据层面的创新**：构建了大规模、多情绪的表演者步态数据集（约 225 万帧、12,243 个周期片段、6 类情绪），并设计了一套**自监督式的自动化精炼管线**——重定向 → 支撑相检测 → 动态规划周期分割 → 生物力学回归（步频—速度线性关系）过滤离群点，将原始表演动作转化为物理一致、周期完整的训练数据。
- **标签表示上的创新**：用 Transformer 分类器的 softmax 概率替代离散情感标签，把"哪一类情绪"升级为"多强的情绪"，实现从离散标注到**连续风格流形**的监督信号转化，使风格强度可平滑插值、可渐变调节。
- **生成架构上的创新**：以轻量 MLP 逐帧回归全身参考状态，配合重构 / 一致性 / 对称 / 平滑四项损失，在极低推理成本下实现风格与指令的联合条件化；生成器与跟踪器解耦，可即插即用地复用不同底层跟踪策略（SONIC、BeyondMimic）。
- **交互层面的创新**：验证了**零微调**的通用多模态大模型（Qwen3-Omni-Flash）通过两步提示即可充当自然语言到（风格码、物理指令）的解析器，并叠加物理约束保证可执行性，降低了系统对任务特定训练数据的依赖。

## 8. 局限与未来工作

- **风格表达幅度受限**：受底层跟踪器与物理稳定性约束，生成的动作在"表现力"上弱于直接重定向的表演动作（执行后识别率普遍低于参考识别率），存在**表达性—可执行性之间的固有折衷**。
- **风格可辨识度不均衡**：confident、shy 等低唤醒/低幅度风格与 neutral 易混淆，说明当前连续编码对"细腻情绪差异"的刻画仍有提升空间，未来或需引入更细粒度的风格维度（唤醒度—效价二维、混合情绪插值等）。
- **消融覆盖不完整**：未系统验证重构损失、平滑损失、标签平滑机制、分类器结构等组件的独立贡献，设计选择的必要性论证尚不充分。
- **评估的统计严谨性**：用户研究虽采用盲测与统一录制条件，但样本量中等且未报告显著性检验、被试背景分布，跨文化、跨年龄的普适性未知。
- **基线公平性**：与 MotionGPT3、DART 的对比更接近"能力维度"比较而非严格控制变量的同任务对比，后者本身不支持精确物理指令控制，故在速度/旋转误差上不可比。
- **真机验证偏定性**：多地形与扰动场景以演示为主，缺少量化的真机跟踪误差、能耗、长时间稳定性与安全边界分析。
- **泛化边界**：未涉及跨表演者泛化、非平坦地形上的表达性步态、以及风格切换时的平滑过渡问题。

## 9. 总体评价

- **学术价值**：论文提出了一条清晰且工程可行的问题拆解路径——把"情感表达"与"运动控制"分而治之，用连续风格码 + 显式物理指令的双通道条件化，配合轻量生成器与现成跟踪器，在保持物理可控性的同时赋予步态情感语义。这一"解耦 + 条件化"的思路对后续表达性机器人运动研究具有可迁移的方法论意义。
- **实证强度**：实验覆盖了可控性、可识别性、基线对比、消融与真机语言驱动五个层面，用户盲测设计（区分参考识别率与执行识别率）是较规范的评估实践；但消融不完整、基线可比性存疑、真机缺定量指标，削弱了结论的严密程度。
- **可复现性**：方法描述较为完整（数据规模、损失形式、指令定义、提示流程均有交代），但**全文未披露任何算力、参数量、训练超参与代码/数据开放信息**，构成明显的复现障碍。
- **应用前景**：作为人形机器人社交化交互的一环，该工作为"用自然语言指挥机器人以特定情绪行走"提供了端到端的概念验证，在服务机器人、陪护、教育娱乐等场景具有潜在落地价值；但要达到自然、可信、长时稳定的情感表达，仍需在风格细粒度、跨场景泛化与安全性上继续推进。
