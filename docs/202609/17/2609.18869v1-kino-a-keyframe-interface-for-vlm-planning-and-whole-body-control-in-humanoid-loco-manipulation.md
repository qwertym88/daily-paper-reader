## 摘要
人形移动操作要求机器人在执行协调的全身运动时，能够理解任务指令和场景语义。我们提出一个分层框架，将运动关键帧用作视觉语言模型（VLM）规划与强化学习（RL）控制之间的中间表示。每个关键帧指定一个目标全身机器人位姿，并在适用时指定物体位姿。给定语言指令、场景观测和执行反馈，VLM从预定义库中选择连续的任务相关关键帧。所选关键帧会被重定向到当前场景，以考虑物体位姿和尺寸。随后，一个以关键帧为条件的全身策略生成关节级动作以实现这些目标。我们引入一种基于显著性的关键帧采样策略用于低层策略训练，在使用稀疏VLM关键帧时，将端到端任务成功率从44%提升至92%。我们在仿真中以及Unitree G1人形机器人上，对物体拾取、运输和放置任务评估了我们的框架。该系统成功执行单手和双手操作，并能泛化到训练参考数据之外的放置位置。

## Abstract
Humanoid loco-manipulation requires robots to interpret task instructions and scene semantics while executing coordinated whole-body motions. We propose a hierarchical framework that uses motion keyframes as an intermediate representation between Vision-Language Model (VLM) planning and Reinforcement Learning (RL) control. Each keyframe specifies a target whole-body robot pose and, when applicable, an object pose. Given a language instruction, scene observations, and execution feedback, the VLM selects successive task-relevant keyframes from a predefined library. The selected keyframes are retargeted to the current scene to account for object poses and dimensions. A keyframe-conditioned whole-body policy then generates joint-level actions to reach these goals. We introduce a saliency-based keyframe sampling strategy for low-level policy training that improves end-to-end task success rate from 44% to 92% when using sparse VLM keyframes. We evaluate our framework on object pickup, transport, and placement tasks in simulation and on a Unitree G1 humanoid. The system successfully performs both one- and two-handed manipulation and generalises to placement locations beyond the training reference data.

## 2. 方法论

### 2.1 整体架构（三级流水线）

- 输入：文本指令、机器人状态上下文、场景视觉观测。
- **VLM 规划器**从预定义关键帧库中选出下一个任务相关关键帧（如接近、下蹲、抓取等语义阶段）。
- **重定向器（Retargeter）**将关键帧按当前场景的物体位姿与尺寸进行适配。
- **关键帧条件全身策略**输出关节级动作，驱动机器人到达该位姿。
- 核心设计取舍：VLM 只做**离散关键帧选择**而非连续关节命令预测，从而无需为高层规划采集机器人特定数据。

### 2.2 关键帧条件策略

- 形式化为**目标条件 RL**：策略接收关键帧目标并输出全身动作。
- **观测向量**包含：
  - 机器人状态：基座局部线速度与角速度、投影重力向量、关节位置与速度；
  - 物体状态：局部位置与四元数；
  - 上一时刻动作；
  - 关键帧目标 $K_t = (\hat{p}^r_t, \hat{R}^r_t, \hat{q}_t, \hat{p}^o_t, \hat{Q}^o_t)$，即基座坐标系下的目标根位置、根朝向、目标关节角，以及目标物体位置与朝向；若无物体则物体项置零。
  - 策略输入使用过去 10 帧观测历史。
- **非对称 Actor-Critic**：Critic 额外接收特权观测（参考运动状态、目标误差 $\Delta K_t$、剩余时间 $\tau_t$），并使用 3 帧历史；部署时策略仅依赖真机可获取的观测。
- **训练算法**：PPO；参考运动数据库涵盖 locomotion、盒子操作、水桶操作。
- **奖励设计**分为三组：
  - 参考跟踪 $r^{track}_t$（DeepMimic 形式，匹配参考根位姿与速度、关节构型、身体位姿及物体位姿）；
  - 关键帧到达 $r^{goal}_t$（仅在目标时刻激活）；
  - 正则化 $r^{reg}_t$（惩罚力矩、动作变化率、关节加速度、脚部打滑）。
  - 采用**多 Critic 形式**（$V_{track}, V_{goal}, V_{reg}$）以缓解不同奖励组之间的负干扰。
- **动作空间**：29 维目标关节位置，由 Unitree G1 的 PD 控制器跟踪。
- **Sim2Real**：域随机化（摩擦、物体与机器人质量、质心偏移、执行器增益、关节参数、执行器延迟、观测噪声、外部推力）。

### 2.3 关键帧采样（核心技术创新）

- 动机：训练关键帧分布应逼近推理时 VLM 预测的关键帧分布；loco-manipulation 片段包含接近、抬起、运输、放置等阶段，均匀采样会被大量行走/接近中间帧淹没，导致策略暴露于关键事件目标的次数不足。
- **基于加速度的候选提取**：
  - 定义聚合加速度信号 $\Gamma(t)=\sum_j \lVert \ddot{p}_j(t)\rVert_2$（$p_j$ 为身体部位 $j$ 的位置），经低通滤波后在局部时间邻域内取局部极大值作为候选 $P_\Gamma$；
  - 这些极大值对应机器人运动的快速变化，常与抓取/放置等阶段切换重合。
- **周期性腿部运动过滤**：分别计算左右腿加速度剖面，估计局部相位相似性与周期性，剔除由规律交替腿运动主导的候选（多为行走中间态），得到机器人事件候选 $\tilde{P}_\Gamma$。
- **物体运动精修**：
  - 取物体垂直加速度峰值作为物体事件候选 $P_o$；
  - 物体开始运动时刻 $T_o$ 之后的候选，若在时间容差 $\delta$ 内与某物体事件对齐则保留；
  - 未与已有候选重合的物体事件候选被补充加入。
  - 最终显著关键帧集合为 $P_{salient} = \{1, T\} \cup P_r \cup P^{new}_o$。
- **关键帧库**：包含运动数据集中的代表性位姿，每个关键帧对应一个语义运动阶段（接近物体、抬起、搬运等），包含机器人完整位姿及（如适用）物体位姿，定义机器人与被操作物体的名义空间关系，并配有自然语言描述供 VLM 检索。

### 2.4 场景对齐

- **关键帧重定向**：
  - 设源/目标物体帧为 $B_i=(c_i,R_i,h_i)$ 与 $B^*=(c^*,R^*,h^*)$，其中 $c$ 为物体中心、$R\in SO(3)$ 为朝向、$h$ 为包围盒半尺寸；
  - 变换 $T_{i\to*}(p)=c^*+R^*\big(R_i^\top(p-c_i)\oslash h_i\odot h^*_i\big)$，即保持各点相对源物体的归一化位置，同时适配目标物体的位姿与尺寸；机器人根节点只更新水平坐标；
  - 得到目标末端执行器位置后，用**迭代阻尼最小二乘逆运动学**恢复其余机器人构型，目标函数最小化末端位置误差并加权约束脚部垂直位置以保持贴地（基于 MuJoCo 广义坐标积分）。
- **路径规划**：
  - 在初始与目标 locomotion 关键帧之间构造中间关键帧序列，帮助机器人到达训练数据之外的位置；
  - 轨迹用切向对齐的圆弧表示，必要时用最短有效 Dubins 路径；曲率限制为 3 m⁻¹（最小转弯半径约 0.33 m），以排除训练轨迹中未出现的急转；
  - 路径稠密采样后贪婪选择中间目标：从每个已选目标出发，选最远的下一个样本，要求累积航向变化不超过 45°、相对前一目标的欧氏位移不超过 2 m。

### 2.5 VLM 规划器

- **职责**：解释用户指令与当前场景，选择下一个语义关键帧，判断任务是否完成。
- **请求构成**：自然语言长时程任务指令 + 第三人称视角图像 + 结构化规划器上下文；系统提示词规定输入输出含义与格式。
- **规划器上下文**：上一关键帧、上一目标是否完成及成功与否、当前机器人根位姿、当前物体位姿、目标物体位姿、控制器诊断（如目标误差）。若上一关键帧成功到达则推进到下一语义阶段，否则重试或选择恢复关键帧。
- **约束输出**：返回结构化 JSON，如 `{"keyframe": "crouch_to_pick_box", "object_to_manipulate": true, "task_complete": false}`；物体操作标志决定重定向器是否保持物体相对手部构型、物体位姿是否作为有效目标的一部分（为 false 时物体相关输入置零，重定向只考虑根位置）；任务完成标志终止规划循环。
- **闭环事件驱动执行**：仅在机器人与物体均达到静止且上一目标已有足够执行时间后才发起新的 VLM 查询，避免在低层策略执行期间打扰。

## 3. 实验设计

- **任务场景**：两类 pick-transport-place 任务——双手盒子操作、单手水桶操作。
- **参考运动数据**：
  - 52 条来自 AMASS 的 locomotion 片段；
  - 105 条来自 OmniRetarget 的双手盒子操作片段；
  - 120 条自采集的单手水桶操作片段；
  - 通过改变物体初始位置与朝向并相应调整机器人与物体轨迹来增强操作运动。
- **VLM 配置**：Qwen3.6:27B，运行于单张 4090 RTX GPU，通过 ROS 服务接口与重定向器、控制器交互；VLM 输出关键帧平均耗时低于 0.2 s，重定向平均约 5 ms。
- **Sim-to-Sim**（MuJoCo）：
  - 验证规划器、重定向器、策略的闭环交互；
  - 验证 VLM 能根据指令中的物体类型选择单手或双手关键帧；
  - 盒子拾取-放置：机器人在原点朝 −y 方向，目标位置在网格上变化，成功判据为物体最终位置距目标 0.3 m 以内；将成功率图与训练数据的空间覆盖（红色轮廓）对比，考察训练分布之外的泛化能力。
- **真机部署**：Unitree G1，机器人状态来自机载传感，物体相对位姿由外部动捕系统估计；执行盒子（双手）与水桶（单手）的拾取与放置。
- **消融对比**：
  - **Saliency-based（本文）vs Uniform**（固定 1.5 s 间隔）关键帧采样；
  - 100 次试验，起始距盒子 0.5–2.3 m，目标位置距盒子初始位姿 0.2–2.0 m；成功判据为最终物体与机器人根位置误差小于 0.3 m；
  - 统计 Approach / Pick / Place 各阶段成功率与目标到达误差（根位置、关节 RMSE、物体位置）；
  - 失败处理规则：approach 失败则重置到物体附近；操作关键帧失败则省略后续阶段，样本数为均匀采样 97/88/63、本文方法 99/100/93。
- **失败恢复案例**：展示一次未到达目标关键帧后，VLM 基于视觉与上下文误差重发上一关键帧并最终成功。

  - 关键帧采样消融虽统计充分，但未报告方差/置信区间，也未分析不同显著性阈值对采样结果的影响；
  - 重定向与路径规划的失效边界（如目标物体尺寸远超训练分布、需要大范围转向的场景）缺少专门压力测试。

- **总体判断**：核心消融（采样策略）的统计设计较扎实，但整体实验更偏向"系统可行性验证"而非"全面基准对比"，说服力主要来自 sim-to-sim 与真机的双重闭环演示。

## 6. 主要结论与发现

- **关键帧是可用的语义—控制接口**：VLM 只输出离散关键帧选择，重定向器与全身策略负责落地，从而在不采集机器人特定规划数据的前提下完成长时程 loco-manipulation。
- **显著性采样显著优于均匀采样**：100 次试验中端到端成功率由 44% 提升至 92%，且 Approach / Pick / Place 各阶段成功率与目标到达误差均一致改善——说明训练关键帧分布向"事件密集帧"对齐能直接提升策略对推理时稀疏目标的到达能力。
- **VLM 语义选择有效**：规划器能依据指令中的物体类型（盒子 vs. 水桶）选择单手或双手关键帧序列，并在上下文中利用控制器诊断信息进行重试与恢复。
- **分布外泛化**：放置位置网格扫描显示，成功区域超出训练数据的空间覆盖（红色轮廓）之外，表明重定向与路径规划的组合可把训练分布内的运动基元外推到新目标位置。
- **闭环恢复可行**：当低层未到达目标关键帧时，VLM 能依据视觉观测与目标误差重新发起上一关键帧，最终完成任务，体现事件驱动闭环的价值。
- **推理开销低**：VLM 关键帧决策平均 < 0.2 s，重定向约 5 ms，说明高层语义规划不构成实时性瓶颈。

## 7. 方法亮点与创新

- **接口层面**：用"运动关键帧"这一紧凑、语义可命名、物理可执行的中间表示替代连续动作或纯语言目标，天然规避了 VLM 输出与关节控制之间的表示鸿沟。
- **训练层面**：基于加速度显著性 + 周期性腿运动过滤 + 物体运动对齐的关键帧采样，是针对"关键事件帧在数据中稀疏"这一实际痛点的针对性设计，且与推理时 VLM 的关键帧分布假设保持一致。
- **工程层面**：将物体尺寸/位姿归一化映射的重定向公式与阻尼最小二乘 IK 结合，使同一关键帧库可适配不同场景的物体实例；路径规划用曲率受限圆弧/Dubins 路径限制在训练分布内的运动模式，降低分布外风险。
- **系统层面**：非对称 Actor-Critic + 多 Critic 分解奖励 + 域随机化的组合，是把已有 RL 技术系统性组装为可 sim2real 的全身控制器的务实做法。

## 8. 局限性

- 高层仅做**关键帧选择**而非生成新关键帧，能力上界受限于预定义关键帧库；遇到库中无对应语义阶段的任务需人工扩展。
- 真机依赖**外部动捕**估计物体位姿，未验证纯机载视觉下的物体位姿估计，实际部署门槛较高。
- 任务与物体类型单一，未涉及形变物体、铰接物体或需要力控的接触丰富任务。
- 失败恢复机制只是"重发上一关键帧"的简单策略，缺少系统性的恢复动作库与失败模式分析。
- 训练算力、数据采集成本等关键复现信息缺失，可复现性受限。
- 未与 VLA 端到端方法或其它 VLM+RL 分层框架做横向比较，难以判断该方法在更广泛方法谱系中的相对位置。

## 9. 启示与可迁移要点

- **"中间表示的选择"比"模型规模"更关键**：在 VLM 与低层控制之间插入一个物理可执行、语义可标注的紧凑表示（此处是关键帧），能同时降低数据需求与接口复杂度，这一思路可迁移到机械臂、四足、灵巧手等平台。
- **训练分布应对齐推理分布**：如果推理时高层只给出稀疏目标，那么训练采样就应偏向事件帧而非均匀帧——这种"接口感知的数据采样"值得在其他分层系统中借鉴。
- **闭环与恢复应由高层负责**：低层策略只需可靠到达给定目标，失败检测与重规划交给 VLM，分工清晰且易于调试。
- **外推要靠几何变换而非策略本身**：通过重定向 + 路径规划把新场景映射回训练分布内的运动模式，比让策略直接泛化更可控。
