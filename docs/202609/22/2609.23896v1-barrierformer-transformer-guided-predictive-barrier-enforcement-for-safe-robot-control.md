## 摘要
控制障碍函数（CBF）已成为在安全关键机器人中编码和执行状态约束的最常用工具之一。标准 CBF 方法本质上具有短视性，因为它们仅在当前时间步执行安全性。因此，系统可能被推向安全集边界，而在未来某一时间步不存在可行的安全控制。基于模型预测控制（MPC）的方法通过在滚动时域上执行状态约束来解决这一问题。然而，这类方法通常要求已知模型，以便在每个步骤求解约束优化问题，这对实时部署而言计算代价高昂。我们提出 BarrierFormer，一种障碍监督的 Transformer 框架，它通过学习无模型安全策略时编码推演级 CBF 约束来应对这些局限。一个因果 Transformer 编码观测-动作历史，通过动力学头自回归地生成预测推演以替代模型，并通过动作头向标称控制器提供残差修正以替代在线计算。一个作用于局部观测的障碍评论器评估沿该推演的 CBF 约束违反情况，而安全教师则计算满足这些约束的障碍一致动作，作为学习控制策略的直接监督目标。在推理阶段，该策略将观测-动作历史映射为控制动作，无需任何在线优化或模型知识，从而实现实时、无模型的预测性安全约束执行。在用于安全目标导向导航的线性和非线性、2D 和 3D 动力系统上的评估表明，BarrierFormer 在安全率和推理延迟方面优于现有的基于强化学习（RL）、基于扩散、基于 MPC 以及基于 Transformer 的方法。

## Abstract
Control barrier functions (CBFs) have become one of the most popular tools for encoding and enforcing state constraints in safety-critical robotics. Standard CBF approaches are inherently myopic in nature as they enforce safety only at the current time step. Consequently, the system can be driven toward the boundary of the safe set where no feasible safe control exists at a future timestep. Model predictive control (MPC) based approaches address this by enforcing state constraints over a receding horizon. However, such approaches generally require the model to be known for solving a constrained optimization problem at every step, which is computationally expensive for real-time deployment. We propose BarrierFormer, a barrier-supervised transformer framework that addresses these limitations by encoding rollout-level CBF constraints in learning a model-free safe policy. A causal transformer encodes observation-action history, autoregressively generates a predictive rollout through the dynamics head to replace the model, and provides a residual correction to a nominal controller through the action head to replace the online computation. A barrier critic operating on local observations evaluates CBF constraint violations along this rollout, and a safety teacher computes barrier-consistent actions satisfying these constraints as direct supervision targets for the learned control policy. During inference, the policy maps observation-action history to control actions without any online optimization or model knowledge, enabling real-time model-free predictive safety enforcement. Evaluations across linear and nonlinear, 2D and 3D dynamical systems for safe goal-directed navigation demonstrate that BarrierFormer outperforms existing reinforcement learning (RL)-based, diffusion-based, MPC-based, and transformer-based approaches in safety rate and inference latency.

- **任务背景**：安全机器人导航属于"到达-避障"（reach-avoid）问题，控制器既要朝目标推进，又必须避免未来发生碰撞，且需在**部分可观测**（只有自身状态 + 固定感知半径内的 LiDAR 读数，超出半径的障碍几何完全未知）条件下工作。
- **标准 CBF 的短视性（myopia）**：控制障碍函数（CBF）通过单步二次规划（QP）把集合不变性转化为控制输入约束，但只约束**当前时刻**的转移。一个动作可能瞬时安全，却把系统推向未来安全集边界，导致后续 `K_h(x)` 为空、无可行安全控制（Remark 3.1 明确指出这一点）。
- **MPC 类方法的代价**：CBF-MPC / 离散时间 CBF-MPC 在滚动时域上施加约束，缓解了短视问题，但需要**已知精确动力学模型**并在线求解（一般非凸的）约束优化，实时部署计算代价高昂。
- **其他范式的问题**：扩散类方法在推理时通过梯度投影迭代去噪，速度慢；Transformer 策略虽擅长聚合时序信息，但 ConBaT 等方法在部署时仍需轻量梯度优化或安全滤波器，牺牲推理效率。
- **核心科学问题**：能否把"在预测推演上评估的安全约束"**直接编码进策略参数**，使部署时无需任何在线优化或模型知识？
- **整体含义**：论文提出 BarrierFormer，把 CBF 约束从"在线求解的约束"转化为"训练时的监督信号"，实现**无模型、无在线优化的实时预测性安全控制**，在安全率与推理延迟上同时优于 RL、扩散、MPC 与 Transformer 基线。

## 2. 方法论：核心思想与关键技术细节

- **总体框架**：一个"障碍监督"（barrier-supervised）的因果 Transformer 框架，分两步：
  - **Step 1（自回归预测推演）**：因果 Transformer 编码观测-动作历史，经动作头输出对标称控制器的残差修正，经动力学头输出状态增量，自回归生成有限时域推演，用学习模型替代真实模型。
  - **Step 2（安全评估，仅训练时）**：障碍评论器沿推演评估 DTCBF 约束违反，SQP 安全教师生成满足约束的修正动作作为动作头的直接监督目标。
  - **部署时**：策略直接把观测-动作历史映射为控制动作，无在线优化、无模型知识。

- **问题建模**：
  - 动力学 `x_{t+1} = F(x_t, u_t) = f(x_t) + g(x_t)u_t`；观测 `o_t = (x_t, p_goal − p_t, {y_{t,j}})`，LiDAR 射线特征含命中指示、归一化回波距离、射线方向。
  - 安全集 `S = {x | d(p, O_i) ≥ r}`，避障集为补集。
  - 离散时间 CBF（DTCBF）：存在 α 使 `h(o+) − h(o) ≥ −α(h(o))`；采用线性 α(s)=γs 得 `h(o+) ≥ (1−γ)h(o)`。
  - 时域约束（式 6）：`h(o_{t+k+1}) ≥ (1−γ)h(o_{t+k})`，k = 0,…,H−1。
  - **问题 3.1**：设计无模型、历史条件策略 π_θ，使闭环轨迹满足安全性（不碰撞）与活性（收敛到目标）。

- **历史编码与网络结构**：
  - 历史 `H_t = (o_{t−T+1}, u_{t−T+1}, …, o_{t−1}, u_{t−1}, o_t)`，共 T 个观测与 T−1 个动作，交错成 2T−1 个 token。
  - 观测与动作分别经独立线性编码器映射到 d_h 维，加可学习绝对位置编码。
  - 主干为 GPT-2 风格 decoder-only Transformer（pre-LayerNorm、因果掩码、2 注意力头、GELU FFN），取最后 token 的隐表示 `z_t = T_θT(H_t)`。

- **双头预测与推演**（式 8–10）：

  - 动力学头 `d_θx`：MLP 输入 `(z_t, u_t)`，输出状态增量 `Δx̂_t`。
  - 逐步推演：`z_{t+k|t} = T_θT(H_{t+k|t})`，`û_{t+k|t} = μ_nom(x̂) + π_θu(z)`，`x̂_{t+k+1|t} = x̂_{t+k|t} + d_θx(z, û)`。
  - 观测重建：机器人状态与目标相对位置已知；预测 LiDAR 射线利用已遇到障碍的历史数据生成，从而在部分可观测下构造未来观测。

- **障碍评论器 h_φ**：
  - 作用于**局部观测**而非完整环境状态，可直接用于部分可观测场景。
  - 逐时刻违反量 `v_k(o_t) = [(1−γ)h_φ(ô_{t+k|t}) − h_φ(ô_{t+k+1|t})]_+`。
  - 用 log-sum-exp 光滑近似最坏违反：`V(o_t) = (1/β)log((1/H)Σ exp(β v_k))`，β→∞ 时逼近 max，全部满足时 V=0。

- **SQP 安全教师（仅训练时）**：
