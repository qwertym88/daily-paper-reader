## 摘要
神经网络规模通常在训练前选定，这使架构选择与权重优化相分离。我们提出神经发生网络（Neurogenesis Network, NGN），一种可微参数化方法，用于学习模型应使用多少个有序结构组件。对于每个有序组件组，一个可学习边界在模型参数训练时选择激活的前缀。该边界可以从紧凑初始化开始增长，并可通过丢弃学习边界之外的组件来部署。受控实验考察了所学边界的收敛性、部署前缀的性能，以及与固定规模模型和学习容量的替代方法的比较。随后，我们将相同机制应用于 MLP、卷积网络和图网络、Transformer、状态空间模型、LoRA 和适配器。在这些设置中，仅部署所学前缀通常对性能影响很小，且所选架构的表现与以相同规模训练的固定模型相似。这些结果表明，结构容量可以直接作为计数进行优化。

## Abstract
Neural network size is usually chosen before training, separating architecture selection from weight optimization. We introduce the Neurogenesis Network (NGN), a differentiable parameterization for learning how many ordered structural components a model should use. For each ordered component group, one learnable boundary selects an active prefix while the model parameters are trained. The boundary can grow from a compact initialization and can be deployed by discarding components beyond the learned boundary. Controlled experiments examine convergence of the learned boundary, the performance of deployed prefixes, and comparisons with fixed-size models and alternative approaches to learning capacity. We then apply the same mechanism to MLPs, convolutional and graph networks, Transformers, state-space models, LoRA, and adapters. Across these settings, deploying only the learned prefix usually changes performance little, and the selected architectures perform similarly to fixed models trained at the same size. These results show that structural capacity can be optimized directly as a count.

## 1. 核心问题与研究动机

- **根本矛盾**：神经网络规模（宽度、深度、秩等结构维度）通常在训练**之前**人工选定，导致"架构选择"与"权重优化"被人为割裂。选择这些量往往依赖专家经验，或需要对多个候选规模反复训练。
- **理想目标**：有效容量应由数据与任务目标决定，因此模型规模应与权重**联合优化**，而非预先设定。
- **已有四类相关工作及其不足**：
  - **训练后剪枝**（SparseGPT、Wanda、SliceGPT）：从已训练模型出发，依赖独立的打分/重要性估计程序，与学习过程分离。
  - **过完备模型上的学习稀疏化**（Hard-Concrete L0、SoRA）：需要预先设定有限的候选集合，"计数"是大量存活决策的涌现结果，而非直接优化对象。
  - **弹性/自适应计算**（DyLoRA、Adaptive Computation Time）：前者支持多部署尺寸但不给出单一确定分配，后者随输入改变计算量，目标与 NGN 不同。
  - **联合结构学习与生长**（UDN、AWNN）：最接近本文目标，但 UDN 表示的是深度的**分布**、AWNN 从**学习到的衰减率分位数**导出宽度，二者均非直接对"计数"建模。
- **本文主张**：结构容量可以**直接作为一个可微计数**来优化，用一个标量边界控制有序组件序列的激活前缀。

## 2. 方法论：NGN 的核心思想与技术细节

### 2.1 核心表示

- 给定有序候选函数序列 $f_0, f_1, \dots$，部署模型为
  $$y(x) = \sum_{k=0}^{\infty} w_k\, g_k(t)\, f_k(x),\quad g_k(t)\in\{0,1\}$$
  其中固定系数 $w_k$ 决定组件 $k$ 的尺度，$g_k(t)$ 由**共享边界** $t$ 控制，因此被激活的组件构成一个**前缀**。
- 每个"有序组件组"学习**一个**边界 $t$，同一表示即可控制宽度、深度、注意力头数、LoRA 秩、适配器宽度、剪枝块数等不同形式的容量。

### 2.2 松弛与部署（软训练 / 硬部署）

- **松弛门**：$g_k(t) = \mathrm{sigmoid}\big(\beta(t - k + \delta)\big)$，$t = \mathrm{softplus}(\tau) > 0$，取 $\delta = 0.5$。
- $\beta$ 增大时门趋近阶跃函数；在 $f_k(x)$ 幅度随 $k$ 亚指数增长的假设下，被门控的尾部会消失。
- **保留计数** = $\mathrm{round}(t) + 1$；**可部署的硬前缀**为 $y_{\text{hard}}(x;t) = \sum_{k=0}^{\mathrm{round}(t)} w_k f_k(x)$。
- 术语区分：**soft evaluation** 用完整候选模型 + sigmoid 门；**truncation** 用硬前缀。$t$ 是离散计数的连续代理，而非计数本身。

### 2.3 目标函数与梯度机制

- 联合目标：$J = L_{\text{task}} + \lambda t + \alpha \sin^2(\pi t)$
  - $\lambda t$：**容量价格**，惩罚规模；
  - $\alpha \sin^2(\pi t)$：**整数吸附项**，在整数处取极小值，把边界"吸附"到整数上，保证硬截断忠实。
  - 非零 $\lambda$ 会把组合正则的最小点推离整数，因此**标准调度将 $\lambda$ 退火到零**，训练结束时只剩周期项，整数极小值精确。
- **边界梯度**：
  $$\frac{\partial y}{\partial t} = \sum_k w_k \beta\, g_k(t)(1-g_k(t)) f_k(x)$$
  $$\frac{\partial J}{\partial t} = \big\langle \nabla_y L_{\text{task}}, \tfrac{\partial y}{\partial t}\big\rangle + \lambda + \alpha\pi\sin(2\pi t)$$
  由于 $g_k(1-g_k)$ 集中在边界附近，**任务梯度主要由当前"前沿"组件主导**。若招募力不足，容量价格会把 $t$ 向内推。
- **容量递增前提**：若 $H_K$ 为前 $K$ 个函数所表示的假设类，则要求 $H_K \subsetneq H_{K+1}$，即前缀必须真正扩展容量；但 $f_k$ 不必同构。

### 2.4 实现与训练调度

- 实验为简化起见**预先实例化 $K$ 个候选函数**（等价但更复杂的实现可随 $t$ 增长动态分配新权重，形成无界模型，本文未采用）。
- 取 $w_k = 2^{-k}$：既给候选排序、衰减后段函数，又**提升学习边界的稳定性**（§4.3 验证）。
- **$\beta$ 退火至关重要**：早期软门让梯度到达前沿，后期锐门逼近硬前缀；线性 $4 \to 12$ 效果良好。
- $f_k$ 采用零初始化；固定排序已打破函数间对称性，无需差异化初始化尺度。
- **调度策略**：$\lambda$ 幂次/线性衰减到 0；$\alpha$ 延迟启动（训练过半后线性上升），这对 prune-from-high 恢复很关键。
- **PEFT 变体**：LoRA 与适配器使用偏移 $\delta = -0.5$，使 $t=0$ 时保留零个方向/块，硬截断恰好保留 $\mathrm{round}(t)$ 块。

## 3. 实验设计：数据集、场景与对比基线

### 3.1 受控分析（1D 回归）

- **任务**：$y^*(x) = \sin(3x) + 0.6\sin(7x) + 0.3\sin(13x)$，$x \in [-\pi,\pi]$，每个 $f_k$ 为 tanh MLP，$K=32$。
- **实验组**：
  - **$\lambda$ 扫描**：$10^{-6}$ 到 $10^{-2}$，共 **500 个模型**；
  - **调度消融**（10 seed）：baseline / 常数 $\lambda$ / 常数 $\alpha$ / $\alpha=0$ / $\beta=4$ 固定 / $\beta=15$ 固定，并统计"整数率"（最终边界落在整数 0.01 内的百分比）；
  - **容量匹配对比**（50 seed）：NGN 生长模型 vs 从零训练的固定前缀 vs **AWNN、L0（Hard-Concrete）、STE**（三者使用同一 MLP 函数库与相同计数单位）；
  - **增长/剪枝稳定性**：$t_{\text{init}} \in [0,16]$，50 seed/初始化，比较几何权重 $r=0.5$ vs 均匀权重 $r=1$、延迟 $\alpha$ vs 常数 $\alpha$。

### 3.2 内在容量学习

- **非线性流形自编码**：$D \in \{1,2,4,6,8\}$ 维内在维度嵌入 16 维环境空间，通过固定随机正交旋转 + 逐坐标 $\tanh$ 构造；使用 VAE，每个 $f_k$ 贡献一个**秩一瓶颈项**，共 10 项。
- 评价指标：学习到的 $D$ 是否等于真实内在维度、NMSE；共 **50 个 seed–维度案例**。

### 3.3 跨结构、跨任务迁移

- **数据集/任务**：MNIST（tanh MLP 特征、卷积分支）、CIFAR-10（卷积分支）、Cora（2-hop GCN 分支）、TinyStories（注意力头、FFN 块、二者联合、Mamba 状态维度）。

- **PEFT**：**Llama-3-8B-Instruct** 上的 LoRA 秩与适配器宽度，任务为 WikiSQL-easy / WikiSQL-hard / Spider / GSM8K / SQuAD；对比 **SoRA** 与 **AdaLoRA**，并与按学习到的取整分配重训的固定模型对照。
