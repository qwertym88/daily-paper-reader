## 摘要
Actor-Critic 架构已被广泛应用于连续机器人控制。然而，它们依赖于学习一个价值网络，这会在训练过程中引入额外的计算开销。此外，策略学习还可能受到价值估计近似误差的影响。无评论家的组相对策略优化方法通过去除对评论家的需求，提供了一种更简单的训练方式。然而，在密集奖励环境中，直接将即时奖励应用于策略优化时，这类方法无法学习长期动作结果。为解决这些问题，我们提出了组相对回报策略优化（GR2PO），一种面向连续机器人控制的无评论家强化学习框架。GR2PO 从并行采集的轨迹中估计折扣回报，在每个 rollout 时间索引处进行组归一化，并使用相对优势和裁剪目标来更新策略。为评估所提出框架的有效性，我们在机器人控制仿真环境中对其进行实例化，并将模型部署到真实世界边缘设备。结果表明，GR2PO 显著优于使用即时奖励的无评论家基线，并与最先进的 Actor-Critic 方法相比具有竞争力。此外，GR2PO 展现出有竞争力的训练效率。在 NVIDIA Jetson TX2 上的推理测试证明了将学习到的策略部署到边缘平台的可行性。进一步的消融实验分析了并行组大小、回报估计方法和目标裁剪比例对学习性能的影响。为支持后续研究，我们将在论文被接收后公开完整代码，包括框架实现、实验配置以及训练和评估脚本。

## Abstract
Actor-critic architecture has been widely used in continuous robot control. However, they rely on learning a value network, introducing additional computational overhead during training. Moreover, policy learning may also be affected by the approximation error of value estimation. Critic-free group relative policy optimization methods provide a simpler training approach by removing the need for a critic. However, they fail to learn long-term action outcomes when directly applying immediate rewards to policy optimization in dense-reward environments. To address these problems, we propose Group Relative Return Policy Optimization (GR2PO), a critic-free reinforcement learning framework for continuous robot control. GR2PO estimates the discounted returns from the parallelly collected trajectories, performs group normalization at each rollout time index, and uses relative advantages and clipped targets to update the policy. To evaluate the effectiveness of the proposed framework, we instantiate it on robot control simulation environments and deploy the model to a real-world edge device. The results show that GR2PO significantly outperforms critic-free baselines that use immediate rewards and performs competitively against state-of-the-art actor-critic methods. Furthermore, GR2PO demonstrates competitive training efficiency. Inference tests on NVIDIA Jetson TX2 demonstrate the feasibility of deploying the learned policies on edge platforms. Further ablation experiments analyze the effects of parallel group size, return estimation methods, and target clipping ratio on learning performance. To support follow-up research, we will make the complete code publicly available after the paper is accepted, including the framework implementation, experimental configuration, and training and evaluation scripts.

# GR2PO 论文中文总结

## 1. 核心问题与研究背景

- **背景**：连续机器人控制（如四足行走、双足行走、高维人形控制）要求在连续动作空间中做决策，追求长期性能。Actor-Critic（AC）架构长期是主流方案（DDPG、TD3、PPO、SAC），通过价值网络支持策略优化。
- **AC 的痛点**：
  - 除策略学习外还需持续训练价值网络，带来额外计算开销；
  - 策略学习质量受价值估计近似误差影响，AC 的性能在很大程度上取决于 critic 质量。
- **无 critic 路线的机遇与不足**：GRPO 类组相对策略优化在 LLM 中成功，通过组内样本相对表现更新策略、免去 critic。但 LLM 中"完整响应评分"与机器人控制中"单步即时奖励"的时间含义不同——在**稠密奖励**环境下，即时奖励只反映动作的局部效果，无法代表未来反馈，高即时奖励不等于更好的长期结果。
- **动机示例（Fig.1）**：机器人导航中，径直冲向目标短期奖励高但会撞障碍物无法到达；先绕行/重规划会暂时降低即时奖励，却为最终成功创造条件。因此必须把**未来收益（return）**纳入组相对评估。

## 2. 方法论：GR2PO

### 核心思想
将**时序信息（rollout 内的回报）**与**跨 rollout 的相对比较（组归一化）**结合：用逆向折扣累积估计回报，在每个 rollout 时间索引上跨并行轨迹做组归一化构造相对优势，再用裁剪代理目标更新策略，全程不学习价值网络。

### 关键流程与细节

- **问题建模**：连续控制建模为 MDP，状态 $s_t$、连续动作 $a_t$，目标最大化期望折扣回报
  $J(\theta)=\mathbb{E}_{\tau\sim\pi_\theta}\left[\sum_{t=0}^{H_\tau-1}\gamma^t r_t\right]$，$\gamma\in[0,1)$。

- **并行 rollout 采集**：
  - 用旧策略 $\pi_{\theta_{old}}$ 在 $N$ 个并行环境中采集长度 $T$ 的轨迹；
  - 定义并行环境数 $N$ 为**组大小（group size）**；
  - **关键设计**：不同环境在同一时间索引 $t$ 的样本视为一组进行归一化，从而**去除了"同组样本必须共享同一状态"的要求**，可直接与并行采样结合，无需从同一状态做多次分支 rollout。

- **回报估计（逆向折扣累积）**：
  $G_t^{(i)} = r_t^{(i)} + \gamma(1-d_t^{(i)})G_{t+1}^{(i)}$，且 $G_{T-1}^{(i)}=0$。
  - 回合终止时用掩码阻断累积，避免把重置奖励计入上一回合；
  - 未结束但到达 rollout 边界的样本采用**零尾值**，不做价值函数 bootstrap。

- **组相对优势构造**：
  计算每个时间索引 $t$ 的组内均值 $\mu_t$ 与样本标准差 $\sigma_t$，则
  $\hat{A}_t^{(i)}=\dfrac{G_t^{(i)}-\mu_t}{\sigma_t+\delta}$，表示该样本相对同组的未来折扣回报优势。

- **目标裁剪与策略优化**：
  - 概率比 $\rho_t^{(i)}(\theta)=\pi_\theta(a_t^{(i)}|s_t^{(i)})/\pi_{\theta_{old}}(a_t^{(i)}|s_t^{(i)})$；
  - 优势截断 $\tilde{A}_t^{(i)}=\text{clip}(\hat{A}_t^{(i)},-c,c)$；
  - 裁剪代理目标：
    $L(\theta)=\mathbb{E}_D[\min\{\rho_t\tilde{A}_t,\ \text{clip}(\rho_t,1-\epsilon,1+\epsilon)\tilde{A}_t\}+\beta H_\theta(s_t)]$；
  - 采用多轮 mini-batch 优化；采样时的 log 概率与优势保持固定，只更新策略参数；
  - 裁剪目标限制策略过度更新，熵正则鼓励探索，并配合 **KL 监测/早停**。

- **部署侧**：回报估计与组归一化仅用于训练，推理时不引入额外计算。

## 3. 实验设计

- **仿真环境/基准**：MuJoCo 平台的三个连续控制任务——Ant-v5（四足移动）、Walker2d-v5（双足行走）、Humanoid-v5（高维人形控制）；并行采样使用 EnvPool。每回合最长 1000 步，可提前终止。
- **训练预算**：Ant 与 Walker2d 各 80M 环境 transition，Humanoid 为 400M（含所有并行环境转移）。
- **对比方法**：
  - 无 critic 基线 **GRPO**（配置与 GR2PO 相同，仅用即时奖励替代回报计算优势）；
  - 最先进 AC 方法 **PPO**（on-policy 代表）与 **SAC**（off-policy 代表）。
- **随机性控制**：统一随机种子 42–46（共 5 个种子），结果以均值 ± 样本标准差报告。
- **评估方式**：训练回报取最后 100 个完成回合的平均累计回报；控制性能通过独立评估学习到的策略来衡量。
- **消融实验**：
  1. **组大小**：$N=16/64/256/1024$，在固定总 transition 预算下相应调整 minibatch 大小与更新 epoch；
  2. **回报估计方法**：Monte Carlo（MC）vs. 使用组统计基线的 GAE 变体；
  3. **目标裁剪比例**：$\epsilon=0.2/0.4/0.6$ 及无裁剪（保留优势截断与 KL 早停）。
- **边缘部署实验**：NVIDIA Jetson TX2 上分别在 CPU 与 CUDA 后端测试 Ant/Walker2d/Humanoid 策略推理，比较 GR2PO、PPO、SAC 的参数量、模型大小与推理延迟（batch size=1，确定性 FP32 输出，含预处理与设备传输/同步，不含仿真与传感器延迟）。

## 6. 主要结论与发现

- **相对即时奖励基线**：GR2PO 在所有任务上显著优于即时奖励的 GRPO 基线（后者训练回报始终很低），验证了将未来回报引入组相对优势估计的必要性。
- **相对 AC 方法**：GR2PO 在 Ant、Walker2d 上达到可比的训练回报与评估回报；在 Humanoid 上评估回报优于 SAC 但低于 PPO。最终确定性评估中 Ant/Walker2d/Humanoid 平均回报分别为 6335.25、5023.95、8330.68。
- **稳定性**：GR2PO 评估回报的标准差在所有任务上低于 SAC，跨种子稳定性更好。
- **训练效率**：相比 SAC，GR2PO 在三个环境中总 wall-clock 时间更短且性能具竞争力；相比 PPO，在 Walker2d 与 Humanoid 上总训练时间更少。
- **消融发现**：
  - **组大小**：小组收敛快但上限低；大组需更多交互才显现优势，未必在有限预算内最优；中等组大小最终回报最高。
  - **回报估计**：MC 支持持续策略改进，GAE 变体几乎学不到有效策略（与即时奖励基线相当），故 MC 作为默认方法。
  - **裁剪比例**：中等裁剪（如 $\epsilon=0.4$）最好；过小限制样本贡献、过大会削弱概率比约束；完全无裁剪也不够好，说明仅靠组相对优势不足，需配合合适裁剪。
- **边缘部署**：GR2PO 训练的策略可在 Jetson TX2 上低延迟推理；对轻量策略网络，GPU 不一定比 CPU 延迟更低；由于部署时只需 actor，critic-free 设计简化了训练流程。

## 7. 优点

- **方法简洁有效**：完全去除 critic，避免价值网络训练开销与价值估计误差对策略学习的干扰，同时通过回报估计解决稠密奖励下的长期信用分配问题。
- **优势构造机制新颖**：以"时间索引 + 并行环境"定义组，去除同组样本共享同一状态的要求，天然适配并行采样，无需同状态分支 rollout，工程上更易实现。
- **训练稳定性设计完整**：优势截断 + 裁剪代理目标 + 熵正则 + KL 早停，多机制协同保障更新稳定。
- **实验维度较全面**：性能、稳定性、时间效率、真实边缘硬件推理、系统消融；统一种子与预算、报告标准差，比较相对客观。
- **部署可行性验证**：把"可训练"推进到"可部署"，提供硬件层面的实证，具有工程参考价值。
- **可复现性承诺**：承诺接收后公开完整代码、实验配置与训练评估脚本。

## 8. 不足与局限

- **任务覆盖有限**：仅 3 个 MuJoCo 运动控制仿真任务，未覆盖操作、导航、多任务或高难度真实机器人任务，泛化性未知。
- **闭环控制未验证**：边缘部署只测了策略推理延迟，未做闭环控制性能验证，也未在真实机器人上实验。
- **超参敏感性**：组大小需与更新配置（minibatch、epoch）匹配，裁剪比例存在最优区间，说明方法对关键超参较敏感，调参成本可能较高。
- **效率结论有条件**：作者自述训练效率受采样规模和策略更新配置共同影响；早期学习速度上 PPO 在部分任务更快。

- **无理论保证**：未提供组归一化回报作为优势估计的无偏性或收敛性分析。
