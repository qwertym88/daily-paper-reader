## 摘要
人形运动需要控制策略在不完美感知下保持稳定，同时利用时间上下文实现一致的运动。我们提出了RoboDreamer，一个两阶段师生框架，结合了下一观测一致性与随机连续时间掩蔽。首先在干净观测上训练教师，然后在掩蔽最近观测的情况下蒸馏学生，鼓励策略从历史中推断缺失的当前信息。在推理时，复用相同的掩蔽接口进行隐式闭环动作细化和可选的多步动作分块。使用Mamba作为时间骨干，而匹配的消融实验表明，掩蔽/蒸馏提供了大部分增益，Mamba贡献了额外的跟踪改进并具有实时延迟。在IsaacLab、MuJoCo和Unitree G1上的实验证明了在观测掩蔽下的鲁棒运动跟踪和成功的实际部署。

## Abstract
Humanoid locomotion requires control policies that remain stable under imperfect sensing while exploiting temporal context for consistent motion. We present RoboDreamer, a two-stage teacher--student framework that combines next-observation consistency with randomized continuous temporal masking. A teacher is first trained on clean observations, and a student is then distilled under masked recent observations, encouraging the policy to infer missing current information from history. At inference, the same masking interface is reused for implicit closed-loop action refinement and optional multi-step action chunking. Mamba is used as the temporal backbone, while matched ablations show that masking/distillation provides a substantial part of the gain and Mamba contributes additional tracking improvements with real-time latency. Experiments in IsaacLab, MuJoCo, and on a Unitree G1 demonstrate robust motion tracking under observation masking and successful real-world deployment.

## 1. 论文的核心问题与整体含义

人形机器人运动控制通常被建模为“从最近观测到电机指令”的反应式映射。这类策略在感知信号干净时表现良好，但一旦观测流出现中断——如传感器丢失、通信延迟、数据包丢失或瞬时损坏——其稳定性会显著下降。论文指出，人类在感官信息暂时缺失时并不会立刻失去平衡，而是会利用运动历史和物理连续性来推断当前状态、预判近未来演化。因此，**核心问题是：如何使人形控制策略具备“预期式”的时间推理能力，即便在不完美感知条件下也能保持鲁棒的运动跟踪？**

- 现有MLP类策略计算高效，但缺乏从时序上下文重构缺失状态的显式机制；
- Transformer策略具备较强序列建模能力，但自注意力二次方复杂度限制了高频控制下的长历史使用；
- 尽管Mamba等选择性状态空间模型已被用于机器人控制，但“替换骨干网络本身并不能教会策略在观测缺失下推理”。

RoboDreamer的提出动机是：**控制器不仅应消费历史观测，更应被显式训练以从历史中推断缺失的物理状态，并预测系统在时间上的局部演化**——即从“反应式感知”转向“预测式物理智能”。

## 2. 论文提出的方法论

### 2.1 核心思想
RoboDreamer是一个**两阶段教师-学生蒸馏框架**，围绕两个关键设计展开：
1. **随机连续时间掩蔽**：在训练中随机遮挡最近的若干观测，迫使策略从历史中“补全”当前状态；
2. **下一观测一致性目标**：约束策略的隐状态对近未来物理演化保持信息量。

这两者有机结合：掩蔽训练策略从残缺观测中推断现在，一致性损失约束隐状态能预测未来。训练好的掩蔽语义在推理阶段被复用，支持隐式闭环修正与多步动作分块。

### 2.2 问题形式化与状态空间骨干
- 将人形运动建模为部分可观测马尔可夫决策过程，策略将历史观测序列映射为动作；
- 采用**Mamba**作为时序骨干，其选择性扫描机制由连续时间线性系统描述：

```
h'(t) = A·h(t) + B·x(t)， y(t) = C·h(t)
```

经数据相关的离散化步骤转化为离散递推。策略维持随时间演化的隐状态，既编码历史又支持预测。

### 2.3 阶段一：教师策略训练（长期上下文）
- 训练基于Mamba的跟踪策略，使用35帧（0.7秒@50 Hz）的历史观测窗口；
- 采用**双头架构**：动作头（PPO优化）+ 辅助观测头（预测下一时刻观测）。
- **一致性损失**：

```
L_cons = E[ || Ψ(h_t) − o_{t+1}^GT ||² ]
```

该目标使隐状态蕴含因果的物理表征，获得精确刻画目标运动流形的教师策略π_T，为后续蒸馏提供稠密监督信号。

### 2.4 阶段二：学生策略训练（掩蔽预测蒸馏）
- **观测掩蔽**：对每个环境以概率ρ激活掩蔽，随机选择m∈{1,...,5}，将末尾m帧观测替换为可学习的[Mask] Token。其目的是让Mamba骨干学会从“反应式倾听者”转变为“主动预测者”。
- **监督蒸馏损失**：

```
L_distill = E[ || π_S(O_masked) − π_T(O_full) ||² ]
```

学生策略在部分观测下模仿教师的完整观测动作输出，同时继续优化一致性损失。采用教师-学生蒸馏而非直接在RL中施加极端噪声，是为了避免高维强化学习中的梯度不稳定与灾难性发散问题。

### 2.5 推理范式：复用掩蔽语义
训练学到的“掩蔽→推断”能力在推理阶段被复用为两种策略：

| 范式 | 做法 | 特点 |
|------|------|------|
| **显式动作分块** | 在历史后拼接k个[Mask] Token，一次前向得到未来k+1个动作 | 降低感知频率；但k增大时开环漂移累积，降低反应性 |
| **隐式动作精化** | 拼接单个[Mask] Token，提取三元组{a_{t−1}, a_t, a_{t+1}}，取平均作为当前动作 | 
```
ā_t = (1/3)(a_{t−1} + a_t + a_{t+1})
```
| 保留闭环反馈的同时利用时间预测，动作更平滑稳定 |

## 6. 论文的主要结论与发现

1. **掩蔽/蒸馏是RoboDreamer的核心贡献**，相对于骨干替换贡献了大部分鲁棒性增益；在MLP、Transformer、GRU、LSTM上应用相同掩蔽蒸馏训练均未能达到Mamba骨干的效果，证明两者相互配合。
2. **Mamba在匹配设置下提供额外跟踪-延迟优势**，其推理延迟接近MLP（4.4ms vs 3.5ms），远优于Transformer（9.8ms），同时FLOPs低于Transformer（43.1M vs 58.8M）。
3. **历史窗口长度以h=35（0.7秒）为最优**——过短不足以推断缺失状态，过长不带来额外收益且增加计算负担。
4. **掩蔽概率上限c=0.5为最优**，更高掩蔽率（0.6）导致训练信号过弱、泛化下降。
5. **一致性损失对多步动作分块尤为关键**：随动作块k增大，有无一致性损失的性能差距扩增，说明预测式物理表征是长时间外推的基础。
6. **动作块大小存在权衡**：k≤3时保持稳定，k>3时累计漂移超过物理稳定边界（实机摔倒）。
7. **隐式动作精化（k=3取平均）优于直接执行更长开环块**，在保持闭环反馈的同时利用时间一致性。

## 7. 优点

1. **问题定位精准**：从“观测缺失下人形机器人易失稳”出发，将时序推理定义为需要显式训练的能力而非架构附带属性，切入点有价值。
2. **简洁自洽的训练框架**：两阶段掩蔽蒸馏合理规避了RL在极端噪声下的训练不稳定性，使“从历史推断缺失”成为结构化学习目标。
3. **掩蔽语义“一次训练、两处复用”**：将训练时的状态推断能力自然延伸到推理时的闭环精化与动作分块，无需额外规划器或轨迹生成模块，设计优雅统一。
4. **方法论贡献独立于骨干网络**：通过与MLP/Transformer在相同掩蔽训练下的对照，严谨地区分了“骨干贡献”与“训练框架贡献”，方法论表述清晰。
5. **评估链条完整**：IsaacLab（大规模并行训练）→ MuJoCo（跨模拟器泛化）→ Unitree G1（真实部署）的三级验证是机器人学习领域较全面的评估范式。
6. **消融较为系统**：骨干类型、历史长度、掩蔽概率、动作块大小、层数、损失分量均有覆盖，且各因素均有性能趋势解释。

## 8. 不足与局限

1. **掩蔽接口的相对简化**：训练和推理都采用随机连续时间掩蔽模式，但实际部署中传感扰动的模式可能更复杂（如非连续突发、偏置噪声、视觉遮挡等），论文未系统覆盖。
2. **实物评估未注入系统扰动**：作者自述“当前实机评估限于Unitree G1且未系统注入传感扰动”，换言之，观测掩蔽下的鲁棒性优势主要在仿真中被量化验证。
