## 摘要
为了让仿人机器人在日常环境中发挥作用，它们必须执行多种将运动与操作耦合在一起的任务。现有方法通常通过奖励工程或演示来获取运动-操作策略，然后进行任务特定训练，这使得扩展到新任务的成本很高。在这项工作中，我们提出了一种用于仿人机器人运动-操作的分层方法，消除了这些针对每个任务的需求。HuGo，即 Humanoid policy code Generation（人形机器人策略代码生成），利用大型语言模型（LLM）在冻结的低层全身策略之上，根据任务描述生成可执行、闭环的高层策略代码。给定任务、观测和命令规范，LLM 用代码构建任务逻辑。HuGo 随后利用数值轨迹和选定视频帧从其 rollout 中细化策略，以产生反馈和有目标的代码更新。在五个仿真任务中，使用两种不同的低层策略，HuGo 显著优于高层强化学习基线，并接近基于演示的基线的性能。我们在没有任务特定奖励设计或演示收集的情况下达到了这一性能水平。我们进一步展示了将仿真生成的策略零样本迁移到硬件，并表明将相同的细化循环应用于真实世界 rollout 可以进一步提高迁移性能，而无需专家演示或策略重新训练。项目网站是 https://iconlab.negarmehr.com/HuGo/

## Abstract
For humanoids to be useful in everyday environments, they must perform a wide range of tasks that couple locomotion and manipulation. Existing approaches commonly acquire a loco-manipulation policy through reward engineering or demonstrations followed by task-specific training, making it costly to scale to new tasks. In this work, we propose a hierarchical approach to humanoid loco-manipulation that eliminates these per-task requirements. HuGo, Humanoid policy code Generation, uses a Large Language Model (LLM) to generate executable, closed-loop high-level policy code from a task description on top of a frozen low-level whole-body policy. Given the task, observation, and command specifications, the LLM constructs the task logic in code. HuGo then refines the policy from its rollouts using numerical trajectories and selected video frames to produce feedback and targeted code updates. Across five simulation tasks, using two different low-level policies, HuGo substantially outperforms a high-level reinforcement learning baseline and approaches the performance of a demonstration-based baseline. We achieve this level of performance without task-specific reward design or demonstration collection. We further demonstrate zero-shot transfer of simulation-generated policies to hardware and show that applying the same refinement loop to real-world rollouts can further improve transfer performance without expert demonstrations or policy retraining. ## 2. 方法论

- **核心思想**：采用分层结构。低层策略 \(\pi_l\) 冻结，接受高层命令；高层策略 \(\pi_h\) 由 LLM 生成代码实现，每个时间步读取观测并输出命令。LLM 不实时控制机器人，而是编写可高频运行的策略代码。
- **命令接口**：
  \[
  a_h = [a_{base}, p_{Lee}, p_{Ree}, z_{body}] \in \mathbb{R}^{10}
  \]
  其中 \(a_{base}\) 表示平面运动与朝向，\(p_{Lee}, p_{Ree}\) 表示左右末端执行器目标位置，\(z_{body}\) 表示期望身体高度。命令限制和坐标框架由低层策略决定，并写入提示。
- **策略表示**：
  \[
  (a_h^t, m^t) = \pi_h(o^t, m^{t-1})
  \]
  策略代码可维护内部状态 \(m^t\)，例如阶段机、上一时刻命令、平滑信息等，从而形成闭环策略。
- **问题目标**：
  \[
  \pi_h^\star = \arg\max_{\pi_h} \mathbb{E}_{x_0 \sim \rho}[S(R(\pi_h, \pi_l; x_0))]
  \]
  即最大化任务成功函数 \(S\) 在随机初始状态分布 \(\rho\) 下的期望。
- **零样本策略生成**：提示词包含任务描述、机器人信息、观测说明、低层命令接口说明，不包含演示、示例代码、动作序列或参考实现。LLM 生成初始策略代码 \(\pi_h^0\)。
- **Rollout 评估与反馈**：
  - 在 \(M\) 个初始状态上评估当前策略，得到成功率，但成功率只说明“是否成功”，不说明“为何失败”。
  - 选择首个失败 rollout，记录观测、内部状态和视频帧。
  - LLM 生成针对当前 rollout 的可执行分析函数 \(f_{analyze}\)，对完整轨迹返回数值摘要 \(D\) 和任务相关关键帧索引。
  - 在固定帧预算 \(B\) 下，若关键帧不足，则用均匀采样帧补齐，兼顾关键事件与时间覆盖。
  - LLM 根据提示、策略代码、数值摘要、轨迹样本和视频帧，生成自然语言反馈 \(F\)，描述执行过程和可能失败原因。
- **迭代代码精化**：
  - 不重新生成整个策略，而是让 LLM 基于反馈生成局部代码差异 \(\Delta\)，保留有效逻辑。
  - 采用“深度”和“轮次”结构：每个深度最多 3 轮尝试；若某轮候选成功率提升，则接受并进入下一深度；否则记录失败 diff、成功率和反馈，供后续避免重复。
  - 终止条件：达到 100% 成功、达到最大深度 \(D_{max}\)，或一个深度内 3 轮均失败。最终返回最佳策略。
- **Best-of-N 选择**：由于 LLM 生成随机性大，独立运行完整流程 \(N\) 次，每次从新的零样本策略开始，选择成功率最高者。文中操作点选 \(N=10\)。

## 3. 实验设计

- **仿真平台与机器人**：Unitree G1 人形机器人，IsaacSim 仿真，单张 NVIDIA L40S GPU。
- **任务 Benchmark**：自定义五个室内全身运动-操作任务，均随机化机器人、物体和目标初始位姿：
  - **Low Gate Passing, LGP**：降低身体高度穿过两个低门。
  - **Narrow Gate Passing, NGP**：侧身穿过两个窄门。
  - **Push Button, PBT**：接近按钮并用末端执行器按下。
  - **Push Box, PBX**：将箱子推向目标 10 cm 内并保持 1 秒。
  - **Lift Box, LBX**：接近讲台上的箱子，抓取并抬升到 1.0 m 以上。
- **两种冻结低层策略**：
  - **rl_isaac**：用稠密奖励训练的 RL 低层策略，命令包含平面线速度/偏航速度、躯干坐标系末端目标、躯干高度。
  - **sonic**：SONIC 3 点 VR 运动跟踪策略，命令包含平面线速度、偏航朝向、骨盆坐标系末端目标、骨盆高度。因不能边走边改变高度，未在 LGP 上评估。
- **对比基线**：
  - **High-level RL**：用 PPO 训练 384M 环境步，使用相同观测、命令空间和低层策略，但每个任务手工设计稠密奖励。
  - **HDMI**：基于人类视频演示的全身交互控制方法。仅在两个任务上比较：
    - **PDH**：开门并穿过。
    - **CPB**：抓取面包箱、搬运并放置。
  - 这两个任务固定机器人与物体初始相对位姿；CPB 中降低了箱子质量以适应低层策略。
- **评估协议**：
  - 主结果使用 100 个未参与策略精化或 best-of-N 选择的 held-out 初始状态。
  - 每个任务独立生成并精化 30 个策略，报告 best-of-10 结果，并对 2000 个随机 10 策略子集取平均。
  - 生成策略代码在 rl_isaac 下 50 Hz 运行，在 sonic 下 10 Hz 运行。
  - 使用 gpt-5.4 作为 LLM，评估器每个 rollout 接收 \(B=10\) 帧，最大精化深度 \(D_{max}=7\)，每深度 3 轮。
- **消融实验**：
  - 比较零样本、仅文本轨迹、仅均匀帧、仅关键帧、关键帧 + 均匀帧。
  - 选择除 LGP 外零样本成功率接近 0 的策略，用 rl_isaac 重复精化，每任务 5 次运行。
- **硬件实验**：
  - Unitree G1，使用与仿真相同的 sonic 低层策略，观测来自运动捕捉系统。
  - 零样本迁移评估 PBT 和 LBX，每任务部署仿真成功率最高的 3 个策略代码，每个 15 次试验。
  - 对迁移后表现最差的 PBT 策略直接在硬件上运行精化循环，每个候选评估 10 次试验。
