## 摘要
深度神经网络架构被广泛用于自动疼痛评估系统中的信号处理。然而，尽管神经架构搜索（NAS）可能带来效率收益，架构设计在很大程度上仍依赖人工。将 NAS 嵌入留一被试（LOSO）评估的计算成本很高，因为完全嵌套的实现需要 N 次独立的架构搜索，并且在训练成本近似线性的假设下，其规模为 O(N²)。我们提出一种基于块的、控制泄漏的方法，在被试之间共享 NAS 运行，将搜索次数从 N 减少到 B（其中 B << N），称为 PainNAS。在 BioVid Heat Pain 数据集上，PainNAS 以显著更少的参数量和 FLOPs 取得了相当的被试级准确率。

## Abstract
Deep neural architectures are widely used for signal processing in automated pain assessment systems. However, architecture design has remained largely a manual task despite the potential efficiency benefits of Neural Architecture Search (NAS). Embedding NAS in a Leave-One-Subject-Out (LOSO) evaluation is computationally demanding because a fully nested implementation requires $N$ independent architecture searches and, assuming approximately linear training cost, scales as $\mathcal{O}(N^2)$. We propose a block-based, leakage-controlled approach that shares NAS runs between subjects, reducing the number of searches from $N$ to $B$, where $B \ll N$, dubbed PainNAS. On the BioVid Heat Pain dataset, PainNAS yields comparable subject-level accuracy with substantially fewer parameters and FLOPs.

## 1. 核心问题与整体含义

- **研究背景**：自动疼痛评估通过 EMG、EDA、ECG 及视频等生理信号识别被试的疼痛水平，近年已从手工特征转向深度/混合模型。然而，网络架构设计仍主要依赖人工，神经架构搜索（NAS）虽有望自动化这一过程，却难以落地。
- **核心障碍**：疼痛评估普遍采用**留一被试（LOSO）交叉验证**作为受试者独立评估协议，以避免模型选择与性能评估共用同一重采样带来的乐观偏差。若将 NAS 完全嵌套进 LOSO，需要为 N 个被试各做一次独立架构搜索，总训练成本近似按 **O(N²)** 增长（N 次搜索 × 每次约 O(N) 训练成本），在 BioVid 这类 N=87 的数据集上代价高昂。
- **关键问题**：如何在 LOSO 协议下实现**既无数据泄漏、又计算可行**的 NAS，并回答三个研究问题——(RQ1) 无泄漏 NAS 能否优于人工设计架构；(RQ2) PainNAS 在搜索成本与 LOSO 泛化性能之间的权衡如何；(RQ3) 跨被试块与分类设置下哪些架构特征被一致选中。
- **整体含义**：作者主张将搜索次数从 N 降到 B（B≪N），在保持无泄漏与 LOSO 泛化能力的同时大幅降低算力与推理开销，为多通道生物医学信号处理提供资源感知的 NAS 方案。

## 2. 方法论（PainNAS）

### 核心思想
- 将受试者集合 S 划分为 B 个互不重叠的**外层块** G₁,…,G_B；对每个外层块 b，NAS 仅在训练集 T_b = S \ G_b 上进行，从而保证该块内所有被试都未参与为其选架构的搜索，实现**泄漏受控**。
- 块内被试**共享**同一次 NAS 搜索得到的架构 a*_b，将独立搜索次数由 N 降为 B。

### 关键流程（Algorithm 1）
1. 将 S 划分为 B 个外层块 G₁,…,G_B；
2. 对每个外层块 b：
   - 排除 G_b，将 S \ G_b 划分为 K 个**被试不相交的内层折** F₁,…,F_K；
   - 对每个候选架构 a：依次在 K−1 折上独立初始化并拟合，在剩余折上验证，得到内层折结果；
   - 依据选择目标 J_b(a) 选出最优架构 a*_b；
3. 对 G_b 中每个 LOSO 目标被试 j：用 S\{j} 训练 a*_b，并在被试 j 上评估一次；
4. 返回所有目标被试的平均 LOSO 准确率。

### 选择目标（Eq. 4–6）
- 平均被试级验证准确率：Ā_b(a) = (1/N_b) Σ_{i∈T_b} A_i(a)
- 样本标准差：σ̂_b(a) = sqrt[ (1/(N_b−1)) Σ_{i∈T_b} (A_i(a) − Ā_b(a))² ]
- 选择分数：**J_b(a) = Ā_b(a) − β · σ̂_b(a)/√N_b**，其中 β 控制方差惩罚强度，实验取 β = 1.0。
- 该目标同时奖励高平均准确率、惩罚高被试间方差，引导选择更稳健、更高效的架构。
- 搜索后保留验证分数最高的检查点，再在全部 86 个非目标被试上额外训练 M 个 epoch（M 取早停前搜索阶段的中位 epoch 数），最后在被试 j 上评估一次。

### 复杂度
- 完全嵌套：T_LOSO-NAS = N[T_NAS(N−1) + T_fit(N−1) + T_test(1)] ∈ O(N²)；
- PainNAS：T_PainNAS = B·T_NAS(N − N/B) + N[T_fit(N−1) + T_test(1)] ∈ O(N²)；
- 整体仍为 O(N²)（因最终仍需 N 次拟合与评估），但**搜索项**由 N 次降为 B 次，实际运行时间显著下降。

### 架构空间
- 使用 Optuna（TPE 采样器），搜索：卷积块数 3–5、每块重复数 1–2、宽度乘子 {0.5, 1, 2}、卷积核大小 {7, 11, 15}、卷积类型、归一化与池化类型、分类器深度与宽度、学习率（10⁻⁵–10⁻³ 对数尺度）。
- 晚期融合（LF）设置中将 EMG 与 ECG 分支架构镜像以缩小搜索空间；最多训练 30 个 epoch，batch size 128，早停；中间折后使用 successive-halving 剪枝。

- **任务设置**：二分类（Binary）与多分类（Multi-Class, MC）。
- **主要消融/变量**：

  - 选择目标 β=1.0 与 β=0 对比；
  - 早/晚融合两种融合范式。
- **评价指标**：平均 LOSO 准确率（含标准差）、F1、推理算力（MFLOPs）、参数量、被试级准确率分布。
