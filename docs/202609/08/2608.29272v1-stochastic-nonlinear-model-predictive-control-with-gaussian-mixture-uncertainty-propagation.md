## 摘要
我们提出了一种针对带有加性噪声的非线性系统的新的随机非线性模型预测控制（SNMPC）框架。基于非线性不确定性传播的最新进展，我们证明了系统状态分布可以随时间用高斯混合分布进行可处理的近似，并具有Wasserstein距离下的形式误差界。这种表示产生了期望成本和机会约束的闭式表达式，这些表达式对于仿射约束是精确的，对于二次成本则是精确到一个常数。因此，所得控制问题可以通过非线性规划高效求解，同时提供正确的形式开环保证和渐近最优性。在一组基准测试上的实验表明，所提出的方法在多模态扰动的非线性场景中与现有方法相比具有优势，而标准方法会导致尺度不佳的解决方案以及不安全或过度保守的控制动作。

## Abstract
We propose a novel Stochastic Nonlinear Model Predictive Control (SNMPC) framework for nonlinear systems with additive noise. Building on recent advances in nonlinear uncertainty propagation, we show that the state distribution of the system can be tractably approximated over time by Gaussian mixture distributions, with formal error bounds in Wasserstein distance. This representation yields closed-form expressions for expected costs and chance constraints, which become exact for affine constraints and exact up to a constant for quadratic costs. Consequently, the resulting control problem can be solved efficiently via nonlinear programming, while providing formal open-loop guarantees of correctness and asymptotic optimality. Experiments on a set of benchmarks demonstrate that the proposed approach compares favorably with existing methods in nonlinear settings with multi-modal disturbances, where standard approaches lead to poorly scaled solutions and unsafe or overly conservative control actions.

### 背景

现代自主系统（如机器人、无人机、自动驾驶车辆）在现实环境中的运行面临大量随机性，主要体现在以下来源：
- **环境不确定性**：真实场景中的传感器噪声、过程扰动是不可避免的；
- **数据驱动方法引入的不确定性**：机器学习方法依赖有限数据和统计近似，增加了额外的随机性；
- **状态估计误差**：噪声环境下需要估计技术，进一步增加了系统随机性。

### 核心问题

对于含加性噪声的非线性系统，如何设计一种高效的随机非线性模型预测控制（SNMPC）框架，使其具备以下特性：

1. **能够处理非高斯、多模态扰动分布**——现有方法大多假设高斯噪声或单模态分布；
2. **有形式化误差保证**——非启发式的可靠性，避免安全性无保障；
3. **计算上可扩展**——能够实际部署于控制场景；
4. **不保守或过于保守**——在安全性与最优性之间取得合理平衡。

### 现有方法的瓶颈

| 方法类别 | 代表性做法 | 主要缺陷 |
|---------|-----------|---------|
| 矩传播 / 无迹变换（UT）类 | 仅传播前二阶矩并做局部线性化 | 忽略高阶效应，存在引入的近似误差但无显式误差界 |

### 论文的定位与意义

本论文提出统一方案：利用高斯混合分布传播状态分布，推导 **Wasserstein 距离下显式的（可计算）误差界**，结合局部线性化得出期望成本与机会约束的闭式近似，将随机最优控制问题转化为高效求解的 NLP 问题。有别于分布鲁棒 MPC 中 Wasserstein 球的一般的真实分布不确定建模，这里的 Wasserstein 半径是一个可控的近似误差刻度，提供了不同于已有文献的视角。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 总体框架

考虑离散时间随机系统：

**x_{t+1} = f(x_t, u_t) + η_t**

- x_t ∈ R^{nx}：状态；
- u_t = π(x_t, θ_t)：控制策略，θ_t ∈ Θ 为待优化参数（可表示开环 u=θ 或状态反馈 u=Kx+v 等形式）；
- η_t：i.i.d. 加性扰动，服从高斯混合分布（各分量协方差相等且对角）；
- 完整状态可观测。

模型预测控制的目标是在滚动时域内，找到最优策略参数序列，在满足机会约束的前提下最小化期望成本。

### 核心思想

**用可控误差的高斯混合分布近似状态分布**，主要步骤：

1. **将状态分布（高斯混合）在每一时刻离散化**为有限支撑的离散分布，并利用一步转移核为一个高斯混合这一关键性质，将下一时刻状态表示保持为高斯混合形式。离散化过程识别当前混合分布的众数（modes），拟合每个众数的局部高斯，用空间中的矩形网格生成支撑点，并推导对应的 Voronoi 区域概率闭式解。

2. **递归传播近似**：每一步递推保持形式为高斯混合分布，分量数保持固定（M = m · m_η），从而计算量与时间步长成比例关系而不爆炸。

3. **形式误差上界**：在整个传播过程中可计算每一步近似分布与真实分布之间的 2-Wasserstein 距离的上界 β_{k|t}，并作为受控系统策略参数的函数对其进行追踪。

### 关键技术细节

#### （1）高斯混合的传播与动态特性

高斯混合分布等同于权重向量 w_{k|t} 与均值集合 μ_{k|t} 的组合。通过离散化与一步转移核的卷积：

- 权重的演化是一个线性更新：w^{(i,j)}_{k|t} = w^{(j)}_η · P̂_{x_{k|t}}(R^{(i)}_{k|t})，其中 R 是在位置 c 上的 Voronoi 区域的集合；
- 均值的演化是确定性函数在支撑点处的映射：μ^{(i,j)}_{k|t} = f_π(c^{(i)}_{k|t}, θ_{k|t}) + μ^{(j)}_η。

#### （2）期望成本的闭式近似

代价被表达成对高斯混合分布的每个分量的期望。使用一阶泰勒展开式（以每个高斯分量的均值为中心）得到：

E_{N(μ,Σ)}[ℓ_k(x)] ≈ ℓ_k(μ)

对于二次型成本 ℓ_k(x) = ‖x − r_k‖²_{Q_k} + b_k，这一期望实际上有一个精确闭式等式：

E_{N(μ,Σ)}[ℓ_k(x)] = ℓ_k(μ) + Tr(Q_k Σ)

因此存在精确的常数偏移与精确的逼近。

**Proposition 1** 提出：当且仅当是二次成本时，期望利润有精确的表达式；此外，其与真实成本 JP 的偏差由 Wasserstein 误差界 β_{k|t} 所限制。

#### （3）机会约束的重构

**原始机会约束**：P_{x_{k|t}}(h(x_{k|t})≤0) ≥ 1 − ε_k。

在这个近似中，替换后的约束是用每个高斯分量下的概率来计算的：

P̂_{x_{k|t}}(h(x_{k|t}) ≤ 0) = Σ_l w^{(l)}_{k|t}·Φ(−h(μ^{(l)}_{k|t}) / ‖∇h(μ^{(l)}_{k|t})‖_{Σ_η})

- 对于仿射约束 h，这是一次精确的重构（因为泰勒展开无误差）；
- 对于非线性约束，则是启发式的一阶近似；
- **Proposition 2** 指出，对仿射约束而言，真实概率与近似概率间平方差的界为：|P − P̂|² ≤ (√(2/π) / ‖a‖_{Σ_η}) · ‖a‖ · β_{k|t}。

#### （4）重构后的优化问题

将上述代入原问题之后，可得到最终的近似 NLP（优化问题 29）：
- 优化变量为策略参数序列 θ_{·|t} 和混合参数序列 z_{·|t}；
- 目标函数：期望经过混合分布的加权的近似成本；
- 引入一致的初始化约束、传播约束与机会约束；
- 约束的可靠性可通过选择更强的不确定性参数和更大的 M 值来增强。

**Theorem 1（正确性与最优性）** 表明：
- 在 f 全局 Lipschitz、约束仿射、成本二次条件下，给定任何 ε̄_k < ε_k（保守的概率阈值），以及足够大的 M 值，几乎所有近似问题（29）的可行解都可行于原问题（3）的可行集合；同时近似问题的最优解距离原问题最优解有一个可量化的上界。

**推论（渐近收敛）** 是当 M→∞ 时近似问题与原始问题的 gap 也会降至零。

#### （5）实际求解细节

- 使用 SQP 方法求解；
- 为了保持计算模型可用，在优化时将模式数量、局部协方差与网格设定为常数；仅在每次 SQP 循环的规划前更新这些参数；

## 6. 论文的主要结论与发现

- 提出基于高斯混合传播的 SNMPC 框架在**多模态非线性扰动**下能产生“成本优且满足约束”的控制行为；
- 相较于矩传播/高斯近似方法，该方法**避免了过度保守策略**；
- 对比场景方法，其使用极少分量数（m=3）即获得了类似的性能；
- 在单模态扰动下，情景法与所提方法的平均成本接近（29.8 vs 29.6），但情景的约束违反率为 0.12 而所提方法为 0.00；

- 计算方面，所提方法的单步优化时间要少于 Scenario 方法的若干倍；在保持较高安全性的约束下，QP 求解更快；
- 在理论上提供了近似问题的正确性/可行性及渐近最优性的严格理论证明（虽然代价函数的限制是类二次型的）。

基本结论是：**基于高斯混合分布传播可在大规模计算量下为非线性 MPC 在不确定情形下提供可靠的引导致安全性、可行性与可扩展性的组合优势**。

| **统一且可扩展的建模** | 高斯混合扰动覆盖高斯、多峰、偏态与非对称分布，框架适用范围广；分量数的固定机制避免了传播过程中混合分量数爆炸，使计算复杂度随预测时域线性增长，具备良好的可扩展性。 |
| **场景方法的替代性** | 相比场景方法（Scenario MPC）需要大量样本，所提方法以少量组分（如 m=3）即可表达多模态分布的高阶矩和尾部行为，大幅降低采样需求，同时保留类似可靠性。 |
| **可实现性** | 构建的 NLP 问题可由标准 SQP 方法求解，兼容 PyTorch/CasADi/acados 等工具，且文中给出了具体的实现细节与计算复杂度分析，使方法易于复现。 |
| **表述与写作清晰** | 动机与挑战梳理清晰，理论推导、问题重构、算法实现与实验验证之间存在明确的逻辑链条；对近似误差的来源与传播路径始终有显式追踪，而非依仗经验性说明。 |
| **对分布鲁棒优化的新视角** | 与通常将 Wasserstein 球作为真实分布不确定集合的做法不同，本文将 Wasserstein 半径用作近似误差的显式度量，为领域提供了方法论上的新视角。 |

## 8. 缺点与局限性

尽管上述优点明显，文章在若干环节仍存在不可忽略的局限：

### （1）底层假设的依赖性强

- 量化误差界的推导要求 **f 全局 Lipschitz、约束仿射、成本二次**；实际控制问题中这些条件往往放松或仅局部成立。
- 扰动分布被限制为 **相同协方差矩阵且对角的混合高斯分量**。对分量间协方差各异（异方差）或多形式协方差结构的支持不足，减弱了对真实噪声建模的通用性。
- 机会约束的重构需将约束近似为围绕每分量均值的一阶泰勒展开，对强非线性约束而言重构残差不受显式控制。

### （2）误差保证与原问题的衔接存在理论缺口

- 误差界、可靠性定理均在**给定策略参数 θ** 的前提下于开环传播过程中得出；闭环滚动时域中存在“噪声实现 → 状态反馈 → 下一步策略参数变化”的耦合，因此开环保证无法直接推广为闭环概率安全保证。
- 实验中也观察到闭环最大约束违反并不恒为零、在双峰噪声下可能超出预期阈值，说明理论与实测之间仍有实际差距。
- 期望成本在二次项上的“精确”表达式依赖已知协方差传播；一旦引入离散化与 Lipschitz 界之外的高阶项，这一精确性随即丧失。

### （3）实验验证的覆盖度偏低

- 仅在 2D、3D 状态空间低维问题中验证，缺乏更高维系统的可扩展性证据。
- 对比算法的参数设置固定，未做系统化敏感性分析（如场景数 Ns、分量数 m、约束阈值 ε、混合协方差的作用）。
- 无消融实验以分别考察离散化密度、分量数、SQP 迭代次数等对保守性与最优性的独立贡献。
- 统计次数（20 条样本路径）偏少，报告方差但不进行显著性检验，对结论稳健性的支撑有限。

### （4）实现中的理论修补略显繁琐

- 为使问题可解，需要在每个采样时刻外生地重估模式数、局部协方差并维护网格构造，在 SQP 循环中引入导数限制技巧将模式递归依赖解耦，这些工程处理虽实用，却使“传播 → 优化”并非一个无缝的整体。
- 近似误差的显式上界作为策略参数的函数被“追踪”，却没有被直接嵌入优化目标或约束——理论界在最终求解中更多作为事后评估而非主动约束使用。

## 9. 可改进方向与未来工作建议

以下改进建议既针对该文自身未竟之处，也指向该方向未来的研究空间：

| 方向 | 具体建议 |
|------|----------|
| 提升理论假设的适配性 | 将 Lipschitz 全局条件放松为局部 Lipschitz + 状态有界假设；扩展混合分量协方差形式（允许非对角与异方差），或将当前一阶约束线性化方法替换为二阶或分段仿射外包以提升非线性约束重构精度。 |
| 闭环安全性认证 | 将开环误差界嵌入闭环分析框架，例如结合 Tube-MPC 或鲁棒不变集思想，推导闭环系统维持给定机会约束保证的条件；或以置信区间形式给出闭环违反概率的界。 |
| 误差界进入优化过程 | 将 Wasserstein 半径或约束违约界作为可调正则项/风险约束直接纳入 NLP 中，而不是在问题求解前固定网格与分量数再事后追踪误差，从而在安全性与最优性之间进行在线权衡。 |
| 增强实验的说服力 | 扩充至更高维度（如四轮车辆、机械臂、四旋翼）；加入对 m, Ns, N, ε, Σ_η 的敏感性分析表格；采用更多样本路径并报告置信区间/统计检验结果。 |
| 与其他随机/鲁棒 MPC 的对比深化 | 与基于多项式混沌、鞅/矩闭合或分布鲁棒 MPC（Wasserstein 球）方法的系统对比，更有助于展现所提方法的优劣边界。 |
| 算法工程化 | 探索将传播步骤与 SQP 求解合并为单层优化的方法，减少交替迭代可能引起的收敛迟滞；同时研究在线自适应网格细化或分量合并/分裂策略，以降低对预设 m 值的敏感性。 |

## 10. 总结性评价

从研究的角度看，该论文并非提出一种全新的随机控制原理，而是**:在“如何以可控精度传播任意分布”这一核心问题上提供了一个特别构造、数学上自洽的可行答案**。它具有理论追求明确（用分布度量给出可验证误差而非依赖仿真拍脑袋）、算法设计完整（分布离散化—递归传播—优化重构—实现细节一应俱全）、实验证据具备基本可信度（突出了在非高斯扰动下相对 Nominal / Gaussian / Scenario 三类方法的优势）三大亮点。

与此同时，它的长处也集中在“开环、离线、理论基础”维度；一旦面对闭环执行、强非线性约束以及真实高维应用，其保证力度与实验依据均显不足。正因如此，此文的贡献更适合被理解为**为后续构建闭环可验证随机 MPC 搭建了一个可解析传播与误差可控的底座**，而并不构成一套端到端、开箱即用的安全关键控制器解决方案。

总体而言，这是一篇**理论有新意、工程有细节、行文严谨的高质量方法论文**；其结论中洋溢“可以在多模态非线性扰动下实现安全、低保守且高效控制”的主张，在论文所设定的前提下是可信的，但其普适性尚需更多在高维、真实系统与闭环长时域下的证据加以支撑。
