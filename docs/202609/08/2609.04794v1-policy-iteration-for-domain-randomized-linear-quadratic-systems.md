## 摘要
本文研究了线性二次控制在域随机化下的策略优化问题，重点是学习一个单一的状态反馈控制器，以最小化在具有不确定动态的系统上的平均成本。我们提出了一种带有步长规则的策略迭代算法，该规则在每次迭代中保持所有采样系统的稳定性。我们证明了该方法能单调改进样本平均目标，并且稳定步长始终存在。在标准光滑性假设下，迭代序列收敛到驻点；在梯度支配条件下，我们获得全局线性收敛速率。

## Abstract
In this work, we study policy optimization under domain randomization for linear quadratic control, focusing on learning a single state-feedback controller that minimizes the average cost across systems with uncertain dynamics. We propose a policy iteration algorithm with a step-size rule that preserves stability across all sampled systems at each iteration. We show that the method yields monotonic improvement of the sample-average objective and that a stabilizing step size always exists. Under standard smoothness assumptions, the iterates converge subsequentially to stationary points, and under a gradient-dominance condition, we obtain a global linear convergence rate.

## 2. 方法论

**核心思想：** 将经典LQR中的策略迭代框架扩展到域随机化场景，通过在采样系统的平均值上交替执行策略评价与策略改进，实现平均代价的单调下降，同时确保每个系统在每一步迭代中都保持联合稳定。

### 关键技术要点

**a) 策略评价步骤**

对于每个采样系统$j \in [M]$，给定当前稳定化控制器$K_i$，分别求解如下Lyapunov方程，得到该系统的代价矩阵$P_{j,i}$与状态协方差矩阵$\Sigma_{j,i}$：

$$P_{j,i} = Q + K_i^\top R K_i + (A_j + B_jK_i)^\top P_{j,i}(A_j + B_jK_i)$$

$$\Sigma_{j,i} = I + (A_j + B_jK_i) \Sigma_{j,i} (A_j + B_jK_i)^\top$$

**b) 策略改进步骤**

通过令平均代价的梯度$\nabla_K J_{SA}(K_{i+1})=0$来得到新的控制增益，这引出了一个线性矩阵方程。借助向量化操作（vec），可得到如下的闭式解（Sylvester型方程），即``PI``更新方向：

$$\mathrm{vec}(\hat{K}_{i+1}) = -\left(\sum_{j=1}^M \Sigma_{j,i} \otimes R_{j,i}\right)^{-1} \mathrm{vec}\left(\sum_{j=1}^M \Gamma_{j,i}\right)$$

其中，$R_{j,i} = R + B_j^\top P_{j,i}B_j \succ 0$且$\Gamma_{j,i} = B_j^\top P_{j,i}A_j\Sigma_{j,i}$。由于系数矩阵以正定矩阵的Kronecker积相加，解的存在性与唯一性天然有保证。此更新式兼具加权聚合特性，即权重由各系统自身状态协方差矩阵决定。

**c) 阻尼更新（关键创新）** —— 为保持稳定性，不直接令$K_{i+1} = \hat{K}_{i+1}$，而采取带步长$\alpha$的阻尼更新：

$$K_{i+1} = K_i + \alpha(\hat{K}_{i+1} - K_i)$$

其中$\alpha$需被约束在范围$0 < \alpha \le \min\{\bar{\alpha},\, c_d/L\}$内——既要不超过保证联合稳定性的上限$\bar{\alpha}$，也要不超过保证充分下降的$c_d/L$上限。

**d) 理论视角**

- 论文从**KKT条件角度**重新推导算法：用拉格朗日乘子法将带Lyapunov约束的DR-LQR原问题写出，发现其KKT条件中的“局部”平稳性条件、对偶可行性、主可行性恰对应PI的策略改进/评价方程，证明PI是有严格优化根基的“冻结估值条件的牛顿式/坐标下降式”策略更新。
- 此推导使得DR-LQR策略迭代法具备了明确的优化解释，路径更加可信。

### 算法流程

1. 输入M个采样系统、稳定初始K₀、Q⪰0和R≻0，给定步长参数α。
2. 对每个系统$j$求Lyapunov方程（策略评价）求$P_{j,i}$和$\Sigma_{j,i}$；
3. 解析式(8)计算未阻尼的新增益$\hat{K}_{i+1}$，令方向$\Delta_i = \hat{K}_{i+1} - K_i$；
4. 采用阻尼更新$K_{i+1} = K_i + \alpha\Delta_i$，同时确保仍处于联合稳定域；
5. 重复直至收敛。
