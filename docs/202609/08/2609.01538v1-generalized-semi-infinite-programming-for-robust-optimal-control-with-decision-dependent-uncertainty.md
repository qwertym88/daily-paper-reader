## 摘要
广义半无限规划(GSIPs)出现在鲁棒最优控制中，当允许的不确定性依赖于状态或控制时。现有的GSIP方法要么施加限制性的结构假设，要么需要全局优化，这在对控制问题的扩展性方面表现不佳。我们提出了一个通用框架，将任何具有温和正则性的GSIP重新表述为具有存在性约束的半无限规划，将其析取可行性条件平滑为在固定指标超集上的可微存在性约束。由此产生的规划通过既有的自适应离散化(割平面)方法求解，仅使用现成的非线性规划求解器，并在标准假设下收敛。将状态轨迹视为不确定性的一部分，将该框架扩展到具有状态相关不确定性的鲁棒非线性最优控制。我们在一个非凸基准GSIP和一个具有动态变化惯性的卫星消旋问题上进行了演示。

## Abstract
Generalized semi-infinite programs (GSIPs) arise in robust optimal control whenever the admissible uncertainty depends on the state or controls. Existing GSIP methods either impose restrictive structural assumptions or require global optimization that scales poorly to control problems. We present a general framework that reformulates any GSIP with mild regularity as an existence-constrained semi-infinite program, smoothing its disjunctive feasibility condition into differentiable existence constraints over a fixed index superset. The resulting program is solved by established adaptive discretization (cutting-plane) methods using only off-the-shelf nonlinear-programming solvers, and converges under standard assumptions. Treating the state trajectory as part of the uncertainty extends the framework to robust nonlinear optimal control with state-dependent uncertainty. We demonstrate it on a nonconvex benchmark GSIP and a satellite de-tumbling problem with dynamically varying inertia.

## 1. 核心问题与研究动机

在鲁棒最优控制中，不确定性集合往往不能预先固定，而会随决策变量（控制输入）或系统状态变化。例如：

- 卫星的转动惯量会随当前角速率（状态）改变；
- 机器人或航空系统中的扰动上界依赖于工作点。

这类问题的数学形式不再是经典的半无限规划（SIP），而是**广义半无限规划（GSIP）**：不确定指标集本身由决策变量决定。

现有 GSIP 求解方法存在两难：

- **直接方法**（如全局优化、分支定界）虽能处理非凸约束，但指数级扩展性差，难以用于控制问题；
- **转化类方法**要么依赖较强结构假设（如多项式约束、多面体指标集），要么只能给出局部变换。

本文的动机是：**建立一种温和条件下将一般 GSIP 转化为经典 SIP 的通用框架**，从而复用成熟的 SIP 自适应离散化算法，用现成的非线性规划（NLP）求解器求解，并推广到含状态相关不确定性的鲁棒最优控制问题。

## 2. 方法论

### 2.1 问题形式

考虑的 GSIP：

\[
\min_{z\in Z} f(z) \quad \text{s.t.} \quad g(z,v) \le 0,\ \forall v \in V(z),
\]

其中决策依赖的不确定集为：

\[
V(z) = \{ v \in \bar V : h(z,v)\ge 0,\ r(z,v)=0 \}.
\]

### 2.2 核心正则性假设（Assumption 1）

- 决策集和不确定集非空、紧致且一致有界；
- **确定部分（determined part）**：变量可分解为 \(v=(p,q)\)，其中对每个 \(q\)，等式 \(r(z,(p,q))=0\) 存在**唯一解 \(p\)**，且关于 \((z,q)\) 连续；
- 目标与约束函数具有一定阶连续可微性（\(C^\rho\)）。

该假设使无穷维不确定性等价地约化为低维自由指标 \(q\in\bar Q\)。

### 2.3 等价改写（Lemma 1）

原 GSIP 可等价写成固定指标集 \(\bar Q\) 上的半无限约束：

\[
[g(z,v)\le 0] \ \vee\ \left[\min_j h_j(z,v)<0\right],
\]

即每个鲁棒约束可以“失败”在不确定性被判定为不可达处；该析取形式随后按非严格意义处理。

### 2.4 析取条件的光滑化（Theorem 1）

将“\(g\le0\) 或 \(\min_j h_j\le0\)”的析取条件等价编码为**存在性约束**：

\[
\forall q\in\bar Q, \ \forall i,\ \exists \lambda_i\in\Lambda_{n_h+1} :
\quad
\lambda_{i,1} g_i(z,v) + \sum_{j=1}^{n_h} \lambda_{i,j+1} h_j(z,v) \le 0,
\]

其中 \(\lambda_i\) 位于概率单纯形上。由于线性函数在单纯形顶点取最小值，这一凸包（convex hull）编码与析取逻辑精确等价；同时原问题仍保持可微性。

### 2.5 自适应离散化求解（Algorithm 1）

算法迭代执行：

1. 求解当前有限离散点集 \(Q\) 上的**主问题**（5）（有限维 NLP，包含每个离散点的状态副本和单纯形乘子）；
2. 对每个鲁棒约束 \(i\) 求解**分离问题（oracle）**（6）：

\[
\max_{q,p,s}\ s \quad \text{s.t.} \quad r(z,v)=0,\ s\le g_i(z,v),\ s\le h_j(z,v),\ \forall j;
\]

3. 若最大违背值 \(s^*_i \le 0\)，则当前解可行并停止；
4. 否则将最坏违约点 \(q^*\) 加入离散集 \(Q\)，重复。

理论保证（Theorem 2）：若各子问题均精确求解，且原问题可行，则算法要么有限步终止，要么产生的任意聚点都是原问题最优解。

### 2.6 扩展至鲁棒最优控制（Theorem 3）

将**状态轨迹 \(x\) 视为不确定性的一部分**，并通过动力学方程将状态与扰动耦合：

\[
V(u)=\{(x,w):\ \phi(u,x,w)=0,\ h_c(u,x,w)\ge0,\ r_c(u,x,w)=0\}.
\]

在确定部分唯一可解（如 index-one DAE 结构）的条件下，带状态相关不确定性的鲁棒 OCP 被转化为标准 GSIP，再用同一算法求解。

## 3. 实验设计

### 3.1 实验一：非凸基准 GSIP（Problem 15 of [24]）

- 决策变量 \(z\in[0,2]^2\)，目标为 \(z_2^2-4z_2\)；
- 鲁棒约束含三角函数，\(V(z)\) 由二次不等式刻画，问题自然非凸；
- 对比对象：[13] 的全局优化方法。

主要结果：

- 本文方法：10,000 次随机运行，平均 **5–6 次迭代**收敛，单次平均 **38.96 ms**；
- 对比方法 [13]：同一问题需 **23.46 s**（但注意其运行于较早硬件，且提供全局最优性保证）。

### 3.2 实验二：卫星去翻滚问题

- 场景：近似平面卫星的姿态消旋与定向；
- 不确定性：振动诱导、随角速率变化的转动惯量：
  \[
  I_{xx}\in[\bar I_{xx}, \bar I_{xx}+\epsilon+a\omega_x^2],\quad
  I_{yy}\in[\bar I_{yy}, \bar I_{yy}+\epsilon+a\omega_y^2],\quad
  I_{zz}=I_{xx}+I_{yy}.
  \]
- 控制目标：最小化控制能量，同时保证终端姿态误差小于 \(15^\circ\)；
- 规模：\(N=10\) 步，共 30 个控制决策变量；
- 参数：\(a=0.05,\ \epsilon=0.01,\ \bar I=0.1\ \mathrm{kg\,m^2}\) 等。

求解与验证：

- 用 Ipopt 多起点求解非凸子问题，并进行 ε‑连续化热启动；
- 共需 **45 次割平面迭代**、耗时 **34 分钟**，目标成本约 \(2.5\times10^{-3}\)；
- 使用 **50,000 次蒙特卡洛采样**（含有偏边界与最坏边缘样本）验证，全部满足 \(15^\circ\) 姿态约束（最大误差 13.3°）；
- 但最坏情形搜索仍可找到终端误差达 19.2° 的混合惯量序列，说明**蒙特卡洛本身不足以认证鲁棒性**，必须依赖割平面 oracle 的非正值终止条件。

Baseline 对比：

- 没有现有方法能在该规模上直接处理此类状态相关不确定性；
- 将不确定性代之以静态保守界（假设 \(|\omega_x|,|\omega_y|\le0.5\ \mathrm{rad/s}\)）后问题**不可行**。

## 6. 主要结论

1. 提出了将 GSIP 转化为带存在约束 SIP 的一般框架，该转化只依赖温和的确定部分唯一可解性与光滑性假设，且可保持可微性；

## 7. 局限性与批判性评述

### 7.1 理论层面

| 局限 | 分析 |
|---|---|
| Theorem 2 的收敛性依赖“子问题精确求解” | 实际分离问题（6）及主问题（5）均为非凸 NLP，求解器只能保证局部最优或 KKT 点；理论保证与实际求解之间的鸿沟未被充分讨论 |
| Assumption 1 的唯一可解性 | 该假设对等式约束 \(r(z,(p,q))=0\) 要求逐 \(q\) 存在唯一连续解 \(p\)。对于更一般的微分代数系统（如 index > 1）或隐式动力学，该假设未必成立，适用范围受限 |
| 析取光滑化缺乏正则化讨论 | Theorem 1 将析取条件编码为凸包上的线性组合，但未讨论 \(\lambda\) 退化到顶点、可行性收紧或病态尺度等问题在数值上如何处理 |
| 无全局最优性保证 | 方法本质上是“局部 NLP + 自适应割平面”，对非凸 GSIP 无法保证找到全局最优解，论文也未尝试用全局优化器做后验验证 |

### 7.2 算法与工程层面

- **热启动依赖经验调参**：卫星问题中采用 ε-连续化热启动，但 ε 的衰减策略、多起点数量均无系统性依据，可复现性受影响；
- **Worst-case oracle 仅提供必要终止条件**：oracle 返回非正值即认为鲁棒可行，但若 oracle 本身陷入局部解，可能漏报真实违约点。论文在卫星验证中对此已有警觉（MC 未发现但 oracle 找到 19.2° 违约），但并未给出防止 oracle 漏报的机制；
- **计算时间敏感**：卫星问题仅 30 个控制变量、45 次迭代即耗时 34 分钟；随着控制步数 \(N\) 或不确定性维度增加，主问题中离散点副本数增大，算法扩展性可能快速恶化。

### 7.3 实验层面

- **缺乏与主流鲁棒控制方法的对比**：未与 tube-based MPC、min-max MPC、scenario approach 或多项式 Chaos 展开等方法对比精度与保守性；
- **未测试不同决策依赖强度的影响**：参数 \(a\)、\(\epsilon\)、惯量上下界的摄动幅度如何影响迭代次数与最终成本，缺少敏感性分析；
- **基准问题的跨硬件对比不可靠**：与 [13] 的 23.46 s 对比发生在不同 CPU、不同求解器（全局 vs 局部）环境下，只能说明数量级差异，不宜视为严格性能优势；
- **状态相关不确定性的实例过于单一**：仅一个平面卫星模型，未展示该方法在更复杂的空间飞行器或机械系统上的表现。

## 8. 创新点与学术贡献

1. **填补了 GSIP 与 SIP 之间转化的空白**：现有文献中，GSIP 到 SIP 的转化通常需要多面体指标集或消去假设；本文用“存在性约束 + 概率单纯形凸包”给出了一类仅要求“确定部分唯一可解”的温和条件下的一般性转化框架，理论上具有较大覆盖范围。
2. **将鲁棒最优控制问题统一到 GSIP 视角**：通过把状态轨迹 \(x\) 视为决策依赖不确定性的一部分，作者将一大类带状态相关不确定性的非线性 OCP 纳入了同一数学框架，表述上具备较强的统一性与说服力。
3. **算法实现完全基于现成 NLP 求解器**：不依赖全局优化或专用半无限规划软件，使得方法在工程实践中具备较好的可落地性。
4. **揭示了一个重要的建模观点**：状态相关不确定性并非“为精确而精确”的建模炫技，而可能与可行性直接相关。该发现在卫星算例中得到了清晰展示。
