## 摘要
Koopman 算子由于能够利用诸如扩展动态模式分解（EDMD）等数据驱动方法为非线性系统提供线性视角，在动力系统中受到了广泛关注。本文中，我们提出一种在 d 维环面上使用傅里叶字典的 EDMD 变体，其中数据在等距张量网格上采样。在此设定下，EDMD 回归问题具有唯一的闭式解，我们证明该解与 Koopman 像的三角插值一致。这一等价关系有两个推论。首先，利用 Sobolev 空间的 Koopman 不变性，我们将三角插值的逼近论结果迁移过来，推导出 Koopman 算子逼近的误差界。特别地，所建立的界具有最优阶，且常数显式。其次，EDMD 矩阵无需组装，因为其作用可归结为（非等距）快速傅里叶变换，从而可以无矩阵地计算 EDMD 近似，其代价关于字典规模是拟线性的。我们以耦合振子的 Kuramoto 模型为例说明这些结果，所用字典最多包含 10^7 个模式。

## Abstract
The Koopman operator has gained considerable attention in dynamical systems due to its capability to provide a linear viewpoint for nonlinear systems using data-driven methods such as extended dynamic mode decomposition (EDMD). In this work, we suggest an EDMD-variant with a Fourier dictionary on the $d$-dimensional torus, where the data are sampled on an equispaced tensor grid. In this setting, the EDMD regression problem admits a unique closed-form solution, which we show to coincide with trigonometric interpolation of the Koopman image. This identification has two consequences. First, using Koopman invariance of Sobolev spaces, we transfer approximation-theoretic results for trigonometric interpolation to derive error bounds on approximations of the Koopman operator. In particular, the established bounds are of optimal order with explicit constants. Second, the EDMD matrix never has to be assembled, since its action reduces to (nonequispaced) fast Fourier transforms such that the EDMD-approximation may be evaluated matrix-free with quasi-linear cost in the dictionary size. We illustrate the results for the Kuramoto model of coupled oscillators with dictionaries of up to $10^7$ modes.

## 2. 方法论

### 核心思想
在等距网格上，字典规模恰等于采样点数，使 EDMD 回归问题具有**唯一闭式解**，且该解**等价于 Koopman 像的三角插值**，从而把经典三角插值逼近论结果迁移到 Koopman 算子误差分析，同时实现无矩阵（matrix-free）快速计算。

### 关键技术细节

- **设定**：$\mathbb{T}^d = \mathbb{R}^d/\mathbb{Z}^d$，离散动力系统 $x^+ = F(x)$，Koopman 算子 $\mathcal{K}f := f\circ F$。
- **傅里叶字典**：$\psi_k(x)=\exp(2\pi i\langle k,x\rangle)$，带宽 $n$ 的字典 $\mathcal{V}_n=\mathrm{span}\{\psi_k:\|k\|_\infty\le n\}$，维度 $N=(2n+1)^d$。
- **等距张量网格**：$x_j=(j_1/(2n+1),\dots,j_d/(2n+1))$，$j\in\{0,\dots,2n\}^d$，网格点数 $|X|=N$。
- **闭式解（核心结构性质）**：由傅里叶基在等距网格上的正交性，采样矩阵满足 $L_X L_X^* = N I_N$，故 $L_X^{-1}=\frac1N L_X^*$，EDMD 解为
  $$K = L_{X^+}L_X^{-1}=\frac1N L_{X^+}L_X^*.$$
  **Gram 矩阵无需形成、逆无需计算。**
- **与三角插值的等价（Proposition 6）**：$K$ 恰是算子 $S_n\mathcal{K}|_{\mathcal{V}_n}$ 的矩阵表示，即 **Fourier-EDMD = Koopman 像的三角插值**。
- **两个 Koopman 逼近算子**：
  - $\hat K_1 := S_n\mathcal{K}$：假设 $f(F(x_j))$ 已知，只需**一次 FFT**；
  - $\hat K_2 := S_n\mathcal{K}S_n$：仅需网格上的 $f(x_j)$，需**两次 FFT + 一次 NFFT**（因像点 $F(x_j)$ 非等距）。
- **误差分析工具链**：
  - 环面 Sobolev 空间 $H^s(\mathbb{T}^d)$ 的傅里叶刻画；
  - Koopman 算子在 $H^s$ 上的有界性（整数阶用微分范数等价，分数阶通过**插值空间等距同构** $H^s=(L^2,H^\sigma)_{\theta,2}$ 得到，且不引入额外插值常数）；
  - 三角插值误差估计（Theorem 13）与求和界引理（Lemma 12），给出**全显式常数**；
  - 主结果（Theorem 15）：$\|\mathcal{K}-\hat K_1\|_{H^s\to L^2}\le C n^{-s}$，$\|\mathcal{K}-\hat K_2\|_{H^s\to L^2}\le \tilde C n^{-s}$，常数 $C,\tilde C$ 显式依赖于 $F$、其光滑度 $\sigma$、维度 $d$ 与 $s$，且速率 $n^{-s}$ 在 $(2n+1)^d$ 点采样下**最优**。
- **无矩阵实现**：FFT 在网格值与傅里叶系数间转换，NFFT（type-2）在非等距像点处求值；总代价 **$O(N\log N)$**，并采用**块状求值**（沿单坐标方向）将临时数组内存从 $O(dN)$ 降到 $O(dB(2n+1)^{d-1})$。

## 3. 实验设计

- **测试模型**：**Kuramoto 耦合振子模型**在 $\mathbb{T}^d$ 上（经典全连接耦合，$1/d$ 归一化），经显式欧拉离散化得到映射 $F$；用恒等式将 $d\times d$ 耦合矩阵替换为两个标量和，将每次求值代价从 $O(d^2)$ 降到 $O(d)$。验证了 $h\kappa<1/2$ 时 $F$ 是 $C^\infty$ 微分同胚且 $|\det DF|$ 有下界。
- **参数设置**：固有频率 $\omega_i \sim \mathrm{Unif}(0.05,0.15)$（避免共振），每步耦合强度 $h\kappa=0.3$。
- **观测量**：二阶张量积 B 样条 $f(x)=\prod_{i=1}^d \sqrt{12}\min\{x_i,1-x_i\}$，满足 $f\in H^s\ (s<3/2)$ 但 $f\notin H^{3/2}$，用于检验理论预测速率 $n^{-3/2}$。
- **评价指标**：相对 $L^2$ 误差 $\|\mathcal{K}f-\hat K_i f\|_{L^2}/\|\mathcal{K}f\|_{L^2}$，用 Monte-Carlo 求积分在**独立于插值网格**的随机点上估计。
- **Benchmark / 对比对象**：**没有与外部方法对比**，仅在同一框架下对比 $\hat K_1$ 与 $\hat K_2$ 两个逼近算子，并以理论预测速率 $n^{-3/2}$（或 $N^{-3/(2d)}$）作为参照线。
- **规模**：维度 $d=1,\dots,5$；带宽范围 $n\in[8,4096]$（$d=1$）到 $n\in[4,12]$（$d=5$）；最大字典 $N=25^5=9{,}765{,}625\approx 10^7$ 模式。

## 6. 主要结论与发现

1. Fourier-EDMD 在等距网格上具有**唯一闭式解**，其逆矩阵即采样矩阵的共轭转置（至多相差标量 $1/N$），Gram 矩阵与逆矩阵均无需计算。
2. 该解**严格等价于 Koopman 像的三角插值**，从而将逼近论结果直接迁移到 Koopman 误差分析。
3. 对可观测量 Sobolev 光滑度 $s$，得到**最优阶 $n^{-s}$ 的误差界**，常数显式且可先验评估；两个逼近算子 $\hat K_1,\hat K_2$ 同阶、仅常数不同。
4. 副产品：显式常数的三角插值误差估计、Koopman 算子在**分数阶 Sobolev 空间**上的有界性、以及环面 Sobolev 空间与插值空间的**等距同构**识别。
5. 矩阵-free 实现达到 **$O(N\log N)$** 拟线性复杂度，与字典规模而非维度相关。
6. 数值实验：观测收敛速率在 $-1.46$ 至 $-1.56$ 之间，与预测的 $-3/2$ 吻合（含 $d\ge3$ 超出理论条件的情形）；最大字典约 $10^7$ 模式，成本确认拟线性。

## 7. 优点

- **理论-算法高度统一**：用"闭式解 = 三角插值"这一简洁结构性事实同时打通误差分析与快速计算两条线。
- **误差界质量高**：最优收敛阶 + **完全显式常数**，可先验评估；借助环面上分数阶 Sobolev 空间与插值空间的等距同构，避免了额外常数损失。
- **计算高效且可扩展**：无需组装/存储巨大矩阵（避免 1.5 PB 级存储），FFT+NFFT 实现拟线性复杂度，配合块状求值支持高维、$10^7$ 规模字典。
- **方法"普适性"好**：三角插值算子不依赖光滑度信息，自动适应目标函数正则性（与核方法需调核形成对比）。
- **数值验证扎实**：跨维度、跨尺度的一致性验证，误差比与耗时均符合理论预测。
- **对适用条件的诚实讨论**：明确指出 $s>d/2$ 的限制及 $d\ge3$ 实验超范围的解释。

## 8. 不足与局限

- **采样结构强假设**：方法依赖**等距张量网格**，且要求网格点数等于字典规模，无法直接适用于任意/随机数据采样（相比 kEDMD 的填充距离框架灵活性差）。
- **维度诅咒**：字典规模 $N=(2n+1)^d$ 随维度指数增长；文章本质上是各向同性 Sobolev 光滑度下的最优，但速率 $N^{-s/d

（$d$ 维下以字典规模计的收敛率）随之衰减，因此高维问题仍需要指数级字典，方法并未真正摆脱维度诅咒，只是把实现代价从“不可行”降到“可行”。在高维、低光滑度组合下（例如 $d$ 较大而 $s$ 仅略大于 $d/2$），可达到的精度与所需内存仍可能迅速变得不可接受。

- **各向同性光滑度假设**：误差界建立在各向同性 Sobolev 空间 $H^s(\mathbb{T}^d)$ 上，即要求各坐标方向光滑度相同、带宽各向同性 $n$。对具有各向异性正则性的函数（不同方向光滑度差异明显，如快慢变量系统），该字典不是最优，理论上应使用各向异性带宽 $(n_1,\dots,n_d)$ 与相应各向异性 Sobolev 范数；文章未给出这一推广。
- **仅限离散映射，未覆盖连续时间/生成元**：全文围绕离散映射 $F$ 的 Koopman 算子 $\mathcal{K}=(\cdot)\circ F$ 展开，未处理连续时间生成元 $L=\lim_{t\to0}(\mathcal{K}_t-I)/t$ 的估计。而连续时间场景在建模中同样常见，且生成元估计的误差分析需要不同的函数空间工具。
- **无噪声与有限数据鲁棒性分析**：所有误差界都假设在网格点上获得精确观测。实际中若 $F(x_j)$ 未知或带噪（例如数据驱动的非精确像点、观测噪声），$\hat K_2$ 的实现需要额外估计 $F$，噪声如何传播到 Koopman 逼近误差中未作分析；这恰是 kEDMD 类方法关注的核心问题之一。
- **边界与几何限制**：方法依赖 $\mathbb{T}^d$ 的无边界、平移不变结构，才能得到 $L_XL_X^*=NI_N$ 与快速 FFT/NFFT。对 $\mathbb{R}^d$、有界域或一般流形，需引入边界修正、非均匀采样或局部字典，文章未讨论。
- **NFFT 近似误差未纳入理论界**：主定理给出的是理想三角插值/投影误差，而实现中 NFFT 本身有截断误差（虽参数下可小于 $10^{-12}$），理论上二者应相加，文章未给出包含 NFFT 误差的严格复合界。
- **实验对比与消融不足**：如前所述，缺乏与 kEDMD、随机傅里叶特征 EDMD 等外部方法在相同问题上的精度/成本对比；也没有对网格类型、字典带宽选择、噪声水平、非等距采样等做消融，因而“相对优势”更多是理论层面的推断而非实验证实。
- **理论条件与实验范围的间隙**：数值实验在 $d\ge3$ 时使用了不满足 $s>d/2$ 的观测量，虽作者用张量积可分解性（Remark 18）解释观测速率仍匹配，但这是经验性解释，缺少严格的放松条件证明，说明理论与实际可用范围之间尚存在未完全闭合的缺口。

## 9. 对后续研究的启示与开放问题

- **方法论模板的可迁移性**：本文示范了一条“结构化正交字典 + 等距采样 → 闭式解 → 经典逼近论误差界 → 快速变换实现”的完整路线。类似思路可能迁移到球面调和、正交多项式、小波等其他正交字典体系，只要能在相应采样集上找到类似的正交/近似正交结构。
- **缓解维度诅咒的可能路径**：结合稀疏性/压缩感知、低秩张量结构、或各向异性/自适应带宽，有望在函数具有额外结构（低内在维数、混合光滑度）时显著降低有效字典规模，这是最直接的后续方向。
- **随机与噪声数据的推广**：将闭式解的优势与 kEDMD 的随机采样框架结合，发展在噪声观测、随机/非等距采样下的误差界，是提升实用性的关键。
- **从算子逼近到控制与预测**：当前只分析 Koopman 算子的逼近误差，尚未讨论该误差如何影响谱估计、长期预测稳定性与控制设计；把这些下游任务的误差传播纳入分析，将增强方法的工程价值。
- **各向异性与连续时间扩展**：建立各向异性 Sobolev 空间下的误差界，以及面向连续时间生成元的傅里叶字典快速估计，都是自然且重要的理论扩展。

## 10. 总体评价

本文在“快速实现”与“严格误差保证”之间建立了少见的强连接：通过等距网格上傅里叶基的正交性，把 EDMD 回归问题化为具有闭式解的三角插值问题，从而同时获得了无矩阵 $O(N\log N)$ 算法与最优阶、常数显式的 $n^{-s}$ 误差界。其理论贡献（显式常数插值误差、分数阶 Sobolev 上 Koopman 有界性、插值空间等距同构）具有独立价值，数值实验也在跨维度、跨 7 个数量级字典规模上给出了一致验证。主要局限在于强采样结构假设、固有的维度诅咒、缺乏噪声/随机数据鲁棒性以及缺少外部方法对比。总体而言，这是一篇在确定性、高维周期系统场景下兼具理论严谨性与工程可行性的高质量工作，为结构化字典 Koopman 逼近提供了可复制的分析范式。
