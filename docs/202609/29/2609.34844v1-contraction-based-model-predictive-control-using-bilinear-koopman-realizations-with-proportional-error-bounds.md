## 摘要
基于 Koopman 算子理论的数据驱动模型预测控制，是处理未知动态非线性系统约束控制的一种有前景的方法。本文针对此类系统提出一种鲁棒模型预测控制框架，采用双线性 Koopman 实现，并具有依赖于状态和输入的比例近似误差界，该误差界在目标平衡点处消失。由于使用有限维 Koopman 实现在提升坐标中进行预测时，预测结果未必保持在有效提升状态的流形上，多步预测可能会离开单步误差证书适用的区域。我们通过将每个预测的提升状态重新投影到原始状态坐标并再次提升来避免这一困难，从而在不假设 Koopman 字典不变性的情况下，得到原始状态空间中的误差感知离散时间控制仿射预测器。针对该预测器，我们基于离散时间鲁棒控制收缩度量开发了一种位似管构造，其半径显式地考虑了比例近似误差界。该管收紧方法可处理任意连续可微非线性约束，所得的模型预测控制问题包含终端要素以及利用目标附近不确定性消失特性的管半径惩罚项。我们证明了：在训练数据上以高概率，原始非线性约束的鲁棒满足性、递归可行性以及采样真实闭环系统的指数稳定性，且不要求模型预测控制问题具有全局最优解。包括非线性避障约束在内的数值算例表明，与现有基于 Koopman 的模型预测控制方法相比，所提方法能够实现鲁棒镇定，并在更小的闭环代价和灵活性方面表现出更高性能。

## Abstract
Data-driven model predictive control based on Koopman operator theory is a promising approach for constrained control of nonlinear systems with unknown dynamics. This paper proposes a robust model predictive control framework for such systems using bilinear Koopman realizations with state- and input-dependent proportional approximation-error bounds that vanish at the target equilibrium. Since prediction in lifted coordinates with a finite-dimensional Koopman realization need not remain on the manifold of valid lifted states, multi-step prediction may leave the region where one-step error certificates apply. We avoid this difficulty by reprojecting each predicted lifted state onto the original state coordinates and lifting it again, yielding an error-aware discrete-time control-affine predictor in the original state space without assuming invariance of the Koopman dictionary. For this predictor, we develop a homothetic tube construction based on a discrete-time robust control contraction metric whose radius explicitly accounts for the proportional approximation error bounds. The tube tightening handles arbitrary continuously differentiable nonlinear constraints, and the resulting model predictive control problem includes terminal ingredients and a tube-radius penalty that exploits the vanishing uncertainty near the target. We prove robust satisfaction of the original nonlinear constraints, recursive feasibility, and exponential stability of the sampled true closed-loop system with high probability over the training data without requiring a globally optimal solution to the model predictive control problem. Numerical examples, including nonlinear obstacle-avoidance constraints, demonstrate robust stabilization and higher performance of the proposed approach compared to existing Koopman-based model predictive control methods in terms of smaller closed-loop cost and flexibility.

## 1. 核心问题与整体含义

- **研究背景**：模型预测控制（MPC）依赖足够精确的预测器。对于软体机器人等难以从第一性原理建模的非线性系统，需要从数据中学习预测器。Koopman 算子理论通过非线性提升（lifting）将非线性预测转化为（双）线性实现，其中双线性 Koopman 实现比线性实现表达能力更强，且近期 SafEDMD 方法可给出**状态/输入依赖、在平衡点处消失的比例误差界**。
- **核心障碍（多步预测一致性）**：提升映射的值域通常是提升坐标中的一个非线性流形 M，有限维学习实现不保证将 M 映射到自身（即不满足 Koopman 字典不变性）。若直接在提升空间传播，后续预测点会落到流形之外，导致单步误差证书失效，多步误差不可控。
- **现有方法缺陷**：
  - 字典不变性假设过强，实际难满足；
  - 惩罚流形偏离无硬性保证；
  - 使用**常数误差界**会随预测时域增长使收紧后的约束集变空，过于保守；
  - 已有工作多要求 MPC 全局最优解，或仅给出 ISS/AS 而非指数稳定（ES）。
- **论文含义**：首次显式利用双线性 Koopman 实现的比例误差界，结合离散时间鲁棒控制收缩度量（RCCM）与位似管（homothetic tube）MPC，在**不要求字典不变性、不要求全局最优解**的前提下，实现约束鲁棒满足、递归可行与高概率指数稳定。

## 2. 方法论

### 核心思想
- 用**重投影（reprojection）**消除流形不变性难题：每一步预测后，把提升预测结果投影回原始状态坐标，再重新提升，保证提升状态始终落在 M 上。
- 由此得到**原始状态空间中的误差感知、控制仿射预测器**，其不确定性大小随状态/输入变化，并在目标平衡点处消失——该结构恰好适配 RCCM 管设计。

### 关键技术细节

- **SafEDMD 与比例误差界**（Lemma 1）：字典 Φ(x) = [1, xᵀ, φ_{n_x+1}(x), …, φ_M(x)]ᵀ 含原始状态坐标与常数可观测项。单步提升表示误差 ξ(x,u) 满足
  - ‖ξ(x,u)‖ ≤ c_x‖Φ̂(x)‖ + c_u‖u‖，
  - 以概率 1−β 对数据成立，且因 Φ̂(0)=0 而**在平衡点处消失**。

- **误差感知预测器**（式 18–21）：真实单步映射写为
  - x⁺ = F̃(x,u) + (c_x‖Φ̂(x)‖ + c_u‖u‖)e，
  - 其中 F̃ 先经学习实现传播、再投影回原始坐标。
  - **Lemma 2（可微不确定性描述）**：将非光滑范数项等价改写为 E(x,u)w 形式，
    - E(x,u) = [c_x(Φ̂(x)ᵀ⊗I), c_u(uᵀ⊗I)]，w ∈ W（单位球组合的 Kronecker 结构），
    - 从而保证在原点处导数良定义，便于 RCCM 设计。

- **离散时间 RCCM（Assumption 1）**：存在度量 M(x)≻0、反馈 K(x) 与常数 0<ρ_c<1、α₁,α₂>0，使闭环雅可比 A_cl 满足
  - A_clᵀM(x⁺)A_cl ⪯ (1−ρ_c)M(x)，α₁I ⪯ M(x) ⪯ α₂I。
  - 可通过变量替换（W=M⁻¹, Y=KW）转化为 LMI/SOS 求解。

- **管与反馈设计**（Prop. 1）：以黎曼距离 V 定义管半径，收缩关系为
  - V(x⁺, z⁺) ≤ √(1−ρ_c)·V(x,z) + √α₂(c_x‖Φ̂(z)‖ + c_u‖v‖)。
  - 关键：误差项在 z→0, v→0 时消失，只剩收缩项，保证收敛。

- **约束收紧**（Prop. 2）：对任意连续可微 h_j，若 h_j(z,v) + c_j·V(x,z) ≤ 0（c_j 由 ∂h/∂x、∂h/∂u、K、M 计算），则整条测地线路径安全，从而真实状态-输入满足原非线性约束。

- **TMPC 问题（Problem 1）**：
  - 决策变量：标称轨迹 z_{i|k}、v_{i|k} 与管半径 δ_{i|k}；
  - 代价含**管半径惩罚** λδ²（利用目标附近不确定性消失，助推收敛）；
  - 约束包括：标称传播 z⁺=F̃(z,v)、半径传播 δ⁺=√(1−ρ_c)δ+√α₂(c_x‖Φ̂(z)‖+c_u‖v‖)、收紧约束、初始 V(x,z₀)=δ₀、终端约束 (z_N,δ_N)∈X_f。

- **终端要素显式构造（Prop. 3）**：X_f = {(z,δ): z=0, h_j(0,0)+c_jδ≤0}，k_f≡0，ℓ_f = λρ_c δ²；利用误差项消失，终端集非空且可显式给出，无需额外假设。

- **在线算法（Algorithm 2）**：以移位可行解为候选，在时限 τ 内求解改进，必要时使用局部候选解 (33)；**不要求全局最优**，超时可用移位解兜底。
