## 摘要
人形机器人有望在杂乱的、以人为中心的环境中实现多样化移动，但实际部署要求具备原理性保障的安全性。经典的基于模型的步态生成器能够产生可解释的运动，但往往缺乏现代强化学习（RL）方法的鲁棒性和适应性。我们提出了一种模型知情强化学习框架，其锚定于解析的角动量线性倒立摆（ALIP）模板。我们通过离散指数控制屏障函数（DECBF）为 ALIP 迈步提供了步到步安全证书，并将其用作 (i) 训练时的塑形信号和 (ii) 运行时动作滤波器，该滤波器以最小方式调整摆动脚落点，以满足模板级约束。全阶安全性在 MuJoCo 中的 Digit 人形机器人上通过全身控制器栈进行了实证评估。与无约束基线相比，我们的方法在报告的外部扰动试验中减少了安全违规事件，而较大的横向速度瞬变则揭示了安全性与跟踪性之间的权衡。

## Abstract
Humanoid robots promise versatile mobility in cluttered, human-centric environments, but real deployment demands principled safety. Classical model-based gait generators yield interpretable motions but often lack the robustness and adaptability of modern reinforcement learning (RL) based approaches. We propose a model-informed reinforcement learning framework anchored to the analytical Angular Momentum Linear Inverted Pendulum (ALIP) template. We provide a step-to-step safety certificate for ALIP stepping via a discrete exponential control barrier function (DECBF) and use it as (i) a training-time shaping signal and (ii) a runtime action filter that minimally adjusts swing-foot placement to satisfy template-level constraints. Full-order safety is evaluated empirically on the Digit humanoid in MuJoCo with a whole-body controller stack. Compared to an unconstrained baseline, our approach reduces safety-violation events in the reported external-disturbance trial, while larger lateral-velocity transients reveal a safety-tracking tradeoff.

## 1. 核心问题与整体含义

- **研究动机**：人形机器人要在杂乱、以人为中心的环境中部署，安全性必须具备原理性保障。双足行走的安全本质上是**预测性**的——当前步的落足决策直接决定下一次冲击事件时机器人的状态，因此步到步（step-to-step）过渡是否处于安全边界内是可靠行走的关键。
- **背景矛盾**：
  - 经典基于模型的步态生成器（HZD、LIP、SLIP、H-LIP、ALIP 等）可解释、具备预测结构，但难以泛化到不同地形、步态模式和扰动，需要大量重调参。
  - 强化学习（RL）在复杂环境中鲁棒性和适应性强，但通常缺乏显式的步到步预测结构和数学安全保证，难以在冲击视界上被解释或认证。
- **核心切入点**：将解析的**角动量线性倒立摆（ALIP）**步到步预测器嵌入 RL 流程，构造**离散指数控制屏障函数（DECBF）**，把安全证书同时用于训练塑形和运行时动作过滤，且仅最小化调整摆动足落点。
- **整体含义**：探索了一条"模型知情 + 无模型 RL"的混合路线，在保留 RL 鲁棒性的同时，把模板级安全约束注入策略层，揭示模板级安全与全阶跟踪之间的固有权衡。

## 2. 方法论

- **ALIP 模板动力学**：
  - 水平模板状态定义为 $x = [p_x, L_y]^\top$（矢状面）、$y = [p_y, L_x]^\top$（额状面），其中 $p_\square$ 为支撑坐标系下 CoM 位置，$L_\square$ 为接触角动量分量。
  - 恒定 CoM 高度 $H$ 下连续动力学为 $\dot{x} = \bar{A}_x x$、$\dot{y} = \bar{A}_y y$，矩阵含 $1/(mH)$ 与 $mg$ 项。
  - 固定步长 $T$ 下，名义预测为 $x(t_0+T) = e^{\bar{A}_x T} x(t_0)$。
- **冲击映射与步到步映射**：
  - 理想冲击映射下接触角动量不变，冲击后状态重表达为 $x_k^+ = [-u_{x,k}, L_{y,k}^-]^\top$（$u$ 为相对 CoM 的落足位置）。
  - 消去冲击后状态得到**离散仿射步映射**：$x_{k+1}^- = A x_k^- - B u_{x,k}$，关键结构性质是**预冲击状态对落足输入仿射**（固定 $T$ 时）。
- **轨道能量**：$E[p, L] = -\frac{g}{2H}p^2 + \frac{1}{2m^2H^2}L^2$，符号决定被动摆行为；$E=0$ 为捕获边界（separatrix）；$E<0$ 时 CoM 不越过顶点，可用于防止侧向腿交叉。
- **轨道能量更新（闭式）**：
  - $E(x_{k+1}^-) = \frac{(L_{y,k}^-)^2}{2m^2H^2} - \frac{g}{2H}u_{x,k}^2$，$E(y_{k+1}^-)$ 同理。
  - 意味着能量约束对落足输入形成环状约束 $r_{\min} \le |u| \le r_{\max}$。
- **DECBF 安全证书**：
  - 安全集 $S = \{z_k \mid B_i(z_k) \ge 0, \forall i\}$。
  - DECBF 条件：$\Delta B_i(x_k^-, u_k, T) + \gamma B_i(x_k^-) \ge 0$，$\gamma \in (0,1)$，满足则前向不变。
  - 定义安全证书 $s_i(x_k^-, u_k, T) = \Delta B_i + \gamma B_i$。
- **两类使用方式**：
  - **训练时塑形**：$r_{\text{safe}} = -\sum_i \eta_i (e^{-k_s s_i} - 1)\mathbf{1}\{s_i < 0\}$，惩罚预测将违反安全的动作，引导探索。
  - **运行时投影滤波**：$u_k^* = \arg\min_u \|u - u_k^{\text{nom}}\|^2 \ \text{s.t.}\ s_i(x_k^-, u, T) \ge 0$。
- **三类屏障函数**：
  1. **横向分离（防腿交叉）**：$B_{\text{sep}}(d_{y,k}) = \sigma_k d_{y,k} - W_{\min} \ge 0$，对 $u_{y,k}$ 仿射，形成半空间。
  2. **轨道能量包络**：$B_E(y_k^-) = -E(y_k^-) + E_{\max}^{\text{ALIP}} \ge 0$，$E_{\max}$ 取负值以抑制侧向腿交叉。
  3. **CoM 可达范围**：$p_{\min} \le p_{x,k+1}^- \le p_{\max}$，导出两个线性不等式，对应区间 $u_{x,k} \in [u_{\text{lo}}, u_{\text{hi}}]$。
- **投影几何与计算**：可达/分离约束给出区间或半空间，能量约束给出环约束；交集为至多两个区间的一维可行集，投影退化为**闭式最近点吸附（clamp + 标量比较）**，计算极轻。
- **RL 集成细节**：
  - 策略输出 3 维动作 $a = [u_{x,k}, u_{y,k}, \theta_{\text{pitch}}]^\top$，仅落足分量被约束，躯干俯仰直接通过。
  - 观测 8 维：CoM 位置、平均速度、速度跟踪误差、期望速度。
  - 网络为 2 层 256 单元的 RNN（ReLU + Sigmoid 输出缩放），PPO 训练。
  - 策略 33 Hz，全身控制器（WBC）1 kHz，步长固定 $T=0.35$ s。

## 6. 主要结论与发现

- **安全塑形有效**：仅使用 DECBF 塑形（滤波关）时，违规度量从无引导策略的 $M=1.0$ 降至 $0.13$，即 **87% 的违规减少**；平均足距远离安全边界，说明塑形成功把策略推向更安全的落足。
- **塑形 + 滤波互补**：DECBF 引导策略加投影滤波后，在报告试验中**零测量违规**；把滤波直接加在无引导策略上也能将 $M$ 降至 $0.23$，说明两层机制分别作用于训练分布和运行时约束。
- **安全—跟踪权衡**：滤波开启会引入**更大的横向速度振荡和更长的调节时间**，且 DECBF 引导策略的足距比无引导情形更宽（安全约束只设下限，宽步可接受且更鲁棒）。
- **轨道能量预警腿交叉**：相图显示稳定行走时 $E<0$；扰动使 $E$ 由负转正后，CoM 越过支撑脚并发生腿碰撞，验证了能量包络约束的动机。
- **矢状约束有效**：无引导策略轨迹越出轨道能量和 CoM 可达边界，DECBF 引导策略在报告试验中保持在模板级安全区内。
- **剩余违规来源**：滤波后的无引导策略仍有违规，说明**模型失配和 WBC 跟踪误差**使"命令可行"与"全阶安全"之间存在间隙。

- **算力与可复现性信息缺失**：训练时长、环境步数、GPU 配置、超参数表等均未给出，第三方难以复现或评估方法成本。
- **安全约束的局部性**：仅约束落足分量，躯干俯仰 $\theta_{\text{pitch}}$ 直接透传不受约束，躯干姿态失控（如过度前倾）可能绕过落足安全约束而危及整体稳定，论文未讨论这类"未受保护维度"的风险。
- **缺少与基线安全方法的对比**：没有与 CBF-QP 全阶滤波、安全 RL（如 CPO、Lagrangian PPO）、传统步态生成器+安全裕度等其他路线做定量对比，难以判断该方法相对现有方案的优劣。
- **计算开销只有定性描述**：虽然声称投影为闭式、开销极低，但未给出与无滤波策略的实测控制周期/推理耗时对比数据。

## 9. 可能的改进方向与后续工作

- **统计严谨化**：多种子（如 10–20 次）重复训练与评估，报告均值、方差、箱线图与显著性检验，并给出违规度量的置信区间。
- **补全消融与敏感性分析**：逐一开启/关闭三类屏障，扫描 $\gamma, \eta_i, k_s, W_{\min}, E_{\max}$ 等超参数，量化其对安全性与跟踪性能的影响。
- **扩展评估维度**：引入更多扰动模式、地形（斜坡、台阶、随机高度场）、变步长/变步时，以及多方向速度指令，检验泛化性。
- **量化模板—全阶间隙**：统计"DECBF 判定安全但全阶仍违规"的比例，并分析其与 WBC 跟踪误差、模型参数偏差的相关性。
- **真机部署验证**：在 Digit 或类似平台上验证实时性与鲁棒性，考察传感器噪声和执行器延迟的影响。
- **扩展到非受约束维度**：将躯干姿态、关节力矩等也纳入安全约束，或将 DECBF 与全阶 CBF-QP 组合，缩小模板级与全阶级的差距。
- **与其他安全 RL 方法对比**：在统一基准上与 CPO、Lagrangian PPO、CBF-QP 滤波等方法定量比较安全性与任务性能。
- **理论深化**：在存在模型失配时给出鲁棒 DECBF 或概率性安全保证的界，而非仅依赖精确模型的前向不变性论证。

## 10. 总体评价与定位

- **贡献定位**：本文提出了一条"解析模板 + 无模型 RL"的混合安全路线，把 ALIP 步到步预测器转化为闭式 DECBF，并同时用于训练塑形与运行时落足投影。其核心价值在于**将步到步预测结构与数学安全证书低成本地嵌入 RL 策略层**，在可解释性、实时性与鲁棒性之间取得折中。
- **方法亮点**：利用 ALIP 步映射对落足输入的仿射性，把安全约束简化为区间/半空间/环约束，投影退化为 clamp + 标量比较，计算极轻；双层机制（塑形改变分布、滤波兜底修正）设计合理且互补。
- **实证强度**：在 MuJoCo 的 Digit 全身控制栈上做了全阶验证，配对实验设计公平，能较干净地隔离塑形与滤波的效应；但受限于单一场景、单次试验、无消融与无真机，实证广度与统计严谨性偏弱，结论应视为**初步可行性验证**而非充分证明。
- **适用场景**：适合固定步长、结构相对规则的行走任务中作为模板级安全层；对于高度非结构地形或需要变步时的任务，需进一步扩展与验证。
- **一句话总结**：这是一项**理论动机清晰、实现轻量、方向有价值但实证尚不充分**的工作，为"模型知情安全 RL 用于双足运动"提供了一个有前景的原型，其真正价值有待更严格的统计评估、消融、泛化测试与真机验证来确认。
