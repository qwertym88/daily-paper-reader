## 摘要
使用离散动作词元的视觉-语言-动作（VLA）模型已被证明能有效控制机械臂完成操作任务。然而，对于人形机器人而言，其全身动作空间——腿、躯干、手臂和手——维度更高且异构性更强，带来了此前的VLA模型未曾解决的词元化、训练和实时推理挑战。我们提出Holo-M，据我们所知，这是首个用于人形机器人移动操作的离散VLA模型，它通过用动作词元扩展语言模型的词表，从本质上利用语言模型。在该模型中，我们设计了一个统一的动作分词器，将人形机器人动作空间分解为四个身体部位特定的分词器——末端执行器、身体、手和运动学——从而能够跨差异极大的具身形态和数据源进行训练，包括人形机器人遥操作、第一人称人类视频和仿真。通过用这些动作词元扩展语言模型的词表，我们避免了使用独立连续动作专家的模型所固有的知识隔离问题。为满足实时控制需求，我们通过分组离散扩散解码来解码每个身体部位的动作词元，而不是对动作词元使用自回归。我们在SIMPLE人形机器人移动操作基准上进行了大量实验，Holo-M在通用型和专用型评估中均取得了最高成功率，并以显著优势领先第二名。我们将发布所有代码和模型权重。

## Abstract
Vision-language-action (VLA) models using discrete action tokens have proven effective for controling robotic arms on manipulation tasks. For a humanoid, however, the whole-body action space -- legs, torso, arms, and hands -- is far higher-dimensional and heterogeneous, raising tokenization, training, and real-time inference challenges that the previous VLA models do not address. We present Holo-M, to our knowledge the first discrete VLA model for humanoid loco-manipulation that intrinsically exploits the language model by extending its vocabulary with action tokens. In this model, we devise a unified action tokenizer that decomposes the humanoid action space into four body-part-specific tokenizers -- end-effector, body, hand, and kinematics -- enabling training across drastically different embodiments and data sources, including humanoid teleoperation, ego-centric human video, and simulation. By extending the language model's vocabulary with these action tokens, we avoid the knowledge-insulation problem inherent to the models that use separate continuous action experts. To meet real-time control requirements, we decode each body part's action tokens through grouped discrete diffusion decoding, rather than using autoregression on the action tokens. We have conducted extensive experiments on the SIMPLE humanoid loco-manipulation benchmark, in which Holo-M achieves the highest success rates in both the generalist and specialist evaluations, leading the second best by significant margins. We will release all the code and model weights.

## 1. 核心问题与研究动机

- **背景**：VLA（Vision-Language-Action）模型已成为通用机器人策略的主流范式。其中"离散动作词元"路线（把动作编码为与文本同一词表中的 token，让动作生成变成语言模型本来就擅长的序列建模问题）在机械臂操作上已被验证有效。
- **缺口**：该路线此前几乎只面向机械臂——其动作空间维度低（若干关节角或末端位姿+夹爪），单一分词器加自回归/离散扩散即可高效处理。而现有人形机器人 VLA 模型普遍转向**连续动作生成**（在 VLM 主干上外挂 flow-matching / diffusion 动作专家，如 Ψ0）。
- **三个复合难题**（作者认为这不是偶然的工程差异）：
  - **分词（Tokenization）**：人形全身动作空间（腿、躯干、臂、灵巧手）维度远高于单臂，且各部位尺度、时标异构，扁平词表要么过粗要么过大。
  - **训练（Training）**：没有任何单一数据集覆盖全部自由度，必须从差异极大、仅部分重叠的数据源（遥操作、第一人称人类视频、仿真）中联合学习。
  - **实时推理（Real-time inference）**：更长的动作 token 序列下，逐 token 自回归解码过慢，无法满足全身控制频率。
- **额外动机**：连续动作专家必须与预训练 VLM 主干做"梯度隔离"（knowledge insulation）以避免破坏其语义表征；而把动作作为同词表 token，则不存在这条需要隔离的边界。
- **整体含义**：论文提出 **Holo-M**，自称是首个用于人形移动操作（loco-manipulation）的离散 VLA 模型，通过扩展语言模型词表把动作词元原生纳入同一序列模型。

## 2. 方法论

### 2.1 核心思想
不采用单一巨型分词器，而是把动作空间**按身体部位因子化**为四组，各自独立分词但共享同一离散词表；解码时不逐 token 自回归，而是**组内并行、组间因果**的分组离散扩散。

### 2.2 统一动作分词器（Canonical Action Space）

- 动作块：T = 30 步 @ 30 Hz，组序固定为 **EEF → body → hand → kinematics**，A_t ∈ R^{30×96}。
- 各组维度：(D_eef, D_body, D_hand, D_kin) = **(48, 29, 14, 5)**
  - EEF：双臂手腕位置、6D 手腕旋转、相机系指尖位置；
  - body / hand：硬件固定顺序的关节空间目标；
  - kinematics：基座速度、高度、偏航角速率指令。
- **关键设计**：某样本缺失的动作组**从损失中排除**（group-validity mask v_g），而非用人工填充补零——这是跨本体、跨数据源训练的基础。

### 2.3 FAST-RVQ 分词（本文提出的具体分词方案）

- 沿用 FAST 的思路，对每个动作维度沿**时间轴**做 DCT。
- 与 FAST 的 BPE 变长编码不同，FAST-RVQ 保留前 **N = 2** 个低频 DCT 系数，并对时域残差 R_{g,N} = X_g − IDCT(P_N·DCT(X_g)) 做 **Q = 4 级 RVQ**，各级码本由 **k-means 拟合**（不训练额外神经分词器）。
- token 长度公式：**L_g = 2·D_g + 4**，得 (L_eef, L_body, L_hand, L_kin) = **(100, 62, 32, 14)**，总动作序列 **L_action = 208** 个 token（不含结构 token）。
- 固定长度便于掩码并行解码；验证集重建误差 **0.0068**。

### 2.4 VLM 主干与条件上下文

- 主干：**Qwen3-VL-2B**；视觉编码器冻结，只优化语言主干。
- 条件顺序固定：**image → task → setup → state**。
  - setup 字段标识本体与数据源（如 "G1 humanoid robot from Humanoid Everyday"、"Human egocentric data from EgoDex"）；
  - state 为选定关节角，裁剪到 [−π, π]、除以 π 归一化、均匀量化为 256 个 state-bin token。
- 通过**扩展 Qwen3-VL 词表**加入 state token、action token 与结构 token（`<action_start>`、`<end_effector_start>` 等）。

### 2.5 分组离散扩散解码（基于 DiffusionVL 改造）

- 训练目标：每个动作组构成一个扩散 block，**块内双向注意力**（可并行重建），**块间保持因果**（当前组只能看条件和前序组，不能看后续组）。
- 对每个有效组独立采样掩码概率 p_g，掩码位置集合 M_g，损失为对掩码位置的对数似然，并以 p_g·N_g 归一化；总体损失按组权重 w_g 与有效性 v_g 加权平均（式 13）。**不引入独立扩散模型或动作头**。
- 推理：置信度式去掩码（confidence-based de-masking），当前组所有位置初始化为 [MASK]，每轮预测全部掩码位置并按置信度择优解掩码，一轮完成后追加进因果上下文再解下一组；前缀与已完成组做缓存。
- 效率：以每组 8 次去掩码计，四组仅需 **32 步串行解码**，对比自回归的 **208 步**，串行深度降低 **6.5×**。

### 2.6 四阶段训练流程（主干与词表全程不变）

1. **Stage I 自回归预训练**：在 EgoDex 与 Humanoid Everyday 上联合训练，用 v_g 掩码让每个样本只监督其具备的组（如 EgoDex 仅 v_eef = 1）。与 Ψ0 分阶段、分解码器的做法不同。
2. **Stage II 人形后训练**：在 SIMPLE 训练集上继续自回归训练，产出 **Holo-M AR** 基线。
3. **Stage III 分组离散扩散微调**：切换到式 (13) 的掩码扩散目标，产出 **Holo-M 通用策略**。
4. **Stage IV 任务专用微调**：从 Stage III 出发，按单任务演示微调，得到 **Holo-M specialist**。
