## 摘要
视觉-语言-动作策略是实现通用机器人控制的一个有前景的基础，但长时域类人全身操控要求机器人将任务物体视为在移动、接触、遮挡和恢复过程中持久的物理实体。我们将这个问题研究为物体状态发散：用于调节全身动作的物体状态可能与用于判断动作是否达到预期物理关系的状态不同。我们提出持久物体令牌化（POT），该方法从RGB-D观测中维护带角色索引的3D物体记录，并将其转换为物体令牌，供全身动作专家使用。实例化为POT-VLA后，相同的物体记录同时调节动作生成并支持几何谓词检查，形成了一个闭环执行系统，其中物体状态既可行动又可验证。在Unitree G1上，POT-VLA在八个真实世界任务族中将匹配的直接GR00T-N1.7基线从39/80成功提升到71/80成功。在外部与Being-0对齐的参考中，POT-VLA在对齐的服务任务上实现了44/50成功，而Being-0论文报告的成功率为37/50。最大的改进出现在需要维持3D关系的任务上，这表明以物体为中心的持久状态是可验证的类人VLA执行的有用抽象。

## Abstract
Vision-language-action policies are a promising foundation for general robot control, but long-horizon humanoid loco-manipulation requires the robot to treat task objects as persistent physical entities across movement, contact, occlusion, and recovery. We study this problem as object-state divergence: the object state used to condition a whole-body action can differ from the state used to decide whether the action achieved the intended physical relation. We propose \emph{Persistent Object Tokenization} (POT), which maintains role-indexed 3D object records from RGB-D observations and converts them into object tokens for a whole-body action expert. Instantiated as \emph{POT-VLA}, the same object records condition action generation and support geometric predicate checks, yielding a closed-loop execution system in which object state is both actionable and verifiable. On a Unitree G1, POT-VLA improves a matched direct GR00T-N1.7 baseline from 39/80 to 71/80 successes over eight real-world task families. In an external Being-0-aligned reference, POT-VLA achieves 44/50 successes on aligned service tasks, compared with the 37/50 success reported by the Being-0 paper. The largest gains occur on tasks requiring maintained 3D relations, suggesting that persistent object-centered state is a useful abstraction for verifiable humanoid VLA execution.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：在类人机器人的长期（long-horizon）全身操作任务（如“整理桌子”、“递饮料”）中，**物体状态的发散（object-state divergence）** 是一个关键的失败模式。具体来说，用于生成动作的物体状态，与用于判断动作是否成功达到预期物理关系的物体状态，可能不一致。例如，机器人根据视觉抓取一个杯子，但抓取后杯子实际位置与规划时的位姿不同，后续行动（如放置）就会出错。
- **背景**：现有的视觉-语言-动作（VLA）策略通常将物体状态隐式编码在当前观测的视觉-语言特征中，而任务进度检查可能由另一个独立的监控器或符号层完成。这种分离导致在移动、接触、遮挡和恢复过程中，物体状态无法保持持久且一致，进而引发抓取错误、放置偏差、过早的任务转换等问题。
- **整体含义**：要实现可验证的类人VLA执行，物体状态必须以一种**既可用于动作生成，又可在执行后用于验证物理结果**的形式进行表示。论文主张以物体为中心的持久3D状态抽象来统一执行与验证，从而闭环控制。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想：持久物体令牌化（Persistent Object Tokenization, POT）

POT的核心是维护一份**角色索引的3D物体记录（role-indexed 3D object records）**，这些记录从RGB-D观测中提取，以机器人基座坐标系表示。记录被序列化为**持久3D物体令牌（Persistent 3D Object Tokens）**，同时供给全身动作专家（action expert）进行动作生成，以及供给几何谓词检查器（predicate verifier）进行验证。这形成一个闭环系统：**感知（ground）→ 行动（act）→ 刷新（refresh）→ 验证（verify）→ 恢复（recover）**。

### 关键技术细节

1.  **任务角色物体记录**：
    - 给定指令 \( I \) 和当前观测，一个VLM规划器或人工任务文件生成包含角色（如 `TARGET`， `DESTINATION`， `SUPPORT`， `HANDOVER_PARTNER`）的逐子任务计划。
    - 对于活跃子任务 \( \tau_i \)，POT为每个实体 \( e \) 构建记录 \( m_e^t \)，存储角色ID、语言短语、2D框（来自SAM3分割）、3D质心和范围、置信度、可见性、以及关系特征（如物体-容器距离、支撑高度、末端-物体偏移等）。
    - 可见性和置信度低的记录仍保留角色槽，但标记为不确定，驱动验证器请求重新观测而非误认为确认。

2.  **持久令牌模式**：
    - 默认分配 \( K = 8 \) 个槽，每个槽 \( F = 33 \) 个特征（可见性、置信度、2D框、3D质心、3D范围、可选方向、关系特征）。
    - 未使用的槽填充为 `PADDING` 并掩码。
    - 令牌化后，通过一个小型投影网络（LayerNorm → Linear → GELU → Dropout → Linear）将特征嵌入动作头的隐藏维度，并与角色嵌入和上下文嵌入结合。

3.  **动作头插入**：
    - 与直接基线（GR00T-N1.7）保持相同骨干网络和动作空间。POT-VLA将物体令牌直接插入DiT动作头的自注意力序列中，布局为 `[Z_state_t, Z_obj_t, Z_action_t]`，视觉-语言特征通过交叉注意力获得。
    - 动作专家预测整段动作块 \( \hat{a}_{t:t+H} \)，经过运行时检查后执行 \( a_{t:t+H} \)。

4.  **训练与适应**：
    - 使用与基线相同的动作块预测目标函数，**不添加辅助物体记忆或谓词损失**。
    - 微调时，演示数据配合同步的物体令牌侧边信息一起训练，使动作头学习将物体状态与动作关联。

5.  **闭环执行与验证**：
    - 执行每个短视界动作块后，机器人刷新RGB-D观测，更新同一份物体记录 \( M_{t+H}^{\tau_i} \)。
    - **几何谓词监督器**从刷新后的记录中计算谓词（如 `contained`， `supported`， `proximity`），判断子任务是否完成（`done`）、进行中（`in_progress`）、阻塞（`blocked`）、失败（`failed`）或不确定（`uncertain`）。
    - 根据反馈，系统选择**继续、重试、重新观测、重新接地或重新规划**。

## 3. 实验设计：数据集、场景、基准与对比方法

- **机器人平台**：Unitree G1 类人机器人，配备 Dex3-1 灵巧手和头戴 RGB-D 相机，在杂乱办公室环境中运行。
- **任务集**：8个真实世界任务族（每个任务10次试验）：
    1.  推车运输与放置（Cart transport/place）
    2.  薯片盒放入灰色篮子（Chip box to basket）
    3.  两个球放入篮子（Two balls to basket）
    4.  堆叠三个杯子（Stack three cups）
    5.  衣物放入洗衣篮（Garments to basket）
    6.  抽屉/托盘放置并关闭（Drawer/tray place-close）
    7.  桌面整理（Tabletop sorting）
    8.  近距离饮料递交（Close-range handover）
- **外部参考基准**：与 Being-0 论文中重叠的服务任务（Fetch-bottle, Deliver-basket, Grasp-bottle, Place-basket, Place-coffee）对比，使用 Being-0 论文报告的成功数（非本地复现）。
- **对比方法**：
    - **直接基线（Direct baseline）**：相同的 GR00T-N1.7 动作专家，但**禁用**持久物体记录、物体令牌和几何谓词监督。
    - **消融变体**：
        - **仅验证器**：使用直接动作路径但开启谓词监督与恢复。
        - **仅POT令牌**：使用物体令牌但禁用谓词监督。
        - **完整POT-VLA**：两者均启用。
- **泛化测试**：在4个任务上，分别测试**新颖物体实例**、**位置/姿态偏移**（20-50cm）、**干扰物**、**执行中扰动**（移动目标）4种变化，每个设置10次试验。
- **评价指标**：任务成功率（最终几何谓词在时间窗口内满足，无人工干预）。

## 6. 论文的主要结论与发现

- **主要结论**：提出POT-VLA系统，通过持久3D物体令牌（POT）在全身动作生成和谓词验证间共享物体状态，能显著提升真实类人机器人在长期操作任务中的成功率。
- **关键发现**：
    - 在8个任务套件上，POT-VLA将成功率从直接基线的 **39/80 提升至 71/80**，主要提升在需要维持3D关系的任务（如堆叠杯子、双球放置、衣物运输），验证了“物体状态发散”假说。
    - 消融实验显示：**物体令牌条件化**是主要贡献因素（直接15/40→仅令牌31/40），**验证器**提供额外增益（仅令牌31/40→完整34/40）。表明令牌解决多数接地失败，验证器捕获残余的虚假完成和部分失败。
    - 在外部Being-0对齐任务上，POT-VLA成功44/50，高于Being-0报告的37/50。
    - 泛化测试表明，在物体实例变化、布局变化、扰动下，POT-VLA均优于基线，说明角色感知的持久3D记录减少了目标搜索振荡和接触相关定位错误。

## 7. 论文的优点（方法与实验设计的亮点）

- **方法上的亮点**：
    1.  **统一物体状态表示**：在同一份角色索引的记录上既做动作条件化，又做几何验证，彻底避免了物体状态发散问题，是简洁而有效的设计。
    2.  **轻量级且即插即用**：POT不依赖仿真器、物理引擎或学习到的动力学模型，仅基于RGB-D测量；作为一种侧边信息注入现有VLA骨架，无需重新训练主干网络，可迁移到其他动作头。
    3.  **细粒度的验证与恢复**：几何谓词监督基于度量3D关系（如距离、包容性、支撑高度），可精确定位失败模式（抓取失败、放置偏外、支撑不稳），支持局部恢复而不触发全局重规划。
    4.  **处理不确定性**：可见性/置信度标记使得遮挡或不稳定的物体记录仍保留角色槽，驱动验证器请求重新观测，避免虚假确认。
- **实验设计上的亮点**：
    1.  **真实机器人上的全面评估**：在8种不同类型的操作性任务上测试，涵盖运输、放置、堆叠、整理、手递等，且包含变形物体（衣物），覆盖面较好。
    2.  **消融设计清晰**：逐步去掉令牌和验证器，量化各自的贡献，支持结论。
    3.  **泛化测试多维度**：涵盖新颖实例、布局变化、干扰物和执行中扰动，验证了鲁棒性。
    4.  **与已发表工作的外部比较**：尽管非严格公平，但提供了性能对照，增强说服力。

## 8. 不足与局限

- **实验覆盖与统计**：
    - 每个任务仅10次试验，样本量较小，个别任务（如推车运输直接基线3/10）可能存在随机波动。未报告置信区间或统计显著性检验。
    - 仅在单一机器人平台（Unitree G1）和单一环境（办公室）中评估，泛化性需在更多平台和场景中验证。
- **性能依赖感知模块**：
    - POT依赖于SAM3分割质量和RGB-D相机校准。在低纹理、快速运动、严重遮挡或照明变化下，对象记录质量下降可能影响整体性能。
- **缺乏与更多SOTA系统的同条件对比**：
    - 只与一个匹配直接基线和外部Being-0对比，未与同样使用物体中心化表示的近期工作（如WholebodyVLA， 3D Diffusion Policies）在同设置下比较。
- **任务复杂性限制**：
    - 实验任务均为短到中等长度（动作块数不超过数个），未验证在更复杂、长链条任务（如多目标、连续操作）下的表现。且所有任务的人类角色（如手递）仅为近距离，未包含动态交互或人为干扰。
- **可扩展性**：
    - 固定8个角色槽，对于包含更多实体的场景可能不够灵活。且角色类型目前手工定义，VLM规划器的集成未在论文中详细评估其泛化性。
- **资源与可复现性**：
    - 未公开代码或训练细节，也未说明微调GR00T-N1.7的计算成本，其他人难以复现。
- **训练数据依赖**：
    - 物体令牌的侧边信息需要与演示同步生成，如果训练时未包含此类标注，则无法适应。这也限制了使用大规模未标注的机器人数据集。
- **验证器局限性**：
    - 几何谓词基于度量关系，对于语义模糊条件（如“接受手递”）需要额外VLM调用，论文仅提及可选，但主要依赖几何阈值。后续任务可能复杂阈值设定。
