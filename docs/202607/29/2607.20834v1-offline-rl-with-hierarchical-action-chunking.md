## 摘要
离线目标条件强化学习有望从静态数据集中学习通用策略。然而，由于“地平线诅咒”——通过长链的引导式贝尔曼备份，值估计误差会不断累积，使得将这些方法扩展到长时域任务仍具挑战。现有层次化方法通过将任务分解为子目标来缓解这一问题，但它们通常依赖于短视执行和偏差值估计的低层控制器。本文提出层次化隐式Q-切分（HiQC），一种结合高层潜在规划与低层动作切分的离线目标条件强化学习算法。通过将低层评论家基于时间扩展的动作序列进行条件化，HiQC实现了无偏的k步值备份，在规划与执行层面均压缩了时域。理论上，我们证明了在每备份误差有界模型下，与单独的标准层次结构或扁平切分相比，这种双重分解能产生更紧的值误差上界。实验上，HiQC在OGBench套件中实现了所比较方法中最高的聚合性能，其最大增益体现在长时域导航任务（如人形机器人-巨人）上。

## Abstract
Offline goal-conditioned reinforcement learning (RL) holds the promise of learning general-purpose policies from static datasets. However, scaling these methods to long-horizon tasks remains a challenge due to the curse of horizon, where value estimation errors can compound through long chains of bootstrapped Bellman backups. Existing hierarchical approaches mitigate this by decomposing tasks into subgoals, yet they often rely on low-level controllers that suffer from myopic execution and biased value estimates. In this work, we propose Hierarchical Implicit Q-Chunking (HiQC), an offline goal-conditioned RL algorithm that combines high-level latent planning with low-level action chunking. By conditioning the low-level critic on temporally extended action sequences, HiQC enables unbiased k-step value backups, compressing the horizon at both the planning and execution levels. We theoretically demonstrate that this dual decomposition results in a tighter bound on value error under a bounded per-backup error model compared to standard hierarchy or flat chunking alone. Empirically, HiQC achieves the highest aggregate performance among the compared methods on the OGBench suite, with its largest gains on long-horizon navigation tasks such as humanoid-giant.

## 2. 方法论
### 核心思想
- **Hierarchical Implicit Q-Chunking (HiQC)**：一种离线目标条件RL算法，由高层潜变量规划器和低层动作切分控制器组成。
  - **高层**：以间隔 c 步生成潜空间中的子目标，采用隐式V学习（IVL）和优势加权回归（AWR）训练。
  - **低层**：将动作序列（chunk）作为基本单元，评论家（Q函数）直接基于完整动作序列进行条件化，实现无偏的 k 步贝尔曼备份；策略由条件流匹配（CFM）生成。

### 关键技术细节
- **高层学习**：
  - 使用价值函数 VH(s,g) ≈ w(s, φ(g))，其中 φ 将状态映射到潜子目标空间 Z。
  - 训练通过 c 步回报的期望损失：LVH = E[Lτ2 (r + γ^c VH(s_{t+c}, g) - VH(s_t, g))]。
  - 提取高层策略 πH(z|s,g) 采用 AWR：LπH = E[exp(advantage/α) log πH(φ(s_{t+c}) | s_t, g)]。
- **低层学习**：
  - 定义动作分块 a ∈ A^k，评论家 QL(s, a, z) 和价值函数 VL(s, z) 通过 IQL 适应动作分块训练：
    - LVL = E[Lτ2(QL - VL)]，LQL = E[(r + γ^k VL(s_{t+k}, z) - QL)^2]。
  - 低层策略 πL(a|s,z) 使用优势加权流匹配：LπL = E[exp((QL - VL)/β) ||vω - u_t||^2]。
- **整体流程**（Alg. 1）：采样轨迹 → 高层更新（VH, πH）→ 低层更新（VL, QL, πL）→ 推理时按序生成子目标和动作分块并开环执行 k 步。

### 理论分析（Theorem 1）
- **模型**：假设每次贝尔曼备份引入有界误差 ε，则总误差与备份次数成正比。
- **对比**：
  - 扁平TD：D = T → 误差 O(T)
  - 扁平动作切分：D = T/k → O(T/k)
  - 标准层次（HIQL）：D_H = T/c，D_L = c → O(T/c + c)
  - HiQC：D_H = T/c，D_L = c/k → O(T/c + c/k)，优化后可达 O(√(T/k))。
- **意义**：双重分解进一步压缩低层备份次数，使误差上界比标准层次更紧，尤其是在 k 较大时。

## 6. 主要结论与发现
- HiQC 在 **OGBench 聚合性能中排名第一**（平均成功率 53%，远超 HIQL 的 42%）。
- **最大优势**出现在长程导航任务（humanoid-giant 提升 23 个百分点，pointmaze-giant 提升 36 个百分点），扁平方法基本失败。
- 在操作任务上表现 **混合**：cube-triple 最优（9%），但 scene-play 和 puzzle-4x6 低于 DQC。
- 消融实验表明：流匹配策略优于高斯；chunk 大小过大会因开环误差下降；子目标间隔存在最优值。
- 理论分析支持双重分解比单独层次或扁平切分更紧的误差上界。

## 7. 优点
- **结构创新**：首次将高层潜规划与低层动作切分结合，实现规划-执行双重时域压缩。
- **理论支撑**：在简化模型下推导了误差上界的改进，提供了直观解释。
- **实验全面**：对比了多种代表性方法，在标准 benchmark 上评估，含长时域和高维操作任务。
- **消融完善**：验证了流匹配策略、chunk 大小、子目标间隔等关键设计的影响。
- **实用扩展**：低层采用流匹配，克服高斯策略的多模态局限。

## 8. 不足与局限
- **实验统计**：仅 4 个随机种子，置信区间可能不够稳定（作者已指出）。
- **超参数敏感性**：未进行大规模调优，scene 环境需调整学习率等。
- **操作任务短板**：在 puzzle 和 scene 上不如 DQC，分析认为可能因潜子目标瓶颈或 critic 时域不够长，但未完全验证。
- **理论简化**：假设每备份误差有界且独立，神经网络的函数近似可能违背这些假设；仅提供直觉而非端到端保证。
- **固定 chunk 大小**：所有状态使用相同 k，开环误差随 k 增大而累积（消融显示）。
- **确定性动力学假设**：高层价值无偏仅适用于确定性环境，随机环境或需额外处理。
- **应用限制**：仅验证了基于状态的导航和操作，未涉及多智能体、图像输入等复杂场景。
