## 摘要
线性注意力模型允许固定的状态大小和每个token固定的计算量。然而，由于其有限的状态大小，线性注意力模型在长上下文回忆方面落后于基于softmax注意力的Transformer架构。增加线性注意力的状态大小可以提高回忆性能，但代价是更高的FLOPs。在这项工作中，我们引入了稀疏Delta记忆（SDM），这是一种通过稀疏寻址方案将门控线性RNN的隐藏状态扩展到更高数量级容量的架构。SDM扩展了门控DeltaNet架构，用对大型显式记忆的稀疏读写替代了稠密的键值外积。我们表明，在isoFLOP约束下，且参数数量相同的情况下，更高的状态记忆容量显著提升了上下文学习和长上下文检索任务的性能。此外，通过学习SDM记忆的初始状态并将其用作参数记忆，我们表明模型在广泛常识和推理任务上进一步得到改进。

## Abstract
Linear attention models allow a fixed state size and a fixed amount of compute per token. However, due to their limited state size, linear attention models fall behind in long-context recall compared to softmax-attention-based transformer architectures. Increasing the state size of linear attention improves recall performance but at the cost of higher FLOPs. In this work, we introduce Sparse Delta Memory (SDM), an architecture that scales the hidden state of gated linear RNNs to orders of magnitude higher capacity using a sparse addressing scheme. SDM extends the Gated DeltaNet architecture by replacing the dense key-value outer product with sparse reads and writes to a large explicit memory. We show that, under an isoFLOP constraint and with an identical number of parameters, a higher state memory capacity significantly improves performance on in-context learning and long-context retrieval tasks. Moreover, by learning the initial state of the SDM memory and therefore using it as a parametric memory, we show that the model further improves on a wide range of common-knowledge and reasoning tasks.

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：将Gated DeltaNet的**稠密键值外积写入**替换为**对大型显式内存表的稀疏读写**。具体地，每个时间步只对少量被选中的内存槽位进行更新和读取，其他槽位保持不变。
- **关键技术细节**：
  1. **Product-Key Memory (PKM) 索引**：利用外积分解避免显式构建全尺寸得分矩阵，将查询/键投影到两个低维向量，通过外积和Top-k选择实现对数百万槽位的快速稀疏寻址。
  2. **门控Delta写入**：对被选中的写入槽位应用遗忘门（α）和输入门（β）以及Delta规则（先读取当前值再写入增量），未选中槽位保持上一时刻值。
  3. **稀疏读取**：仅从被选中的读取槽位加权求和得到输出。
  4. **学习初始状态M0**：将内存初始值作为可训练参数，使模型能存储预训练知识。
  5. **等FLOP设计**：通过设置读/写数量W=R等于稠密GDN的key维度，保证计算量一致；状态大小N可通过减少头数H来增大。
- **公式流程**（文字说明）：
  - 写入阶段：计算稀疏键和查询的得分，选出W个写入槽位；对于每个选中槽位，先衰减旧状态，再用门控Delta规则更新。
  - 读取阶段：计算读取得分，选出R个读取槽位，加权求和得到输出状态。
  - 整合：输出经RMS归一化、门控和头部混合后得到最终输出。

## 6. 主要结论与发现

1. **SDM在所有计算级别持续优于GDN**：在等FLOP和等参数下，SDM的训练损失更低，且遵循幂律可预测扩展（R²=0.999）。
2. **长上下文召回显著提升**：在RULER上，1.4B SDM平均31.2% vs GDN 20.0%；8B SDM 50.2% vs GDN 34.2%。
3. **短上下文任务表现更优**：SDM在13/15个常识推理任务上超过GDN，8B时平均准确率甚至超过Full Attention（56.84% vs 56.65%）。
4. **学习初始内存M0有效**：只有在大内存下学习M0才带来收益（GDN小内存学习M0无改善），说明大容量内存可存储预训练知识。
5. **内存大小与性能单调正相关**：从27MB增大到432MB，各项指标持续提升。
6. **混合FullAttn+SDM可进一步降低损失**：在三路混合（SWA+FullAttn+SDM）中，损失更低，说明二者能力互补。

## 7. 优点

- **创新性**：首次将稀疏寻址（PKM）引入门控线性RNN的在线学习更新中，实现了状态容量三个数量级的提升而不增加计算量。
- **实验设计严谨**：
  - isoFLOP和同参数对比，确保公平。
  - 大规模验证（8B模型、1万亿token）。
  - 详尽的消融实验，分离了内存大小与学习初始化的影响。
- **可扩展性**：SDM在更大规模下甚至超越Full Attention，符合LLM发展趋势。
- **透明度**：代码开源，提供了训练和推理效率分析。

## 8. 不足与局限

- **实际训练速度慢**：当前CUDA内核的MFU远低于优化后的GDN内核，导致SDM训练速度慢约1.49倍（8B模型），推理慢约10%（但比Full Attention快6倍）。
- **内存占用大**：SDM状态自身占用与模型参数相近，虽然相比于KV缓存仍较小，但对边缘设备不友好。
- **仅在文本领域验证**：未在视频、音频等多模态长上下文任务上测试，而论文提到这些场景是重要应用方向。
- **缺少对更大规模（>10B）模型的测试**：现有最大为8B，结论的外推性需进一步验证。
- **评估任务覆盖有限**：虽然RULER覆盖13个任务，但部分任务（如变量跟踪）存在评估问题（文中已指出）。常识推理任务多为选择题，可能无法体现实际长上下文推理能力。
- **未与最新状态空间模型（如Mamba2-H3等）在等计算下比较**：主要基线是GDN和Mamba2，但未包含所有近期高效线性注意力模型。
