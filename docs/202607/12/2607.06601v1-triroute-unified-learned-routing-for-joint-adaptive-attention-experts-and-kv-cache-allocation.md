## 摘要
条件计算可以将语言模型质量与每token推理成本解耦，但领先的技术仅孤立地作用于单一轴：混合专家（MoE）稀疏化FFN，混合深度（MoD）跳过整个Transformer块，KV缓存量化压缩注意力内存。我们认为这三个决策（注意力分辨率、专家选择和缓存位宽）是强耦合的，应联合做出：一个需要充分注意的稀有token，无论由哪个专家处理，都可能需要高精度缓存。我们提出了TriRoute，一个在所有三个轴上共享的轻量级控制器，对于每一层的每个token，发出一个协调策略：（i）注意力模式（跳过/局部/全局），（ii）一组稀疏的FFN专家（具有恢复MoD的空专家），以及（iii）KV缓存位宽。该控制器通过异构松弛（用于分类决策的Gumbel-Softmax与直通估计，以及用于专家的负载均衡top-k门控）在拉格朗日预算约束下进行端到端训练，该约束将平均计算和内存成本变为可控旋钮。我们识别了朴素联合训练中的跨轴路由坍缩级联，其中一轴的坍缩传播到其他轴，并通过每轴归一化和耦合感知的平衡损失来解决它。在从1.6亿到13亿参数、计算最优token数量的decoder-only模型上，TriRoute在匹配推理FLOPs和内存的情况下，帕累托优于最佳的独立MoD+MoE+KV量化组合，同时更好地保留了纯困惑度优化所侵蚀的稀有实体、代码和算术的尾部案例鲁棒性。事后分析揭示了可解释的结构：控制器将完全注意力和高精度缓存分配给句首位置、稀有子词和命名实体，同时廉价地路由功能词。

## Abstract
Conditional computation can decouple language model quality from per-token inference cost, yet leading techniques act on a single axis in isolation: Mixture-of-Experts (MoE) sparsifies the FFN, Mixture-of-Depths (MoD) skips whole transformer blocks, and KV-cache quantization compresses attention memory. We argue these three decisions (attention resolution, expert selection, and cache bit-width) are strongly coupled and should be made jointly: a token rare enough to warrant full attention may also need high-precision caching regardless of which expert processes it. We introduce TriRoute, a single lightweight controller shared across all three axes that, for every token at every layer, emits a coordinated policy: (i) an attention mode (skip/local/full), (ii) a sparse set of FFN experts (with a null expert recovering MoD), and (iii) a KV-cache bit-width. The controller trains end-to-end via a heterogeneous relaxation (Gumbel-Softmax with straight-through estimation for categorical decisions and load-balanced top-k gating for experts) under a Lagrangian budget constraint that turns the average compute and memory cost into a controllable knob. We identify a cross-axis routing-collapse cascade in naive joint training, where collapse on one axis propagates to the others, and address it with per-axis normalization and a coupling-aware balancing loss. On decoder-only models from 160M to 1.3B parameters at compute-optimal token counts, TriRoute Pareto-dominates the best independent MoD+MoE+KV-quantization combination at matched inference FLOPs and memory, while better preserving tail-case robustness on rare entities, code, and arithmetic that pure perplexity optimization erodes. Post-hoc analysis reveals interpretable structure: the controller allocates full attention and high-precision cache to sentence-initial positions, rare subwords, and named entities, while cheaply routing function words.

#### 2. 论文提出的方法论

- **核心思想**：将三个条件计算（注意力分辨率、FFN专家、KV位宽）统一到一个共享的控制器中，通过端到端训练学习耦合策略。
- **关键技术细节**：
  - **控制器结构**：一个共享的轻量级MLP主干，加上三个独立的线性头部（注意力头、专家头、位宽头）。输入是归一化的残差状态加上廉价侧特征（如相对位置、边界、预测熵、前一层决策）。
  - **异构松弛与梯度估计**：
    - 注意力模式和位宽决策：使用Gumbel-Softmax + 直通估计器（STE），温度从2.0退火到0.5。
    - 专家选择：使用标准可微top-k softmax门控（包括空专家恢复MoD）。
    - **跨轴梯度平衡**：通过EMA跟踪每个头部梯度范数，对每个头部的STE输出进行缩放，防止注意力头部主导梯度。
  - **可微成本模型**：为每个资源（FLOPs和内存）定义每token每层的成本，期望成本关于软决策可微。
  - **耦合感知的平衡损失**：
    - 每轴负载均衡损失和z-损失（来自Switch/ST-MoE）。
    - 跨轴坍缩级联问题：一轴坍缩（如注意力全选跳过）会导致共享主干输入低方差，进而引发其他轴坍缩。解决方法：
      1. **每轴白化**：在每轴头部之前对主干输出进行去均值和缩放的停止梯度操作，防止一轴坍缩影响其他轴的输入尺度。
      2. **边际熵下限**：当某一轴的选项使用熵低于最大值的ζ时，施加铰链损失，防止坍缩。
  - **在线拉格朗日预算控制**：对FLOPs和内存分别设置非负乘子λr，通过投影对偶上升更新，使平均成本约束于目标预算C*。
  - **训练与推理**：训练时使用soft决策计算成本并端到端优化；推理时取硬argmax决策，只执行选定计算，实现静态计算图。

#### 6. 论文的主要结论与发现

- **联合路由优于独立前沿**：TriRoute在计算和内存的帕累托前沿上完全主导独立组合，在1.3B模型上以约55% FLOPs和40%内存达到密集模型困惑度。在激进预算区域（35-55% FLOPs）差距更大。
- **尾部鲁棒性更好**：独立组合在稀有实体（+2.1 ppl）、代码（+0.4）、数学（+1.7）上明显退化，而TriRoute保持在0.4 ppl以内；GSM8K仅损失0.3点（密集模型4.8 vs 独立组合3.6 vs TriRoute 4.5）。
- **控制器学到可解释策略**：
  - 读（注意力）和写（缓存位宽）分配给信息量大的token（稀有子词、命名实体、句首词，即注意力沉点）。
  - FFN计算与注意力解耦：稀有实体经常跳过FFN但保留全注意力和高精度缓存（MoD无法表示的模式）。
  - 层间专业化：早期层保持高注意力，后期层更选择性；“先注意后计算”模式自然出现。
- **耦合真实且非对称**：注意力和位宽互信息高（~0.31 nats），FFN相对独立（<0.08 nats），支持共享主干+独立头部的设计。

#### 7. 优点

- **工程收敛性**：通过异构松弛（Gumbel-ST + top-k gating）、梯度平衡、白化、熵下限、在线Lagrangian等设计，使联合训练可行且稳定。

- **可解释性**：控制器策略有语言学上的解释性，便于理解计算节省的来源。

#### 8. 不足与局限

- **FLOPs到墙钟时间转换不完美**：实现速度提升（1.7× tokens/s）低于理论FLOPs比（1.8×），主要因：
  - 参差注意力模式（跳过/局部/全局）导致不规则的attention kernel，当前融合内核未利用。
  - 混合精度缓存管理复杂，需要按精度分组。
  - 控制器增加了每层同步点。
- **训练稳定性与超参数敏感性**：联合训练比单轴路由更精细，额外超参数（α, β, γ, ζ, ρ_λ）虽在三个规模上通用，但仍需仔细调节。
- **规模验证有限**：实验仅到1.3B参数，未验证≥10B参数或极高稀疏度（如8%活跃FLOPs）场景。是否更易控制坍缩级联未知。
- **未测试的扩展**：注意力模式仅3种、位宽仅4个离散值，未考虑连续分辨率或学习跨度/检索注意力；未包括KV驱逐轴（如H₂O/StreamingLLM）。
- **尾部评估是代理**：稀有实体、代码、数学等指标是近似，未全面考察对低资源语言或不同领域的公平性。
- **研究诚信声明**：文中明确所述数字旨在展示预期趋势，作为基准声明时应复现完整训练。
