## 摘要
我们提出OrchNAS，一种能量感知、个性化、联邦边缘智能框架，它利用神经架构搜索服务为异构边缘环境自动设计服务自适应模型。该框架在服务器端的NAS服务上编排架构搜索过程，使边缘服务能够在设备级别的能量、计算和内存约束下派生个性化架构。我们引入了一种能量感知的全局架构搜索机制，该机制学习跨异构服务的紧凑全局表示。我们开发了一种能量高效的架构选择机制，通过渐进式、贪婪、能量感知的剪枝策略，使每个服务能够导出满足其资源约束的个性化子网络。我们提出了一种能量高效的个性化模型优化方案，该方案在保持全局表示的同时更新服务自适应参数，其中原始-对偶优化机制在架构适应过程中强制执行严格的能量预算。在真实世界和基准数据集上的实验证明了所提方法的有效性。

## Abstract
We propose OrchNAS, an energy-aware, personalised, federated edge intelligence framework that leverages a Neural Architecture Search Service to automatically design service-adaptive models for heterogeneous edge environments. The framework orchestrates the architecture search process on a server-side NAS service, enabling edge services to derive personalised architectures under device-level energy, computation, and memory constraints. We introduce an energy-aware global architecture search mechanism that learns a compact global representation across heterogeneous services. We develop an energy-efficient architecture selection mechanism that enables each service to derive a personalised subnet that satisfies its resource constraints via a progressive, greedy, energy-aware pruning strategy. We propose an energy-efficient personalised model optimisation scheme that updates service-adaptive parameters while preserving global representations, where a primal-dual optimisation mechanism enforces strict energy budgets during architecture adaptation. Experiments on real-world and benchmark datasets demonstrate the effectiveness of the proposed approach.

## 1. 核心问题与整体含义（研究动机和背景）
- **问题背景**：边缘设备（无人机、穿戴设备、IoT传感器等）资源高度异构，且对能耗敏感。传统联邦学习（FL）使用统一模型难以适应不同设备约束，而个性化联邦学习（PFL）虽能适配本地数据，但手动设计架构耗时且难以能量高效。
- **核心挑战**：
  - NAS本身能量开销大，在分布式环境下更严重；
  - 全局与个性化表示的平衡——全局骨干太大则计算成本高，太小则无法提取足够特征；
  - 服务自适应架构搜索：不同设备的计算、内存、能量预算差异大，需为每个服务定制可行架构。
- **研究意义**：自动设计既符合设备资源约束、又保持全局表征能力的个性化模型，对于边缘智能的实用化至关重要。

## 2. 方法论
- **核心思想**：将NAS过程从客户端卸载到服务器端的NAS Service，统一编排全局架构搜索与个性化适配；采用能量感知进化搜索、渐进贪婪剪枝、原对偶优化三阶段，确保全局紧凑、个性化可行、能量预算严格满足。
- **关键技术细节**：
  - **能量感知全局架构搜索**：
    - 服务器维护候选架构池 $A_b$，每轮通过进化突变生成新架构。
    - 各服务计算每个候选架构的预计训练能量 $\hat{E}_t^k(a) = \alpha_t^k F(a) T_t^k$ 和能量感知得分 $S_t^k(a) = \text{ValAcc}_t^k(a) - \lambda \hat{E}_t^k(a)$。
    - 服务器加权聚合得分，选出全局架构 $a_t = \arg\max_{a \in A_b} \sum_{k \in K_t} p_t^k S_t^k(a)$。
    - 广播全局架构与共享参数，各服务执行局部SGD更新全局参数。
  - **能量感知架构选择（渐进贪婪剪枝，Algorithm 2）**：
    - 每个服务评估当前子网是否满足资源约束（能量 ≤ 预算、FLOPs ≤ 计算容量、参数量 ≤ 内存）。
    - 若不满足，对每条边上的每个操作计算移除后的精度下降 $\Delta\text{Acc}$ 和能量减少 $\Delta E$，按得分 $\text{Score} = \Delta\text{Acc} - \beta \Delta E$ 排序，逐步去除得分最低的操作，直到约束满足。
    - 剪枝后服务获得个性化子网 $a_t^k$。
  - **能量高效个性化模型优化（原对偶优化）**：
    - 保留全局参数固定，仅更新个性化参数 $v_k$，含近端项 $\frac{\mu}{2}\|v_k - w_{\text{global}}\|^2$。
    - 引入非负对偶变量 $\eta_k$ 构造拉格朗日函数 $L_k(a_k, \eta_k) = F_k(w_{\text{global}}, v_k, a_k) + \eta_k (E_k(a_k) - B_k)$。
    - **原始更新**：通过贪心剪枝近似最小化 $L_k$（等价于最小化 $F_k + \eta_k E_k$）。
    - **对偶更新**：$\eta_k^{t+1} = [\eta_k^t + \rho (E_k(a_k^{t+1}) - B_k)]_+$，能量超支时增加惩罚强度，确保长期平均违反量被约束在 $\epsilon = O(\rho)$ 内。
- **算法流程**（Algorithm 1概括）：
  1. 初始化全局参数、候选池、各服务个性化参数和子网。
  2. 每轮通信：服务端生成候选架构，并行评估得分，选择全局架构；各服务更新全局参数。
  3. 各服务检查可行性，若违反则执行变精度剪枝得到 $a_t^k$。
  4. 个性化参数更新（含近端项）并执行对偶更新；上传更新后的全局参数；服务器加权平均。
