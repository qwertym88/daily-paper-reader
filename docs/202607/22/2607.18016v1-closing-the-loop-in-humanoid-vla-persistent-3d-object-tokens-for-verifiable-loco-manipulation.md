## 摘要
视觉-语言-动作策略是通用机器人控制的一个有前景的基础，但长期的人形移动操作任务要求机器人将任务物体视为在运动、接触、遮挡和恢复中持续存在的物理实体。我们将此问题研究为物体状态发散：用于调节全身动作的物体状态可能与用于判断动作是否达到预期物理关系的状态不同。我们提出了持久化物体标记化（POT），它从RGB-D观测中维护角色索引的3D物体记录，并将其转换为用于全身动作专家的物体标记。实例化为POT-VLA后，相同的物体记录既用于条件动作生成，又支持几何谓词检查，从而形成一个闭环执行系统，其中物体状态既可操作又可验证。在Unitree G1上，POT-VLA在八个真实世界任务族中将匹配的直接GR00T-N1.7基线从39/80成功提升到71/80。在一个外部Being-0对齐的参考中，POT-VLA在对齐的服务任务上取得了44/50的成功率，而Being-0论文报告的成功率为37/50。最大的提升出现在需要维持3D关系的任务上，表明以物体为中心的持久化状态是可验证的人形VLA执行的有用抽象。

## Abstract
Vision-language-action policies are a promising foundation for general robot control, but long-horizon humanoid loco-manipulation requires the robot to treat task objects as persistent physical entities across movement, contact, occlusion, and recovery. We study this problem as object-state divergence: the object state used to condition a whole-body action can differ from the state used to decide whether the action achieved the intended physical relation. We propose \emph{Persistent Object Tokenization} (POT), which maintains role-indexed 3D object records from RGB-D observations and converts them into object tokens for a whole-body action expert. Instantiated as \emph{POT-VLA}, the same object records condition action generation and support geometric predicate checks, yielding a closed-loop execution system in which object state is both actionable and verifiable. On a Unitree G1, POT-VLA improves a matched direct GR00T-N1.7 baseline from 39/80 to 71/80 successes over eight real-world task families. In an external Being-0-aligned reference, POT-VLA achieves 44/50 successes on aligned service tasks, compared with the 37/50 success reported by the Being-0 paper. The largest gains occur on tasks requiring maintained 3D relations, suggesting that persistent object-centered state is a useful abstraction for verifiable humanoid VLA execution.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题背景**：人形机器人的长期移动操作任务（如收拾桌子、递饮料）需要将任务物体视为持续存在的物理实体，在行走、接触、遮挡和恢复过程中始终保持对其状态的追踪。现有视觉-语言-动作（VLA）策略通常将物体状态隐式编码在视觉-语言特征中，导致“物体状态发散”现象：用于条件动作生成的物体状态与用于验证动作是否达成预期物理关系的状态不一致。这种不一致会造成抓取失败、错误操作、无效恢复等问题。
- **整体含义**：论文提出一种闭式循环执行系统，通过共享的、持久的、以物体为中心的3D状态表示，同时支撑动作生成和执行验证，从而提升人形VLA在长时移动操作中的可靠性和可验证性。

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：提出**持久化物体标记化（Persistent Object Tokenization, POT）**，将RGB-D观测中的任务相关物体提升为角色索引的3D物体记录，并序列化为持久化3D物体标记（Persistent 3D Object Tokens），供全身动作专家（whole-body action expert）使用。该物体记录在每次动作块执行前后被刷新，既用于条件动作预测，也用于几何谓词验证，从而形成“维护-动作-观测-验证-恢复”的闭环。
- **关键技术细节**：
  - **任务-角色物体记录**：给定指令和观测，由VLM规划器或任务文件生成类型化子任务计划，每个子任务指定角色、接地查询、成功谓词等。从RGB-D观测中构建角色索引物体内存 \(M_t^{\tau_i} = \{m_e^t \mid e \in E_i\}\)，每个记录包含角色、短语、图像框、3D质心和范围、置信度、可见性及关系特征（如物体-容器距离、支撑高度、末端-物体偏移等）。使用SAM3提供角色/查询掩码，通过相机内参和相机-基底变换将有效深度像素反投影到机器人基底坐标系。
  - **持久化标记模式**：将物体内存映射为固定槽位的特征张量 \(x_t^{obj} \in \mathbb{R}^{K \times F}\)，默认 \(K=8\) 槽位，每槽 \(F=33\) 特征。有效槽携带角色ID（TARGET, DESTINATION, SUPPORT, HANDOVER_PARTNER等），未用槽为PADDING并掩码。特征包括可见性、置信度、2D框、3D质心、3D范围、可选方向及关系特征。持久性来自：任务实体绑定到角色槽，每次动作块后刷新度量证据；即使物体被遮挡或低置信度，角色槽仍存在，但标注不确定性。
  - **物体标记条件VLA执行**：以GR00T-N1.7为基础动作专家，保持相同骨架、体现和运行时。在动作头序列中插入物体标记：序列布局为 \([Z_t^{state}, Z_t^{obj}, Z_t^{action}]\)，其中物体槽投影器 \(f_\theta^{obj}\) 将槽特征嵌入DiT隐藏维度。动作头预测候选全身块 \(\hat{a}_{t:t+H} = \pi_\theta(S_t, Z_t^{vl})\)。训练时，演示与物体标记侧车配对，使用相同动作块预测损失，无辅助损失。仅更新物体标记分支和动作头参数。
  - **谓词级验证与恢复**：几何谓词监督器读取与动作策略相同的角色索引物体内存，检查子任务就绪性并验证每次动作块后的物体内存。谓词类型包括containment, support, end-effector–target proximity, target–destination displacement等，每个谓词定义为 \(\langle \kappa, \alpha, op, \nu, n \rangle\)。验证返回状态：in_progress, done, blocked, failed, uncertain。低置信度触发重新观测或重新接地。基于诊断选择继续、重试、重新观测、重新接地或重新规划。
