## 摘要
在未知场景中快速规划新行为仍然是机器人领域的基本挑战。人形机器人移动操作的高维、混合和欠驱动特性持续阻碍着这一目标的实现。在本文中，我们通过提出一个嵌套的运动-动力学框架来解决这一挑战，该框架用于在给定候选接触序列的情况下快速进行可行性检查和生成动态一致的轨迹。通过将该模块与可行性引导的树搜索以及基于大型语言模型（LLM）的接触计划采样策略相结合，我们证明了所提出的框架可以显著改善搜索过程。此外，我们展示了生成的轨迹可以使用基于强化学习（RL）的控制器进行跟踪，并且结果表明所产生的轨迹具有足够高的质量，可在真实世界的移动操作场景中执行。补充视频见：https://youtu.be/R6qCHoCormQ。

## Abstract
Fast planning of novel behaviors in unseen scenarios remains a fundamental challenge in robotics. The high-dimensional, hybrid, and underactuated nature of humanoid loco-manipulation continues to hinder the realization of this goal. In this paper, we address this challenge by proposing a nested kino-dynamic framework for rapid feasibility checking and dynamically consistent trajectory generation given a candidate contact sequence. By integrating this module with a feasibility-guided tree search and a Large Language Model (LLM)-based contact plan sampling strategy, we demonstrate that the proposed framework can substantially improve the search process. Furthermore, we show that the generated trajectories can be tracked using a reinforcement learning (RL)-based controller and show that the resulting trajectories are of sufficiently high quality for execution in real-world loco-manipulation scenarios. ## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：建立一套**渐进式、分层次的可行性检查**，由简单到复杂依次筛选候选接触模式序列，尽早剪枝掉不可行的候选，避免昂贵的完整轨迹优化计算。通过缓存已检查的模式/边结果，进一步减少冗余计算。
- **关键技术细节**：
    1.  **统一接触显式优化框架**：定义一个接触模式序列 \( C = (c_0, ..., c_{K-1}) \)，每个模式 \( c \) 是所有接触界面（机器人脚、手、物体、环境）的接触状态分配。
    2.  **三级可行性检查**（由便宜到昂贵）：
        - **模式/边优化 (Mode/Edge Optimization)**：求解一个逆运动学问题，检验单个模式或两模式间过渡的静态几何可行性（接触、碰撞、关节限位）。使用 Ipopt 求解。
        - **运动学序列优化 (Kinematic Sequence Optimization, KSO)**：对给定序列，求解一系列配置（每过渡一个配置），检验整个序列的几何一致性，包括相邻模式间的接触驻留/释放约束。使用 acados SQP 求解。KSO 比 TO 快约两个数量级，且覆盖约70%的 TO 约束类型。
        - **完整轨迹优化 (Trajectory Optimization, TO)**：在全程离散化轨迹上施加完整动力学（浮动基动力学、质心动量、物体动力学）、接触、碰撞、力矩/速度限幅。使用 Hippo SQP 求解。
    3.  **可行性引导的树搜索 (Feasibility-Guided Tree Search)**：在 UCT 搜索框架内，使用上述三种检查（或子集）作为过滤器。搜索中动态维护可行性缓存 \( K_{feas}, K_{infeas} \)，避免重复求解。
    4.  **LLM 接触计划采样**：利用 GPT-5.5 根据场景和目标生成多样化的接触计划，再由 KSO 快速筛选，过滤掉不可行的序列，再提交给 TO。
    5.  **执行**：生成的轨迹通过一个预训练的 RL 跟踪控制器 [19] 在真实人形机器人上执行。
