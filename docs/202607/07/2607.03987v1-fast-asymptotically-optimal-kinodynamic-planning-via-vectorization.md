## 摘要
基于采样的运动规划器已被证明对于具有复杂运动学约束和高维度的系统是有效的。然而，这些算法难以实现实时性能，导致最近有工作尝试并行化规划。尽管GPU加速规划器已实现显著加速，现有方法需要专门的CUDA编程，限制了可访问性和可移植性。我们提出了并行渐近最优运动学RRT（PAKR），这是一个大规模并行运动学规划器，利用JAX和XLA编译器通过标准Python工具实现GPU加速。通过将我们的并行规划器与AO-x元算法结合，我们通过快速迭代重规划实现了渐近最优性。我们提供了概率完备性的理论分析，分析了批大小和分支因子对收敛的影响，并使用MuJoCo-XLA模拟器展示了对复杂动力学的可扩展性。实验表明，其运行时间与最先进的GPU规划器相当，且解质量更优。

## Abstract
Sampling-based motion planners have been shown to be effective for systems with complex kinodynamic constraints and high dimensionality. However, these algorithms struggle to achieve real-time performance, leading to recent efforts to parallelize planning. While GPU-accelerated planners have achieved significant speedups, existing approaches require specialized CUDA programming that limits accessibility and portability. We present Parallel Asymptotically Optimal Kinodynamic RRT (PAKR), a massively parallel kinodynamic planner leveraging JAX and the XLA compiler to achieve GPU acceleration through standard Python tooling. By combining our parallel planner with the AO-x meta-algorithm, we achieve asymptotic optimality through fast iterative replanning. We provide a theoretical analysis of probabilistic completeness, analyze the effects of batch size and branching factor on convergence, and demonstrate scalability to complex dynamics using the MuJoCo-XLA simulator. Experiments show competitive runtimes with state-of-the-art GPU planners and superior solution quality.

## 1. 核心问题与整体含义（研究动机和背景）
- **研究动机**：采样运动规划器（SBMP）虽能处理高维状态空间和复杂非线性动力学，但计算耗时严重（简单系统需数百毫秒，复杂系统需数十秒），难以满足动态环境中实时反应性要求。
- **背景瓶颈**：
  - GPU加速方法（如Kino-PAX）依赖CUDA编程，限制了可访问性和可移植性。
  - 现有并行规划器在追求渐近最优性时面临“信息陈旧”问题——由于并行批处理中节点间缺乏全局可见性，后续插入可能基于次优父节点，导致冗余探索和收敛困难。
  - AO算法（如RRT*、SST*）依赖严格顺序性（重连、最佳代价节点维护），与并行化天然冲突。

## 2. 方法论：核心思想、关键技术细节、算法流程
- **核心思想**：利用AO-x元算法将任意概率完备的规划器转化为渐近最优规划器，其迭代重规划范式天然适合并行化。不是对抗信息陈旧，而是拥抱快速次优规划，通过快速重规划收敛到最优。
- **关键技术细节**：
  - **并行RRT内循环**：
    - 每轮迭代并行采样B/A个目标状态，通过最近邻查询选择父节点，每个父节点采样A个随机控制，并行执行B次前向传播（rollout），检查碰撞和代价约束。
    - 只有满足`g(n) + h(n) < c_best`（f-代价低于当前最优解代价）的节点才被插入树中，其中`h(n)`为欧几里得启发式距离。
  - **静态图架构与JAX/XLA编译**：
    - 整个规划循环融合为单个GPU内核，消除CPU-GPU传输开销。
    - 编译时需固定最大树大小N和批大小B，树使用结构体数组（状态、控制、父索引、代价）表示，通过索引切片实现批量写入。
    - 采用分层最近邻策略：按树大小分阶段（4^[6,10]），每个阶段有专用内核处理活跃部分。
  - **分支因子A**：选择K=B/A个父节点，每个父节点采样A个控制，可减少NN搜索开销（NN是瓶颈）。
  - **模块化传播器**：支持任意动力学（通过MuJoCo-XLA差分模拟器），使用四阶龙格-库塔积分，全程向量化。
- **算法流程（文字说明）**：
  - 外层AO-x循环：反复重启规划器，每次使用更紧的代价界限`c_best`（初始无穷大，每次找到解后更新）。
  - 内层并行RRT：每批并行采样、传播、代价剪枝、插入；当某一节点到达目标区域时，记录解并跳出内循环。
