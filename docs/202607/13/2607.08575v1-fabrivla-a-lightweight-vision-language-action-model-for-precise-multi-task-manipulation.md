## 摘要
我们提出了FabriVLA，一种用于精确多任务操作的轻量级视觉-语言-动作模型。FabriVLA将InternVL3.5视觉-语言骨干网络与流匹配动作头相结合，该动作头具有跨动作令牌的门控自注意力机制，并通过浅层VLM层融合以丰富空间上下文。该模型通过单阶段联合优化进行训练，从预训练的VLM和随机初始化的动作头开始。在涵盖50种不同操作任务的Meta-World MT50基准测试中，FabriVLA的平均层级成功率达到90.0%，这表明基于1B规模VLM构建的紧凑型VLA无需依赖数十亿参数的VLA骨干网络即可实现强劲性能。

## Abstract
We present FabriVLA, a lightweight Vision-Language-Action model for Precise Multi-Task Manipulation. FabriVLA combines an InternVL3.5 vision-language backbone with a flow-matching action head featuring gated self-attention across action tokens and shallow VLM layer fusion for enriched spatial context. The model is trained via single stage joint optimization from a pretrained VLM and randomly initialized action head. On the Meta-World MT50 benchmark spanning 50 diverse manipulation tasks, FabriVLA achieves a tier-average success rate of 90.0%, demonstrating that a compact VLA built on a 1B scale VLM can achieve strong performance without relying on multi billion parameter VLA backbones.

# 2. 方法论：核心思想、关键技术细节

## 2.1 核心思想
- 采用**InternVL3.5-1B**作为视觉-语言骨干（保留14层），搭配**流匹配动作头**，并引入**门控自注意力**和**浅层VLM层融合**以增强时序依赖和空间上下文。
- 整个模型通过**单阶段联合训练**（VLM骨干和动作头同时优化）从预训练VLM和随机初始化的动作头开始。

## 2.2 关键技术细节

### 门控自注意力（Gated Self-Attention）
- 在每个Transformer Block中，对动作令牌序列（50步）施加自注意力，但使用一个**可学习门控参数g**（初始化为0）。
- 初始化时门控关闭，行为等价于仅交叉注意力的Transformer；训练过程中门控逐渐打开，使模型学习跨动作步骤的依赖关系。
- 公式：\( A' = A + g \cdot \text{SelfAttn}(\text{LayerNorm}(A)) \)

### 浅层VLM层融合（Shallow Layer Fusion）
- 除了使用VLM最后一层（layer 14, 语义信息）外，额外提取中间层（layer 6, 空间细节）特征。
- 将深层和浅层令牌序列沿特征维度拼接，并通过一个可学习的线性投影（初始化为[I|0]）降回1024维，确保初始化时等同于仅使用深层。
- 该融合使动作头同时获得语义理解和空间定位能力，特别有利于精确操作。

### 流匹配训练（Flow Matching Training）
- 动作生成采用流匹配框架：从均匀噪声 \(\epsilon \sim U([-1,1]^{50\times24})\) 到真实动作 \(a\) 的线性插值 \(x_t = (1-t)\epsilon + t a\)。
- 时间 \(t\) 服从 Beta(2,2) 分布，使训练样本集中于中间阶段（t≈0.5），避免边界过于简单。
- 模型预测速度场 \(v_\theta(x_t,t|\cdot)\)，损失为 \(\|v_\theta - (a-\epsilon)\|^2\)。
- 推理时从均匀噪声出发，通过欧拉积分（50步）得到最终动作块。

### 状态与动作编码
- 机器人状态 \(s \in \mathbb{R}^{24}\)（含末端执行器位姿、夹爪状态、物体位置）通过两层MLP编码为状态令牌（1024维）。
- 噪声动作 \(x_t\) 通过共享MLP逐步骤投影，并添加位置编码，得到动作令牌序列。

### 动作头模块
- 堆叠8个FabriVLA TransformerBlock，每个包含：门控自注意力 → 交叉注意力到上下文 → 前馈网络（带时间嵌入）。
- 最终输出经LayerNorm、序列池化、两层MLP解码为速度场 \(v \in \mathbb{R}^{50\times24}\)。

# 7. 优点

1. **轻量高效**：仅0.89B参数，远小于π0（3.5B）、RoboTron-Mani（4B）等，但取得更优性能，便于实际部署。
2. **架构创新**：门控自注意力提供平滑的优化路径（零初始化），避免训练初期破坏预训练知识；浅层融合以极小参数（2.1M）显著提升空间精度。
3. **单阶段训练**：无需分阶段冻结或微调，简化流程，同时保留VLM的语义对齐能力。
4. **实验设计严谨**：消融实验中所有模块采用零初始化，保证初始状态一致；控制变量（如冻结VLM）使对比纯粹；按任务需求和精度子集进行多维度分析，揭示模型特性。
5. **可复现性**：使用了公开数据集（Evo-1 Meta-World）和开源VLM（InternVL3.5），训练配置详细，有利于后续研究。

# 8. 不足与局限

1. **仅模拟环境**：所有实验在Meta-World模拟环境中进行，未在真实机器人上验证。模拟与真实之间存在差距（Sim-to-Real），模型在实际物理环境中的泛化能力未知。
