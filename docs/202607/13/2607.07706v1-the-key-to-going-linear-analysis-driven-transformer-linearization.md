## 摘要
因果自注意力的二次复杂度严重限制了长上下文Transformer的推理。尽管存在多种事后线性化管线，但难以确定哪些组件能保持模型质量。本文在严格的冻结主干框架下隔离了状态更新设计的影响。我们展示了softmax依赖于键相关的秩1正交投影，阐明了为什么delta式网络优于纯门控累积。我们识别了近似误差的一个潜在来源，并引入了结构性的干预措施，具体包括sink token、短卷积和固定预算缓存路由，从而缩小了剩余差距。我们将这种线性化方法扩展到LLaMA和Qwen模型，参数量高达32B，在MMLU上优于先前的事后基线，并匹配了复杂自适应缓存框架的长上下文检索性能。

## Abstract
The quadratic cost of causal self-attention severely bottlenecks long-context transformer inference. While numerous post hoc linearization pipelines exist, it is difficult to identify which components preserve model quality. This work isolates the effect of state update design in a strict frozen-backbone regime. We show that softmax relies on key-dependent, rank-1 orthogonal projections, elucidating why delta-style networks outperform purely gated accumulation. We identify a potential source of approximation errors and introduce structural interventions, specifically sink tokens, short convolutions, and fixed-budget cache routing, which reduces the remaining gap. We scale this linearization approach across LLaMA and Qwen models up to 32B parameters, outperforming prior post hoc baselines on MMLU and matching the long-context retrieval of complex adaptive-caching frameworks.

## 1. 核心问题与整体含义（研究动机与背景）

因果自注意力的计算复杂度随序列长度呈二次增长，严重制约了预训练 Transformer 在长上下文场景下的推理效率。事后线性化（post hoc linearization）是一种极具吸引力的解决方案，它可以在不从头预训练的前提下将现有全注意力模型转换为线性时间架构。然而，现有方法往往同时叠加多种干预（低秩适配、滑窗注意力、混合路由、蒸馏等），使得一个根本问题被掩盖：**哪种线性状态更新规则最能近似预训练的 softmax 注意力？** 本文旨在通过严格冻结骨干网络的分析驱动方法，隔离研究不同线性注意力替换机制的近似能力。

## 2. 方法论：核心思想、关键技术细节与理论分析

### 2.1 理论分析：连接 Softmax 与 Delta 规则
- **一阶泰勒展开近似**：对 softmax 权重在零向量处做一阶展开，得到  
  \( p_i(x) \approx \frac{1}{t} + \frac{1}{t}(q^\top (k_i - \bar{k})) \)，其中 \(\bar{k}\) 为平均键。
- **投影近似**：将 \(k_i - \bar{k}\) 替换为 \((I - \Pi_{\bar{k}})k_i\)（正交于平均键方向的投影），引入可控误差。
- **秩1乘积近似**：将 delta 规则中的累乘矩阵 \(M_t = \prod_{j=1}^t (I - \beta_j k_j k_j^\top)\) 近似为 \(I - c\Pi_{\bar{k}}\)，证明当键向量集中在平均方向附近时成立。
- **结论**：Delta 更新（如 Gated Delta Network, GDN）天然实现了 softmax 所隐含的**关键依赖的秩1正交投影校正**，而纯门控累积（如 Gated Linear Attention, GLA）仅依靠与键无关的衰减，缺少这一几何修正。

### 2.2 线性替换机制
论文对比四类线性注意力（图1）：
- **Hedgehog**：基于核函数特征映射的归一化线性注意力。
- **GLA**：输入依赖的对角门控（纯累积，无键依赖投影）。
- **kGLA**（本文提出）：在 GLA 中引入键相关的门控对角近似 \(Diag(k_j \odot k_j)\)，保持硬件效率。
- **GDN**：带 delta 规则的更新，使用秩1算子 \(I - \beta_j k_j k_j^\top\)。

所有原始 Q/K/V 投影和 RMSNorm 参数冻结，仅训练新引入的参数（门控、beta、特征映射等）。

### 2.3 结构干预
基于理论识别出的近似误差来源（序列早期 token 偏差大、键集中度低），引入三种结构干预：
- **滑窗注意力（SWA）**：固定预算 64 token，其中 8 个 sink token（序列开头的关键 token）+ 56 个局部窗口 token。
- **Sink Token**：将最前面的 token 纳入精确注意力计算，缓解线性机制对前缀的近似困难。
- **短卷积 / LoRA**：对 Q/K/V 投影进行小参数适应（短卷积或低秩适配），增加表示能力。

最终的输出形式：  
\( y_t = q_t S_{s:t-w} + y_t^{\text{swa}} \)，其中第一个项来自线性路径（从 sink 到窗口起点），第二个项来自滑窗注意力。

## 6. 主要结论与发现
1. **GDN（Delta 机制）在冻结骨干下始终优于 GLA 和 Hedgehog**，与理论分析一致：delta 规则能捕捉 softmax 的秩1投影校正。
2. **Sink Token 显著提升性能**：在 64 固定缓存预算中分配 8 个 sink token 比纯滑窗窗口效果好，尤其在 Lambada 等上下文依赖任务上。
3. **短卷积几乎消除了 GLA 与 GDN 之间的差距**，表明足够的表示能力可以补偿机制差异。
4. **最终方案（GDN + SWA + sink + 短卷积）匹配甚至超越现有事后线性化基线**：在 MMLU 上达到 59.17%（Llama3.1-8B），优于 LoLCaTs（54.88%）和 Liger-GLA（46.9%）；长上下文上匹配 STILL 等复杂缓存框架。
5. **线性化性能随模型规模一致扩展**：在 Qwen 系列 0.6B～32B 上，线性化模型与全注意力模型的差距保持稳定（common reasoning 约 1-2%，MMLU 约 5-6%）。
6. **混合模型**：保留少量全注意力层（20%）即可大幅缩小差距，且**基于“困难度”信号选择保留层**（键集中度、投影残差）优于均匀选择。

## 7. 优点
- **分析驱动**：从一阶泰勒展开推导出 delta 规则与 softmax 的联系，为线性化设计提供了理论依据，而非仅凭经验。
- **严格隔离变量**：采用“冻结骨干”设置，仅训练新参数，能干净地评估各机制的近似能力。
- **可控的组件添加**：逐步引入 SWA、sink、短卷积，并量化每个组件的贡献，工程实践指导性强。
- **可扩展性好**：在最大 32B 模型上验证，且跨系列（LLaMA、Qwen）均有效。
- **长上下文匹配强基线**：尽管使用简单的固定预算缓存，仍能与采用复杂自适应缓存的 STILL、LoLA 等竞争。

## 8. 不足与局限
- **理论假设的局限**：一阶近似依赖于键向量集中等假设，在极端情况下（如层间差异大、极短前缀）可能不成立，文中也承认这一点。
- **训练量偏小**：仅 10M tokens 训练（约 0.01B），而多数对比基线使用 40M～12B tokens，因此结论可能低估了某些干预（尤其是 LoRA、Hedgehog）在更大训练量下的表现。
- **长上下文能力待验证**：仅在 4K 上下文下评测长检索，未测试 32K 以上。且在多查询/多值检索等复杂任务上仍明显弱于自适应缓存方法（如 STILL）。
- **缓存策略简单**：采用固定预算 sink + 滑窗，未集成内容感知的 token 选择（如 LoLA 的基于查询的稀疏缓存），这可能限制了长上下文性能的上限。

- **硬件依赖性**：Hedgehog 因缺乏高效 Triton 实现导致训练慢 8 倍，这属于工程实现问题，并非理论缺陷，但影响实验公平性。
- **LoRA 学习率下调**（2e-3 → 5e-4）可能导致其结果未达到最佳，文中也提到“可以受益于更长训练”，因此 LoRA 与短卷积的比较不够公平。
