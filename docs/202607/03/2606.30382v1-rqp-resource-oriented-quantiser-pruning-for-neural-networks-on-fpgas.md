## 摘要
高粒度量化（HGQ）利用权重级量化和剪枝来设计资源高效的神经网络加速器，在准确性与硬件利用率之间实现了有吸引力的权衡。HGQ特别适用于基于FPGA的边缘神经网络应用。标准的HGQ工作流从高精度模型开始，在基于梯度的优化指导下逐步减少位宽，以勾勒出帕累托前沿。这种单调且不可逆的剪枝过程计算密集，且可能忽略给定资源级别下的最优子网络。我们提出了一种面向资源的一次性量化器剪枝方法，直接将网络接近目标搜索空间，然后使用双向beta调度进行微调，以实现对帕累托前沿更精细的扫描。在喷注子结构分类（JSC）任务上验证，我们的方法相比标准HGQ工作流中的单调资源减少，将搜索成本降低了最多20.58倍，同时获得了具有竞争力的帕累托前沿和最终网络配置。

## Abstract
High granularity quantisation (HGQ) exploits weight-level quantisation and pruning to design resource-efficient neural network accelerators, achieving an attractive trade-off between accuracy and hardware utilisation. HGQ is particularly well suited to FPGA-based edge neural network applications. Standard HGQ workflow starts from a high-precision model and progressively reduces bit width, guided by gradient-based optimisation to outline the Pareto frontier. This monotonic and irreversible pruning process is computationally intensive and can overlook the optimal subnetwork for a given resource level. We propose a resource-oriented one-shot quantiser pruning method that brings the network directly close to the target search space, and then use bidirectional beta scheduling for fine-tuning to enable a more refined scan of the Pareto frontier. Validated on the jet substructure classification, JSC, task, our method reduces the search cost by up to 20.58x compared with monotonic resource reduction in standard HGQ workflows, while achieving a competitive Pareto frontier and final network configuration.

# RQP: Resource-Oriented Quantiser Pruning for Neural Networks on FPGAs 论文详细总结

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：FPGA 上的超低延迟神经网络加速器（如高能物理、量子电路控制、高频交易）需在严格资源约束下实现高精度推理。高粒度量化（High Granularity Quantisation, HGQ）通过 **权重级可微位宽优化** 统一量化与剪枝，可自动搜索精度-资源的帕累托前沿。但标准 HGQ 工作流采用 **单调资源递减**（从高精度模型逐步增加资源惩罚系数 β 迫使模型压缩），该过程计算密集（需数万至数十万训练 epoch），且受路径依赖影响，一旦连接被过早压至低位宽或剪除，梯度路径受限，可能错过给定资源预算下的最优子网络。

- **核心问题**：如何 **高效** 地将预训练高精度 HGQ 模型直接导向目标资源预算附近，并在该区域 **精细探索** 出更优的帕累托前沿点，同时避免搜索浪费和路径锁定。

- **整体含义**：本文提出的 **RQP（Resource-Oriented Quantiser Pruning）** 方法，用 **一次性量化器剪枝** + **双向 β 调度** 替代了 HGQ 的长时间单调压缩，显著降低了搜索成本（最高 20.58×），同时保持或提升了最终精度，为 FPGA 上的神经网络加速器设计提供了更实用的训练范式。

## 2. 方法论：核心思想、关键技术细节

RQP 建立在 HGQ 的框架之上，使用相同的 EBOPs（有效比特操作数）资源代理和联合损失函数：

\[
L = L_{\text{base}} + \beta \cdot \text{EBOPs} + \gamma \cdot \sum \text{bit-widths}
\]

### 2.1 一次性量化器剪枝（One-shot Quantiser Pruning）

直接从预训练的高资源模型出发，通过两个步骤将网络投影到目标预算 \(E^*\) 附近：

1. **目标预算位宽重分配（Algorithm 1）**：
   - 计算全局收缩比 \(\alpha = E^* / E_{\text{cur}}\)。
   - 根据各层平均位宽计算层缩放因子 \(\alpha_l = \alpha \cdot r_l / \bar{r}\)，并按层缩放、裁剪到有效范围，得到初始位宽矩阵 \(B^{(0)}_l\)。
2. **谱约束拓扑补偿**：
   - 基于权重幅度和重分配位宽计算结构分数 \(S_l = |W_l| \odot B^{(0)}_l\)，选出最高分连接构成初始二元掩码 \(M_l\)。
   - **条件数约束**：若保留的活跃矩阵违反条件数上限 \(\kappa(W_l \odot M_l) \le \tau_l\)（\(\tau_l = 3\kappa(W_l^{\text{pre}})\)），则通过贪婪替换低分连接为高分候选，直至满足条件。此步骤确保剪枝后子网络信号/梯度路径稳定，提升可训练性。
   - 最后通过全局标量 \(\lambda^*\) 调整所有活跃位宽，使总 EBOPs 精确匹配目标 \(E^*\)。

**关键点**：与常规二进制掩码剪枝不同，RQP 在 **连续位宽空间** 中操作，且显式优化资源代理而非直接稀疏权重，因此能更精确地命中目标资源。

### 2.2 双向 β 调度（Bidirectional β Scheduling, Algorithm 2）

用于在目标预算附近进行精细化微调，避免单调压缩导致的 β 死锁（低精度连接难以重新激活）：

- **内环（预算追踪）**：每 epoch 测量当前模型 EBOPs \(E^{\text{obs}}_t\)，若高于目标则增大 β（\(\beta \leftarrow \beta \sqrt{E^{\text{obs}}_t / E^*} \text{ capped}\)），使资源压力回推；若低于目标则减小 β，使资源放松。调整强度随偏离程度自适应。
- **外环（β 松弛）**：当验证指标连续 S 个 epoch 停滞时，将 β 线性向 \(\beta_{\text{lo}}\) 松弛（\(\beta \leftarrow \beta_{\text{lo}} + \frac{t}{T}(\beta - \beta_{\text{lo}})\)），释放压缩压力，允许子网络重新打开连接。后续内环再将其推回目标预算。此机制模拟退火，早期松弛搜索更大邻域，后期精细微调。

**效果**：缓解了 HGQ 单调压缩中因 β 长期维持高强度而锁死子网络的问题，使得在同预算下能发现更好精度点。

## 3. 实验设计

### 3.1 数据集与任务
- **任务**：5 类冲激子结构分类（Jet Substructure Classification, JSC）。

- **网络架构**：全连接网络，3 个隐层，层配置 16-64-32-32-5（输入 16 特征，输出 5 类）。

### 3.2 基准与对比方法
- **主基线**：标准 HGQ 渐进训练（monotonic resource reduction），采用递增 β 调度（\(5\times10^{-7} \to 10^{-3}\)），训练 epoch 设为 6k、20k、100k、200k。
- **一次性剪枝对比**：将 RQP 的一次性剪枝步骤替换为五种经典一次性剪枝方法（SNIP, Random, Reallocation, Magnitude, GraSP），这些方法生成二元剪枝掩码后映射到量化器位宽上进行后续微调，作为对比。
- **消融**：Reallocation（仅位权重分配不含谱约束）用于验证谱约束贡献。
- **硬件实现对比**：与 PolyLUT, NeuraLUT, LogicNets, ReducedLUT, QKeras, AmigoLUT 等先前报告的 FPGA 加速器结果对比。

## 7. 优点

- **方法创新性**：将一次性剪枝从离散掩码扩展到连续位宽空间，并集成谱约束，直接优化资源代理而非稀疏性，具有更好的目标匹配能力。
- **效率突破**：显著减少了达到部署级精度所需的训练成本（20× 以上），对实际应用中的快速迭代设计非常有价值。

- **实验完整性较好**：不仅报告了训练阶段数据，还进行了实际 FPGA 综合验证，提供了硬件实现性能（延迟、频率、资源），增强了说服力。

## 8. 不足与局限

1. **架构和任务覆盖有限**：仅在 JSC 任务的全连接网络上验证，未涉及 CNN、Transformer 等更复杂架构，通用性待验证。
2. **单种子评估**：所有结果使用单一随机种子（1998），缺乏多种子统计量（均值、方差），可能存在偶然性偏差。
3. **超参数敏感性未充分讨论**：双向 β 调度中的初始 β₀、上限 β_hi、下限 β_lo、停滞窗口 S 等超参数需要人工设定，文中未分析其敏感度。
4. **训练开销不透明**：虽然总 epoch 数少，但一次性剪枝步骤本身有额外计算（奇异值分解、贪婪替换），文中未量化该部分时间占比。
5. **对比基线有限**：与 HGQ 比较时，仅与单调 β 调度版本比较（虽然 HGQ 论文也使用类似），但未与更先进的 β 控制策略（如 PID 控制，见引用[18]）对比。

7. **应用场景受限**：针对的是 FPGA 超低延迟推理场景，对于其他硬件平台（GPU、ASIC）或高吞吐场景的适用性未探讨。
