## 摘要
引入了一种基于MinHash的相似性调度框架，为基于LLM的神经架构搜索（NAS）构建了针对神经架构代码的渐进式课程。利用128排列MinHash签名对归一化的7-gram源代码碎片进行处理，将参考池划分为相似度带，并按架构异质性递增的顺序呈现，每个阶段的最佳LoRA适配器累积合并到主干网络中。我们在LEMUR基准测试中，针对CIFAR-10图像分类任务，使用OlympicCoder-7B对该框架进行了评估，在六次渐进式微调步骤中每轮生成N=15个候选架构。该课程在高相似度水平上达到了60%的峰值成功率，无需后处理修复。在最多样化水平课程与基础模型的2x2消融实验（有无部分接口修复）中，发现无修复情况下基础模型（峰值SR 47%）显著优于课程模型（SR 7%），而添加部分修复后两者均达到53% SR。这种模式与合并层面的权重漂移逐渐擦除评估器接口先验的现象一致，表明接口修复和课程调度针对不同的失败模式。我们进一步在SVHN上报告了跨数据集迁移的观察结果，直接使用未经过课程预热的基础模型生成的峰值成功率为27%，准确率（60.5%）显著低于CIFAR-10上的对应结果，这与unq家族锚定架构的合成难度增加一致。

## Abstract
Introduce a MinHash-based similarity scheduling framework that constructs a progressive curriculum over neural architecture code for LLM-based neural architecture search (NAS). Using 128-permutation MinHash signatures over normalised 7-gram source code shingles, we partition the reference pool into similarity bands and present them in increasing architectural heterogeneity, with the best LoRA adapter from each stage merged cumulatively into the backbone. We evaluate the framework on OlympicCoder-7B within the LEMUR benchmark on CIFAR-10 image classification, generating N =15 candidate architectures per epoch across six progressive fine-tuning steps. The curriculum achieves 60% peak success rate at the high-similarity level without post-processing repair. A 2*2 ablation at the most diverse level curriculum versus base model, with versus without partial interface repair reveals that without repair the base model (47% peak SR) substantially outperforms the curriculum model (7% SR), while adding partial repair brings both to 53% SR. This pattern is consistent with merge-level weight drift progressively erasing evaluator-interface priors, and suggests that interface repair and curriculum scheduling target distinct failure modes. We further report a cross-dataset transfer observation on SVHN, where direct base-model generation without curriculum warmup yields 27% peak SR at substantially lower accuracy (60.5%) than the CIFAR-10 equivalent, consistent with the increased synthesis difficulty of the unq-family anchor architecture.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：LLM 已应用于神经架构搜索（NAS），将架构设计转化为程序合成问题（如 NNGPT、LEMUR）。现有的 LLM-based NAS 管道在微调阶段，通常将参考架构库视为无序集合，直接暴露所有结构差异给模型，可能导致代码先验不稳定，影响生成评估器兼容设计的可靠性。
- **核心问题**：如何根据架构代码的结构相似性，对参考库进行排序（课程设计），以提升 LLM 生成可靠候选架构的成功率和性能。
- **动机**：神经架构代码不仅在准确率上不同，还在模块组合、参数路由、残差连接、张量形状约束等方面存在差异。无序训练可能破坏 LLM 对评估器接口（如 `supported_hyperparameters`、`train_setup`）的内部化先验。

## 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

### 2.1 核心思想

- 使用 **MinHash** 近似 Jaccard 相似度，衡量两个架构代码的 7-gram 碎片重叠程度。
- 基于相似度将参考库划分为三个递增异质性的**相似度带**（高、中、低/极低），按顺序呈现给 LLM 进行渐进式微调。
- 每阶段选择最佳 LoRA 适配器，**累积合并**到主干模型，以保持各阶段学到的编码约定。

### 2.2 关键技术细节

- **MinHash 签名计算**：对源代码按正则分词后构建 7-gram shingles，用 128 个排列哈希函数计算签名，每个签名 512B（BLOB 存储）。使用 SQLite 标量 UDF `jaccard_blobs` 在数据库内直接计算相似度，避免 Python 端构造倒排索引。
- **相似度带划分**：
  - L1 高相似度：J ∈ [0.95, 0.98)
  - L2 中相似度：J ∈ [0.85, 0.95)
  - L3 低/极低相似度：J ∈ [0.30, 0.85)（合并了两个原始低带）
- **锚点选择**：自动选择最高准确率且在三个带宽均有足够邻居的架构（`rl-bb-init-9afa16ef`）。
- **提示设计**：每个级别调整约束（L1 强调模块脚手架，L2 增加骨干使用限制，L3 增加维度推断约束）。
- **顺序适配器合并**：每阶段选最佳 epoch 的 LoRA 适配器，解量化→合并（`W_merged = W_base + ΔW`）→重新量化（NF4），最小化量化误差累积。

### 2.3 算法流程

1. 预处理：对所有架构代码计算 MinHash 签名并存入数据库。
2. 课程阶段 t：
   - 对当前锚点，运行 SQL 查询取回 J 在指定范围内的 k 个最近邻。
   - 构建包含锚点和近邻的提示。
   - LLM 生成 N=15 个候选架构，提交给 LEMUR 评估器。
   - 评估器筛选有效生成，计算复合分数 S = (|V|/N)×max_accuracy。
   - 选择最佳 epoch，训练 LoRA 适配器 Δt。
   - 合并 Δt 到主干，进入下一阶段。

## 6. 论文的主要结论与发现

1. **课程有效性（高相似度）**：L1 无需修复达到 **60% 峰值成功率**（SR），均 SR 40%，准确率 96.3%。
2. **课程与接口修复的交互**：L3（最低相似度）无修复时，课程模型仅 7% SR，而基础模型（无课程微调）达 47% SR；加入部分修复后两者均提升至 53% SR。表明**权重漂移（merge-level drift）会擦除评估器接口先验**，课程调度和接口修复针对不同失败模式。
3. **结构新颖性不牺牲性能**：随着课程推进，生成模型与锚点的 Jaccard 相似度从 L1 的 0.513 降至 L3 的 0.236-0.266，但准确率维持在 93-95%，说明课程驱动真实架构发散而非复制。
4. **随机排序**：随机排序能达到与课程相近的峰值性能，但**步内波动更大**（包括完整失效 epoch），说明课程主要提升训练稳定性。
5. **跨数据集困难**：SVHN 上直接生成仅 27% SR，准确率 60.5%，显著低于 CIFAR-10 等效设置，表明 `unq` 架构族是更难的合成目标。

## 7. 优点

- **新颖的课程设计**：首次将代码级结构相似度（MinHash）引入 LLM-based NAS 的微调顺序控制，方法简洁、可解释性强（相似度带宽具有结构意义）。
- **低开销实现**：MinHash 签名预处理一次，查询时全在 SQLite UDF 内完成，无需 Python 侧索引构造，实现亚秒级检索。
- **渐进式适配器合并**：通过累计合并 LoRA 保留各阶段学到的编码约定，思考了权重漂移问题。
- **揭示了接口修复与课程互补的失败模式**：2×2 消融设计清晰展示了不同修复条件对结果的影响。
- **跨数据集初步探索**：虽仅一个额外数据集，但指出了迁移困难和新的研究问题。
