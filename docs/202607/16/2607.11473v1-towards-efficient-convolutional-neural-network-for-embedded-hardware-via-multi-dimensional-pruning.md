## 摘要
本文提出TECO，一种多维剪枝框架，通过协同剪枝卷积神经网络（CNN）的三个维度（深度、宽度和分辨率）来提升在嵌入式硬件上的执行效率。在TECO中，我们首先引入一个两阶段重要性评估框架，该框架根据每个维度内部的局部重要性和跨维度的全局重要性，高效且全面地评估每个剪枝单元。基于该评估框架，我们提出一种启发式剪枝算法，逐步剪枝CNN的三个维度，以在准确性和效率之间取得最优权衡。多个基准实验验证了TECO相较于现有最先进方法的优势。代码与预训练模型可在https://github.com/ntuliuteam/Teco获取。

## Abstract
In this paper, we propose TECO, a multi-dimensional pruning framework to collaboratively prune the three dimensions (depth, width, and resolution) of convolutional neural networks (CNNs) for better execution efficiency on embedded hardware. In TECO, we first introduce a two-stage importance evaluation framework, which efficiently and comprehensively evaluates each pruning unit according to both the local importance inside each dimension and the global importance across different dimensions. Based on the evaluation framework, we present a heuristic pruning algorithm to progressively prune the three dimensions of CNNs towards the optimal trade-off between accuracy and efficiency. Experiments on multiple benchmarks validate the advantages of TECO over existing state-of-the-art (SOTA) approaches. The code and pre-trained models are available at https://github.com/ntuliuteam/Teco.

### **2. 论文提出的方法论**

- **核心思想**：提出一个名为 **TECO (Towards Efficient COnvolutional neural network)** 的多维剪枝框架。其核心是一个**两阶段重要性评估机制**，用于高效且公平地比较和选择不同维度（深度、宽度、分辨率）中的冗余单元进行剪枝。在此基础上，通过一个启发式算法逐步迭代地移除冗余单元。

- **关键技术细节**：
    1.  **两阶段评估框架**：
        - **第一阶段：内维重要性评估 (INTS， Inner-dimensional Evaluation Strategy)**。该阶段目标是在每个维度内部快速找出“最不重要”的候选单元。
            - **宽度与深度**：通过向网络中插入可学习的门控机制（通道门 `CG` 和层门 `LG`），构建“全门控残差瓶颈块”。剪枝单元的“局部重要性”通过其对应门在反向传播中的梯度平方来近似（公式7和8）。只需一次反向传播即可计算所有通道和层的局部重要性。
            - **分辨率**：不对单个图像进行重要性评估，而是对所有输入图像进行**统一缩小**（uniformly shrinking）处理，以降低计算开销。
        - **第二阶段：跨维重要性评估 (ITES， Inter-Dimensional Evaluation Strategy)**。该阶段负责公平比较来自不同维度的三个“待定”候选单元（深度/宽度/分辨率），以决定最终剪枝哪一个。
            - **全局重要性指标 `I(u)`**（公式6）：这是一个综合指标，用于量化剪枝一个单元 `u` 带来的“收益与损失”。其计算公式为：
                `I(u) = A(u) / (αM(u) + (1-α)T(u))`
                - **`A(u)`**：**精度损失**。定义为移除该单元后模型交叉熵损失的增加量。
                - **`M(u)`**：**计算量减少**。定义为移除该单元后模型MACs（乘加运算）的减少量。
                - **`T(u)`**：**延迟减少**。通过一个拟合的**线性延迟模型**来估计。该模型认为对于给定维度，延迟与MACs呈线性关系（`ls = as * m + cs`，如图3所示），因此 `T(u) < as * M(u)`。
                - **α**：超参数，用于平衡计算量和延迟优化的重要性（实验中设为0.5）。
            - **决策**：全局重要性 `I(u)` 值越低，意味着剪枝该单元能以最小的精度损失换来最大的效率提升。因此，每次迭代选择全局重要性最低的单元进行剪枝。

    2.  **启发式剪枝算法 (Heuristic Architecture Descent)**：
        - **流程**：该算法模拟“梯度下降”的思想，逐步引导模型架构向最优效率-精度权衡的方向“下降”。
        - **步骤**（如算法1所示）：
            a.  **内维评估**：对当前模型 `N`，使用INTS评估每个维度的局部重要性，选出每个维度内最不重要的候选单元（`d*`, `w*`, `r*`）。
            b.  **跨维评估**：使用ITES计算这三个候选单元的全局重要性 `I(u)`。
            c.  **剪枝**：移除全局重要性最低的那个单元。
            d.  **微调**：对剪枝后的模型进行短时间微调（1个epoch），以恢复部分精度，为下一次迭代准备。
            e.  **重复**：上述步骤迭代进行 `n` 次（根据资源预算决定），直到达到目标。
