## 摘要
我们研究Transformer前馈块架构设计中每个组件如何决定初始化时跨越深度保留的秩。我们将长期被理解为控制量级的跳跃连接和归一化重新解释为跨深度保留梯度秩的机制，因为正是那些使网络具有表达能力的矩阵乘法和非线性激活也会降低秩。我们表明，跳跃连接在秩坍塌与类似集成行为之间进行权衡，受支路和跳跃的相对尺度控制：跳跃连接将梯度绕开残差支路（那里秩会丢失），而不是沿着鼓励层组合的长梯度路径传递。归一化层的位置通过设定跨深度的支路-跳跃比率来控制这一权衡，统一了许多关于归一化位置和深度缩放的文献，特别是解释了为什么后归一化（Post-Norm）会导致秩坍塌，而预归一化（Pre-Norm）则使秩保持稳定。架构的其他方面，例如扩展和收缩宽度的双矩阵结构，使用额外的参数来保留表示或支路雅可比矩阵的秩。第二个矩阵对跨块增长的相干平均尖峰（在使用单一矩阵和非中心化激活时会出现）进行去相关，防止残差表示坍塌。两个矩阵之间的宽度扩展使支路雅可比矩阵保持满秩：在这个扩展空间中应用降秩激活，保留足够多的方向来覆盖原始空间，宽度遵循Marchenko–Pastur定律。输入-输出雅可比矩阵的初始化秩预测了哪些网络可以在CIFAR-10上训练。综上所述，我们将深度网络的架构设计重新定义为在秩坍塌、类似集成行为和参数数量之间的内在权衡。

## Abstract
We investigate how each component of the Transformer feedforward block architecture design determines how much rank survives across depth at initialization. We reinterpret skip connections and normalization, long understood as controlling magnitude, as mechanisms for preserving gradient rank across depth, since the very matrix multiplications and nonlinear activations that make the network expressive also reduce the rank. We show that skip connections trade off rank collapse against ensemble-like behavior, controlled by the relative scales of the branch and the skip: skip connections route the gradient around the residual branch, where rank is lost, rather than along the long gradient paths that encourage the layers to compose. The placement of the normalization layer controls this same tradeoff by setting the branch-to-skip ratio across depth, unifying much of the normalization placement and depth scaling literature, in particular why rank collapses for Post-Norm but plateaus for Pre-Norm. Other aspects of the architecture, like the two-matrix structure that expands and contracts the width, use additional parameters to preserve the representation or branch Jacobian rank. The second matrix decorrelates a coherent mean spike that would grow across blocks with a single matrix and uncentered activation, preventing the residual representation from collapsing. The width expansion between the two matrices keeps the branch Jacobian full rank: applying the rank-reducing activation in this expanded space leaves enough directions to span the original, at a width that follows a Marchenko--Pastur law. The initialization rank of the input--output Jacobian predicts which networks train on CIFAR-10. Taken together, we recast architecture design for deep networks as navigating an intrinsic tradeoff among rank collapse, ensemble-like behavior, and parameter count.

- **研究动机**：现有工作多从**量级控制**（避免梯度爆炸/消失）角度理解跳跃连接（skip connections）和归一化（normalization），但本文发现它们实际上通过**控制秩的保留**来影响深度；同时也发现双矩阵结构（先扩维再缩维）和宽度扩维对秩的独特贡献。最终将架构设计重新阐释为**秩坍塌、类似集成行为（ensemble-like behavior）和参数数量**三者之间的基本权衡。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想
- **秩的三个对象**：输入-输出雅可比矩阵 (∂h_L/∂h_0)、前向残差表示 Z_ℓ、分支雅可比矩阵 J_f。
- **分支-跳转比率（branch-to-skip ratio）**：定义 r_ℓ = ‖βJ_ℓ‖_F / ‖I‖_F，控制梯度有多少流经降秩的分支，多少流经满秩的恒等跳跃。

### 2.2 关键技术细节
- **跳跃连接的角色**：将梯度绕过分支中的秩损失，通过恒等路径恢复秩，形成“锯齿”模式（秩在分支中下降，在跳跃处恢复）。β和初始化尺度α共同决定路径分布：小β/α使梯度主流经短路径（类似集成行为），大β/α使更多梯度流经长路径（鼓励层组合但加速秩坍塌）。
- **归一化放置的影响**：
  - Pre-Norm（当前主流）：归一化放在分支输入，残差流尺度随深度增长（∥h_ℓ∥ ∝ √ℓ），分支-跳转比率按 1/√ℓ 衰减，因此秩趋向平台，但深层网络靠近集成行为。
  - Post-Norm（原始Transformer）：归一化在残差加法后，重新缩放流到单位尺度，分支-跳转比率恒定，秩随深度线性坍塌。
  - 中间结论：归一化中的投影项（移除方向）对秩损失贡献极小（<0.4%），真正原因在于分支-跳转比率随深度的变化模式。
- **双矩阵结构 vs 均值尖峰（Mean Spike）**：
  - 单矩阵 + 非中心化激活（如ReLU）会导致每层分支均值中包含沿全1方向的共同分量（相干性 c_ℓ = E[σ]²/E[σ²]），这些均值跨层对齐，使残差表示产生秩-1尖峰，秩快速坍塌。
  - 第二个矩阵（down-projection）将这一共同分量旋转到与各层独立的随机方向，去相关了均值，阻止尖峰累积。
- **宽度扩维（width expansion）与满秩阈值**：
  - 分支雅可比 J_f = W_down diag(σ′(W_up x)) W_up。激活导数掩码保留比例 p(σ) 的行，有效行数 pm，乘积满秩需要 pm ≥ d，即 m/d ≥ 1/p(σ)（ReLU为2倍，GELU~2.2倍，SiLU~2.6倍）。在此阈值之上，Gram矩阵谱遵循Marchenko–Pastur律，最小特征值从0分离，条件改善。
  - 实验验证：GPT-2 Medium训练后，奇异向量相干性接近Haar基线，证实自由假设基本成立。

### 2.3 公式或算法流程（文字说明）
- 输入-输出雅可比分解为路径和：∂h_L/∂h_0 = Σ_{k=0}^L β^k S_k，其中S_k是通过k个分支的路径和。每个路径权重为 (βα^M)^k（M为分支矩阵数）。路径数量近似L^k/k!，因此范数依赖于 βα^M √L。
- Pre-Norm下，分支-跳转比率 r_ℓ = βα^M / ∥h_ℓ∥，而∥h_ℓ∥^2 ≈ d (1 + κ(βα^M)²ℓ)，因此r_ℓ ∝ 1/√ℓ。
- 后验证：初始秩仅取决于 βα^M √L，等秩轮廓尺度为 1/√L。

## 6. 论文的主要结论与发现

1. **跳跃连接通过绕过分支恢复秩**，但代价是梯度流偏向短路径（集成行为），深层可能堆叠“无效”。分支-跳跃比率决定网络处于秩保留还是集成回归。
2. **归一化放置通过控制该比率随深度的变化决定秩命运**：Pre-Norm让比率衰减，秩保持平台；Post-Norm保持比率恒定，秩坍塌。
3. **第二个矩阵去相关了分支均值跨层相干性**，防止前向表示坍塌到单个方向；若无此结构，需中心化激活或额外归一化。
4. **宽度扩维使分支雅可比满秩**，阈值 m/d = 1/p(σ)（p为激活导数存活率），且条件数随扩维增加而改善，但分支雅可比本身仍可能病态；有效秩随扩维提升。
5. **初始化输入-输出雅可比的有效秩能预测CIFAR-10训练性**：秩降至~2%以下时准确率跌至随机；中等损失则稍降。
6. 深度网络架构设计本质是**秩坍塌、集成行为、参数数量**的三方权衡：跳跃/归一化偏向集成但保留秩（不消耗额外参数），双矩阵/扩维消耗额外参数以保留分支内秩。
